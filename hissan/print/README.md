# クルミせんせいの ひっさん プリント（ひき算のひっ算・くりさがりあり）

ひっ算アプリ「クルミせんせいの どんぐり ぎんこう」（[hissan/](../README.md)）で学んだやり方で練習する、紙のプリントです。
1のくらいを **10 − ひく数 ＋ ひかれる数** で計算し、十のくらいは **1 へらして から ひく** やり方を、スモールステップで練習します。

- プリントを作るページ：`https://zku0395-ops.github.io/hori/hissan/print/`
- できあがった PDF：`hissan/print/pdf/` にあります（じゅんび・れんしゅう・テスト・こたえ・ぜんぶ）
- 用紙は **A4たて**、カラーです。記録はとりません。

## できること

| 項目 | 内容 |
|---|---|
| じゅんび | ①10 − □、②□ ＋ □、③くりさがりの しるし（各1まい） |
| れんしゅう | ステップ1〜6（各20まい、全部で120まい） |
| テスト | テストA（けいさんメモ あり）・テストB（けいさんメモ なし）（各5まい） |
| こたえ | すべてのプリントに、こたえのページがあります（答えは むらさき色） |
| 色 | ひかれる数＝赤、ひく数＝青、10＝緑。アプリと同じ色です |
| 名前 | PDF は名前の欄が空いています（子どもが手で書きます）。作るページで名前を入れると、名前入りで印刷できます |
| 問題 | PDF は決まった問題です。作るページの「べつの もんだいに する」を押すと、新しい問題とこたえを作ります |
| プリントの上 | ステップ名、タイトル、クルミせんせい、がつ にち・なまえ（テストは点数の欄「／100」） |
| プリントの下 | クルミせんせいの合言葉と「できたよ」（シール・スタンプ）の欄。テストにはありません |

## ステージ構成

| プリント | 問題の数 | 子どもがすること |
|---|---|---|
| じゅんび① 10 − □ | 8問 | 10こ入りのどんぐりの絵で、とる数だけ ／ で消し、残りを数えて「10 − 3 ＝ □」に書く |
| じゅんび② □ ＋ □ | 8問 | 残りのどんぐり（みどり）とばらのどんぐり（あか）を合わせた数を書く |
| じゅんび③ くりさがりの しるし | 6問 | 1のくらいが「ひける」か「ひけない」かを○でかこむ。ひけないときは、くりさがりの印（ななめの線・1へった数・10）を書く（6問のうち2問は ひける問題） |
| ステップ1 なぞって おぼえよう | 6問 | すべての数字がうすく出ています。なぞって書きます |
| ステップ2 □に すうじを かこう | 6問 | 式の数字（10 − 7、＋2）は書いてあります。答えの□を書きます |
| ステップ3 しきの すうじも じぶんで かこう | 6問 | 10 − □ ＝ □、□ ＋ □ ＝ □ をぜんぶ書きます |
| ステップ4 1つの しきに しよう | 6問 | 10 − □ ＋ □ ＝ □ |
| ステップ5 メモを つかって | 8問 | ①〜④は 10 − □ ＋ □ ＝ □、⑤〜⑧は「けいさんメモ」の欄に自分で式を書きます。1のくらいが0の問題（80 − 19 など）を1問入れています |
| ステップ6 ひっさんだけで | 8問 | ひっ算だけです。1のくらいが0の問題を1問入れています |
| テストA | 9問（100点） | ①〜⑧ひっ算（けいさんメモの欄あり）、⑨お話の問題（式・こたえ・ひっ算を書く） |
| テストB | 9問（100点） | テストAと同じ形で、けいさんメモの欄はありません |

- 問題は、アプリと同じ条件で作っています（2けた − 2けた、1のくらいでくりさがる、答えは2けた）。
- テストは、①〜⑧が1問10点、⑨が20点です。⑧までのどこかに、1のくらいが0の問題が1問入ります。

## 支援の工夫

- **アプリと同じ順番・同じ色**：アプリで練習したやり方を、そのまま紙でも使えます。
- **合言葉**：練習プリントの下に「1のくらいは 10 − ひく数 ＋ ひかれる数 で けいさん！／十のくらいは 1 へらして から ひこう！」を、いつも入れています。
- **10のふくろの図**：じゅんび③とステップ1には、「ばらが たりない ときは、ふくろを 1つ あけて 10こ！」の図を入れています。
- **マスの大きさ**：6問のプリントはマスを大きく（約1.45cm）、8問のプリントは約1.15cm にしています。
- **つまずきが分かる欄（テスト）**：①〜⑧の右に、先生が○×をつける小さな欄が3つあります（しるし・1のくらい・十のくらい）。どこでまちがえたかが分かります。
- ひらがなと分かち書きで書いています。漢字は「数（かず）」「十（じゅう）」だけで、ふりがなを付けています。

## 公開の手順

### 1. GitHub Pages で公開する

- 変更を `main` に取り込む（Pull Request をマージする）と、数分後に `https://zku0395-ops.github.io/hori/hissan/print/` で開けるようになります。
- Apps Script やスプレッドシートは使いません。

### 2. 印刷する

**PDF をそのまま使うとき**

1. 作るページの上にある「📄 じゅんび」「📄 れんしゅう」などのボタンを押します。PDF が新しいタブで開きます。
2. 右上の印刷のアイコン（または Ctrl＋P）を押します。
3. 一部だけ印刷するときは、「ページ」で「カスタム」を選び、ページ番号を入れます（例：ステップ3だけなら「41-60」）。

**作るページから印刷するとき（名前入り・べつの問題）**

1. 「1. プリントを えらぶ」で、印刷したいプリントにチェックを入れます。何まい目から何まい目までかを選べます。
2. 名前を入れると、名前入りで印刷されます。空けておくと、子どもが手で書けます。
3. こたえも印刷するときは「こたえの ページも つける」にチェックを入れます。
4. 「🖨 いんさつ する」を押します。
5. 印刷の画面で、用紙は「A4」、倍率は「100%（実際のサイズ）」、「背景のグラフィック」をオンにします。

- 「べつの もんだいに する」を押すと、PDF とはちがう問題になります。「もとの もんだいに もどす」で、PDF と同じ問題にもどります。

## 注意事項

- **絵**：クルミせんせいの絵は、ひっ算アプリと同じ画像です（先生の Canva で、このアプリのために作りました）。どんぐり・10のふくろ・ひっ算の図は、プログラムで描いています（オリジナル）。
- **問題**：先生からもらったプリントの問題をそのまま写してはいません。アプリと同じ条件で作った、オリジナルの問題です。
- **白黒で印刷するとき**：色分けは見えにくくなりますが、数字と線はそのまま読めます。
- **使っているもの**：BIZ UDPゴシック（Google Fonts）をインターネット経由で読み込んでいます。
- **PDF を作り直すとき**：`node hissan/print/tools/make-pdf.js` を動かします（Playwright と Chromium がいります）。
