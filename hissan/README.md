# クルミせんせいの どんぐり ぎんこう（ひき算のひっ算・くりさがりありの学習アプリ）

小学校の特別支援学級向けの、ひき算のひっ算（2けた − 2けた、くりさがりあり）の学習アプリです。
りすの「クルミせんせい」と一緒に、1のくらいを **10 − ひく数 ＋ ひかれる数** で計算するやり方（減加法）を、スモールステップで身につけます。

- 先生が使っているプリント「ひき算のひっさん くりさがりあり（ステップ1〜5）」の流れに合わせています。
- 舞台は、森の「どんぐり ぎんこう」です。どんぐりは **10こで ふくろ1つ** にして預かります。
  - 「ばらが足りないから、ふくろを1つあける」が、くりさがりの意味と重なるようにしています。
- 正解すると、どんぐりが1こもらえます。5問（1かい）を終えると、ボーナスで3こもらえます。
- どんぐりが10こたまるたびに、10こをふくろに入れるアニメーションが出ます。
- どんぐりで家具やかざりを買い、「もりの おうち」の好きな場所に置けます。
- ステップをクリアすると、森の友だちが遊びに来て、アルバムに入ります。

## できること

| 項目 | 内容 |
|---|---|
| 学習内容 | じゅんび①〜③、ステップ1〜6、発展ア〜ウ（下の表） |
| 問題 | アプリが毎回ちがう問題を作ります。条件はプリントと同じです（2けた − 2けた、1のくらいでくりさがる、答えは2けた） |
| 進め方 | 5問で「1かい」（5〜10分）。同じステップを2かい（10問）終えるとクリアで、次のステップが開きます。途中でやめても「つづきから」始められます |
| 答え方 | □を順に光らせ、画面の大きな数字ボタン（0〜9）で入れます。くりさがりの印は、十のくらいの数字を指で押します。ドラッグや手書きはありません |
| 色分け | ひかれる数は赤、ひく数は青、10は緑です。式の中の数字も同じ色にします（先生用画面で消せます） |
| 文字 | ひらがなと分かち書きが中心です。漢字は「数（かず）」「十（じゅう）」「数字（すうじ）」だけで、すべてにふりがなを付けています |
| 声 | クルミせんせいのセリフを読み上げます（ふつうは0.8倍の速さ）。クルミせんせいを押すか「🔊 もういちど」で聞き直せます |
| 先生用画面 | 暗証番号4けたで開きます。記録の確認、設定、記録の送信、CSV書き出し、バックアップができます |
| 全員の記録 | 1問とくたびに、結果が先生のGoogleスプレッドシートへ自動で届きます（ほかのアプリとは別のスプレッドシートを使います） |

## ステップ構成

| ステップ | 内容 | 画面で子どもがすること |
|---|---|---|
| じゅんび① 10 − □ | 10の合成・分解 | 10こ入りのふくろから□こ取る絵を見て、「10 − 7 ＝ □」の答えを入れる |
| じゅんび② □ ＋ □ | たし算（答えは9まで） | 残りのどんぐりとばらのどんぐりを合わせる絵を見て、答えを入れる |
| じゅんび③ くりさがりの しるし | ひけるかどうかの見分け | 「2から7は ひける？」に「ひける／ひけない」で答える。ひけないときは十のくらいを押して印をつける（ひける問題もまぜます） |
| ステップ1 なぞって おぼえよう | プリントのステップ1 | すべての□にうすい数字が出ています。光る□と同じ数字のボタンを押します |
| ステップ2 □に 数字を かこう | プリントのステップ2 | 印は自分でつけます。式の数字（10 − 7、＋2）は出ていて、答えの□だけ入れます |
| ステップ3 しきの 数字も じぶんで | プリントのステップ3 | ひく数・ひかれる数の□も入れます |
| ステップ4 1つの しきに しよう | プリントのステップ4 | 10 − □ ＋ □ ＝ □ |
| ステップ5 メモを つかって | プリントのステップ5 | 式の枠は「📝 メモ」を押すと出ます。1のくらいが0の問題（80 − 19 など）を5問に1問まぜます |
| ステップ6 ひっさんだけで | ふつうのひっ算 | 式は出ません（ヒントを押すと式が出ます）。十のくらいの「1へらした数」も自分で入れます |
| 発展ア 2けた − 1けた | 先生が開きます | 42 − 7 など |
| 発展イ こたえが 1けた | 先生が開きます | 43 − 36 ＝ 7 など。十のくらいの0は書かないことを学びます |
| 発展ウ おはなしの もんだい | 先生が開きます | お話を読んで「□□ − □□」の式を作ってから、ひっ算をします |

1問の進み方（ステップ1〜6）は、プリントと同じ順番です。

1. 十のくらいを押す（7に斜線、上に「6」と「10」が出る）
2. 1のくらいの式（10 − 7 ＝ 3、3 ＋ 2 ＝ 5）
3. 答えの1のくらいに「5」を入れる
4. 十のくらい（へった「6」から3をひいて「3」）

- 初めてのステップでは、はじめにクルミせんせいのお話（やり方の説明）が出ます。
- クリアしたステップは、メニューから何度でもやり直せます。

## 支援の工夫

- **ヒントは3段階**です。
  - 1段階目：ことば（例：「10この どんぐりから 7こ とると？」）
  - 2段階目：10のふくろとどんぐりの絵、または見る数字を光らせる
  - 3段階目：どんぐりに番号をつけて一緒に数えるアニメーションと、押す数字ボタンを光らせる
  - 同じところで2回まちがえるとヒントボタンが光り、3回まちがえると一番くわしいヒントが自動で出ます。
- **まちがい方に合わせた声かけ**をします。72 − 37 の例です。

  | まちがい | 答えの例 | 声かけと支援 |
  |---|---|---|
  | 大きい方から小さい方をひいた | 1のくらいに「5」（7 − 2） | 「2から 7は ひけないね。ふくろを 1つ あけよう」と、10のふくろの絵を出す |
  | 十のくらいを1へらしていない | 十のくらいに「4」（7 − 3） | 「十のくらいは 1 へらしたかな？」と、ふくろの絵を出す |
  | 10 − ひく数 のまちがい | 10 − 7 ＝ 4 など | 10こ入りのふくろの絵を出す |
  | たし算のまちがい | 3 ＋ 2 ＝ 6 など | どんぐりの絵を出し、一緒に数える |

- **まちがえた数字のボタンは消えて**、残りから選び直せます。まちがえたときの音は、ブザーではなく小さな音です。
- **10のまとまり**：じゅんびとヒントで、10こ入りのふくろとばらのどんぐりの絵を使います。ヘッダーのどんぐりの数も「ふくろ○こ ＋ ばら○こ」で表示します。
- **合言葉の表示**：ステップ1〜5では、プリントの下の欄と同じ「1のくらいは 10 − ひく数 ＋ ひかれる数 で けいさん！／十のくらいは 1 へらして から ひこう！」を画面の上に出します。
- **ごほうび**：ヒントを使っても、正解すればどんぐりは同じようにもらえます。時間制限はありません。
- **称号**：クリアしたステップの数で変わります（どんぐり みならい → ぎんこう いん → まどぐち めいじん → ひっさん はかせ → ぎんこう ちょう）。

## 公開の手順

### 1. GitHub Pages でアプリ本体を公開する

ほかのアプリと同じリポジトリの `hissan` フォルダに入っています。

- 音読アプリの手順で GitHub Pages を公開していれば、変更を `main` に取り込む（Pull Request をマージする）だけで、数分後に `https://zku0395-ops.github.io/hori/hissan/` で開けるようになります。
- まだ公開していないときは、リポジトリの `README.md` の「GitHub Pages でアプリ本体を公開する」を先に行ってください。

### 2. Google Apps Script とスプレッドシートの準備（学校のアカウントで）

ほかのアプリとは**別のスプレッドシート**を使います。

1. 学校のGoogleアカウントで、新しい Google スプレッドシートを作ります（名前の例：「ひっ算の学習 記録」）。
2. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、`hissan/gas/Code.gs` の内容を貼り付けます。
   - GitHub で `Code.gs` を開き、「Raw」を押します。翻訳の案内が出たら「翻訳しない」を選びます。
   - Ctrl＋A（全部選ぶ）→ Ctrl＋C（コピー）→ Apps Script の画面で全部消してから Ctrl＋V（貼り付け）します。
4. 左の「ファイル」の「＋」→「HTML」を選び、名前を `start` にします。中身をすべて消し、`hissan/gas/start.html` の内容を同じように貼り付けます。
   - 貼り付けたら、いちばん下が `</html>` になっているか確かめます。
5. 上の保存ボタン（💾）を押します。
6. 右上の「デプロイ」→「新しいデプロイ」を押します。
   - 左の歯車から種類「ウェブアプリ」を選びます。
   - 「次のユーザーとして実行」：**自分**
   - 「アクセスできるユーザー」：**全員**
7. 「デプロイ」を押します。アクセスの承認を求められたら、自分のアカウントを選んで「許可」します。
   - 「このアプリは Google で確認されていません」と出たときは、「詳細」→「（プロジェクト名）に移動」を押します。
8. 表示された「ウェブアプリ」のURL（`https://script.google.com/macros/s/…/exec`）を、Classroom などで子どもに配ります。
9. スプレッドシートを開き直すと、メニューに「クルミせんせい」が出ます。

**大切なこと**

- 子どもは、配ったURL（入口ページ）の「はじめる」から開いてください。こうすると、記録の送り先と合言葉がアプリに自動で設定されます。
- アプリは新しいタブで開きます。開かないときは、ボタンの下に出る「このページで ひらく」を押してください。
- 一度設定されれば、次からは GitHub Pages のURLを直接開いても記録は届きます。
- `Code.gs` や `start.html` を書き換えたときは、「デプロイ」→「デプロイを管理」→ 鉛筆のアイコン →「バージョン：新バージョン」→「デプロイ」で更新します（URLは変わりません）。

### 3. Chromebook の準備（1台ずつ、最初に1回）

1. 入口ページの「はじめる」でアプリを開きます。
2. 「はじめての設定」画面で、先生が次のことを行います。
   - 児童の名前を入れる
   - 先生用の暗証番号（4けた）を決める
   - 「声と音を確認する」で、クルミせんせいの声とファンファーレが聞こえるか確かめる
3. 先生用画面の「データ」タブで、「先生のスプレッドシートへの送信」の送り先が「✅ 設定ずみ」になっているか確かめます。
4. 必要なら「設定」タブで、始めるステップを決めます（例：たし算・ひき算の基礎ができている子は「ステップ1」から）。

### 4. Googleサイトに置くとき（必要なときだけ）

Googleサイトでは、入口ページを「埋め込む」で貼らずに、**「ボタン」**を使ってください。

- 埋め込むと、入口ページがGoogleサイトの枠の中に入ります。この枠の中からは、新しいタブを開くこともページを切りかえることも止められるため、「▶ はじめる」を押しても何も起きません。
- ボタンは、リンク先を新しいタブで開くので止められません。

**ボタンの置き方**

1. Googleサイトの編集画面で、右側の「挿入」→「ボタン」を押します。
   - すでに埋め込んだ枠があるときは、枠を押して選び、ゴミ箱のアイコンで消します。
2. 次のように入れて、「挿入」を押します。
   - 名前：例「▶ クルミせんせいの どんぐり ぎんこう」
   - リンク：入口ページのURL（`https://script.google.com/macros/s/…/exec`）
3. 右上の「公開」を押します。
4. 公開したサイトでボタンを押すと、入口ページが新しいタブで開きます。そこで「▶ はじめる」を押すと、アプリが開きます。

**1回でアプリを開きたいとき**

ボタンのリンクを次のURLにすると、ボタンを1回押すだけでアプリが開きます。記録の送り先と合言葉も自動で設定されます。

1. 入口ページのURLを、ブラウザーで直接開きます。
2. 「▶ はじめる」の上で右クリック（Chromebook では2本指でタップ）し、「リンクのアドレスをコピー」を選びます。
   - `https://zku0395-ops.github.io/hori/hissan/#rec=…&key=…` という長いURLがコピーされます。
3. このURLを、Googleサイトのボタンの「リンク」に貼ります。

- このURLには合言葉が入っています。ただ、入口ページから開いたときにアプリへ渡しているものと同じなので、子どもが見ても問題ありません。
- 1回で開くボタンで記録が届かないときは、入口ページのURLを使うボタンにもどしてください。
- 「新しいデプロイ」を作ってウェブアプリのURLが変わったときは、このURLもコピーし直してください。

### 設定

| 設定 | 内容 |
|---|---|
| 始めるステップ | この児童が最初に取り組むステップです。それより前のステップは「とばす」になり、クリアしていなくても次へ進めます |
| じゅんび①〜③ | する／とばす（とばすと、ステップ1から始めます） |
| すべてのステップを開く | 前のステップをクリアしていなくても挑戦できるようにします |
| 発展 | 発展ア〜ウを開くかどうか |
| 色分け | ひかれる数＝赤、ひく数＝青、10＝緑の色分けを出すかどうか |
| 10のふくろの絵 | じゅんびの絵とヒントの絵を出すかどうか（出さないときは、ヒントで数字を光らせます） |
| 読み上げの速さ | 0.6倍〜1倍（ふつうは0.8倍） |
| クルミせんせいの声・効果音とファンファーレ・文字と画面の大きさ・暗証番号の変更 | ― |

- 1台の Chromebook を1人の児童が使う前提です。設定はその Chromebook（その児童）ごとに保存されます。
- 「とばした」ステップも、メニューから選べば練習できます。称号とクリア数では、とばしたステップもクリアとして数えます。

## 全員の記録を見る（先生のスプレッドシート）

| シート | 内容 |
|---|---|
| いちらん | 1人1行で、名前・称号・クリアしたステップ数・といた問題数・1回で正解した割合・どんぐり・かぐ・ともだちの数・最後の学習日時・いまのステップを表示します。ステップの列は「◎＝クリア（数字はクリアした回数）」「3/10＝挑戦中（クリアまでの10問のうち3問まで終わった）」「とばす」です。右側のオレンジの列は、つまずきの種類ごとのまちがえた回数です |
| きろく | 全員の1問ごとの結果です（日時・名前・ステップ・問題番号・問題・正しい答え・答えた内容・結果・まちがえた回数・ヒントの回数・かかった時間・つまずき・メモを使ったか・色分け） |

「答えた内容」には、まちがえた場所と数字が入ります（例：「10−ひく数:4」は、10 − 7 の答えに4と入れた）。

つまずきの種類は次のとおりです。

- 大きい方から小さい方をひいた
- 十の位を1へらしていない
- 10−ひく数のまちがい
- たし算のまちがい
- 式に入れる数字のまちがい（ひく数とひかれる数の取りちがえなど）
- ひけるかどうかの見分け（じゅんび③）
- 式の数の順番（発展ウ）
- その他

記録について：

- 「いちらん」は記録が届くたびに作り直されます。手で書き込んだ内容は消えるので、メモは別のシートに書いてください。
- 途中でやめた問題も、答えたことがあれば「とちゅうでやめた」として記録されます。
- インターネットにつながっていないときの記録は端末にためておき、次につながったときに送ります。同じ記録が二重に書き込まれることはありません。
- 子どもは名前で区別します。名前は1人ずつ違うものにしてください。

## 注意事項

- **データの保存場所**：記録・進み具合・どんぐり・かぐ・設定は、そのChromebookのブラウザの中（IndexedDB と localStorage）に保存します。Chromeの閲覧データを消すと記録も消えるので、ときどき「バックアップを書き出す」で保存してください。
- **スプレッドシートへの送信**：送り先が設定されている場合は、名前と問題の結果だけを先生のスプレッドシート（Apps Script）に送ります。
- **読み上げ**：Chrome の音声合成を使います。日本語の声が入っていない端末では読み上げられません。
- **暗証番号を忘れたとき**：元にもどす機能はありません。Chromeの設定からこのサイトのデータを消すと最初からやり直せますが、記録も消えます。
- **絵と音**：
  - クルミせんせい（ふつう・よろこぶ・かんがえる）、ホームの「どんぐり ぎんこう」、もりの おうちの部屋の絵は、先生の Canva で、このアプリのために作った画像です（Canva のデザイン「クルミせんせい どんぐりぎんこう え（書き出し用）」に保存しています）。
  - どんぐり・10のふくろ・ひっ算の絵は、数や色を正しく動かすため、プログラムで描いています（オリジナル）。
  - かぐ・かざり・ともだちは絵文字です。ファンファーレの曲は、このアプリのためのオリジナルです。
- **問題**：参考にしたプリントの問題をそのまま写してはいません。プリントと同じ条件で、アプリが毎回作ります。
- **使っているもの**：React と Babel（unpkg）、BIZ UDPゴシック（Google Fonts）をインターネット経由で読み込んでいます。
