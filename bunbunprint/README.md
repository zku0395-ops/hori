# ブンブンちょうろうの ぶんづくり プリント（ことばを えらんで 文を つくる）

文をつくる学習アプリ「ブンブンちょうろうの ことばの ぼうけん」（[bunbun/](../bunbun/README.md)）と同じ文で、ことばを えらんで 文を つくる、紙のプリントです。
さし絵を見て、えらぶ ことば（5つ以上）から使うことばに ✓ をつけ、ことばの数だけある わくに書いて、文を つくります。

- プリントを作るページ：`https://zku0395-ops.github.io/hori/bunbunprint/`
- できあがった PDF：`bunbunprint/pdf/` にあります（カラー・しろくろ・こたえ）
- 用紙は **A4よこ**、**たて書き** です。1まいに2問です。記録はとりません。

## できること

| 項目 | 内容 |
|---|---|
| 問題 | 48問（12エリア × 4問）、24まい。アプリと同じ文です。先生のスライド「ことばや もじを ならべて 文を つくろう」の文を20文 入れています |
| えらぶ ことば | 文のことばに、まちがいやすい ことばを足して、5〜7こにしています（カードが8まい以上の長い文は、まちがいやすい ことばを1つ）。ことばの上の □ に、使ったら ✓ をつけます |
| ならび方 | 問題の下の段は、右に「えらぶ ことば」、その左に「ぶんを かこう」の わくがあります。見出しは どちらも たて書きで、右はしにあります |
| 書く わく | 使う ことばの数だけ わくがあります。わくの長さは ことばの長さと同じで、1文字ずつ うすい点線で区切っています。「は・が・を」などの ちいさい ことばの わくは、少し細くしています |
| つかう ことばは ○こ | 問題ごとに、使う ことばの数を出しています |
| カラー版 | アプリと同じ色で、品詞ごとに カードに色をつけています（れんしゅう用）。「ぶんを かこう」の わくは、カラー版でも 線は黒、中は白です。いちばん下に 色の見本があります |
| しろくろ版 | 色わけなし（テスト用）。白黒のプリンターでも そのまま使えます |
| こたえ | 赤い字で わくに書いています。使う ことばの □ には ✓ が入っています。べつの並べ方でも正解になる文には「ほかの こたえ」を書いています |
| やりかた | カラー版・しろくろ版の はじめに、「やりかた」のページ（れいの問題つき）が1まいあります |
| プリントの上 | タイトル、エリア、ブンブンちょうろうと ふきだし、「　がつ　にち」、「　ねん　なまえ」、「できたかな？」（😊🙂😐 に ○） |
| 先生の欄 | 問題ごとに、先生が ○ をつける欄があります |
| 名前 | PDF は名前の欄が空いています。作るページで名前を入れると、名前入りで印刷できます |
| PDF で ほぞん | 作るページの「📄 PDF で ほぞん」で、えらんだ プリント（名前入りも）を PDF にして保存できます。ファイルの名前は「ぶんづくりプリント_しろくろ_かわ_たろう.pdf」のように、なかみに合わせて付きます。できあがった PDF（名前なし）も、作るページの ④ から ダウンロードできます |

- 1エリア＝2まい（1まいめ ①②、2まいめ ③④）です。
- スライドの文のうち、「あねは ちょうしょくを たべた」「ぼくは おとしだまを もらった」「ははが だいどころで ゆうしょくを つくっている」「わたしたちは こうていで なわとびを しました」の4文は、入れていません。入れかえるときは `data/mondai.js` の文の番号を変えます。

## 支援の工夫

- **アプリと同じ文・同じカード**：カードの区切り（「でんしゃ／が／えき／に／とうちゃく した。」）と品詞の色は、アプリと同じです。アプリで練習した文を、紙でも書けます。
- **まちがいやすい ことば**：えらぶ ことばに、文の「が」に対して「を」「は」のような にている助詞と、同じなかまの ことば（「いぬ」に対して「ねこ」、「きいろい」に対して「あおい」など）を足しています。カードを1つずつ確かめて えらぶ練習になります。
- **わくの長さが ヒント**：わくの長さは ことばの文字数と同じです。「は・が・を」の わくは細く、どこに ちいさい ことばが入るかが分かります。
- **カラー版は色も ヒント**：カードを品詞ごとに色わけしています。「ぶんを かこう」の わくは、書きやすいように 黒い線と白い中にしています。テストは しろくろ版を使います。
- **たて書き**：先生のスライドと同じ たて書きです。右の問題（①）から、上から下へ、右の わくから書きます。
- **書きやすい大きさ**：わくの1文字は、短い文で約1.1cm、長い文でも約0.7cm以上にしています。
- ひらがなと分かち書きで書いています。漢字は使っていません。

## ファイル構成

```
bunbunprint/index.html          プリントを作るページ（印刷もここから）
bunbunprint/data/mondai.js      つかう文（エリアごとに4問）と、まちがいやすい助詞
bunbunprint/img/                さし絵（ChatGPT で作成。q_文の番号.webp）
bunbunprint/e_chatgpt.md        ChatGPT に さし絵を頼むときの文
bunbunprint/pdf/                できあがった PDF
  ぶんづくりプリント_1_カラー.pdf     25まい（やりかた ＋ 24まい）
  ぶんづくりプリント_2_しろくろ.pdf   25まい（やりかた ＋ 24まい）
  ぶんづくりプリント_3_こたえ.pdf     24まい
bunbunprint/tools/make-pdf.js   PDF を作るプログラム（node bunbunprint/tools/make-pdf.js）
```

- 文・カード・品詞・正解の並べ方は、アプリのデータ（`bunbun/data/bunbun.js` と `bunbun/data/kumitate.js`）を読みこんで使います。ブンブンちょうろうの絵も、アプリの絵（`bunbun/img/`）を使います。
- さし絵がまだない問題は、アプリと同じ絵文字が出ます。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/bunbunprint/` を開きます。
3. ①カラー・しろくろ・こたえ を選び、②エリアを選び、③名前を入れる（入れなくても よい）、の順に選んで「🖨 いんさつ する」を押します。
4. 印刷の画面で、用紙を **A4**、向きを **よこ**、余白を **なし** にし、**背景のグラフィック** に チェックを入れます。

**PDF で保存するとき**

1. ①〜③を選んで、「📄 PDF で ほぞん」を押します。
2. 手順が出るので、「わかった。印刷の 画面を ひらく」を押します。
3. 印刷の画面で、「送信先」を **「PDF として保存」**（パソコンでは「PDF に保存」）にします。
4. 用紙 **A4**・**よこ**・余白 **なし**・**背景のグラフィック** に チェック を確かめて、「保存」を押します。
5. 保存する場所（Chromebook は「ダウンロード」や Google ドライブ）を選びます。

- 名前の入っていない PDF がほしいときは、作るページの「④ できあがった PDF」の ボタンを押すと、すぐ ダウンロードできます。
- **印刷の画面が出ないとき**：作るページを Googleサイトなどの わくの中で開いていると、印刷の画面が出ません。そのときは「⚠ 印刷の 画面が ひらきませんでした」の欄が出るので、「↗ あたらしい タブで ひらいて 印刷する」を押します（選んだものと名前は そのまま）。キーボードの Ctrl ＋ P でも開きます。学校の設定で印刷が止められているときは、④ から ダウンロードしてください。
- Googleサイトに置くときは、ページを「埋め込む」のではなく、「ボタン」で置いてください。

### 2. Apps Script とスプレッドシート

- このプリントは記録をとらないので、Apps Script とスプレッドシートは いりません。

### 3. Chromebook の準備

- 先生の Chromebook や パソコンで、作るページか PDF を開いて印刷します。子どもの Chromebook の準備は いりません。

### 4. Googleサイトに置くとき

- 作るページの URL か、PDF の URL を「ボタン」や「リンク」で置いてください。

## 先生用画面

- 作るページの上の部分が、先生が選ぶところです（印刷には出ません）。
  - ①どのプリント（カラー・しろくろ・こたえ）と、「やりかた」のページを入れるか
  - ②エリア（1つずつ、または ぜんぶ）
  - ③学年と名前、「🖨 いんさつ する」「📄 PDF で ほぞん」
  - ④できあがった PDF の ダウンロード

## 全員の記録を見る

- このプリントは記録をとりません。できたかどうかは、問題ごとの「せんせい」の欄に ○ をつけて見てください。
- アプリの記録（どの文・どの助詞で つまずいたか）は、アプリの先生用画面で見られます。プリントとアプリで同じ文を使っているので、つまずいた文を プリントで もう一度 練習できます。

## 注意事項

- **文**：先生からいただいたスライド「ことばや もじを ならべて 文を つくろう①〜⑫」の文（20文）と、アプリのために書いたオリジナルの文です（スライドの「ちょくしょく」は「ちょうしょく」、「一じかんめ」は「いちじかんめ」にしています）。
- **絵**：ブンブンちょうろうは、先生が ChatGPT で作ったアプリの絵です。さし絵は、先生が ChatGPT で作るオリジナルの絵です（頼み方は `e_chatgpt.md`。4こまの絵を1まいずつに切り分けて `img/` に入れます）。いま入っているのは 1 はらっぱ・2 もり・3 かわ の12まいです。ほかは、そろうまで絵文字です。
- 作るページは、文のデータを `bunbun/` から読みこみます。`bunbun/` のフォルダの文を直すと、このプリントの文も変わります（PDF は作り直すまで変わりません）。
- PDF を作り直すときは、`node bunbunprint/tools/make-pdf.js` を動かします。

## これから相談して決めること

- ChatGPT の さし絵を入れる（はらっぱ・もり・かわ の12まいは入れました。のこり36まい）

- カードを切って並べる「カード用」のまいを作るか
- 「そらの うえの がっこう」の先生用画面の プリント や、「ショコの まなびの としょかん」の たなに置くか
