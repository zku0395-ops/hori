# ChatGPT に絵を頼むときの文（ゲンじいの つりマスター への みち）

## つかいかた

1. ChatGPT を開き、下の「はじめに 1回だけ はる文」を貼って送ります。
2. つぎに、作りたい絵の文（①〜⑦）を1つずつ貼って送ります。
3. できた絵を保存します（右クリック →「名前を付けて画像を保存」）。
4. 保存した絵を、このチャット（Claude）に貼ってください。
   - こちらで、切り分け・背景をすかす・名前を付ける・軽くする をして、アプリに入れます。
   - ファイル名を付けなくても大丈夫です。「ゲンじい の よろこぶ」「さかな の 3まいめ」のように、どの絵かを書いてください。
5. 気に入らない絵は、「もっと やさしい顔に」「線を太く」のように ChatGPT に頼んで作り直します。

- 絵がそろうまでは、アプリの中の仮の絵（自作の絵と絵文字）で動きます。全部そろえなくても使えます。
- おすすめの順番：① ゲンじい → ② つりびと → ③ つりばの背景 → ④ さかな。はじめの画面・地図・ふねは あとでかまいません。

## はじめに 1回だけ はる文

```
これから、小学校の特別支援学級の子ども（1〜4年生）が使う、算数の学習アプリの絵を、何まいか続けて作ってもらいます。
アプリは、いろいろな川や海で魚をつり、魚の数と ねだんから、電卓で いくらになるかを計算するゲームです。
次のルールを、すべての絵で守ってください。
・絵本のような、やさしい色の、子ども向けのイラスト。太めの、やわらかい線。
・こわくない、やさしい顔。深海の魚も、こわくしない。
・既存のアニメ・ゲーム・キャラクターに似せない、オリジナルのデザイン。
・絵の中に、文字・数字・ロゴを入れない。
・キャラクターと魚の絵は、背景を真っ白（または透明）にして、全体が切れないように入れる。
・すべての絵で、絵柄（線の太さ・色合い・頭身）をそろえる。
わかったら「OK」とだけ答えてください。
```

## ① ゲンじい（3まい）

```
アプリの案内役「ゲンじい」を描いてください。
・漁師の、やさしい おじいさん。日にやけた はだ、白い かみ（横だけ）、白くて太い まゆげ、白い口ひげと短い あごひげ、丸い鼻、ほっぺが少し赤い。
・頭に白い ねじりはちまき（むすび目は右）。
・白いシャツの上に、あざやかな青（#2563eb くらい）の ベスト。青はベストだけに使い、ほかには使わない。
・上半身〜ひざくらいまで。正面より少し右を向いている。背景は白。正方形。
・表情を3まい：1まいめ「ふつう（にっこり）」、2まいめ「よろこぶ（目を細めて大きく笑う、両手を広げる）」、3まいめ「がんばれ（こぶしを にぎって ガッツポーズ、はげます顔）」。
3まいを横にならべて、1まいの絵にしてください。
```

> ベストの青いところを、アプリが「きがえ」で選んだ色にぬりかえます。青はベストだけにしてください。

## ② つりびと（子どもが自分で選ぶ主人公。2まい）

```
子どもが自分のかわりに使う主人公「つりびと」を描いてください。
・小学生くらいの子ども。男の子にも女の子にも見える、性別が分からない デザイン。
・青い服（あざやかな青 #2563eb くらい。服以外には青を使わない）、黄色のベルト、こん色の ながぐつ。
・はだと かみは、青以外の色。ぼうしは かぶらない（アプリで ぼうしを のせます）。
・全身。正面より少し右を向いて立ち、右手を少し前に出している（アプリが つりざおを かきます）。背景は白。たて長。
・「かたち1」はみじかい かみ、「かたち2」は肩までの かみ。ほかは同じ。
2まいを横にならべて、1まいの絵にしてください。
```

## ③ つりばの背景（7まい）

```
つりのゲームの背景を描いてください。キャラクターと魚は入れません。横長（16:9）。
・左下に、子どもが立って つりをする場所（地面・岩・ふね）がある。
・まん中から右は、ひろい水面。水面に うきが見えるように、ごちゃごちゃさせない。
・明るく、やさしい色。文字は入れない。
場所：かわ（山から流れてくる すんだ川。左下は草の川岸。遠くに緑の山）
```

「場所：」のところを入れかえて、7まい作ります。

1. かわ（山から流れてくる すんだ川。左下は草の川岸。遠くに緑の山）
2. みずうみ（しずかな大きい湖。左下は草の岸と小さな木のさんばし。遠くに山）
3. いそ（海べの岩場。左下は平らな岩。いそぎんちゃくや かにが少し見える）
4. みなと（ふねが とまる港。左下はコンクリートの岸壁。遠くに灯台と倉庫）
5. おき（陸の見えない青い海の上。左下に小さな木のボートの はしが少し見える。白い雲）
6. ふかい うみ（夜の海の上の大きなふね。暗い青の海、星空、海の中が少し光っている。こわくしない）
7. つり たいかい（にぎやかな海べ。左下は さんばし。色とりどりの旗が空にかかっている）

## ④ さかな（31しゅるい。6まいに分けて）

```
図鑑のような、魚の絵を描いてください。背景は白。
・本物に近い形と色。目だけ少し やさしくする。太めの、やわらかい線。
・全部 横向きで、頭を右に向ける。体全体が切れないように入れる。
・魚どうしは かさならないように、間をあける。文字は入れない。
1まいに、次の5ひきを 横にならべてください：
あゆ／やまめ（体に だ円の もよう）／こい／なまず（長い ひげ）／さけ
```

続けて、次の魚を頼みます（1まいに5〜6ぴき）。

- ふな／わかさぎ／にじます（体に ピンクの線）／ざりがに（赤い はさみ）／うなぎ
- かに（赤い）／たこ（赤い）／くまのみ（オレンジに白い しま）／かさご（赤い）／めばる（目が大きい）
- いわし（体に 黒い点）／あじ／さば（背中に なみの もよう）／かれい（平たい、目は体の右がわ）／いか（白っぽい）
- たい（ピンク）／かつお／ぶり（黄色の線）／まぐろ／さめ（こわくない顔）／かじき（とがった はな）
- きんめだい（赤い体、金色の大きい目）／めんだこ（オレンジの小さい たこ、耳のような ひれ）／だいおういか（大きい目）／ちょうちんあんこう（頭の ちょうちんが光る。こわくない顔）／りゅうぐうのつかい（銀色の長い体、赤い ひれ）

> 「りゅうぐうのつかい」「だいおういか」は とても長いので、1まいに入らないときは、べつに頼んでかまいません。

## ⑤ はじめの画面（1まい）

```

・晴れた空と、きらきらした海。右の水の中に、いろいろな魚が少し見える。
・左下は すなはま。あとから キャラクターと題名を重ねるので、上と左は あけておく。
・文字は入れない。
```

## ⑥ つりばの地図（1まい）

```
つりの冒険の地図を描いてください。上から見下ろした、絵本のような地図。横長（16:9）。
・左上の山から川が流れ出し、まん中の みずうみ を通って、下の海べ（岩場）へ流れこむ。
・右半分は海。海べの右上に みなと、右上の遠くの海は「おき」、右下は 暗い青の ふかい海。
・左上：川、まん中左：みずうみ、まん中下：岩場、まん中右：みなと、右上：おき、右下：ふかい海。上のまん中に つり大会の会場（旗のある さんばし）。
・文字は入れない。
```

> 地図ができたら、こちらで つりばのボタンの位置を、絵の場所に合わせます。
