# ゲンじいの つりマスター への みち（電卓で お金を計算する学習アプリ）

小学校の特別支援学級（1〜4年生）向けの、算数のアプリです。
いろいろな川や海で魚をつり、つった魚の数と、魚ごとの ねだんから、電卓を使って いくらになるかを求めます。
求めた お金をためて、つりざおや ふねを買い、「つりマスター」を目指します。

- 先生からいただいたスライド「なんひき つれたかな？」「1ぴきの ねだん」「合計で いくらかな？」と同じ流れです。
  - つれた数を かぞえる → 1ぴきの ねだんを見る → 「ねだん × ひき ＝ えん」を電卓で求める → 全部たして合計を求める
- 案内役は、漁師の おじいさん「ゲンじい」です。子どもは「つりびと」（かみの形と服の色を選ぶ）になります。
- 形は、九九・ことばの ぼうけん と同じ「Apps Script だけ」です。子どもは名簿の名前のボタンを押して始めます。
- 魚のデータと絵は、GitHub Pages（`https://zku0395-ops.github.io/hori/tsuri/`）から読みこみます。Apps Script に貼り付けるファイルを短くするためです。

## できること

| 項目 | 内容 |
|---|---|
| つり | 「🎣 なげる」を押す → うきが しずんだら「💪 ひく！」を押す。早く押しても「まだ だよ」と言うだけで、失敗にはしません。おそくても魚は にげません（時間制限なし）。1問で、魚の しゅるいの数だけ なげます |
| けいさんの シート | スライド3まいめと同じ ならびです。「1ぴき 200えん × □ひき ＝ □えん」を魚ごとに並べ、いちばん下に「ごうけい」。ます は 順番に光ります（かず → かけ算 → 合計） |
| 色分け | ねだん＝青、なんびき＝黄色、魚ごとの えん＝オレンジ、ごうけい＝緑（スライドの色に近づけています） |
| かぞえる | 魚を押すと 1、2、3 と番号が付き、数を読み上げます。「↺ かぞえなおす」で番号を消せます。数は 1〜10 のボタンで答えます |
| 電卓 | 画面の電卓は、本物の電卓と同じキーの並びです（C ÷ × − ／ 7 8 9 ＋ ／ … ／ 0 00 ＝）。押したキーが上に小さく出ます（例：200×3＝）。「⬅ こたえを いれる」で ますに入れます |
| てもとの 電卓 | 先生用画面で、子どもごとに「てもとの 本物の電卓」に切りかえられます。そのときは、答えだけを数字のボタンで入れます |
| お金 | 1問できるごとに、合計の お金（えん）がもらえます。ヒントを使っても同じです |
| おみせ | つりざお（ぬしが つれやすくなる）・えさ（大きい魚が つれやすくなる）・うき・ふね・すいそうの かざり・ぼうし・ふくの いろ。値段は ふつう・ごうか・ちょうごうか・でんせつ の4段階です |
| ふね | 「おき」には ボート（20,000えん）、「ふかい うみ」には ふね（80,000えん）が必要です。おおきい ふね（300,000えん）は ぬしが つれやすくなります |
| ずかん | 31しゅるいの魚。つった数・いちばん大きいサイズ・ねだん・説明（押すと読み上げ）。つりばの「ぬし」は金色の わくです |
| すいそう | つった魚が泳ぎます。買った かざりが そこに並びます |
| きがえ | 自分の かたち・服の色・ぼうし、ゲンじいの 服の色・ぼうし、うき を選べます |
| しょうごう | つり みならい → かわの つりびと → … → つりマスター → でんせつの つりマスター（10こ） |
| 先生用画面 | 暗証番号4けたで開きます。だんかいごとの結果、まちがいの しゅるい、まちがえた問題と電卓で押したキーが分かります |
| 全員の記録 | 結果は先生のGoogleスプレッドシートへ届きます。進み具合・お金・ずかん・買った物も、スプレッドシートに保存します |

## ステージ構成

### つりば（6か所 ＋ はってん）

| つりば | 魚（👑は ぬし。めったに つれない） | 1ぴきの ねだん | 1しゅるいの数 |
|---|---|---|---|
| 🏞️ 1 かわ | あゆ・やまめ・こい・なまず・👑さけ | 100えん・200えん | 1〜5ひき |
| 🛶 2 みずうみ | ふな・わかさぎ・にじます・ざりがに・👑うなぎ | 100・200・300えん | 1〜5ひき |
| 🪨 3 いそ | かに・たこ・くまのみ・かさご・👑めばる | 100・200・300・500えん | 1〜6ひき |
| ⚓ 4 みなと | いわし・あじ・さば・かれい・👑いか | 150・250・350えん | 1〜8ひき |
| 🚤 5 おき（ボートが必要） | たい・かつお・ぶり・まぐろ・さめ・👑かじき | 1000〜3000えん | 1〜9ひき |
| 🌊 6 ふかい うみ（ふねが必要） | きんめだい・めんだこ・だいおういか・ちょうちんあんこう・👑りゅうぐうのつかい | 2500〜10000えん | 1〜9ひき |
| 🏆 はってん つり たいかい | ① スライドと同じ8しゅるい（さけ100・たい200・たこ100・かに200・さめ200・かれい100・まぐろ200・くまのみ100えん）② いろいろな つりばの8しゅるい | | 1〜9ひき |

### だんかい（1つの つりばに 6つ）

| だんかい | すること | 1回の問題（ふつう） | れい |
|---|---|---|---|
| ⓪ かぞえる | つれた魚を かぞえる（お金は ゲンじいが計算して見せる） | 5問 | たい …… 3びき |
| ① たして もとめる | 同じ ねだんを電卓で たす | 5問 | 200 ＋ 200 ＋ 200 ＝ 600 |
| ② かけて もとめる | 「ねだん × ひき」を電卓で求める。はじめて正解すると「200＋200＋200 と同じ こたえ だね」 | 5問 | 200 × 3 ＝ 600 |
| ③ 2しゅるい | 魚ごとに かけ算 → 合計 | 3問 | 200×3＝600、100×2＝200、600＋200＝800 |
| ④ 3〜4しゅるい | 同じように | 2問 | |
| ⑤ まとめ | その つりばの魚 全部（スライド3まいめと同じ形） | 1問 | |

- 前の だんかいを クリアすると、次が開きます。⑤を クリアすると、次の つりばが開きます。
- 「おき」「ふかい うみ」は、お店で ふねを買うと行けます（先生用画面の「全部開く」にすると、ふねがなくても行けます）。
- はってん（つり たいかい）は、はじめは閉じています。先生用画面の「子どもごと」で開きます。
- 途中でやめても、次は「つづきから」始められます。
- 魚・ねだん・品物は `data/tsuri.js` にあります。

## 支援の工夫

- **スモールステップ**：かぞえる → 同じ数を たす → かける → 2しゅるい → 3〜4しゅるい → 全部、の順です。たし算で求めてから かけ算に進むので、「× は 同じ数を何回も たすこと」が分かります。ねだんは 100えん・200えんから始め、つりばが進むと 150えん・1000えんより大きい数になります。
- **数の見せ方**：魚は1ぴきずつ絵で並べます。押すと番号が付き、数を読み上げます。ヒント②では5ひきずつ わくで かこみます。
- **電卓**：本物の電卓と同じ並びなので、手元の電卓にも移りやすくしています。押したキーが画面に残るので、自分で確かめられます。
- **まちがえたとき**：ますが ゆれて、小さな音が出ます。まちがい方に合わせて声をかけます。
  - 0の数がちがう：「0の かずが ちがうよ。ねだんは 200えん。0が いくつ あるか たしかめよう」
  - ＋と× の押しまちがい：「『＋』を おしたかな？ 200 × 3 だよ。『×』の キーを おそう」
  - たしわすれ：「たしわすれが あるよ。うえの えんを ぜんぶ たそう」
  - ちがう魚の ねだん：「たこは 1ぴき 100えん だよ」
  - かぞえまちがい：「おしい！ もう いちど、1ぴきずつ さわって かぞえよう」（まちがえた数のボタンは消えます）
- **ヒントは3段階** です。同じ ますで2回まちがえるとヒントボタンが光り、3回まちがえると ヒント③が自動で出ます。
  1. ことば：「1ぴき 200えんが 3びき だから、200 × 3。でんたくで『200』『×』『3』『＝』と おそう」
  2. しきを色分けで見せる：「200 × 3 ＝ ？」（ねだん＝青、なんびき＝黄色）。かぞえる ときは 5ひきずつ わくで かこむ
  3. 電卓の次に押すキーが光る（押しまちがえると「C」が光る）。かぞえる ときは、いっしょに数える声と光で1ぴきずつ数え、答えのボタンが光る。てもとの電卓のときは、押す順番（例：200×3＝）を大きく出す
- **つり**：時間制限はありません。早く押しても失敗にしません。どの魚が何びき つれるかはアプリが決めるので、問題が むずかしくなりすぎません。
- **ごほうび**：お金は「その問題の合計」なので、大きい数の計算ほど たくさん もらえます。買い物で、自分のお金と値段を くらべる練習にもなります（「あと 3,000えん たりないね」）。
- **問題の画面**：つりの場面だけ絵の背景です。計算の画面は、すっきりした白い ますにしています。

## ファイル構成

```
tsuri/index.html          アプリ本体（Apps Script の HTML ファイル「index」に貼り付けます）
tsuri/コード.gs            スプレッドシートとつなぐプログラム（Apps Script の「コード.gs」に貼り付けます）
tsuri/data/tsuri.js       つりば・魚・だんかい・おみせ・しょうごうのデータ
tsuri/img/                ChatGPT で作った絵（これから入れます）
tsuri/e_chatgpt.md        ChatGPT に絵を頼むときの文（コピーして使います）
tsuri/tools/check.js      データの点検（node tsuri/tools/check.js）
tsuri/tools/test_gas.js   コード.gs のテスト（node tsuri/tools/test_gas.js）
tsuri/tools/cutfish.py    ChatGPT の 魚の絵を 1ぴきずつ切り分けて 背景をすかす（python3 tsuri/tools/cutfish.py 絵 tsuri/img id …。品物は --holes を つける）
```

- `data/` と `img/` は、GitHub Pages から読みこみます。魚や品物を直したときは、`data/` を直して `main` に入れるだけで、Apps Script を貼り直さなくても全員の画面に反映されます。
- 品物は絵文字が出ます。絵が読みこめないときは、自作の絵（ゲンじい・つりびと・魚・つりば・地図）が かわりに出ます。

### ChatGPT で作る絵（ファイル名）

頼み方の文は `e_chatgpt.md` にあります（品物は「⑧ おみせの 品物」）。

| 絵 | ファイル名 |
|---|---|
| ゲンじい（ふつう・よろこぶ・がんばれ。ベストは青）✅ 入れました | `gen.webp`・`gen_happy.webp`・`gen_cheer.webp`（小さく出すときは顔だけの `gen_face.webp` など） |
| つりびと（かたち2しゅるい。服は青）✅ 入れました | `hero_1.webp`・`hero_2.webp` |

| つりばの地図 ✅ 入れました | `map.webp`（つりばのボタンの位置は、`data/tsuri.js` の SPOTS の x・y で絵に合わせます） |
| つりばの背景（7まい。ホーム・つりの画面）✅ 全部入れました | `spot_1.webp` 〜 `spot_7.webp`（1 かわ・2 みずうみ・3 いそ・4 みなと・5 おき・6 ふかい うみ・7 つり たいかい） |
| 魚（31しゅるい）✅ 全部入れました | `fish_ayu.webp` など（`data/tsuri.js` の FISH の id）。切り分けは `tools/cutfish.py` |

- ゲンじいの ベストと、つりびとの 服の色は、絵の あざやかな青のところを、アプリが選んだ色にぬりかえて出します（ながぐつの こい青は ぬりかえません）。
- 「おき」「ふかい うみ」で、つりびとの足もとに出す ふねの絵文字は、背景の絵が ないときだけ出します（背景の絵に ふねが かいて あるため）。
- つりの画面では、つりびとを左右反対にして、前に出した手が水のほうを向くようにしています。つりざおは アプリが かきます。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/tsuri/` を開きます。
   - 「おためしモード」で動けば、魚のデータと絵の公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「つりマスター 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。
4. 画面の文字が小さいときは、先生用画面の「もじの おおきさ」で変えます。
5. 手元の本物の電卓を使う子は、先生用画面の「子どもごと」で「🧮 でんたく」を切りかえます。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、電卓やボタンが小さくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。
- 「そらの うえの がっこう」に置くときは、URLを教えてください。こちらで `sora/apps.js` に足します。

## 先生用画面

1. 名前を選ぶ画面の右下（学習中は右上）の **🔒** を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「せってい」で変えてください。**

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの いまのステージ・クリアした つりばの数・電卓（がめん／てもと）・お金・ずかんの数・問題の数・まちがえずに できた割合・多い まちがい・最後に学習した日。クラス全体の「まちがいの しゅるい」「だんかいごとの表」 |
| 子どもごと | ステージごとの結果、だんかいごとの表、まちがいの しゅるい、まちがえた問題と電卓で押したキー（新しい順・15問まで） |
| 子どもごと（ボタン） | 🧮 でんたく（アプリの画面／てもとの本物）、全部開く（その子だけ、すべてのステージと つりばを開く。ふねが なくても行けます）、はってんを開く、お金を足す・引く（±1,000・±10,000）、この子の記録を消す |
| せってい | 読み上げの速さ、文字の大きさ、1回の問題の数（すくなめ・ふつう・おおめ）、効果音、おんがく（つかう・つかわない）、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、全員の記録を消す |

- **まちがえずに できた割合** は、まちがえず、ヒントも使わずに できた問題の割合です。
- **まちがいの しゅるい**

  | しゅるい | 内容 |
  |---|---|
  | ゼロの かず | 0の数がちがった（60 と 600、2000 と 200 など。けたの まちがい） |
  | ＋と × | かけ算のところで「＋」を押した（200＋3＝203 など）、または たし算で「×」を押した |
  | かぞえまちがい | つれた魚の数を かぞえまちがえた |
  | たしわすれ | ごうけいで、たしていない えんが あった |
  | たしすぎ | ごうけいで、同じ えんを2回たした |
  | たす かいすう | たし算で、たす回数が多い・少ない（かけ算では、かける数がちがった） |
  | ちがう ねだん | ほかの魚の ねだんを使った |
  | おしまちがい | 上のどれにも当てはまらない、電卓の押しまちがい |

- **電卓で押したキー** の書き方：「たい:200×3=→600○」＝たいの ますで 200 × 3 ＝ と押して 600 になった（○正解・✖まちがい）。「てもと」は手元の電卓で答えだけ入れたときです。
- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。

## 全員の記録を見る

- スプレッドシートの **「きろく」** シートに、1問ごとの結果が入ります。

  |---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

  - ステージ：「3-2」＝3ばんめの つりば（いそ）の ② かけて もとめる。「7-1」「7-2」は はってん（つり たいかい）です。
  - もんだい：「たい200えん×3・たこ100えん×2」のように、つれた魚と ねだんと数　ごうけい：答えの お金
  - けっか：○＝まちがえず、ヒントも使わずに できた　△＝まちがえてから、またはヒントを使って できた
  - まちがい：その問題で まちがえた回数　ヒント：使ったヒントの段階（0〜3）
  - まちがいの しゅるい：上の表の しゅるい（2つ以上のときは「・」で区切ります）
  - おした キー：電卓で押したキーの順（ますごとに「／」で区切ります）
  - でんたく：がめん（アプリの電卓）／てもと（手元の本物の電卓）
  - びょう：その問題の計算にかかった時間（つりの時間は入りません）
- **「まとめ」** シートに、子どもごと・ステージごとの結果と、まちがいの しゅるいが入ります。先生用画面を開いたとき、またはメニュー **つりマスター → まとめを更新する** で更新されます。
- **「名簿」** シートのB列に、進み具合・お金・ずかん・買った物・きがえが入ります。ちがう Chromebook を使っても「つづきから」始められます。
- 記録は、1問ごと・やめたとき・終わったときに送ります。ネットが切れていたときの記録は、その Chromebook にためておき、つながったときに送り直します。同じ記録は二重に書きません。
