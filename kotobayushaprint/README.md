# ことばの ゆうしゃ ワークシート（絵を見て文を書くプリント）

文を書く学習アプリ「ことばの勇者」（[kotobayusha/](../kotobayusha/README.md)）と同じ絵と問題で、紙に文を書くワークシートです。
絵を見て「だれが」「どこで」「なにを している」を書いてから、つなげて1つの文にします。

- ワークシートを作るページ：`https://zku0395-ops.github.io/hori/kotobayushaprint/`
- できあがった PDF：`kotobayushaprint/pdf/` にあります（カラー・しろくろ・こたえ）
- 用紙は **A4よこ** です。1まいに2問です。記録はとりません。

## できること

| 項目 | 内容 |
|---|---|
| 問題 | 100問（10エリア × 10問）、50まい。アプリと同じ絵と問題です |
| 3つのわく | 「だれが」（赤）「どこで」（緑）「なにを している」（青）のわくに、ことばを書きます。わくの右に「が」「で」が書いてあります |
| ぶんを かこう | 3つのことばをつないで、ます目（1行12ます × 4行）に文を書きます。ます目には うすい十字の線があります |
| カラー版 | 3つのわくを、アプリと同じ色で色わけしています（れんしゅう用） |
| しろくろ版 | 3つのわくの色わけなし（テスト用） |
| こたえ | 赤い字で、わくと ます目に答えの例を書いています。ます目は、ことばの とちゅうで行がかわらないようにしています |
| プリントの上 | タイトル、エリア、勇者の絵と ふきだし、「　がつ　にち」、「できたかな？」（😊🙂😐 に ○）、**学年と名前を書く わく** |
| 先生の欄 | 問題ごとに、先生が ○ をつける欄があります |
| 学年と名前 | PDF は空いています。作るページで学年と名前を入れると、入ったまま印刷できます |
| PDF で ほぞん | 作るページの「📄 PDF で ほぞん」で、えらんだ ワークシート（名前入りも）を PDF にできます。できあがった PDF（名前なし）も、作るページの ④ から ダウンロードできます |

## ステージ構成

アプリと同じ10のエリアです。1エリア＝5まい（10問）です。

| エリア | 場所 |
|---|---|
| 1 | はじまりの まち |
| 2 | みどりの はらっぱ |
| 3 | まなびの とう |
| 4 | にぎやか いちば |
| 5 | まよいの もり |
| 6 | しずくの みずうみ |
| 7 | ほのおの やま |
| 8 | こおりの どうくつ |
| 9 | そらの おしろ |
| 10 | てんくうの しま |

## 支援の工夫

- **スモールステップ**：先に3つのわくに ことばを書き、そのあとで文にします。「が」「で」は わくの右に書いてあるので、ことばだけを考えればよいです。
- **色で分ける**：カラー版は、アプリと同じ赤・緑・青です。アプリで練習した子は、色で「だれが」「どこで」「なにを している」が分かります。
- **ます目**：1文字ずつ書けるように、1ます 約1cm の ます目にしています。ことばの あいだは1ます あけます（こたえの例も そうしています）。
- **アプリと同じ絵**：アプリで見た絵なので、安心して取り組めます。アプリでつまずいた問題を、紙でもう一度 練習できます。
- ひらがなと分かち書きで書いています。漢字は使っていません。
- 書き方がちがっても（「おとこのこ」と「男の子」など）、正しい文なら ○ にしてください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ワークシートを作るページ（問題と絵は `kotobayusha/` から読みこみます） |
| `pdf/` | できあがった PDF（カラー・しろくろ・こたえ、各50まい） |

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/kotobayushaprint/` を開きます。
3. ①カラー・しろくろ・こたえ を選び、②エリアを選び、③学年と名前を入れる（入れなくても よい）、の順に選んで「🖨 いんさつ する」を押します。
4. 印刷の画面で、用紙を **A4**、向きを **よこ**、余白を **なし** にし、**背景のグラフィック** に チェックを入れます。

**PDF で保存するとき**

1. ①〜③を選んで、「📄 PDF で ほぞん」を押します。
2. 手順が出るので、「わかった。印刷の 画面を ひらく」を押します。
3. 印刷の画面で、「送信先」を **「PDF として保存」**（パソコンでは「PDF に保存」）にします。
4. 用紙 **A4**・**よこ**・余白 **なし**・**背景のグラフィック** に チェック を確かめて、「保存」を押します。
5. 保存する場所（Chromebook は「ダウンロード」や Google ドライブ）を選びます。

- 名前の入っていない PDF がほしいときは、作るページの「④ できあがった PDF」の ボタンを押すと、すぐ ダウンロードできます。
- **印刷の画面が出ないとき**：作るページを Googleサイトなどの わくの中で開いていると、印刷の画面が出ません。そのときは「↗ あたらしい タブで ひらいて 印刷する」を押します。キーボードの Ctrl ＋ P でも開きます。

### 2. Apps Script とスプレッドシート

- このワークシートは記録をとらないので、Apps Script とスプレッドシートは いりません。

### 3. Chromebook の準備

- 先生の Chromebook や パソコンで、作るページか PDF を開いて印刷します。子どもの Chromebook の準備は いりません。

### 4. Googleサイトに置くとき

- 作るページの URL か、PDF の URL を「ボタン」や「リンク」で置いてください。

## 先生用画面

- 作るページの上の部分が、先生が選ぶところです（印刷には出ません）。
  - ①どのワークシート（カラー・しろくろ・こたえ）
  - ②エリア（1つずつ、または ぜんぶ）
  - ③学年と名前、「🖨 いんさつ する」「📄 PDF で ほぞん」
  - ④できあがった PDF の ダウンロード

## 全員の記録を見る

- このワークシートは記録をとりません。できたかどうかは、問題ごとの「せんせい」の欄に ○ をつけて見てください。
- アプリの記録（どの問題で つまずいたか）は、アプリ「ことばの勇者」の先生用画面で見られます。

## 注意事項

- **絵**：アプリ「ことばの勇者」の絵で、すべて ChatGPT で作ったオリジナルです。問題もオリジナルです。
- 作るページは、問題と絵を `kotobayusha/` から読みこみます。アプリの問題や絵を直すと、作るページの ワークシートも変わります（PDF は作り直すまで変わりません）。
- PDF を作り直すときは、Windows の Git Bash で `sh kotobayushaprint/tools/make-pdf.sh` を動かします（Edge を使います）。
