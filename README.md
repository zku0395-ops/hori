# おんどくはかせの ちょうせんじょう

小学校の特別支援学級（2〜4年生）向けの音読学習アプリです。
フクロウの「ホーホーはかせ」が課題を出し、子どもが音読を録音すると、100点満点で採点します。

## できること

| 項目 | 内容 |
|---|---|
| 課題 | スモールステップで全42問（準備運動4問＋ステージ1〜6 各5問＋早口言葉8問） |
| 文字 | ひらがなが中心で、分かち書きにしています。漢字は1〜2年生で習うものだけを使い、すべてにふりがなを付けています |
| 挿絵 | 絵文字の組み合わせで場面を表します |
| お手本 | 機械の声で読み上げます（ふつう／ゆっくり）。先生が録音した課題では、先生の声が流れます |
| 採点 | 声の大きさ・読みの正確さ・強弱・速さの4観点で100点満点。80点以上で合格です |
| ごほうび | 初めて合格するとシールがもらえます。ステージをクリアすると称号が上がります（おんどく たまご → … → おんどく はかせ） |
| 支援の工夫 | 1行ずつ表示（リーディングスリット）、こえメーター、手順カード（きく→れんしゅう→ろくおん→てんすう）、文字の大きさ変更、効果音のオン／オフ |
| 先生用画面 | 暗証番号4けたで開きます。記録と録音の確認、お手本の録音と配布、設定、CSV書き出し、バックアップができます |

### ステージ構成

| ステージ | 内容 | 例 |
|---|---|---|
| じゅんびうんどう（自由） | 発声練習 | あ い う え お／あめんぼ あかいな あ い う え お |
| 1 ことば | 短いことば | 犬（いぬ）、りんご、電車（でんしゃ） |
| 2 みじかい ぶん | 二語文 | 犬が 走る。 |
| 3 すこし ながい ぶん | 三〜四語文 | 赤い りんごを 食べる。 |
| 4 ふたつの ぶん | 2文 | 雨が ふって きた。／かさを さそう。 |
| 5 みじかい おはなし | 3〜4文 | 「うさぎの ぴょん」など |
| 6 し | 詩 | 「あめの うた」など |
| とくべつ はやくちことば | 早口言葉 | なまむぎ なまごめ なまたまご |

- 課題は、前の課題に合格すると順に開きます。
- 次のステージは、前のステージをクリアすると開きます。
- 早口言葉は、ステージ2をクリアすると開きます。
- 先生用画面の設定で、全部の課題を最初から開くこともできます。

## ファイル構成

```
index.html        アプリ本体（GitHub Pages で公開します）
gas/Code.gs       Google Apps Script の入口ページ（サーバー側）
gas/start.html    Google Apps Script の入口ページ（画面）
```

Google Apps Script の画面の中ではマイクが使えません。そのため、アプリ本体は GitHub Pages で公開し、Apps Script の入口ページにある「はじめる」ボタンから開く形にしています。

## 公開の手順

### 1. GitHub Pages でアプリ本体を公開する

1. このブランチの変更を `main` に取り込みます（Pull Request をマージ）。
2. 無料プランで GitHub Pages を使うには、リポジトリを「Public（公開）」にする必要があります。
   - 設定場所：リポジトリの Settings → General → いちばん下の「Change repository visibility」
   - 児童の記録や録音は各Chromebookの中にだけ保存されます。リポジトリを公開しても、児童のデータが外に出ることはありません。
3. Settings → Pages を開き、次のように設定して「Save」を押します。
   - Source：「Deploy from a branch」
   - Branch：`main`、フォルダは `/ (root)`
4. 数分後に `https://zku0395-ops.github.io/hori/` で開けるようになります。

### 2. Google Apps Script で入口ページを作る

1. https://script.google.com で「新しいプロジェクト」を作ります。
2. 最初からある `コード.gs` の中身を、`gas/Code.gs` の内容に置き換えます。
3. 「ファイルを追加（＋）」→「HTML」を選び、名前を `start` にして、`gas/start.html` の内容を貼り付けます。
4. `Code.gs` の `APP_URL` が、手順1で公開したURLになっているか確かめます。
5. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」を選び、アクセスできるユーザー（学校のドメイン内など）を決めてデプロイします。
6. 表示されたウェブアプリのURLを、Classroom などで子どもに配ります。

### 3. Chromebook の準備（1台ずつ、最初に1回）

1. 入口ページの「はじめる」でアプリを開きます。
2. 「はじめての設定」画面で、先生が次のことを行います。
   - 児童の名前を入れる
   - 先生用の暗証番号（4けた）を決める
   - 「マイクを確認する」を押す（マイクの使用を聞かれたら「許可」を押します）
3. 先生用画面の「設定」→「マイクの調整」で、声の大きさの基準をその端末に合わせておくと、採点が安定します。
4. 先生のお手本を使う場合は、「お手本の録音」タブで「お手本セットを読み込む」を行います（後述）。

次の点も確認してください。

- 音声認識を使うため、**インターネット接続が必要**です。
- 学校の管理設定（Google 管理コンソール）で、マイクや `github.io` が制限されていないか確認してください。必要ならICT担当の方に相談してください。

## 先生用画面

子どもの画面の右上にある「⚙ せんせい」を押し、暗証番号を入れると開きます。

| タブ | できること |
|---|---|
| 📊 記録 | 合格数・挑戦回数・称号を確認できます。課題ごとの点数（観点別）、音声認識が聞き取った言葉、録音の再生もできます |
| 🎙️ お手本の録音 | 課題ごとに先生の声でお手本を録音します。「書き出す」で1つのファイルにまとめ、他のChromebookで「読み込む」と全員に配れます |
| ⚙️ 設定 | 名前、採点のきびしさ（やさしい／ふつう／きびしい）、文字の大きさ、1行ずつ表示、効果音、はかせの声、お手本の速さ、全ステージを開く、マイクの調整、暗証番号の変更 |
| 💾 データ | 記録のCSV書き出し、バックアップ（書き出し／元にもどす）、記録の消去 |

### 先生のお手本を全員に配る方法

1. どれか1台のChromebookで、「お手本の録音」タブから課題ごとに録音します。
2. 「お手本セットを書き出す」を押すと、`おてほんセット_日付.json` がダウンロードされます。
3. このファイルを Google ドライブの共有フォルダなどに置きます。
4. 各児童のChromebookで「お手本セットを読み込む」を押し、そのファイルを選びます。

### 録音の保存について

- 録音は、課題ごとに「最新3回」と「最高得点の回」を残します。
- 点数の記録は、すべての回が残ります。

## 採点のしくみ

| 観点 | 配点（早口言葉） | 測り方 |
|---|---|---|
| 📢 こえの おおきさ | 30（25） | マイクの音量を測ります。録音前の「3・2・1」の間に部屋の静かさを測り、それと比べます |
| 🎯 よみの せいかくさ | 40（40） | Chromeの音声認識で声を文字にし、お手本の文（ひらがな）とどれだけ一致するかを見ます |
| 🎵 つよさ・よわさ | 20（10） | 声の大きさと高さの変化から、棒読みになっていないかを見ます |
| 🏃 はやさ | 10（25） | 文字数と読んだ時間から判定します。ふつうの課題は「速すぎ・遅すぎ」でないか、早口言葉は「どれだけ速く言えたか」を見ます |

- 合格は80点以上です。
- 採点のきびしさは、先生用画面で3段階に切り替えられます。
- 結果画面では、はかせが「よかったところ」と「次のめあて」を1つずつ伝えます。
- 聞き取りにくかった部分は、本文にオレンジの波線で表示します。

**限界について**

- 音声認識は聞き取れない部分を推測で補うため、小さな読み間違いや発音のあいまいさを見逃すことがあります。発音の細かい評価はできません。
- 強弱の評価は目安です。
- 音声認識は漢字まじりの文字を返すため、アプリの中の辞書（`READING_DICT`）でひらがなに戻してから比べています。

## 課題の追加・変更

`index.html` の `STAGES` に課題が並んでいます。1問は次のように書きます。

```js
{ id: 's3-1', lines: ['[赤|あか]い りんごを [食|た]べる。'], pic: ['🍎', '😋'], bg: 'room' },
```

| 項目 | 書き方 |
|---|---|
| `id` | 課題を区別する名前です。ほかの課題と重ならないようにします。記録と結びついているので、あとから変えないでください |
| `lines` | 読む文です。1行ずつ配列に書きます。`[漢字\|よみ]` でふりがなを付けます。半角スペースは分かち書きのすきまになります |
| `pic` | 挿絵にする絵文字です |
| `bg` | 挿絵の背景です：`sky` `grass` `sun` `rain` `room` `sea` `night` `snow` `flower` |
| `title` | お話・詩の題名です（省略できます） |
| `tts` | 機械の声で読み上げる文です（省略できます。読み間違えるときに使います） |

- ひらがなで書いた言葉が音声認識で漢字になって返ってくる場合は、`READING_DICT` に `'漢字': 'よみ'` を追加すると、正確さの判定が正しくなります。
- 課題の `[漢字|よみ]` は、`READING_DICT` に書かなくても自動で使われます。

## 注意事項

- **音声の送信**：読みの正確さを判定するため、Chromeの音声認識が声をGoogleのサーバーに送って文字にします。
- **データの保存場所**：記録・録音・お手本は、そのChromebookのブラウザの中（IndexedDB と localStorage）にだけ保存し、ほかのサーバーには送りません。
- **データが消えるとき**：Chromeの閲覧データを消すと、記録も消えます。ときどき「バックアップを書き出す」で保存してください。端末を替えるときも、バックアップから元にもどせます。
- **暗証番号を忘れたとき**：暗証番号を元にもどす機能はありません。Chromeの設定からこのサイトのデータを消すと最初からやり直せますが、記録も消えます。
- **教材の出典**：
  - お話と詩は、このアプリのためのオリジナルです。
  - 早口言葉は、昔から伝わるものです。
  - 準備運動の「あめんぼ あかいな…」は、北原白秋「五十音」（著作権の保護期間は満了）から引用しています。
- **使っているもの**：React、Babel、Tailwind CSS、BIZ UDPゴシック（Google Fonts）をインターネット経由で読み込んでいます。
