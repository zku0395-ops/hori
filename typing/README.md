# キャプテン・キーボの タイピング うちゅうりょこう（タイピング練習アプリ）

小学校の特別支援学級向けの、キーボード（ローマ字入力）のタイピング練習アプリです。
宇宙船の船長ロボット「キャプテン・キーボ」と一緒に、子どもは自分のロボットを連れて、キーボードの「ほし」を順にめぐります。

- ホームポジションから始めて、キーの段 → 数字 → ひらがな（ローマ字）→ ことば → 文 と、スモールステップで進みます。
- 1問できるごとにコインが1まいもらえます。コインで「おみせ」の品物（16しゅるい × 10こ ＝ 160こ）を買い、「ずかん」に集めます。
- 品物の値段は「ふつう・ごうか・ちょうごうか・でんせつ」の4段階です。
- 30問ごとに「プレゼントボックス」が1つ開き、まだ持っていない品物が1つ出ます。
- 「ロボットの ぶひん・ぼうし・からだ・はいけい・アクセサリ」を買うと、「ガレージ」で自分のロボットに付けかえられます。
- ほしをクリアすると、そのほしの文字で遊ぶゲーム「いんせきを うちおとせ！」が開きます。
- 形は、漢字アプリと同じ「Apps Script だけ」です。子どもは名簿の名前のボタンを押して始めます。
- 問題のデータ・ローマ字のしくみ・絵は、GitHub Pages（`https://zku0395-ops.github.io/hori/typing/`）から読みこみます。Apps Script に貼り付けるファイルを短くするためです。

## できること

| 項目 | 内容 |
|---|---|
| ほし（ステージ） | 本編16（なかよし星〜ぶん星）と、はってん2（ながい ぶん星・カタカナ星） |
| 入力 | ローマ字入力。画面には教科書と同じ書き方（し＝si、ち＝ti、つ＝tu、ふ＝hu、じ＝zi、しゃ＝sya）を出します。shi・chi・tsu・fu・ji・sha・cha・ja と打っても正解です |
| 「ん」「っ」 | 「ん」は画面に nn と出します。次の音が あいうえお・や行・な行 でなければ、n 1つでも正解です。「っ」は次の音のはじめのキーを2回（xtu・ltu でも正解） |
| 文 | ことばの あいだの すきま（分かち書き）は打たなくてよいです。「、」はコンマ、「。」はピリオドのキーです |
| 1回の長さ | 30問（先生用画面で 10問・20問 にもできます）。なかよし星だけは10問です。途中でやめても「つづきから」始められます |
| 画面のキーボード | 学校の Chromebook と同じ並び（JIS）です。次に押すキーが光ります。キーは指ごとに色分けします（こゆび＝ピンク、くすりゆび＝きいろ、なかゆび＝みどり、ひとさしゆび＝あお） |
| 手の絵 | 次に押す指を、手の絵で光らせます |
| いんせきを うちおとせ！ | クリアしたほしの文字が、いんせきに書かれて落ちてきます。打つとロボットのビームでこわれます。速さは5段階（はじめは「とても ゆっくり」）。下まで落ちても失敗にはせず、また上から出てきます |
| ごほうび | 1問で1コイン（ヒントを使っても同じ）。ほしを初めてクリアすると、ボーナスで5コイン。30問ごとにプレゼントボックス（まだ持っていない品物が1つ出ます。ふつうが出やすく、でんせつはめったに出ません） |
| おみせ・ずかん | 16のたな × 10こ。のりもの・たべもの・デザート・でんせつの いきもの・どうぶつ・ぶんぼうぐ・ぶき（ものがたりの どうぐ）・やさい・くだもの・のみもの・でんかせいひん と、ロボットに つける もの（ぶひん・ぼうし・からだ・はいけい・アクセサリ）。1つのたなを全部そろえると称号（例：「やさい はかせ」）がもらえます |
| 値段の段階 | どのたなも、ふつう 4こ（5コイン）・ごうか 3こ（15コイン）・ちょうごうか 2こ（30コイン）・でんせつ 1こ（60コイン）。品物のカードに段階の札が付き、わくの色が変わります（でんせつは金色に光ります） |
| ガレージ | ロボットの色（8色）と、買ったもの（からだ・ぼうし・アンテナ・め・むね・うで・あし・アクセサリ・はいけい）を付けかえます。ぼうしをかぶると、アンテナはかくれます。はいけいは、ガレージとけっかの画面で出ます |
| 声 | キャプテン・キーボのセリフと問題を読み上げます（はじめは0.8倍の速さ）。キーボか「🔊 もういちど」を押すと、もう一度聞けます |
| 先生用画面 | 暗証番号4けたで開きます。記録の確認（まちがえやすいキー・音、速さ、正しく打てた割合）、設定、記録の送信、CSV書き出し、バックアップ、記録の消去ができます |
| 全員の記録 | 結果は先生のGoogleスプレッドシートへ届きます。進み具合・コイン・集めたものも、スプレッドシートに保存します |

## ステージ構成

| ほし | 名前 | 練習すること |
|---|---|---|
| 0 | なかよし星 | キーボードの見方、F と J のでっぱり、ホームポジション（説明のあと F と J を10問） |
| 1 | ホームポジション星1 | F J D K（ひとさしゆび・なかゆび） |
| 2 | ホームポジション星2 | S L A ; G H（と、1のふくしゅう） |
| 3 | うえのだん星 | Q W E R T Y U I O P |
| 4 | したのだん星 | Z X C V B N M |
| 5 | すうじ星 | 1〜0 |
| 6 | あいうえお星 | あ い う え お |
| 7 | かさた星 | か行・さ行・た行 |
| 8 | なはま星 | な行・は行・ま行 |
| 9 | やらわ星 | や行・ら行・わ行・ん |
| 10 | てんてん・まる星 | が・ざ・だ・ば・ぱ行 |
| 11 | ちいさい「っ」星 | きって・がっこう など |
| 12 | きゃきゅきょ星 | きゃ・しゅ・ちょ など |
| 13 | ことば星1 | 2〜3もじの ことば |
| 14 | ことば星2 | 4〜6もじの ことば |
| 15 | ぶん星 | みじかい ぶん（「いぬが はしる。」など） |
| はってんA | ながい ぶん星 | 「、」の ある ながい ぶん（はじめは閉じています） |
| はってんB | カタカナ星 | カタカナの ことば。のばす ぼう「ー」（はじめは閉じています） |

- 1〜5（キーのほし）：その ほしで習うキーを中心に出し、4問に1問くらい、前のほしのキーをまぜます。はじめの3問は、新しいキーを順に出します。
- 6〜10・12（ひらがなのほし）：1回の 3ぶんの2 は1もじずつ、のこりの 3ぶんの1 は その ほしまでの もじで できた ことばです。5問に1問くらい、前のほしの もじをまぜます。
- ひらがなのほしの ことばは、その ほしまでに習った もじ だけで作っています（`node typing/tools/check.js` で点検できます）。
- 前のほしをクリアすると、次のほしが開きます。クリアしたほしは何回でもできます。
- ことばと文の一覧は `data/mondai.js` にあります。

## 支援の工夫

- **ヒントは3段階**です。同じ音で2回まちがえるとヒントボタンが光り、3回まちがえると一番くわしいヒントが自動で出ます。

  | | 内容 |
  |---|---|
  | まちがえたとき | 「おしいね」と声をかけ、押したキー（赤い ✕）と正しいキー（光る）を見せます。音は小さな音です |
  | ヒント1（ことば） | 例：「『か』は、はじめに K、つぎに あいうえおの A だよ」「ちいさい『っ』は、つぎの もじの はじめの キーを 2かい おすよ」。ローマ字を消しているときは、ローマ字を出します |
  | ヒント2（指） | 手の絵で指を光らせ、「みぎての ひとさしゆびで U を おそう」と声で知らせます |
  | ヒント3（つづり） | 「『け』は K、E。つぎは K だよ」と、つづりを1文字ずつ読みます |

- 時間制限はありません。いんせきのゲームも、下まで落ちて失敗になることはありません。
- ゲームは「⏸ ひとやすみ」で止められます。画面の外を押してキーボードがきかなくなったときは、自動で止まり「がめんを タッチしてね」と出ます。
- 日本語入力（かな）のままのときは、「『英数』キーを おしてね」と知らせます。
- 問題の画面は背景をすっきりさせています。にぎやかな絵は、ちず・おみせ・ゲームだけで使います。
- 上達してきたら、先生用画面で「キーを光らせない」「ゆびの いろわけを ださない」「ローマ字を ださない」にすると、キーボードを見ないで打つ練習になります（まちがえてヒントが出たときは見えます）。

## ファイル構成

```
typing/index.html          アプリ本体（Apps Script の HTML ファイル「index」に貼り付けます）
typing/コード.gs            スプレッドシートとつなぐプログラム（Apps Script の「コード.gs」に貼り付けます）
typing/data/romaji.js      ローマ字のしくみ（どの打ち方でも正解にする）
typing/data/mondai.js      ほし・ことば・文・おみせの品物のデータ
typing/img/                キャプテン・キーボ（ふつう・よろこぶ・かんがえる）・宇宙の背景の絵（Canva で作成）
typing/tools/check.js      問題データの点検（node typing/tools/check.js）
typing/tools/test_gas.js   コード.gs のテスト（node typing/tools/test_gas.js）
```

- `data/` と `img/` は、GitHub Pages から読みこみます。ことばや文を直したときは、`data/mondai.js` を直して `main` に入れるだけで、Apps Script を貼り直さなくても全員の画面に反映されます。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/typing/` を開きます。
   - 「おためしモード」で動けば、問題のデータと絵の公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「タイピング 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。
4. **入力モードを「英数」にしておきます。** 日本語入力（かな）のままでも動くことが多いですが、「にほんごの モードに なって いるよ」と出たら、キーボードの「英数」キーを押します。
5. 画面の外（アドレスバーなど）を押すと、キーボードがきかなくなります。そのときは、アプリの画面を1回タッチします。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、キーボードの絵が小さくなります。また、キーを打つ前に毎回画面をタッチする必要が出ます。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

1. 名前を選ぶ画面の右下（学習中は右上）の **🔒** を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「せってい」で変えてください。**

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの クリアしたほしの数・コイン・集めた数・打った問題の数・正しく打てた割合・はやさ・最後に学習した日・まちがえやすいキー（上位3つ）・まちがえやすい音（上位3つ）。クラス全体の まちがえやすいキー（キーボードの絵で、まちがいが多いキーほど赤い）と、まちがえやすい音の一覧 |
| 子どもごと | ほしごとの結果（問題の数・まちがえずにできた割合・正しく打てた割合・はやさ）、はやさの のび（日ごと）、まちがえやすいキー（キーボードの絵と、どの指のキーか）、まちがえやすい音 |
| 子どもごと（ボタン） | 全部開く（その子だけ、すべてのほしを開く）、はってんを開く、コインを足す・引く、この子の記録を消す |
| せってい | 読み上げの速さ、文字の大きさ、1回の問題の数（10・20・30）、キーを光らせるか、指の色分け、ローマ字を出すか、いんせきのゲームを開くか、効果音、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、全員の記録を消す |

- **はやさ** は、れんしゅうで 1分間に押したキーの数です（いんせきのゲームはふくみません）。考えて止まっている時間は、1回5秒までしか数えません。
- **正しく打てた割合** は、押したキーのうち、まちがえなかったキーの割合です。
- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。

## 全員の記録を見る

- スプレッドシートの **「きろく」** シートに、1問ごとの結果が入ります。

  | 日時 | なまえ | ほし | しゅるい | もんだい | けっか | まちがい | ヒント | まちがえた キー | まちがえた おと | うった キー | びょう | ID |
  |---|---|---|---|---|---|---|---|---|---|---|---|---|

  - ほし：0〜15、はってんA・はってんB
  - しゅるい：「れんしゅう」または「ゲーム」
  - けっか：○＝まちがえず、ヒントも使わずに打てた　△＝まちがえてから、またはヒントを使って打てた
  - まちがい：まちがえて押したキーの数　ヒント：使ったヒントの段階（0〜3）
  - まちがえた キー：「k>j」は「K を押すところで J を押した」という意味です
  - まちがえた おと：まちがえたときに打っていた音（例：「か」「っ」「しゃ」）
  - うった キー：その問題で打ったキーの数　びょう：打つのにかかった時間
- **「まとめ」** シートに、子どもごと・ほしごとの結果と、まちがえやすいキー・音が入ります。先生用画面を開いたとき、またはメニュー **キーボ → まとめを更新する** で更新されます。
- **「名簿」** シートのB列に、進み具合・コイン・集めたもの・ロボットの色と部品が入ります。ちがう Chromebook を使っても「つづきから」始められます。
- 記録は5問ごとと、やめたとき・終わったときに送ります。ネットが切れていたときの記録は、その Chromebook にためておき、つながったときに送り直します。同じ記録は二重に書きません。

## 注意事項

- **個人情報**：名簿には、呼び名かひらがなの名前だけを入れてください。
- **絵**：キャプテン・キーボと宇宙の背景は、先生の Canva で、このアプリのために作った画像です。子どものロボット（ぶひん・ぼうし・からだ・はいけい・アクセサリをふくむ）・ほし・手とキーボードの絵は、このアプリのための自作の絵（SVG）です。品物の絵は絵文字です。
- **ことば・文**：すべて、このアプリのためのオリジナルです。
- **効果音**：このアプリのためのオリジナルです（プログラムで作っています）。
- 参考にしたタイピング練習アプリ（「いきもの」を打ってたおす形）の考え方をもとにしていますが、キャラクター・絵・ことば・プログラムは、すべてこのアプリのために作りました。
- 問題のデータと絵は GitHub Pages から読みこむので、ネットにつながっている必要があります。
- 「データを よみこめませんでした」と出るときは、`https://zku0395-ops.github.io/hori/typing/` が開けるか確かめてください。
- 「止まった」「開かない」ときは、まず `index.html` の貼り付けが最後（`</html>`）まで入っているかを確かめてください。

## これから相談して決めること

- ことばと文の見直し（子どもの生活に合わせて入れかえる。`data/mondai.js` を見て、合わないものを教えてください）
- 画面のローマ字の書き方（いまは教科書と同じ si・ti・tu・hu。学校で ヘボン式（shi・chi・tsu・fu）を先に教えているときは、切りかえを付けます）
- 画面のキーボードの文字（いまは実物と同じ大文字。ローマ字は小文字で出しています）
- 2〜3キーを続けて打つ練習（例：「fj」「asdf」）を、キーのほしに入れるか
- ロボットに名前を付けられるようにするか
- 品物の値段と、プレゼントボックスの出やすさ（使ってみて、たまりすぎ・たりなすぎがあれば調整します）
- アクセサリを2つ以上同時に付けられるようにするか
- 記号（？！）や、ことばの間のスペースを打つ練習を入れるか
