# ChatGPT で作る絵の注文書（ワケルンの ぶんすう うちゅう パトロール）

絵がそろうまでは、アプリは自作の SVG と絵文字で動きます。
作った絵は `wakerun/img/` に置き、`data/data.js` の `IMAGES` にファイル名を足すと、その絵が使われます。

## 共通のルール

- 参考の画像のうち、**素材サイトの透かしが入っているロボットの絵は、ChatGPT に読みこませません**。下の「ことば」だけで作ってもらいます。
- タイピングロボ2の画面・宇宙船の絵も、読みこませません。雰囲気（明るい3Dのおもちゃ風、やわらかい光、宇宙）だけを、ことばで伝えます。
- 文字は絵に入れないでもらいます（ひらがなはアプリが出します）。
- 形式：PNG で作り、WebP（`.webp`）に変えて保存します（ファイルを小さくするため）。
- ロボットは **背景を透明** にしてもらいます。

## 1. ワケルン（3まい）

| ファイル名 | 表情 |
|---|---|
| `wakerun_normal.webp` | ふつう（にっこり） |
| `wakerun_happy.webp` | うれしい（目が ^ ^、両手を上げる） |
| `wakerun_think.webp` | かんがえる（首をかしげる） |

ChatGPT にわたす文（1まいめ）：

> 子ども向け学習アプリの主人公の、オリジナルの小さなロボットを描いてください。
> 3Dのおもちゃのような、つやのある、やわらかい雰囲気。全身、正面、立ちポーズ。背景は透明。
> 体は白、ふちどりと関節は明るい青。頭は大きく、角の丸い横長の四角。顔は黒いガラスのバイザーで、その中に水色に光る丸い目と小さな笑った口。ほっぺは うすいピンク。
> 頭のてっぺんに短いアンテナがあり、先に黄色く光る玉。耳の位置に青い丸いパーツ。
> 体は小さく丸い。胸に、丸いピザを4つに分けて1つだけ黄色く光るマーク。
> 手足は短く、足は青い。正方形の画像。頭のてっぺんが画像の上から10%くらい、足が下から5%くらいになるように、まん中に大きく。
> 文字は入れないでください。

2まいめ・3まいめ：「同じロボットで、表情を（うれしい／かんがえる）に変えてください。大きさと位置は同じに」と頼みます。

## 4. 落ちてくる形（まるごとの絵）

切れ目のない「まるごと」の絵を作ってもらいます。分ける線と光る場所は、アプリが絵の上にかきます（大きさが正確になるように）。
真上から見た平らな形で、まん中に大きなものを置かないようにしてもらいます。

| ファイル名 | 形 |
|---|---|
| `piece_pizza.webp` | ピザ（入れました） |
| `piece_sand.webp` | サンドイッチ（正方形の食パン） |
| `piece_ufoR.webp` | まるい ユーフォー（ふちだけにライト） |
| `piece_ufoS.webp` | しかくい ユーフォー（ふちだけにライト） |

## 5. まだ絵にしないもの

- まる・しかく（図の形）は、アプリの SVG でかきます。
- ぼうし・アクセサリ・えんしゅつは絵文字です。

## 絵を足したあと

1. `wakerun/img/` に置きます。
2. `wakerun/data/data.js` の `const IMAGES = [];` に、ファイル名を足します（例：`const IMAGES = ['wakerun_normal.webp', 'bg_home.webp'];`）。
3. `main` に入ると、Apps Script を貼り直さなくても絵が出ます（絵とデータは GitHub Pages から読みこみます）。
