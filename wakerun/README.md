# ワケルンの ぶんすう うちゅう パトロール（分数を図で見分けるアプリ）

小学校の特別支援学級向けの、分数（1/2・1/4・1/8・1/3）を図で見分けて選ぶ学習アプリです。
主人公はロボットの「ワケルン」です。子どもは、ワケルンと一緒に宇宙をパトロールします。

- 宇宙から、ピザ・まる・まるい ユーフォー・しかく・サンドイッチ・しかくい ユーフォー が落ちてきます。
- どれも等分してあり、1つ分だけが黄色く光っています。
- 「1/2 を さがせ！」のコーナーでは、落ちてくるものの中から 1/2 のものをタッチします。
- 見つけるたびにコインが1枚もらえます。コインで、ワケルンの はいけい・からだ・ぼうし・アクセサリ・すがた・えんしゅつ を買えます。

## できること

| 項目 | 内容 |
|---|---|
| 学習内容 | 1/2・1/4・1/8・1/3 を図で見分ける（等分した1つ分）。ひとしく分けていない形との見分け。はってんで、ななめに分けた形と、2つ分が光る形 |
| 形 | ピザ・まる・まるい ユーフォー（まるい形）、しかく・サンドイッチ・しかくい ユーフォー（しかくい形）の6しゅるい。分ける線と光る場所が正確になるよう、プログラムの絵（SVG）でかいています |
| 進め方 | さがせ は、正解を10こ見つけたら「1かい」クリアです（5〜10分）。1つのステージは3かいでクリアです。えらんで みよう は8問で1かい、2かいでクリアです。途中でやめても、次は続きから始められます |
| 時間 | 時間制限はありません。下まで落ちても失敗にはならず、また上から落ちてきます |
| 速さ | 5段階（とても ゆっくり〜とても はやい）。自動では速くなりません。先生用画面で決めます |
| ごほうび | 正解1こでコイン1まい、1かいクリアでボーナス5まい。ヒントを使っても同じようにもらえます |
| おみせ | 6しゅるい × 12こ ＝ 72こ。値段は4段階（ふつう・ごうか・でんせつ・ちょうでんせつ）。買ったものは「そうびする」で付けかえられます |
| ずかん | かたち ずかん（6つの形 × 4つの分数 ＝ 24こ）、しょうごう、レベル |
| 文字 | ひらがなと分かち書きです。漢字は使っていません。分数は教科書と同じ たての書き方で出し、「にぶんの いち」と読み上げます |
| 声 | ワケルンのセリフを読み上げます（ワケルンか「🔊 もういちど」を押すと聞き直せます） |
| 先生用画面 | 暗証番号4けたで開きます。分数ごと・形ごとの結果、まちがいの しゅるい、設定、CSV書き出し、バックアップができます |
| 全員の記録 | 1こ見つけるたびに、結果が先生のGoogleスプレッドシートへ届きます |

## ステージ構成

| ステージ | 内容 | まちがいの形 |
|---|---|---|
| 0-1 であう | 落ちてこない画面で、ピザとしかくを「✂️ わける」→ ばんごうで数える → 1つ分が光る → 光っているところをタッチ。1/2 → 1/4 → 1/8 → 1/3 の順 | なし |
| 0-2 えらんで みよう | 落ちてこない画面で「1/2 は どれ？」。1かい8問（1/2・1/4・1/8・1/3 を2問ずつ）。1かいめは2つ、2かいめは3つの中から選ぶ。1問の選択肢は同じ形（ピザならピザだけ）。2かいでクリア | ほかの分数（1/3 のときは 1/4 を必ずまぜる） |
| 1 1/2 を さがせ | 2つに分けた1つ分 | 1/4・1/8 |
| 2 1/4 を さがせ | 4つに分けた1つ分 | 1/2・1/8 |
| 3 1/8 を さがせ | 8つに分けた1つ分 | 1/2・1/4 |
| 4 1/3 を さがせ | 3つに分けた1つ分 | 1/2・1/4・1/8 |
| 5 まぜて さがせ | 1かいめ 1/2、2かいめ 1/4、3かいめ 1/8 か 1/3 | ほかの分数、ひとしく分けていない形 |
| 6 まとめ パトロール | 1かいの途中で「さがす分数」が変わる（「こんどは 1/4 を さがせ！」） | ほかの分数、ひとしく分けていない形 |
| はってん ななめに わけた かたち | しかくを ななめに分けた形（三角になるもの）もまざる | ほかの分数、ひとしく分けていない形 |
| はってん 2つぶん ひかる かたち | 2つ分が光っている形もまざる。途中で「さがす分数」が変わる | ほかの分数、ひとしく分けていない形、2つ分 |

- ステージ0から順に、前のステージをクリアすると次が開きます。
- はってんは、最初は閉じています。先生用画面で、子どもごとに開きます。
- クリアしたステージは、何度でもやり直せます（コインももらえます）。
- 1/4 は「たて・よこ 2つずつ」と「4本の帯」、1/8 は「4つ × 2つ」に分けます。まるい形は、まん中から等しく分けます。

## 支援の工夫

- **スモールステップ**
  - 最初に「であう」で、分ける → 数える → 1つ分が光る、を自分の手で確かめます。
  - 次に「えらんで みよう」で、落ちてこない画面で、ゆっくり2〜3つから選びます。まちがえた選択肢は消えて、もう一度選べます。
  - そのあとで、落ちてくる中から さがします。
  - 1つの分数を1つのステージで練習してから、まぜます。
  - 最初は「ほかの分数」だけをまぜます。慣れたステージで「ひとしく分けていない形」を足し、「2つ分が光る形」は はってんにしました。
- **まちがいやすい形を入れる**
  - 1/3 を さがすときに 1/4（分けた数を数えまちがえやすい）をまぜます。
  - 「2つに分けてあるけれど、大きさがちがう」形（2つに分けた1つ分のように見える）をまぜます。
- **まちがえたとき**
  - 小さな音が鳴り、その形は止まってゆれます。上に「1/8 だよ」「おなじ おおきさ じゃない」と出ます。
  - まちがい方に合わせて声かけをします。
    - ほかの分数：「これは 8つに わけた 1つぶん、1/8 だよ。2つに わけた ものを さがそう。」
    - 1/3 と 1/4 のまちがい：上に加えて「いくつに わけて あるか、かぞえて みよう。」
    - ひとしくない形：「2つに わけて あるけど、おおきさが ちがうね。」
    - 2つ分：「ひかって いる ところが 2つ あるね。」
  - コインはへりません。
- **ヒントは3段階**
  1. ことば：「1/2 は、2つに おなじ おおきさに わけた 1つぶん だよ。」
  2. 見本と ばんごう：左上に見本（まると しかく）が出て、落ちてくる形の全部のピースに 1・2・3… の番号が付きます。
  3. 答えを光らせる：正しい形が光り、落ちる速さが半分になります。
  - 同じ分数で2回まちがえるとヒントボタンが光り、3回まちがえると 3 のヒントが自動で出ます。
  - 1こ見つけると、ヒントは元にもどります。
- **画面・操作**
  - 「▶ スタート」を押すまで落ちてきません。ワケルンの説明を聞いてから始められます。
  - 「⏸」で止められます。
  - 落ちてくる数（2〜5こ）を先生が決められます。少ないほど さがしやすくなります。
  - 正しい形は、画面にいつも1こ以上あるようにしています。
  - ゲームの画面は、背景を暗くして形が見やすいようにしています。にぎやかな背景は、ホーム・おみせ・ずかんで使います。

## ファイル構成

```
wakerun/
├── index.html        アプリ本体（Apps Script の HTML ファイル「index」に貼り付けます）
├── コード.gs         Apps Script（シートの準備・記録の受け取り・先生用の集計）
├── data/data.js      ステージ・形・おみせの品物・レベルのデータ（GitHub Pages から読みこみます）
├── e_chatgpt.md      ChatGPT で作る絵の注文書
├── img/              ChatGPT で作った絵（いまは ワケルンの ふつう・うれしい・かんがえる）
├── tools/test_gas.js コード.gs のテスト（node wakerun/tools/test_gas.js）
└── tools/check.js    データと形の点検（ひとしく分けた形のピースが同じ大きさか など）
```

- 絵がそろうまでは、ワケルン・はいけい・すがたは自作の SVG と絵文字で出します。
- 絵を `img/` に置いたら、`data/data.js` の `IMAGES` にファイル名を足します（くわしくは `e_chatgpt.md`）。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/wakerun/` を開きます。
   - 「おためしモード」で動けば、データの公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「ワケルン ぶんすう 記録」）。ほかのアプリ（モカせんせいの ケーキやさん もふくむ）とは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `wakerun/index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、形が落ちる場所が小さくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

子どもの画面の右上 🔒（名前を選ぶ画面では「🔒 せんせい用」）を押し、暗証番号を入れます。はじめの番号は **1234** です。最初に「せってい」で変えてください。

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの クリアしたステージ・レベル・見つけた数・まちがえずに見つけた割合・まちがえたタッチの数・ヒント・コイン・いちばん にがてな分数・よくある まちがい。クラス全体の分数ごとの結果と、まちがいの しゅるい |
| 子どもごと | 分数ごとの結果（どの分数で つまずいているか。60%未満は赤、80%未満は黄色）と、まちがえてタッチしたもの（例：1/3 をさがして 1/4 をタッチ）。まちがいの しゅるい、形ごとの結果、ステージごとの結果。「全部開く」「はってん」を開く、コインを足す・へらす、この子の記録を消す |
| せってい | 読み上げの速さ、文字の大きさ、1回で見つける数（5・10・15こ）、落ちる速さ（5段階）、いっしょに落ちる数（2〜5こ）、効果音、暗証番号 |
| データ | まだ送れていない記録を送る、CSVで書き出す、バックアップの保存と元にもどす、全員の記録を消す |

## 全員の記録を見る

スプレッドシートの「きろく」シートに、1こ見つけるたびに1行ずつ記録が届きます。

| 列 | 内容 |
|---|---|
| ステージ | `s0`（であう）・`s0e`（えらんで みよう）・`s1`〜`s6`、はってんは `h1`・`h2` |
| かい | そのステージの何かいめか（1〜3） |
| さがす ぶんすう | 1/2・1/4・1/8・1/3 |
| みつけた かたち | 正しくタッチした形（ピザ など） |
| けっか | ○＝まちがえずに見つけた、△＝まちがえてから見つけた |
| まちがい | 見つけるまでに、まちがえてタッチした数 |
| ヒント | 使ったヒントの段階（0〜3） |
| まちがえた もの | 「まる:1/4・ピザ:ひとしくない」のように、形とその分数 |
| まちがいの しゅるい | ほかの ぶんすう・ひとしくない・2つぶん |

- 「まとめ」シートは、先生用画面を開いたときか、メニュー **ワケルン → まとめを更新する** で作り直されます。子どもごと・分数ごとの結果が出ます。
- 子どもの名前は、呼び名かイニシャルで登録してください。

## 注意事項

- 記録は、先生のスプレッドシートとその端末のブラウザに保存されます。ネットにつながらないときは端末にためておき、つながったときに送り直します。
- 同じ子どもが別の Chromebook を使っても、スプレッドシートの進み具合から続きができます。
- 形・ワケルン・背景・音は、すべてこのアプリのためのオリジナルです（形とワケルンは自作のSVG、品物は絵文字）。
- ChatGPT で作る絵は、ユーザーが作ります。参考にした画像のうち、素材サイトの透かしがある画像は ChatGPT に読みこませず、ことばで特徴だけを伝えます（`e_chatgpt.md`）。
- 分数の読み上げは「にぶんの いち」のように、ブラウザの声で読みます。

## これから相談して決めること

- ChatGPT の絵（ワケルン・すがた・はいけい）がそろったら、アプリに組みこむ。
- ワケルンの声を Gemini-TTS にするか（いまはブラウザの声のまま。様子を見て決める）。
- 2/4・2/8 などの「2つ分」を、はってんでどこまで あつかうか（いまは「まちがいの形」として出すだけ）。
- プリント（1/2・1/4・1/8・1/3 に色をぬる）を作るか。
