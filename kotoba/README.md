# ドラッチと ことばの ぼうけん（ことばの意味の学習アプリ）

小学校の特別支援学級向けの、国語の「ことばの意味」を学ぶアプリです。
小さなドラゴンの「ドラッチ」と一緒に、子どもは勇者になって冒険します。

- おはなし：せかいの「ことばの いし」がこわれて、ことばがモンスターになってにげだしました。モンスターに勝って、ことばを とりもどします。
- 1つの学年が1つの「ちほう」です。いまは1年生「はじまりの ちほう」・2年生「みなとの ちほう」・3年生「やまの ちほう」・4年生「そらの ちほう」です（240語）。5・6年生のちほうは、相談して足します。
- 1つのちほうに6つの場所があり、場所ごとに10語（ことばの なかま）を学びます。
- 1つの場所の流れは「①いみを えらぶ → ②ことばを えらぶ → ③ぶんで つかう」です。10語を5語ずつ「1くみ」「2くみ」に分けて行い、最後にボスと たたかいます。
- まちがえても負けません。正解するとモンスターに こうげきし、勝つとモンスターが なかまになります。
- 形は、九九・わり算・漢字アプリと同じ「Apps Script だけ」です。子どもは名簿の名前のボタンを押して始めます。
- ことばのデータと絵は、GitHub Pages（`https://zku0395-ops.github.io/hori/kotoba/`）から読みこみます。Apps Script に貼り付けるファイルを短くするためです。

## ステージ構成

### 1つの場所の流れ

| くみ | ステージ | 内容 | モンスター |
|---|---|---|---|
| 1くみ（1〜5語め）・2くみ（6〜10語め） | ① いみを えらぶ | ことばを見て、合う意味を3つから選びます | その場所の モンスター 1ぴき |
| | ② ことばを えらぶ | 意味を読んで、合うことばを3つから選びます | 同じ モンスターが 2ひき（A・B） |
| | ③ ぶんで つかう | 文の（　）に入ることばを3つから選びます。初めてクリアすると、その くみの5語を とりもどします | 同じ モンスターが 3びき（A・B・C） |
| ボス | 👑 ボスと たたかう | その場所の10語が まざって出ます（①②③の形がまざります）。勝つと次の場所が開きます | その場所の ボス |
| はってん | ✨ ただしい つかいかた | 「〇〇の つかいかたが ただしい 文は どれ？」3つの文から選びます。ボスに勝った場所で出ます | ボス |
| やどや | 🛏️ やどやで ふくしゅう | とりもどしたことばから出します。まちがえたことばが多めに出ます | 出ません |

- モンスターが2ひき・3びきのときは、問題の数を分けて HP にします（5問・3びきなら 2・2・1）。左の モンスターから じゅんに たおします。ねらっている モンスターは、名前のわくが 黄色く光ります。

- 前のステージをクリアすると、次のステージが開きます。
- 1年生のちほうの最後の場所（ときの とう）のボスに勝つと、2年生のちほうが開きます。同じように、2年生の最後の場所で3年生、3年生の最後の場所で4年生のちほうが開きます。2〜4年生の子は、先生用画面の「子どもごと」で、その学年のちほうを はじめから開けます。
- はってんは、はじめは閉じています。先生用画面の「子どもごと」で開きます。

## 支援の工夫

- **スモールステップ**：1つのことばを「意味を選ぶ → ことばを選ぶ → 文で使う」の順に、少しずつ使えるようにします。5語ずつの くみで行います。
- **意味は ひらがなと分かち書き**：意味と例文は短い文にし、すべて読み上げます。
- **まちがいやすい選択肢**：選択肢には、まちがいやすいことばを入れています。
  - はんたいの意味のことば（ふかい ↔ あさい、ふえる ↔ へる）
  - 音がにていることば（しらべる・くらべる）
  - 同じなかまの、にていることば（どうぐ・かぐ、きっと・たぶん）
  - ③ぶんで つかう では、文に入れても意味が通ってしまうことば（例：わくわく と びくびく）は出しません。
- **まちがえたとき**：まちがえた選択肢は うすくなって、もう選べなくなります。選んだことばの意味を教えて、まちがい方に合わせて声をかけます（例：「『あさい』は、『ふかい』の はんたいの いみの ことばだよ」）。まちがえたときの音は小さな音です。
- **ヒントは3段階** です。選択肢が3つなので、1回まちがえるとヒントボタンが光り、2回まちがえると一番くわしいヒント（答えが光る）が自動で出ます。

  | 問題 | ヒント1（ことば） | ヒント2（絵・選択肢を1つ消す） | ヒント3 |
  |---|---|---|---|
  | ①いみを えらぶ | そのことばを使った例文を読みます | 絵を出し、まちがいの選択肢を1つ消します | 答えが光ります |
  | ②ことばを えらぶ | ことばを（　）にした例文を読みます | 同じ | 同じ |
  | ③ぶんで つかう | （　）に入ることばの意味を読みます | 同じ | 同じ |
  | はってん | ことばの意味を読みます | まちがいの文を1つ消します | 同じ |

- **負けない たたかい**：まちがえても子どもの体力はへりません（モンスターが「ひらり！」とよけるだけ）。正解するたびにモンスターの体力がへり、さいごまで答えると必ず勝ちます。まちがえず・ヒントなしで答えると「かいしんの いちげき！」になります。
- **どこにいるか分かる たたかいの場面**：問題の上の たたかいの枠には、その場所の絵（村・森・どうくつ など）を出し、ぼうけんしゃと モンスターを大きく出します。問題と選択肢の部分は、白い わくで すっきりさせています。
- 時間制限はありません。

## ファイル構成

```
kotoba/index.html          アプリ本体（Apps Script の HTML ファイル「index」に貼り付けます）
kotoba/コード.gs            スプレッドシートとつなぐプログラム（Apps Script の「コード.gs」に貼り付けます）
kotoba/data/kotoba.js      ちほう・場所・ことば・モンスター・おみせ・しょうごうのデータ
kotoba/img/                ドラッチ・主人公・地図・場所・モンスターの絵（Canva で作成）
kotoba/tools/check.js      ことばのデータの点検（node kotoba/tools/check.js）
kotoba/tools/test_gas.js   コード.gs のテスト（node kotoba/tools/test_gas.js）
```

- `data/` と `img/` は、GitHub Pages から読みこみます。ことばや品物を直したときは、`data/kotoba.js` を直して `main` に入れるだけで、Apps Script を貼り直さなくても全員の画面に反映されます。
- 絵が読みこめないときは、ドラッチ・主人公・地図は自作の絵（SVG）、モンスターは絵文字が出ます。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/kotoba/` を開きます。
   - 「おためしモード」で動けば、ことばのデータと絵の公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「ことばの ぼうけん 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。

### 4. Googleサイトに置くとき

- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

1. 名前を選ぶ画面の右下（学習中は右上）の **🔒** を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「せってい」で変えてください。**

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの いまのステージ・とりもどした場所の数・ことばの数・ゴールド・問題の数・まちがえずに できた割合・多い まちがいの しゅるい・にがてな ことば・最後に学習した日。クラス全体の ことばの表（場所ごと）と、まちがいの しゅるい |
| 子どもごと | ステージごとの結果、ことばの表（場所ごと）、にがてな ことば、まちがいの しゅるい、まちがえた問題（多い順） |
| 子どもごと（ボタン） | 全部開く（その子だけ、すべてのステージを開く）、はってんを開く、2〜4年生の ちほうを開く、ゴールドを足す・引く、この子の記録を消す |
| せってい | 読み上げの速さ、文字の大きさ、1回の問題の数（3・5・10）、かんじの ひょうじ（だす・かくす）、効果音、おんがく（つかう・つかわない）、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、全員の記録を消す |

- **ことばの表**：場所を選ぶと、その場所の10語が「①いみ・②ことば・③ぶん・はってん」の表で出ます。それぞれの ます に「まちがえずに できた数 ／ 問題の数」を出し、割合で色をつけます（赤：60%未満、黄：60〜79%、緑：80%以上）。✖ は まちがえた回数、💡 は ヒントを使った問題の数です。
- **まちがえずに できた割合** は、まちがえず、ヒントも使わずに できた問題の割合です。
- **にがてな ことば** は、2回以上といて、まちがえずに できた割合が60%未満のことばです。
- **まちがいの しゅるい**

  | しゅるい | 内容 |
  |---|---|
  | はんたいの いみ | はんたいの意味のことばを選んだ（例：ふかい → あさい）。意味の向きを取りちがえている |
  | にている おと | 音がにていることばを選んだ（例：しらべる → くらべる）。音だけで選んでいる |
  | おなじ なかま | 同じなかまの、にていることばを選んだ（例：こんちゅう → しょくぶつ）。意味のちがいがあいまい |
  | ちがう ことば | 上のどれにも当てはまらない ほかのことばを選んだ |
  | つかいかた | はってん：使い方がおかしい文を選んだ |

- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。

## 全員の記録を見る

- スプレッドシートの **「きろく」** シートに、1問ごとの結果が入ります。

  | 日時 | なまえ | ステージ | ばしょ | もんだい | こたえ | けっか | まちがい | ヒント | まちがいの しゅるい | えらんだ こたえ | ことば | かたち | びょう | ID |
  |---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

  - ステージ：「1-1-A1」＝1年生の1ばんめの場所・1くみ・①いみを えらぶ。A＝1くみ、B＝2くみ。数字は 1いみ・2ことば・3ぶん（はじめの版にあった 0であう は なくしました）。「1-1-X」＝ボス、「1-1-H」＝はってん、「R」＝やどや
  - もんだい：「どうぐ（いみ）」など　こたえ：正しい答え（意味・ことば・文）
  - けっか：○＝まちがえず、ヒントも使わずに できた　△＝まちがえてから、またはヒントを使って できた
  - まちがい：まちがえた回数　ヒント：使ったヒントの段階（0〜3）
  - まちがいの しゅるい：上の表の しゅるい（2つ以上のときは「・」で区切ります）
  - えらんだ こたえ：まちがえて選んだことば・文
  - ことば：その問題のことば　かたち：いみ・ことば・ぶん・つかいかた
  - びょう：その問題にかかった時間
- **「まとめ」** シートに、子どもごと・ステージごとの結果と、まちがいの しゅるい・にがてな ことば・まちがえた問題が入ります。先生用画面を開いたとき、またはメニュー **ことばの ぼうけん → まとめを更新する** で更新されます。
- **「名簿」** シートのB列に、進み具合・ゴールド・ことば・なかま・そうびが入ります。ちがう Chromebook を使っても「つづきから」始められます。
- 記録は、やめたとき・終わったとき・1問ごとの区切りで送ります。ネットが切れていたときの記録は、その Chromebook にためておき、つながったときに送り直します。同じ記録は二重に書きません。

## 注意事項

- **個人情報**：名簿には、呼び名かひらがなの名前だけを入れてください。
- **絵**：ドラッチ・主人公・地図・場所・モンスターは、先生の Canva で、このアプリのために作ったオリジナルの絵です（Canva のデザイン「ドラッチ ことばの ぼうけん え（書き出し用）」に保存しています）。先生からいただいた参考の画像（ロールプレイングゲームの画面）は、Canva に読みこませず、「ドット絵・青空と草原・石だたみの道・村」などの雰囲気をことばで伝えるだけにしています。既存のゲームのキャラクターやモンスターは使っていません。品物・ことばの絵は絵文字です。
- **ことば・意味・例文**：このアプリのために書いたオリジナルの文です。ことばは、小学校の国語の教科書でよく出ることばと、学校の生活でよく使うことばから選びました。1年生のちほうは、1年生の教科書の後半〜2年生のはじめくらいのことばです。3年生は にている・はんたいの いみの ことばや かんようく、4年生は ことわざ・つなぎことば・たとえ・じゅくご です。ことわざ・かんようくは、昔から使われていることばです。
- **効果音・音楽**：このアプリのためのオリジナルです（プログラムで作っています）。
- **ことば**：子どもの画面は ひらがなと分かち書きです。漢字は、ことばの横の「かんじで かくと」の欄だけに使い、ふりがなを付けています。
- ことばのデータと絵は GitHub Pages から読みこむので、ネットにつながっている必要があります。
- 「データを よみこめませんでした」と出るときは、`https://zku0395-ops.github.io/hori/kotoba/` が開けるか確かめてください。
- 「止まった」「開かない」ときは、まず `index.html` の貼り付けが最後（`</html>`）まで入っているかを確かめてください。
