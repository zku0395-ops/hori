### アプリ（kotoba）の いまの すがた
- RPG風。案内役は小さなドラゴンのドラッチ。主人公（3しょくぎょう×2かたち×色）が、ことばを とりもどす冒険をします。
- ことばは **340語**：1年生80語（8か所）・2年生80語（8か所）・3年生90語（9か所）・4年生90語（9か所）。1か所10語（1くみ5語×2）。
- 1か所の流れ：①いみを えらぶ（モンスター1ぴき）→ ②ことばを えらぶ（2ひき）→ ③ぶんで つかう（3びき）→ ボス。はってん「ただしい つかいかた」は先生が開きます。
- モンスターは「あらわれた！」のときに「ピュッ」と出ます。勝つと なかまに なります（68ぴき）。
- 絵（ドラッチ・主人公・地図4まい・場所の背景34まい・モンスター68ぴき）は Canva で作りました。書き出し用の Canva デザイン：「ドラッチ ことばの ぼうけん え（書き出し用）」（ID `DAHY5nKzezY`）。
- 読み上げで まちがえやすい ことばは `index.html` の `SPEAK_FIX` で直しています（例：「はいて」→「履いて」）。
- アプリの版：`APP_VERSION = '1.0.6'`。`index.html` を変えたら版を上げ、先生が Apps Script に貼り付け直します（`データと絵`だけの変更なら貼り付け直しは いりません）。
- 先生の Apps Script のウェブアプリの URL は「そらの うえの がっこう」（`sora/apps.js` の `dracchikotoba`）に入っています。

### ワークシート（kotobaprint）
- 1まい＝1くみ（5語）、68まい。①せんで むすぶ ②○を つける ③文に 書く。学年・なまえ・がつ にち・できたかな？ の欄。こたえ（赤）つき。
- 「✨ はってん」：つかいかたが ただしい文に ○ ＋ じぶんで文を つくる。68まい。
- PDF は学年ごとに 16ファイル（`kotobaprint/pdf/`）。作り直し：`node kotobaprint/tools/make-pdf.js`

## 3. 先生（ユーザー）との約束（`CLAUDE.md` にも あります）

- 返事・コミットメッセージ・PR の説明は日本語。専門用語をさけ、「どこを押すか」まで書く。
- 新しく作るときは、番号つきの質問（おすすめつき）で相談し、「ok」と言われてから作る。
- PR は頼まれたときだけ作り、`main` にマージまでする。
- 作ったらブラウザ（Playwright）で動かして確かめ、スクリーンショットを見せる。
- ファイルを足したり消したりしたら `node toshokan/tools/mokuroku.js` で目録を作り直して一緒にコミット。
- `index.html` を変えたら、Apps Script に貼る「貼り付け用 .txt」を渡すと喜ばれる。

## 4. これから相談して決めること

- アプリ：5・6年生の ちほうを作るか。むずかしすぎる・やさしすぎることばの入れかえ。おみせの値段。プリントやKahoot!の ほかの学年。
- ワークシート：場所ごとの「まとめ テスト」（10語）を作るか。4年生の字の大きさ（ことわざの場所で 少し小さく なる）。
- Kahoot!：ほかの学年（1・3・4年生）も作るか。取りこみで止まったときの直し。
