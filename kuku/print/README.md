# くく しゅぎょう プリント（かけ算九九）

かけ算九九の学習アプリ「忍者九九修行」（[kuku/](../README.md)）と同じ順番で練習する、紙のプリントです。
アプリの「しのびの いりぐち」と、1〜9の段の ⓪であう・②じゅんばん・③ばらばら・④にんじゃ しけん を、紙で練習できます。

- プリントを作るページ：`https://zku0395-ops.github.io/hori/kuku/print/`
- できあがった PDF：`kuku/print/pdf/` にあります（カラー・しろくろ・こたえ）
- 用紙は **A4たて** です。記録はとりません。

## できること

| 項目 | 内容 |
|---|---|
| しのびの いりぐち | ① 1つ分は いくつ？・② 〇の △つ分・③ かけざんの しき の3段階 × 各5まい（15まい） |
| 段の プリント | 5・2・3・4・6・7・8・9・1の段（アプリと同じ順）× ⓪・②・③・④ の4段階 × 各5まい（180まい） |
| 色 | カラー（かけられる数＝あお、かける数＝ピンク、こたえ＝みどり。アプリと同じ）・しろくろ |
| こたえ | すべてのプリントに、こたえのページがあります（こたえは 赤） |
| プリントの上 | 段・段階・その○、タイトル、子どもの忍者と その階の あいて、がつ にち、ねん くみ、なまえ |
| できたかな？ | 3つの顔（にっこり・ふつう・うーん）に○をつけます |
| ごほうび | ④にんじゃ しけん に「ごうかく シール」を はる わくがあります |
| 名前 | PDF は ねん・くみ・名前の欄が空いています。作るページで入れると、入った形で印刷できます |
| 問題 | PDF は決まった問題です。「べつの もんだいに する」を押すと、新しい問題とこたえを作ります |

## ステージ構成

| 場所 | 段階 | 内容 | 1まいの 問題 |
|---|---|---|---|
| しのびの いりぐち | ① 1つ分は いくつ？ | おぼんの しゅりけんを見て「1つの おぼんに □まい」 | 3もん |
| | ② 〇の △つ分 | 「□まいの □つぶん」 | 3もん |
| | ③ かけざんの しき | 「3まいの 4つぶん」を見て「□ × □ ＝ □」 | 3もん |
| 1〜9の段 | ⓪ であう | おぼんが 2・3・4（5）まいと ふえていきます。「□まいの □つぶん」と「□ × □ ＝ □」 | 3もん |
| | ② じゅんばん | ×1 から ×9 まで じゅんばんに。となえかたの 前の半分（「ごいちが …」）を 小さく書いています | 9もん |
| | ③ ばらばら | じゅんばんを ばらばらに。となえかたは ありません | 9もん |
| | ④ にんじゃ しけん | ③と同じ形。「ごうかく シール」の わく つき | 9もん |

- しのびの いりぐち の おぼんは 2〜5まい、しゅりけんは 2〜5まいずつです。
- ⓪であう の おぼんは、2〜5まいから 3つを 小さい じゅんに 出します。

## 支援の工夫

- **アプリと同じ絵と色**：おぼんと しゅりけんは アプリと同じ形です。□の わくの色も、アプリの しきの色と同じです。
- **数えやすい ならべかた**：しゅりけんが 4まいより 多いときは 2れつ、7まいより 多いときは 3れつに ならべます（9まいは 3×3）。しろくろで 印刷しても、りんかくで 数えられます。
- **こたえの わくは 約1.5cm**：大きな数字で 書けます。
- **ヒント**：②じゅんばん の 10ばんめの わくに「こたえは ○ずつ ふえるよ」、③ばらばら には「こまったら、○の だんを こえに だして となえて みよう」と書いています。
- **となえかたは 前の半分だけ**：②じゅんばん では「ごいちが …」のように、こたえの部分は かくしています。こたえの ページには ぜんぶ書いています。
- **アプリの 階と つながる**：プリントの上に、その段の 階（5の段なら 1かい）の 子どもの忍者と あいてを のせています。
- ひらがなと分かち書きで書いています。漢字は「九九・分」だけで、ふりがなを付けています（絵の中の ことばは ひらがなです）。

## ファイル構成

```
kuku/print/index.html          プリントを作るページ（印刷もここから）
kuku/print/pdf/                できあがった PDF（どれも 195まい・同じ問題・同じ順番）
  くくプリント_1_カラー.pdf
  くくプリント_2_しろくろ.pdf
  くくプリント_3_こたえ.pdf
kuku/print/tools/make-pdf.js   PDF を作り直すプログラム
```

- ページの順番：しのびの いりぐち ①＝1〜5、②＝6〜10、③＝11〜15、5の段＝16〜35、2の段＝36〜55、3の段＝56〜75、4の段＝76〜95、6の段＝96〜115、7の段＝116〜135、8の段＝136〜155、9の段＝156〜175、1の段＝176〜195ページ。
- 1つの段の中は、⓪であう・②じゅんばん・③ばらばら・④にんじゃ しけん の順に 5まいずつです（5の段なら ⓪＝16〜20、②＝21〜25、③＝26〜30、④＝31〜35）。
- 段・あいて・となえかたは、アプリの `kuku/data/mondai.js` を そのまま読みこんでいます。

## 公開の手順

### 1. GitHub Pages で公開する

- 変更を `main` に取り込むと、数分後に `https://zku0395-ops.github.io/hori/kuku/print/` で開けるようになります。
- Apps Script やスプレッドシートは使いません。

### 2. 印刷する

**PDF をそのまま使うとき**

1. 作るページの上にある「📄 カラー」「📄 しろくろ」「📄 こたえ」のボタンを押します。PDF が新しいタブで開きます。
2. 右上の印刷のアイコン（または Ctrl＋P）を押します。
3. 一部だけ印刷するときは、「ページ」で「カスタム」を選び、ページ番号を入れます（例：5の段の ②じゅんばん だけなら「21-25」）。

**作るページから印刷するとき（名前入り・べつの問題）**

1. 「1. プリントを えらぶ」で、印刷したい段と段階にチェックを入れます。
2. 下の「どれも その ○ 〜 ○」で、何まい目から何まい目までかを選びます。
3. 「🎨 カラー」か「⚫ しろくろ」を選びます。
4. ねん・くみ・名前を入れると、入った形で印刷されます。空けておくと、子どもが手で書けます。
5. こたえも印刷するときは「こたえの ページも つける」にチェックを入れます。
6. 「🖨 いんさつ する」を押します。
7. 印刷の画面で、用紙は「A4」、倍率は「100%（実際のサイズ）」、「背景のグラフィック」をオンにします。

- 「べつの もんだいに する」を押すと、PDF とはちがう問題になります。「もとの もんだいに もどす」で、PDF と同じ問題にもどります。

## 注意事項

- **絵**：子どもの忍者・あいて・カゲマルせんせいの絵は、アプリと同じ画像です（Canva で作成）。おぼん・しゅりけん・わく・顔のしるしは、プログラムで描いています（オリジナル）。
- **白黒で印刷するとき**：「しろくろ」の PDF を使ってください。おぼんが うすい はいいろになり、□の色わけが なくなります。
- **使っているもの**：BIZ UDPゴシック（Google Fonts）をインターネット経由で読み込んでいます。
- **PDF を作り直すとき**：`node kuku/print/tools/make-pdf.js` を動かします。Playwright があれば それを、なければ パソコンの Edge か Chrome を使います。

## これから相談して決めること

- てんしゅかく（1〜9の段が ぜんぶ まざる）・はってん（こたえから しきを さがす・□を もとめる）の プリントを作るか
- 九九の ひょう（あなうめ）を作るか
- ④にんじゃ しけん に 点数の欄・まちがえた九九に○をつける欄を入れるか
- ②じゅんばん の となえかたを、こたえまで ぜんぶ書くか
