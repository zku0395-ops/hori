# 忍者九九修行 引き継ぎメモ（Claude 用）

このメモは、九九アプリ（`kuku/`）を別の Claude（デスクトップ版など）で続けて作るための引き継ぎです。
先に、リポジトリの `CLAUDE.md`（作り方の決まり）と `kuku/README.md`（アプリの説明書）を読んでください。

## 1. いまの状態（2026年11月）

- 画面の版：`APP_VERSION = '1.3.0'`（`kuku/index.html`）。1.3.0 で「まおうの もり」を足しました。
- 先生は Apps Script に `index.html` と `コード.gs` を貼って使っています（形B）。
  - `index.html` を直したら、先生に貼り直してもらいます。`.txt` の「貼り付け用」ファイルを SendUserFile で渡すと喜ばれます。
  - `data/mondai.js` と `img/` は GitHub Pages から読みこむので、`main` に入れるだけで反映されます（貼り直し不要）。
- `コード.gs` は最初に作ったあと変えていません。記録の形式（きろくシートの見出し・ID・ステージの id）は変えないでください。

## 3. 絵の作り方（Canva）

- 書き出し用の Canva デザイン：**DAHYv8oqW3c**「カゲマルせんせい 忍者九九修行 え（書き出し用）」（1200×900 のページが33まい）。
- 絵柄をそろえる見本の画像（Canva の media id）
  - あいて：`MAHYxk5crSs`（はんにゃ）。あいてを作るときは imageReferences にこれを入れる。
  - 子どもの忍者（とくべつな いろ）：`MAHYwV7vvXo`
- 手順
  1. `generate-image` で作る。あいては「6たいを1列に、白い背景、すきまを空けて」と頼む（LANDSCAPE_2_1）。
  2. デザインにページを足し（`add_page`）、`insert_fill` で絵を置き、`commit` する。
  3. `export-design` で PNG（2400×1800）。人物は `transparent_background: true`。
  4. 下の道具で切り分けて `kuku/img/` に WEBP で入れる。
- Canva は1まい作るごとに約25分の待ち時間がある（`quota_cooldown`）。その間は他の作業をするか、少し待ってからやり直す。

### 切り分けの道具（`kuku/tools/e/`。Python と Pillow を使う）
| ファイル | 使い方 |
|---|---|
| `cut.py` | `python3 cut.py 入力.png 出力.webp 512` 白い背景を すかし、まわりを切って正方形の WEBP にする |
| `split2.py` | `python3 split2.py 入力.png 出力の頭 人数` くっついていない あいてを、かたまりごとに切り分ける |
| `holes.py` | `python3 holes.py 入力 出力 600` うでと体の あいだなど、とじた白い すきまも すかす |
| `specks.py` | `python3 specks.py 入力 出力 0.004` となりの絵の はしなど、小さな かけらを消す |
| `panels.py` | `python3 panels.py 入力.png` 2×2 などの パネルの わくの位置を調べる |
| `rooms.py` | `python3 rooms.py 入力 x0,y0,x1,y1:下の余白:出力.webp` 背景を 1600×400 に切る（たたかいの場面用。ゆかが見える高さにする） |
| `cut6.js`・`sheet.js`・`rooms.js`・`holes.js`・`specks.js` | Python が ない パソコン用（node と sharp）。1章の「デスクトップ版で 進んだこと」を見る |

- あいてが くっついているときは、列の すきま（白の多い列）を調べて切るか、さかいめを見て多角形で消す。
- 切ったら、紺色の背景の上に6たい並べた見本を作って、目で確かめる。

## 4. 確かめ方

- データの点検：`node kuku/tools/check.js`（ステージ・あいて・ぼうけん・おみやげの数）
- `コード.gs` のテスト：`node kuku/tools/test_gas.js`
- ブラウザ：`kuku/tools/browser/bouken_test.js`・`mori_test.js`（Playwright）
  - クラウドの環境では unpkg などに つながらないので、`pw.js` が CDN を手元のファイルに おきかえる。
  - `kuku/tools/browser/vendor/` に、npm の `react@18.3.1`・`react-dom@18.3.1`・`@babel/standalone@7.24.7` を展開し、
    `npx tailwindcss@3.4.17 -i in.css -o tw.css --content ../../index.html` で `tw.css` を作っておく（`vendor/` はコミットしない）。
  - 自分のパソコン（インターネットに つながる）なら、`pw.js` を使わず、ふつうに `index.html` を開いても動く。
  - `OUT=スクリーンショットの置き場所 node bouken_test.js`
- 画面は Chromebook と同じ 1366×768 で確かめる。

## 5. 気をつけること

- `index.html` を直したら `APP_VERSION` を上げる。
- 読み上げは `fmtSpeech` を通る。数＋「つ」や「〜は」の読みに気をつける。
- 新しいクラス名（Tailwind）を足したときは、テスト用の `tw.css` も作り直す。
- 子どもの名前など個人情報はコミットしない。
