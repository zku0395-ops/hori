# 忍者九九修行（にんじゃ くく しゅぎょう）（かけ算九九の学習アプリ）

小学校の特別支援学級向けの、かけ算九九の学習アプリです。
忍者の「カゲマルせんせい」と一緒に、子どもは「みならい にんじゃ」になって、夜のお城にしのびこみます。

- お城の1つの階が、九九の1つの段です。下の階から上がっていき、最後は「てんしゅかく」を目指します。
- 段の順番は教科書と同じ **5 → 2 → 3 → 4 → 6 → 7 → 8 → 9 → 1** です。
- 1つの階の修行は「⓪であう → ①となえる → ②じゅんばん → ③ばらばら → ④にんじゃ しけん」の5つです。どれも9問（×1〜×9）です。
- ④にんじゃ しけん は、その階の **あいて**（忍者・妖怪・武者など）との たたかいです。まちがえずに答えると しゅりけんが当たり、あいての体力がへります。
- あいてを たおす（＝しけんに合格する）と、その階の **たからばこ** が開き、からくりが解けて次の階へ進めます。
- てんしゅかくを クリアすると **ぼうけん** が開きます。お城の外の8か所（じょうかまち〜おにがしま）で、48たいの あいてと たたかいます。
- 1問できるごとに「こばん」が1まいもらえます。こばんで「よろずや」の ぶき・もちもの・あいぼう・とくべつな いろ を買い、自分の忍者に持たせます。
- 形は、わり算・漢字アプリと同じ「Apps Script だけ」です。子どもは名簿の名前のボタンを押して始めます。
- 問題のデータと絵は、GitHub Pages（`https://zku0395-ops.github.io/hori/kuku/`）から読みこみます。Apps Script に貼り付けるファイルを短くするためです。

- 前のステージをクリアすると、次のステージが開きます。④にんじゃ しけんは、合格すると次の階が開きます。
- しけんに合格できなかったときは「おしい！」と声をかけ、③ばらばら で練習してから、もう一度ちょうせんするように案内します。こばんは もらえます。
- しのびの いりぐち は、先生用画面の「子どもごと」で とばせます（かけ算の意味が分かっている子のため）。
- はってんは、はじめは閉じています。先生用画面の「子どもごと」で開きます。
- ぼうけんは、てんしゅかくに合格すると開きます（先生用画面の「全部開く」でも開きます）。たおした あいてとも また たたかえます（こばんは もらえ、おみやげは はじめの1回だけ）。
- ステージの一覧・唱え方・たからもの・よろずやの品物・ぼうけんの場所と あいてと おみやげは `data/mondai.js` にあります。

## 支援の工夫

- **スモールステップ**：1つの段を、見る（であう）→ 唱える → 順に答える → ばらばらに答える → しけん、の5つに分けています。
- **かけ算の いみ から**：しのびの いりぐち で「1つ分の数 × いくつ分」を、おぼんと しゅりけん の絵で確かめてから九九に進みます。
- **色分け**：式の かけられる数は あお、かける数は ピンク、答えは みどり です。
- **唱え方**：教科書の唱え方（ごいちが ご、ににんが し、さざんが く、はっぱ ろくじゅうし など）を ひらがなで出し、その通りに読み上げます。慣れたら先生用画面で かくせます。
- **まちがいやすい答えを選択肢に入れる**：1つ前・1つ後ろの答え（5×4 で 15・25）、ほかの段の答え（6×4＝24）、たし算の答え（5＋4＝9）、十の位と一の位の入れかわり（6×7 で 24）をまぜます。
- **まちがえたとき**：まちがえた選択肢は うすくなって、もう選べなくなります。まちがい方に合わせて声をかけます（例：「15は 5 × 3の こたえ。5の だんは 5ずつ ふえるから、あと 5だよ」「5 たす 4に なって いるよ。かけざんは 5が 4つ分 だよ」）。まちがえたときの音は小さな音です。
- **ヒントは3段階** です。同じところで2回まちがえるとヒントボタンが光り、3回まちがえると一番くわしいヒントが自動で出ます。

  | ヒント1（ことば） | ヒント2（見本） | ヒント3（いっしょに） |
  |---|---|---|
  | 「5の だんは 5ずつ ふえるよ。5 × 3は 15だったね」 | その段の表を出し、1つ前の九九を光らせて「15 に 5を たすと いくつ？」 | おぼんが1つずつ出て、5、10、15、20 と一緒に数えます。答えを光らせます（すうじ のときは「こたえは 20 だよ」と出します） |

- **負けない たたかい**：④にんじゃ しけん では あいてが出ますが、子どもの体力はへりません。まちがえても あいてが「まだまだ！」と言うだけで、合格に足りないときは あいてが にげます。⓪〜③では あいては出ず、正解するたびに忍者が ろうか を1歩ずつ進みます。
- **あいての絵**：ほどよい こわさにしています。血や きずは出しません。
- 時間制限はありません（しゅりけん しゅぎょう も同じです）。
- 問題の画面は背景をすっきりさせています。にぎやかな絵は、はじめの画面・お城・ごほうびの画面だけで使います。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/kuku/` を開きます。
   - 「おためしモード」で動けば、問題のデータと絵の公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「九九修行 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、ボタンが小さくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

1. 名前を選ぶ画面の右下（学習中は右上）の **🔒** を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「せってい」で変えてください。**

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの ごうかくした階の数（いま やっている ステージ、ぼうけんで たおした あいての数）・たからもの・こばん・問題の数・まちがえずに できた割合・多い まちがいの しゅるい・にがてな 九九・最後に学習した日。クラス全体の 九九の表（81こ）と、まちがいの しゅるい |
| 子どもごと | ステージごとの結果（ぼうけんの あいてごとの結果も）、ぼうけんの進み具合、九九の表（81こ）、にがてな 九九、まちがいの しゅるい、まちがえた問題（多い順） |
| 子どもごと（ボタン） | 全部開く（その子だけ、すべてのステージを開く）、はってんを開く、いりぐちを とばす、こばんを足す・引く、この子の記録を消す |
| せってい | 読み上げの速さ、文字の大きさ、1回の問題の数（3・5・9）、こたえかた（じどう・えらぶ・すうじ）、となえかたの ひょうじ（だす・かくす）、しけんの ごうかく（7問いじょう・9問ぜんぶ・さいごまで こたえたら）、効果音、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、全員の記録を消す |

- **九九の表**：九九81こ を「段（たて）× かける数（よこ）」の表にしています。それぞれの ます に「まちがえずに できた数 ／ 問題の数」を出し、割合で色をつけます（赤：60%未満、黄：60〜79%、緑：80%以上）。✖ は まちがえた回数、💡 は ヒントを使った問題の数です。
- **まちがえずに できた割合** は、まちがえず、ヒントも使わずに できた問題の割合です。
- **にがてな 九九** は、2回以上といて、まちがえずに できた割合が60%未満の九九です。
- **しけんの ごうかく** は、9問のうち、まちがえず・ヒントも使わずに できた問題の数で決めます。はじめは「7問いじょう」です。
- **まちがいの しゅるい**

  | しゅるい | 内容 |
  |---|---|
  | となりの こたえ | 1つ前・1つ後ろの答え（例：5×4 で 15・25）。段を順に唱えて、何番目かを数えまちがえている |
  | ちがう だん | ほかの段の答え（例：5×4 で 24＝6×4） |
  | たしざん | たし算の答え（例：5×4 で 9）。かけ算の意味があいまい |
  | すうじの いれかわり | 十の位と一の位が逆（例：6×7 で 24） |
  | そのほか | 上のどれにも当てはまらない答え |
  | かぞえまちがい | しゅりけんの数を数えまちがえた（しのびの いりぐち） |
  | とりちがい | 「1つ分の数」と「いくつ分」・ぜんぶの数を取りちがえた（しのびの いりぐち） |
  | いれちがい | かけられる数と かける数の入れちがい（例：3まいの 4つ分 を 4×3） |
  | ちがう しき | 答えに合わない式を選んだ（はってん①） |

- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。

## 注意事項

- **絵**：カゲマルせんせい・子どもの忍者・お城・たからものは、先生の Canva で、このアプリのために作ったオリジナルの絵です（Canva のデザイン「カゲマルせんせい 忍者九九修行 え（書き出し用）」に保存しています）。子どもの忍者とたからものは、何人分・何こ分かを1まいの絵にまとめて作り、切り分けています。しゅりけん・まきびし・かたな などの一部の道具は自作の絵（SVG）、そのほかの品物は絵文字です。既存のゲームやアニメのキャラクターは使っていません。先生からいただいた参考の写真や絵は、雰囲気をことばで伝えるだけにして、そのまま まねしていません。

- **効果音**：このアプリのためのオリジナルです（プログラムで作っています）。
- **ことば**：子どもの画面は ひらがなと分かち書きです。漢字は「忍者九九修行」（タイトル）と「〇つ分」の「分」だけを使い、ふりがなを付けています。
- 問題のデータと絵は GitHub Pages から読みこむので、ネットにつながっている必要があります。
