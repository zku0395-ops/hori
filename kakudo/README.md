# ワニワニ先生の ピザやさん（角の学習アプリ）

小学校の特別支援学級（知的障害学級・3〜4年生）向けの、角の大きさの学習アプリです。
口の開き方で角を表すワニの「ワニワニ先生」と一緒に、スモールステップで学びます。

- ピザやさんが舞台です。
- 1問正解するたびにトッピングを1つ選び、自分だけのピザを作ります。
- ステージをクリアすると、ピザが焼き上がってお店の額縁に飾られます。

## できること

| 項目 | 内容 |
|---|---|
| 学習内容 | 頂点と辺、直角、角の大きさくらべ、回転の大きさ（直角・半回転・1回転）、分度器のしくみ、目盛りの読み方、分度器ではかる、角をつくる、180°より大きい角（発展） |
| 問題 | 全11ステージ・55問（ステージ0〜8 各5問、とくべつ2つ 各5問）。角度は毎回変わります |
| 1ステージ | ワニワニ先生のお話（導入アニメーション）と5問で、5〜10分くらい |
| 文字 | ひらがなと分かち書きが中心です。使っている漢字には、すべてふりがなを付けています |
| 声 | ワニワニ先生のセリフを読み上げます（ワニワニ先生をタップするか「🔊 もういちど」で聞き直せます） |
| 操作 | Chromebook のタッチ操作向けです。ドラッグがむずかしい児童のために、◀ ▶ ボタン（長押しで連続）でも操作できます |
| ごほうび | 正解するとトッピングを1つ選べます。5問でピザが焼き上がり、額縁とピザアルバムに飾られます。クリアしたステージの数で称号が上がります |
| 先生用画面 | 暗証番号4けたで開きます。記録の確認、設定、CSV書き出し、バックアップができます |
| 全員の記録 | 1問とくたびに、結果が先生のGoogleスプレッドシートへ自動で届きます（音読アプリとは別のスプレッドシートを使います） |

## ステージ構成

| ステージ | 内容 | 5問 |
|---|---|---|
| 0 かどを みつけよう | 頂点と辺 | ①ピザの頂点 ②ピザの辺 ③三角形の頂点 ④角になっている形をえらぶ ⑤ワニワニ先生の口の頂点と辺 |
| 1 直角を たしかめよう | 直角（導入：紙を2回折って直角をつくるアニメーション） | ①三角定規の直角のかど ②三角定規を当てて直角か調べる ③身の回りの直角（ノート・まど・ドア） ④「直角より小さい／直角／直角より大きい」のなかま分け ⑤ワニの口を直角に開く |
| 2 どっちが 大きい？ | 角の大きさくらべ | ①ぱっと見でくらべる ②重ねてくらべる ③辺の長さがちがう角 ④直角とくらべる ⑤大きい順にならべる |
| 3 ワニの口は まわる大きさ | 直角・半回転・1回転 | ①直角いくつ分 ②半回転（直角2つ分） ③1回転（直角4つ分） ④直角・半回転・1回転は何度 ⑤口を180°に開く |
| 4 分度器と なかよし | 分度器のしくみ | ①中心 ②0°の線 ③外側の0 ④内側の0 ⑤90°の目盛り |
| 5 目盛りを よもう | 置いてある分度器を読む | ①片側の目盛りだけ（右向き） ②片側の目盛りだけ（左向き） ③両側・色分けあり ④両側・色分けなし ⑤両側・向きいろいろ |
| 6 はかって みよう | 分度器を自分で合わせてはかる | ①中心だけ合わせる ②0°の線だけ合わせる ③両方（右向き） ④両方（左向き） ⑤両方（ななめ） |
| 7 角を つくろう | お客さんの注文どおりの角をつくる | ①ワニの口を○°に開く ②目盛りに点をうつ ③点と頂点をむすぶ ④全部（右向き） ⑤全部（左向き） |
| 8 180°より大きい角（発展） | 180°＋□、360°−□ | はじめは閉じています。先生用画面で開きます |
| とくべつ だいたい何度？ | 見当をつける | 直角と比べて、3つの角度から選びます |
| とくべつ ワニワニ先生に ピザを あげよう | 量感 | 言われた角度だけ口を開けて、ピザを食べさせます（±10°で正解） |

- ステージ0から順に、前のステージをクリアすると次が開きます。
- とくべつステージは、ステージ5をクリアすると開きます。
- 先生用画面の設定で、全部のステージを最初から開くこともできます。
- 途中でやめても、次は「つづきから」始められます。

## 支援の工夫

- **スモールステップ**
  - ステージ6は「中心だけ」「0°の線だけ」と1つずつ練習してから、両方を合わせます。
  - ステージ7は「口を開く」「点をうつ」「線をむすぶ」と分けて練習してから、全部を通して行います。
- **手順カード**：ステージ6・7では手順を表示し、できた手順に ✅ が付きます。
- **見当づけ**：分度器で読む前に「直角より大きい？小さい？」を選びます（設定でオフにできます）。
- **ヒントは3段階**
  - 言葉 → 色分けや見本の表示 → 0から数えるアニメーション・拡大鏡・自動で合わせる「おたすけ」。
  - 同じところで2回まちがえるとヒントボタンが光り、3回まちがえると一番くわしいヒントが自動で出ます。
- **まちがい方に合わせた声かけ**
  - 内側と外側の読みちがい（例：50°と130°）のときは、「どっちの 0から かぞえたかな？」と声をかけ、使う目盛りを色分けします。
  - 目盛りの読みずれのときは、拡大鏡を出します。
- **3つから選ぶ答え方**：選択肢には、内側と外側を読みちがえたときの数が必ず入ります。まちがえた選択肢は消えて、もう一度選べます。
- **吸い付き**：分度器を頂点や辺の近くに置くと、ぴったりの位置に吸い付きます（強い／弱い／なし）。
- **画面**
  - 問題の画面は、背景をすっきりさせています。お店の絵は、ホームとごほうびの画面だけで使います。
  - 時間制限はありません。ヒントを使っても、トッピングは同じようにもらえます。

## 公開の手順

### 1. GitHub Pages でアプリ本体を公開する

音読アプリと同じリポジトリの `kakudo` フォルダに入っています。

- 音読アプリの手順で GitHub Pages を公開していれば、変更を `main` に取り込む（Pull Request をマージする）だけで、数分後に `https://zku0395-ops.github.io/hori/kakudo/` で開けるようになります。
- まだ公開していないときは、リポジトリの `README.md` の「GitHub Pages でアプリ本体を公開する」を先に行ってください。

### 2. Google Apps Script とスプレッドシートの準備（学校のアカウントで）

音読アプリとは**別のスプレッドシート**を使います。

1. 学校のGoogleアカウントで、新しい Google スプレッドシートを作ります（名前の例：「角の学習 記録」）。
2. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、`kakudo/gas/Code.gs` の内容を貼り付けます。
4. 左の「ファイル」の「＋」→「HTML」を選び、名前を `start` にします。中身をすべて消し、`kakudo/gas/start.html` の内容を貼り付けます。
5. 上の保存ボタン（💾）を押します。
6. 右上の「デプロイ」→「新しいデプロイ」を押します。
   - 左の歯車から種類「ウェブアプリ」を選びます。
   - 「次のユーザーとして実行」：**自分**
   - 「アクセスできるユーザー」：**全員**
7. 「デプロイ」を押します。アクセスの承認を求められたら、自分のアカウントを選んで「許可」します。
   - 「このアプリは Google で確認されていません」と出たときは、「詳細」→「（プロジェクト名）に移動」を押します。
8. 表示された「ウェブアプリ」のURL（`https://script.google.com/macros/s/…/exec`）を、Classroom などで子どもに配ります。
9. スプレッドシートを開き直すと、メニューに「ワニワニ先生」が出ます。

**大切なこと**

- 子どもは、配ったURL（入口ページ）の「はじめる」から開いてください。こうすると、記録の送り先と合言葉がアプリに自動で設定されます。
- 一度設定されれば、次からは GitHub Pages のURLを直接開いても記録は届きます。
- `Code.gs` を書き換えたときは、「デプロイ」→「デプロイを管理」→ 鉛筆のアイコン →「バージョン：新バージョン」→「デプロイ」で更新します（URLは変わりません）。

### 3. Chromebook の準備（1台ずつ、最初に1回）

1. 入口ページの「はじめる」でアプリを開きます。
2. 「はじめての設定」画面で、先生が次のことを行います。
   - 児童の名前を入れる
   - 先生用の暗証番号（4けた）を決める
   - 「声を確認する」でワニワニ先生の声が聞こえるか確かめる
3. 先生用画面の「データ」タブで、「先生のスプレッドシートへの送信」の送り先が「✅ 設定ずみ」になっているか確かめます。

## 先生用画面

子どもの画面の右上にある「⚙ せんせい」を押し、暗証番号を入れると開きます。

| タブ | できること |

| 📊 記録 | クリアしたステージ数、といた問題数、1回で正解した割合、ステージごとの様子、つまずきの種類ごとの回数、最近の記録（答えた内容・ヒントの回数・かかった時間など） |
| ⚙️ 設定 | 下の表のとおり |
| 💾 データ | スプレッドシートへの送信の状態と「今すぐ送る」、記録のCSV書き出し、バックアップ（書き出し／元にもどす）、記録の消去 |

### 設定

| 設定 | 内容 |
|---|---|
| 目盛りの細かさ | 10°とび（基本）／5°とび／1°とび。ステージ5〜8で使う角度と、分度器の目盛りの細かさが変わります |
| ステージ8 | 180°より大きい角（発展）を開くかどうか |
| すべてのステージを開く | 前のステージをクリアしていなくても挑戦できるようにします |
| 答え方 | 3つから選ぶ／数字ボタン |
| 正解の幅 | ±0°／±1°／±2°（数字ボタンで答えるときや、角をつくるとき） |
| 見当をつける質問 | 分度器で読む前に「直角より大きい？小さい？」を聞くかどうか |
| 分度器が吸い付く強さ | 強い／弱い／なし |
| 使う目盛りの色分け | ステージ6〜8で、0から数える側の目盛りを最初から色分けするかどうか |
| 拡大鏡をいつも出す | 読む所を大きく見せる拡大鏡を、いつも出すかどうか |
| ◀ ▶ ボタン | ボタンで分度器やワニの口を動かせるようにするかどうか |
| ワニワニ先生の声・効果音・文字と画面の大きさ・暗証番号の変更 | ― |

## 全員の記録を見る（先生のスプレッドシート）

| シート | 内容 |
|---|---|
| いちらん | 1人1行で、名前・称号・クリアしたステージ数・といた問題数・1回で正解した割合・最後の学習日時・いまのステージを表示します。ステージの列は「◎＝クリア（数字はクリアした回数）」「○問＝挑戦中」です。右側のオレンジの列は、つまずきの種類ごとのまちがえた回数です |
| きろく | 全員の1問ごとの結果です（日時・名前・ステージ・問題・正しい答え・答えた内容・結果・まちがえた回数・ヒントの回数・かかった時間・つまずき・目盛り・答え方） |

つまずきの種類は次のとおりです。

- 内側と外側の読みちがい
- 目盛りの読みずれ
- 中心のずれ
- 0°の線のずれ
- 辺の長さにつられた
- 直角とのくらべちがい
- 頂点・辺のまちがい
- 数えまちがい
- 計算のまちがい
- その他

記録について：

- 「いちらん」は記録が届くたびに作り直されます。手で書き込んだ内容は消えるので、メモは別のシートに書いてください。
- 途中でやめた問題も、答えたことがあれば「とちゅうでやめた」として記録されます。
- インターネットにつながっていないときの記録は端末にためておき、次につながったときに送ります。同じ記録が二重に書き込まれることはありません。
- 子どもは名前で区別します。名前は1人ずつ違うものにしてください。

## 注意事項

- **データの保存場所**：記録・ピザ・設定は、そのChromebookのブラウザの中（IndexedDB と localStorage）に保存します。Chromeの閲覧データを消すと記録も消えるので、ときどき「バックアップを書き出す」で保存してください。
- **スプレッドシートへの送信**：送り先が設定されている場合は、名前と問題の結果だけを先生のスプレッドシート（Apps Script）に送ります。
- **読み上げ**：Chrome の音声合成を使います。日本語の声が入っていない端末では読み上げられません。
- **暗証番号を忘れたとき**：元にもどす機能はありません。Chromeの設定からこのサイトのデータを消すと最初からやり直せますが、記録も消えます。
- **絵**：ワニワニ先生、ピザやさん、ピザ、トッピング、分度器などの絵は、すべてこのアプリのためのオリジナルです（画像ファイルは使わず、プログラムで描いています）。
- **使っているもの**：React と Babel（unpkg）、BIZ UDPゴシック（Google Fonts）をインターネット経由で読み込んでいます。
