# ドラッチの ことばの ワークシート（ことばの意味の学習プリント）

小学校の特別支援学級向けの、ことばの意味の **ワークシート** です。
アプリ「ドラッチと ことばの ぼうけん」（[kotoba/](../kotoba/README.md)）で学習したことばを、紙で ためします。
アプリの ①いみを えらぶ → ②ことばを えらぶ → ③ぶんで つかう と同じ順で、1まいに3つの問題が入っています。

- ワークシートを作るページ：`https://zku0395-ops.github.io/hori/kotobaprint/`
- できあがった PDF：`kotobaprint/pdf/` に入っています（ページの上の「できあがった PDF」からも開けます）。
- 用紙は **A4たて** です。

## できること

| 項目 | 内容 |
|---|---|
| 1まいの ことば | アプリの1くみ（5語）。1つの場所に 1くみ・2くみ の2まいです |
| まい数 | 1年生 16まい・2年生 16まい・3年生 18まい・4年生 18まい（あわせて 68まい・340語） |
| ① いみを えらぶ | 左の ことば5つと、右の 意味5つを、せんで むすびます。ことばの下に、漢字（ふりがな つき）を小さく出します |
| ② ことばを えらぶ | 意味を読んで、3つの ことばから 合うものに ○を つけます |
| ③ ぶんで つかう | 文の（　）に入る ことばを、上の5語から えらんで 書きます |
| 欄 | 「　ねん」「なまえ」「　がつ　にち」「できたかな？（◎ ○ △ に ○）」 |
| 絵 | ページの上の帯に、ドラッチ・場所の名前・その場所のモンスター（1くみは ふつうの モンスター、2くみは ボス）を入れます。問題の中には絵を入れません |
| こたえ | 子ども用と同じ形で、答えを **赤** で入れています（① は赤い せん、② は赤い ○、③ は赤い字）。上に「こたえ」の はんこ |
| はってん | アプリの「✨ ただしい つかいかた」と同じ問題です。1まいに5語。① ことばごとに3つの文から、つかいかたが ただしい文に ○。② 5語から1つえらんで、じぶんで 文を つくる（書く行は 1・2年生 3本、3・4年生 2本）。こたえには、アプリの例文を「れい」として赤で入れます。ふつうと同じ 68まい・同じ ばんごうです |
| えらんで 印刷 | 作るページで、学年・場所・くみを えらんで、1まいだけでも印刷・PDF保存できます |

## ステージ構成

| 学年 | ばんごう | 場所（1つの場所に 1くみ・2くみ） |
|---|---|---|
| 1年生 | 1〜16 | はじまりの むら → そよかぜの もり → にじいろの いずみ → きもちの はなばたけ → おとの どうくつ → ときの とう → でこぼこ いわば → おてつだいの こみち |
| 2年生 | 1〜16 | みなとまち → ひろびろ こうげん → すなかぜ さばく → しずくの みずうみ → ふかい もり → かぞえかたの しろ → そらもようの みさき → はたらく ひとの まち |
| 3年生 | 1〜18 | ささやきの たに → かがみの みずうみ → くもの たかはら → ふたごの つりばし → こころの やまざと → かんようくの とりで → そわそわ どうくつ → べんりな こうぼう → じゅんばんの ほこら |
| 4年生 | 1〜18 | ことわざの としょかん → どうぶつの そらじま → つなぎの にじばし → ほしぞらの おか → じゅくごの ひこうせん → てんくうの しろ → よじじゅくごの もん → こころの くもの うみ → てんびんの とう |

- ばんごう 1 が 1つめの場所の1くみ、2 が 2くみ、3 が 2つめの場所の1くみ … の順です。
- ことばの一覧は、アプリの README（[kotoba/README.md](../kotoba/README.md)）にあります。

## 支援の工夫

- アプリと同じ ことば・意味・文なので、アプリで学習したことを そのまま紙で ためせます。
- アプリと同じ ①②③の順です。① で意味をたしかめてから、② ③ に進みます。
- 問題の文は、ひらがなと分かち書きです。① の ことばの下に、アプリと同じように漢字を出し、すべてにふりがなを付けています。
- ② の ことばには、アプリと同じ「まちがいやすい ことば」（はんたいの いみ・にている おと など）を入れています。
- はってんの まちがった文は、アプリと同じです（「のみものを はいて、そとを あるく。」のように、意味から見て おかしい文）。正しい文は ③ の文に ことばを入れたものです。
- ③ の（　）の大きさは、どの文も同じです（大きさで答えが分からないように）。
- 1・2年生は字を大きめ、3・4年生はふつうにしています。ことわざなど長いことばが多い場所は、1まいに入るように 字を少し小さくします。
- 場所ごとの色の帯を入れています。うすい色なので、白黒で印刷しても読めます。
- ① の右の意味や、② ③ の順番は、いつも同じです（プリントと こたえで 順番が かわりません）。

## ファイル構成

```
kotobaprint/index.html          ワークシートを作るページ（?g=1 で 1年生ぜんぶ。&p=1-1 で 場所、&k=A で くみ、&t=h で はってん、&ans=1 で こたえ）
kotobaprint/pdf/                PDF（16ファイル）
kotobaprint/tools/make-pdf.js   PDF を作るプログラム
```

- ことば・意味・文・絵は、アプリの `kotoba/data/kotoba.js` と `kotoba/img/` を使います。アプリの ことばを直すと、ワークシートも同じように かわります。
- ことばを直したら、PDF を作り直します：`node kotobaprint/tools/make-pdf.js`（1つの学年だけなら `node kotobaprint/tools/make-pdf.js 3`）

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入ると、`https://zku0395-ops.github.io/hori/kotobaprint/` で開けます。
2. ページの上の「できあがった PDF」から、PDF を保存できます。

### 2. Apps Script とスプレッドシート

- このワークシートは記録をとらないので、Apps Script とスプレッドシートは使いません。

### 3. 印刷のしかた

1. 印刷したい PDF を開きます。
2. 印刷の画面で、次のようにします。
   - 用紙サイズ：**A4**
   - 向き：**縦**
   - 倍率：**100%**（「実際のサイズ」）
3. 1まいだけ印刷するときは、印刷の画面の「ページ」で番号を入れます（例：3まいめ なら「3」）。

- ワークシートを作るページで印刷するときは、上で学年・場所・くみ（はってんは「✨ はってん」）を えらんで「🖨️ いんさつ・PDF に ほぞん」を押します。
  - 余白は「なし」、「背景のグラフィック」は オン にしてください。
  - 「送信先」で「PDF に保存」を えらぶと、PDF に なります。

### 4. Googleサイトに置くとき

- 「ボタン」を置き、リンクに PDF かワークシートを作るページのURLを入れてください。

## 先生用画面

- このワークシートには、先生用画面はありません。

## 全員の記録を見る

- このワークシートは記録をとりません。アプリの記録は、アプリのスプレッドシートで見られます。

## 注意事項

- **ことば・意味・文**：アプリのために書いたオリジナルの文です。ことわざ・かんようく・四字じゅくごは、昔から使われていることばです。
- **絵**：アプリのために Canva で作った絵（ドラッチ・モンスター）です。
