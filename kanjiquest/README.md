# フデリュウと かんじの ぼうけん（1〜3年生の漢字の ロールプレイングゲーム風 アプリ）

小学校の特別支援学級向けの、1〜3年生で習う漢字（440字）の読み書きのアプリです。
小さなドラゴンの「フデリュウ」と一緒に、まものを たおして 漢字を とりもどす冒険をします。

- おはなし：ことばの しま「コトノハ」の かんじを、まものたちが もって いって しまいました。まものに 勝って、かんじを とりもどします。
- 主人公は「ゆうしゃ・まほうつかい・しょうにん・ぶとうか」から選びます（性別では分けません）。あとで「おみせ」で かえられます。
- 1つの学年が1つの「しま」です。1年生「ことばの しま」（4エリア）・2年生「にじいろの しま」（8エリア）・3年生「ほしぞらの しま」（10エリア）。2・3年生の しまは、先生が子どもごとに開きます。
- 漢字・例文・書き順は、漢字アプリ「ポンタせんせいの かんじ マーケット／デパート／ショッピングモール」（`kanji1/` `kanji2/` `kanji3/`）の データを そのまま 使います。そちらの例文を直すと、このアプリにも反映されます。
- 形は、ドラッチ（`kotoba/`）と同じ「Apps Script だけ」です。子どもは名簿の名前のボタンを押して始めます。
- ぼうけんの データと絵は、GitHub Pages（`https://zku0395-ops.github.io/hori/kanjiquest/`）から読みこみます。

## 支援の工夫

- **スモールステップ**：1つのステージの5字を、えらぶ → かく の順に、わざを1つずつ ふやして練習します。
- **負けない たたかい**：まちがえても子どもの体力は へりません（まものが「ひらり！」と よけるだけ）。正解すると こうげきが あたり、さいごまで答えると必ず勝ちます。まちがえず・ヒントなしで答えると「かいしんの いちげき！」です。
- **まちがいやすい選択肢**（kanji1 と同じ考え方。選択肢は3つ）
  - よみ：同じ字の ほかの読み（例：「五つ」の「ご」）、形のにている字の読み、同じステージの字の読み
  - かんじ：形のにている字（例：「木」と「本」「休」）、同じステージの字
- **まちがえたとき**：まちがえた選択肢は うすくなって選べなくなり、まちがい方に合わせて声をかけます（例：「『ご』も この じの よみかただけど、この ぶんでは ちがう よみかただよ」）。音は小さな音です。
- **ヒントは3段階**：1回まちがえると 💡ヒント が光り、2回まちがえると いちばん くわしいヒントが自動で出ます。

  | わざ | ヒント1 | ヒント2 | ヒント3 |
  |---|---|---|---|
  | よみ・かんじを えらぶ | 例文の絵と、なりたち・おぼえかた | まちがいの選択肢を1つ消す | こたえが光る |
  | よみを かく | さいしょの もじ | ぜんぶの もじを うすく出す | 押す もじが光る |
  | かんじを かく | 💡を押すたびに、つぎの1画が うすく出る（なぞれる） | 同じ画で1回まちがえると、書きはじめの みどりの まると 正しい線の動きが出る | 同じ画で3回まちがえると、その画が自動で うすく出る |
- **問題の画面はすっきり**：上は たたかいの場面、下は問題だけです。時間制限はありません。

## 公開の手順

### 1. GitHub Pages

- `main` ブランチに入ると、`https://zku0395-ops.github.io/hori/kanjiquest/` に公開されます（データと絵の置き場所です）。
- `kanji1/data/` も同じように公開されている必要があります（すでに公開されています）。
- このページを直接開くと「おためしモード」で動きます（記録は その端末の中だけ）。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「かんじの ぼうけん 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、ボタンが小さくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

1. 名前を選ぶ画面の右下の **🔒 せんせい** を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「せってい」で変えてください。**

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの しょくぎょう・クリアした数（110のうち）・カード（440のうち）・ひらいた しま・ゴールド・問題の数・まちがえずに できた割合・にがてな かんじ・最後に学習した日。クラス全体の 漢字の表 |
| 子どもごと | ステージごとの 使える わざ・クリア・結果（学年を えらんで 見ます）、漢字の表、にがてな かんじ、よく まちがえた問題。**2年生・3年生の しまを ひらく／とじる**、全部開く（すべての しま・ステージ・わざ）、ゴールドを足す・引く、この子の記録を消す |
| せってい | 読み上げの速さ、文字の大きさ、1回の問題の数（3・5・10）、よみを かく ときの入力（もじカード・50おんひょう）、かんじを かく ときの みほん（じぶんで かく〈はじめ〉・じゅんばん・なぞる・うすい）、かく ときの判定（やさしい・ふつう）、効果音、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、全員の記録を消す |

- **漢字の表**：80字 × 4つの わざ（よみ・えらぶ／かんじ・えらぶ／よみ・かく／かんじ・かく）の表です。ます に「まちがえずに できた数 ／ 問題の数」を出し、割合で色をつけます（赤：60%未満、黄：60〜79%、緑：80%以上）。✖ は まちがえた回数、💡 は ヒントを使った問題の数です。
- **まちがえずに できた割合** は、まちがえず、ヒントも使わずに できた問題の割合です。
- **にがてな かんじ** は、2回以上といて、まちがえずに できた割合が60%未満の字です。
- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。
