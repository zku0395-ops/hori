# ブンブンちょうろうの ことばの ぼうけん（文をつくる学習アプリ）

小学校の特別支援学級（1〜4年生）向けの、国語の「ことばを ならべて 文を つくる」アプリです。
ことばのカード（名詞・助詞・動詞・形容詞・形容動詞・副詞）を並べかえて、意味の通る文を作ります。
文を作りながら冒険し、集めたざいりょうで自分の町を作っていきます。

- おはなし：いたずらモンスターの「バラバラン」が、町の人たちの文を ばらばらにしてしまいました。ブンブンちょうろうと一緒に、カードを並べて文を元にもどします。正しく並べると「ことばの まほう」がモンスターに当たります。
- 子どもは「たびびと」です。地図の10のエリアを順に進みます（はってんの2エリアは先生が開きます）。
- 1つのエリアに たたかいが3つ（① ② と 👑ボス）あります。1回のたたかいは5問です。
- 正解すると、コインと ざいりょう（き・いし・てつ・エリアの とくべつな ざいりょう）がもらえます。ざいりょうで町に たてものを建てます。
- 形は、九九・ことばの ぼうけん（ドラッチ）と同じ「Apps Script だけ」です。子どもは名簿の名前のボタンを押して始めます。
- 文のデータと絵は、GitHub Pages（`https://zku0395-ops.github.io/hori/bunbun/`）から読みこみます。Apps Script に貼り付けるファイルを短くするためです。
- 先生からいただいたスライド「ことばや もじを ならべて 文を つくろう①〜⑫」の24文も、問題に入れています。

## できること

| 項目 | 内容 |
|---|---|
| 問題 | 240文（10エリア×20文、はってん 2エリア×20文）。1回のたたかいは5問です（先生用画面で3問・10問にもできます） |
| ならべかた | カードを押すと、上から順に ますに入ります。ドラッグで好きな ますに入れることもできます。ますのカードを押すと、カードの おきばに もどります |
| 書き方 | たて書き（スライドと同じ）。先生用画面で よこ書きにもできます |
| カードの色 | 品詞ごとに色を分けます（先生用画面で「なし」にもできます）。助詞のカードは小さくします |
| 声 | ちょうろうのセリフを読み上げます（はじめは0.8倍の速さ）。カードを押すと、そのカードを読みます。「🔊 カードを よむ」で、残っているカードを全部読みます |
| こえに だして よむ | 正解すると、ちょうろうが文を読み上げ、「こえに だして よもう」と声をかけます。子どもが読んで「📣 よんだよ！」を押すと、まほうが出ます（先生用画面で「つかわない」にもできます） |
| ならびかた | 「こうえん で ぼく は」のように「どこで・どこへ・だれと・いつ」を前に出した文も正解にします（くわしくは「支援の工夫」） |
| 問題の絵 | いまは絵文字の組み合わせです。あとから1文ずつ ChatGPT の絵に差しかえられます |
| たたかい | まちがえても子どもの体力は減りません（モンスターが「ばらばら〜！」と言うだけ）。最後まで並べると必ず勝ちます。時間制限はありません |
| ごほうび | 1問で コイン2まい・ざいりょう1こ・けいけんち1（ヒントを使っても同じ）。たたかいに勝つと ざいりょう（ボスは とくべつな ざいりょう3こ）。初めて勝つと コイン5まい |
| まちづくり | 町のマス（はじめは 3×3＝9マス。ボスに勝つたびに3マス広がり、最大 7×5＝35マス）に たてもの（25しゅるい）を建てます。たてものは レベル3まで上げられ、場所を うごかせます |
| まちの ひと | エリアのボスに勝つと、そのエリアで困っていた人（うさぎの ミミさん など12人）が町に引っこしてきて、町を歩きます |
| レベル・しょうごう | 文を10こ作るごとにレベルが上がります。レベルで しょうごう（みならいの たびびと → … → でんせつの たびびと）が変わります |
| そうび | 初めに たびびとの かたち（2しゅるい）と ふくの色（6色）を選びます。おみせで ぼうし・つえ・ふく（各8こ）をコインで買えます。つえで まほうの光り方が変わります。強さは変わりません |
| ずかん | まちの ひと・バラバラン・たてもの・しょうごう |
| 先生用画面 | 暗証番号4けたで開きます。どの文・どの助詞でつまずいているかが分かります |
| 全員の記録 | 結果は先生のGoogleスプレッドシートへ届きます。進み具合・コイン・ざいりょう・町も、スプレッドシートに保存します |

## 支援の工夫

- **スモールステップ**：はじめは3まいのカード（だれが・が・どうする）から。助詞を1つずつ増やし、ようすの ことば、どのくらいの ことば、「の・です」、いつ、と少しずつ長くします。
- **たて書き**：先生のスライドと同じたて書きです。ますには小さく番号が付き、上（右の列）から順に入ります。よこ書きにもできます。
- **品詞の色分け**：だれ・なに＝青、ちいさい ことば（助詞）＝緑、どうする・なんだ＝赤、ようす＝オレンジ、どのくらい・どんなふうに＝むらさき、いつ＝水色、つなぐ ことば＝ピンク。助詞のカードは小さくします（スライドと同じ）。色の見本を問題の下に出します。
- **ならびかたの みとめかた**：日本語は語順がある程度自由なので、次のように決めています。
  - 正解：見本の文と、「どこで・どこに・どこへ・だれと・どこから・いつ」の まとまりを ほかの場所に動かした文（例：「こうえん で ぼく は おにごっこ を した。」）。「たくさん・ゆっくり」なども、文のはじめ以外なら動かせます。
  - 正解にしない：「だれが」と「なにを」の順番を入れかえた文（例：「にんじん を うま が たべる。」）、助詞が ちがう ことばに付いた文（例：「にんじん が うま を たべる。」）、ようすの ことばが かかる ことばから離れた文。
  - 「にんじん を うま が たべる。」のように、意味は合っているが ふだん使わない並び方のときは、「いみは つうじるね！ でも、よく つかう ならびかたに して みよう」と声をかけます。先生用画面の「ならびかた：ひろく」にすると、これも正解になります。
  - 「ぼく は おとうと と」と「おとうと は ぼく と」のように、入れかえても意味が同じ文は、データに「べつの ならびかた」として書いています。
- **まちがえたとき**：ちがう ますのカードだけが ゆれて、カードの おきばに もどります。正しい ますのカードは、緑のわくが付いて残ります。まちがいに合わせて声をかけます。
  - 助詞の場所がちがう：「ちいさい カードの ばしょが ちがうよ。『にんじん』の あとに くるのは どれかな？」
  - 文の終わりがちがう：「ぶんの おわりには『どう した』『なんだ』の ことばが くるよ。」
  - ようすの ことば：「『きいろい』は『ぼうし』の ようすを あらわす ことばだよ。」
  - まちがえたときの音は、小さな音です。
- **ヒントは3段階** です。2回まちがえるとヒントボタンが光り、3回まちがえると ヒント③が自動で出ます。
  1. ちょうろうが、次に入れる ことばを たずねます（「だれが？ なにが？」「なにを？」「どこで？」「いつ？」「どんな ぼうし？」など）。
  2. カードに品詞の色が付き（色分け「なし」のとき）、次に入れるカードが光ります。
  3. 次に入れるカードと、入れる ますが光り続けます。
- **読むことの支援**：カードを押すと読み上げます。「🔊 カードを よむ」で、残りのカードを全部読みます。助詞の「は・へ・を」は「わ・え・お」と読みます。
- **こえに だして よむ**：正解のあと、ちょうろうが文を読み、子どもも声に出して読んでから次へ進みます。
- **負けない たたかい**：体力が減るのはモンスターだけです。時間制限はありません。
- **問題の画面**：たたかいの画面は、先生のご希望で、エリアの絵を画面いっぱいの背景にしています。文を並べる ますと カードの おきばは、白い わくにして読みやすくしています。

```

bunbun/コード.gs            スプレッドシートとつなぐプログラム（Apps Script の「コード.gs」に貼り付けます）
bunbun/data/bunbun.js      エリア・文・モンスター・まちの ひと・たてもの・おみせ・しょうごうのデータ
bunbun/data/kumitate.js    文の くみたての しくみ（カードの まとまり、正解の ならびかた、まちがいの しゅるい）
bunbun/img/                ChatGPT で作った絵（これから入れます）
bunbun/e_chatgpt.md        ChatGPT に絵を頼むときの文（コピーして使います）
bunbun/tools/check.js      文のデータの点検（node bunbun/tools/check.js。node bunbun/tools/check.js 4-01 で、その文の正解の並び方を全部出します）
```

- `data/` と `img/` は、GitHub Pages から読みこみます。文や品物を直したときは、`data/` を直して `main` に入れるだけで、Apps Script を貼り直さなくても全員の画面に反映されます。
- 絵がまだないところは、自作の絵（ちょうろう・たびびと・バラバラン・地図）と絵文字（たてもの・まちの ひと・問題の絵）が出ます。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/bunbun/` を開きます。
   - 「おためしモード」で動けば、文のデータと絵の公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「ぶんの ぼうけん 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。
4. 画面の文字が小さいときは、先生用画面の「もじの おおきさ」で変えます。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、カードやボタンが小さくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。
- 「そらの うえの がっこう」に置くときは、URLを教えてください。こちらで `sora/apps.js` に足します。

## 先生用画面

1. 名前を選ぶ画面の右下（学習中は右上）の **🔒** を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「せってい」で変えてください。**

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの いまのステージ・クリアしたエリアの数・コイン・問題の数・まちがえずに できた割合・多い まちがいの しゅるい・まちがえた助詞・最後に学習した日。クラス全体の「じょしの表」「まちがいの しゅるい」「ぶんの表（エリアごと）」 |
| 子どもごと | ステージごとの結果、じょしの表、まちがいの しゅるい、まちがえた文（多い順）、ぶんの表 |
| 子どもごと（ボタン） | 全部開く（その子だけ、すべてのステージを開く）、はってんを開く、コインを足す・引く、この子の記録を消す |
| せってい | 読み上げの速さ、文字の大きさ、1回の問題の数（3・5・10）、かきかた（たてがき・よこがき）、カードの いろわけ（あり・なし）、ならびかた（ふつう・ひろく）、こえに だして よむ（つかう・つかわない）、効果音、おんがく（つかう・つかわない）、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、全員の記録を消す |

- **じょしの表**：助詞（が・は・を・に・で・へ・と・の・から）ごとに、その助詞が入った文を といた数、その助詞の ますに ちがうカードを置いた回数、かわりに置いてしまった助詞（例：「に」のところに「を」）を出します。
- **ぶんの表**：エリアを選ぶと、20文ごとに「まちがえずに できた数 ／ 問題の数」を出し、割合で色をつけます（赤：60%未満、黄：60〜79%、緑：80%以上）。✖ は まちがえた回数、💡 は ヒントを使った問題の数です。
- **まちがえずに できた割合** は、まちがえず、ヒントも使わずに できた問題の割合です。
- **まちがいの しゅるい**

  | しゅるい | 内容 |
  |---|---|
  | じょしの いち | 「は・が・を・に」などの ちいさい ことばを、ちがう ところに置いた |
  | おわりの ことば | 「どうした・なんだ」の ことばを、文の終わり以外に置いた（または、終わりに ほかの ことばを置いた） |
  | くわしく する ことば | 「きいろい」「たくさん」などを、かかる ことばから離して置いた |
  | ことばの じゅんばん | 「だれが」「なにを」などの順番がちがった |
  | ならびかた（いみは あう） | 意味は合っているが、ふだん あまり使わない並び方（「ならびかた：ふつう」のとき） |

- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。

- スプレッドシートの **「きろく」** シートに、1問ごとの結果が入ります。

  | 日時 | なまえ | ステージ | エリア | ぶん | こたえ | けっか | まちがい | ヒント | まちがいの しゅるい | ならべた こたえ | じょし | カードの かず | びょう | ID |

  - ステージ：「3-2」＝3ばんめのエリア（かわ）の ② たたかい2。「-3」はボスです。
  - ぶん：文の番号（「3-05」＝かわの 5ばんめの文）　こたえ：見本の文
  - けっか：○＝まちがえず、ヒントも使わずに できた　△＝まちがえてから、またはヒントを使って できた
  - まちがい：「できた！」を押して まちがえた回数　ヒント：使ったヒントの段階（0〜3）
  - まちがいの しゅるい：上の表の しゅるい（2つ以上のときは「・」で区切ります）

## 注意事項

- **個人情報**：名簿には、呼び名かひらがなの名前だけを入れてください。
- **文**：先生からいただいたスライド「ことばや もじを ならべて 文を つくろう①〜⑫」の24文（でんしゃ が えき に とうちゃく した。など。スライドの「ちょくしょく」は「ちょうしょく」、「一じかんめ」は「いちじかんめ」にしています）と、このアプリのために書いたオリジナルの文です。子どもの生活（学校・家・公園・季節）に近い文にしています。
- **絵**：ブンブンちょうろう・たびびと・バラバラン（36ぴき）は、先生が ChatGPT で このアプリのために作ったオリジナルの絵です（背景をすかし、1まいずつに切り分けています）。はじめの画面・ぼうけんの地図・ホームの町・まちづくりの土地も、先生が ChatGPT で作った絵です。ほかの背景は、いまは自作の絵（SVG）です。これから ChatGPT の絵に差しかえます。参考にした「九九クエスト」の画面は、AIに読みこませず、「ぼうけんに出る・まちを作る」という しくみ だけを参考にしています。問題の絵・たてもの・まちの人・品物は絵文字です。
- **効果音・音楽**：このアプリのためのオリジナルです（プログラムで作っています）。
- **ことば**：子どもの画面は ひらがなと分かち書きです。漢字は使っていません。
- 文のデータと絵は GitHub Pages から読みこむので、ネットにつながっている必要があります。
- 「データを よみこめませんでした」と出るときは、`https://zku0395-ops.github.io/hori/bunbun/` が開けるか確かめてください。
- 「止まった」「開かない」ときは、まず `index.html` の貼り付けが最後（`</html>`）まで入っているかを確かめてください。
- 正しいのに まちがいになる文があれば、教えてください。「べつの ならびかた」に足します。
