# ChatGPT に絵を頼むときの文（ブンブンちょうろうの ことばの ぼうけん）

## つかいかた

1. ChatGPT を開き、下の「はじめに 1回だけ はる文」を貼って送ります。
2. つぎに、作りたい絵の文（①〜⑨）を1つずつ貼って送ります。
3. できた絵を保存します（右クリック →「名前を付けて画像を保存」）。
4. 保存した絵を、このチャット（Claude）に貼ってください。
   - こちらで、切り分け・背景をすかす・名前を付ける・軽くする をして、アプリに入れます。
   - ファイル名を付けなくても大丈夫です。「ちょうろう の ふつう」のように、どの絵かを書いてください。
5. 気に入らない絵は、「もっと やさしい顔に」「線を太く」のように ChatGPT に頼んで作り直します。

- 絵がそろうまでは、アプリの中の仮の絵（自作の絵と絵文字）で動きます。全部そろえなくても使えます。
- おすすめの順番：① ちょうろう → ② たびびと → ③ バラバラン → ④ 背景。たてもの（⑨）は あとでかまいません。

## はじめに 1回だけ はる文

```
これから、小学校の特別支援学級の子ども（1〜4年生）が使う、国語の学習アプリの絵を、何まいか続けて作ってもらいます。
次のルールを、すべての絵で守ってください。
・絵本のような、やさしい色の、子ども向けのイラスト。太めの、やわらかい線。
・こわくない、かわいい顔。モンスターも、いたずらっ子のような ゆかいな顔。
・既存のアニメ・ゲーム・キャラクターに似せない、オリジナルのデザイン。
・絵の中に、文字・数字・ロゴを入れない。
・キャラクターの絵は、背景を真っ白（または透明）にして、全身が切れないように入れる。
・すべての絵で、絵柄（線の太さ・色合い・頭身）をそろえる。
わかったら「OK」とだけ答えてください。
```

## ① ブンブンちょうろう（3まい）

```
アプリの案内役「ブンブンちょうろう」を描いてください。
・村の ものしりの、やさしいおじいさん。長い白いひげ、白い まゆげ、丸い鼻、ほっぺが少し赤い。
・むらさき色の長いローブ（えりは黄色）。
・右手に木のつえ。つえの先に、何も書いていない小さな木の札が下がっている。
・肩のあたりに、小さな丸いミツバチが1ぴき飛んでいる（なかよしの相棒）。
・正面より少し右を向いた、上半身〜全身。背景は白。正方形。
・表情を3まい：1まいめ「ふつう（にっこり）」、2まいめ「よろこぶ（目を細めて大きく笑う、両手を広げる）」、3まいめ「かんがえる（首をかしげ、あごひげに手を当てる）」。
3まいを横にならべて、1まいの絵にしてください。
```

## ② たびびと（子どもが自分で選ぶ主人公。2まい）

```
子どもが自分のかわりに使う主人公「たびびと」を描いてください。
・小学生くらいの子ども。男の子にも女の子にも見える、性別が分からない デザイン。
・青い服（あざやかな青 #2563eb くらい。服以外には青を使わない）と、茶色のリュック、茶色のくつ。
・はだと かみは、青以外の色。
・全身、右を向いて少しななめ、元気に立っている。背景は白。たて長。
・「かたち1」はみじかい かみ、「かたち2」は肩までの かみ。ほかは同じ。
2まいを横にならべて、1まいの絵にしてください。
```

> 服の青いところを、アプリが子どもの選んだ色にぬりかえます。服だけを青にしてください。

## ③ バラバラン（いたずらモンスター。エリアごとに3びき × 12まい）

まず、この文で1まい目（はらっぱ）を作ります。

```
いたずらモンスター「バラバラン」の なかまを描いてください。
・ぷにぷにした スライムのような丸い からだ。小さな手。ゆかいな いたずら顔（こわくない）。
・からだの まわりに、白い小さな四角いタイル（字は書かない）が3〜4こ、ふわふわ ちらばっている（ことばのかけら）。
・全身、左を向いて少しななめ。背景は白。
・3びきを横にならべて、1まいの絵にしてください。左から：
  1. くさバラン：みどり色。頭に草が生えている。
  2. ちょうバラン：きいろ。ちょうちょの はねが ついている。
  3. はらっぱの バラバラン（ボス）：こい みどり色。ほかより大きく、金色の小さな王かんをかぶっている。
```

## ④ エリアの背景（12まい。たたかいの画面と エリアの画面の背景）

```
冒険のゲームの背景を描いてください。キャラクターは入れません。横長（16:9）。
・下の3分の1は、キャラクターが立てる平らな地面。上はひらけた空や景色。
・明るく、ごちゃごちゃしない、やさしい色。
場所：はらっぱ（花が少し咲いている広い草原、遠くに丘）
```

「場所：」のところを入れかえて、12まい作ります。

1. はらっぱ（花が少し咲いている広い草原、遠くに丘）
2. もり（木もれ日の ふかい森、どんぐりの木）
3. かわ（すんだ川と小石の川原、小さな橋）
4. うみ（すなはまと青い海、かいがら）
5. やま（岩の多い山道、遠くに高い山）
6. ゆきの くに（まっしろな雪の野原、雪の木）
7. そら（くもの上、青空、虹がうっすら）
8. おかしの むら（ケーキや キャンディの家がならぶ、あまい色の村）
9. とけいの とう（大きな時計の塔の前の広場、はぐるま）
10. バラバランの しろ（少しくもった空の下の、ゆかいな形の お城の前。こわくしない）
11. にじの はし（雲の上にかかる虹の橋）
12. ほしの おか（夜空に星がいっぱいの丘、流れ星）

## ⑨ たてもの（あとでかまいません）

```
町に建てる たてものを、ななめ上から見た小さなイラストで描いてください。背景は白。
1まいに 5こずつ、横にならべてください：
いえ／はたけ／ふんすい／はなや／こうえん（すべりだい）
```

続けて、次の5こずつを頼みます。

- パンや／ログハウス／さかなや／はし／すいぞくかん
- みなと（ヨット）／ほうせきや／てんぼうだい／スケートじょう／おんせん
- てんもんだい／ききゅうの のりば／おかしや／ケーキや／とけいとう
- えき／がっこう／おしろ／かんらんしゃ／ロケット（発射台）
