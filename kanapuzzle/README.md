# ロボタンの カナカナパズル（カタカナのプリント）

小学校の特別支援学級（1〜4年生）向けの、カタカナの **プリント** です。
カタカナを1画ずつに分けた「ピース」を見て、子どもが同じ色の色鉛筆でわくの中に書き、カタカナを組み立てます。
カタカナの学習アプリ「ロボタンと カタカナ」（[katakana/](../katakana/README.md)）のロボタンが出てきます。

- プリントを作るページ：`https://zku0395-ops.github.io/hori/kanapuzzle/`
- できあがった PDF：`kanapuzzle/pdf/` にあります（段階ごとに1つのファイル。3段階をまとめた「ぜんぶ」もあります）
  - 清音（ア〜ン）：各15まい
  - てんてん・まる（濁音・半濁音）：各8まい
- PDF は保存して、メールでほかのパソコンに送れます（[PDF を保存して、メールで送る](#pdf-を保存してメールで送る)）

## できること

| 項目 | 内容 |
|---|---|
| 文字 | 清音46文字。画数の少ない文字から、やさしい形の順にならべています |
| てんてん・まる | 濁音・半濁音25文字（ガ〜ポ。ヂ・ヅも入れています。ヴは入れていません）。「もとの もじ」と「゛」「゜」の2まいのピースで組み立てます |
| プリント | 清音：れんしゅう1まい ＋ その1〜その14（3段階で45まい）<br>てんてん・まる：5つの行 ＋ みくらべ1〜3（3段階で24まい） |
| 組み立て方 | はさみは使いません。ピースと同じ色の色鉛筆で、わくの中に書きます |
| 色 | 1画目 あか、2画目 あお、3画目 みどり、4画目 オレンジ。どの文字も同じです |
| 書き順 | ピースに ①②③ の番号と、書きはじめの「○」を付けています |
| 用紙 | A4たて。清音は1まいに3文字（れんしゅうは4文字）で、わくは約5.6cm角です。てんてん・まるは1まいに1つの行（5文字）で、わくは約4cm角です |
| プリントの上 | ロボタンとセリフ、段階のマーク、がつ・にち・なまえ、「できたよ」のシールらん |
| 作るページ | 段階・プリントを選んで印刷できます。好きなカタカナ（濁音も）を入れて作ることもできます |
| 保存・メール | できあがった PDF を「⬇ ほぞん」で保存できます。選んだプリントも「💾 PDFで ほぞん」で PDF にできます。保存した PDF は、メールに付けて送れます |

## ステージ構成

### 段階

| 段階 | わくの中 | ピース | みほん |
|---|---|---|---|
| ★1 かげ | 色付きのうすい「かげ」と、色の点（書きはじめ） | 番号の順 | なし（かげが見本） |
| ★2 マス | 十字の点線と、灰色の点（書きはじめ） | 番号の順 | あり |
| ★3 じぶんで | わくだけ | 順番をばらばらにしています | あり |

- どの段階も、左に読み（ひらがな）を出しています。
- 作るページで「『みほん』を出さない」を選ぶと、★2・★3 のみほんを消せます。

### てんてん（゛）・まる（゜）のプリント

ピースは2まいです。①「もとの もじ」（灰色）はえんぴつで、②「゛」「゜」（むらさき）はむらさきの色鉛筆で書きます。

| プリント | 文字 | ねらい |
|---|---|---|
| ガぎょう | ガ ギ グ ゲ ゴ | カ行に「゛」 |
| ザぎょう | ザ ジ ズ ゼ ゾ | サ行に「゛」 |
| ダぎょう | ダ ヂ ヅ デ ド | タ行に「゛」 |
| バぎょう | バ ビ ブ ベ ボ | ハ行に「゛」 |
| パぎょう | パ ピ プ ペ ポ | ハ行に「゜」 |
| みくらべ1 | バ パ ビ ピ | 「゛」と「゜」を見くらべる |
| みくらべ2 | ブ プ ベ ペ | 〃 |
| みくらべ3 | ボ ポ | 〃 |

- 段階（★1 かげ／★2 マス／★3 じぶんで）は、清音と同じです。★1 のかげは、もとの文字が灰色、「゛」「゜」がむらさきです。
- ★3 では、「゛」「゜」のピースを先にならべています。
- みくらべは、同じもとの文字のペア（バとパ など）が、まいをまたがないようにしています。

## 支援の工夫

- **スモールステップ**：1画の文字 → 2画 → 3画 → 4画。同じ文字を ★1 → ★2 → ★3 の3段階で練習できます。
- **色で手がかり**：「1画目は いつも あか」と決めているので、色を見るだけで書き順が分かります。色の見分けがむずかしい子のために、番号も必ず付けています。白黒で印刷しても、番号で分かります。
- **にている文字**：ソとン、シとツは、同じプリントにならべて見くらべられるようにしています。
- **濁音のしくみが見える**：「カ」のピースに「゛」のピースを足すと「ガ」になります。「゛」「゜」はいつもむらさきなので、どこに付けるかに集中できます。バとパは、みくらべのプリントでならべて練習します。
- **ピースの大きさ**：ピースは、わくの中の文字と同じ大きさです（はみ出しそうなときだけ、少し小さくしています）。
- **はさみを使わない**：切ったり貼ったりがむずかしい子でも取り組めます。
- **ごほうび**：できたら「できたよ」らんにシールやスタンプを押します。
- ひらがなと分かち書きで書いています。

## 公開の手順

### 1. GitHub Pages

ほかのアプリと同じで、`main` ブランチに入ると `https://zku0395-ops.github.io/hori/kanapuzzle/` で開けます。新しい設定はいりません。

### 2. Apps Script とスプレッドシート

このプリントは、記録をとりません。Apps Script やスプレッドシートは使いません。

### 3. 印刷のしかた（Chromebook・パソコン）

**PDF を印刷するとき**
1. 作るページの「できあがった PDF を ほぞんする」で、印刷したい段階の「みる」を押します。PDF が新しいタブで開きます。
2. 右上の 🖨（印刷）を押します。
3. 「ページ」で、印刷したいページだけを選びます（例：れんしゅうは 1、その1 は 2）。

**作るページで選んで印刷するとき**
1. `https://zku0395-ops.github.io/hori/kanapuzzle/` を開きます。
2. 「1．段階を えらぶ」で ★1〜★3 を押します。
3. 「2．プリントを えらぶ」で、印刷したいプリントにチェックを入れます。
   - 好きな文字で作りたいときは、「じぶんで 文字を えらぶ」にカタカナを入れます（例：`シツソン`）。
4. 下にプリントの見本が出ます。よければ「🖨 いんさつ」を押します。
5. 印刷の画面で、次のように選びます。
   - 用紙サイズ：**A4**
   - 倍率：**100%**（または「実際のサイズ」）
   - 余白：**なし**
   - 「背景のグラフィック」に **チェック**（色がきれいに出ます）

### PDF を保存して、メールで送る

**できあがった PDF を保存する**
1. `https://zku0395-ops.github.io/hori/kanapuzzle/` を開きます。
2. 「できあがった PDF を ほぞんする」で、ほしい段階の「⬇ ほぞん」を押します。清音（ア〜ン）と、てんてん・まるに分かれています。
   - 3段階を1つのファイルで送りたいときは、「ぜんぶ」の「⬇ ほぞん」を押します。
3. PDF が「ダウンロード」フォルダに入ります。
   - Chromebook：左下の ○（ランチャー）→「ファイル」→「ダウンロード」
   - Windows のパソコン：エクスプローラー →「ダウンロード」

**選んだプリントだけを PDF にする**
1. 作るページで、段階とプリントを選びます。
2. 「💾 PDFで ほぞん」を押します。印刷の画面が開きます。
3. 「送信先」（Chromebook は「宛先」）を **「PDF に保存」** にします。
4. 「保存」を押します。ファイル名には、段階とプリントの名前が入ります。

**メールで送る（Gmail のとき）**
1. Gmail を開き、左上の「作成」を押します。
2. 宛先に、送り先のメールアドレスを入れます（自分のアドレスに送れば、自宅のパソコンでも開けます）。
3. 下にある 📎（ファイルを添付）を押します。
4. 「ダウンロード」フォルダから PDF を選び、「開く」を押します。
5. 「送信」を押します。

- PDF の大きさは、清音が1つの段階で約0.8MB、「ぜんぶ」で約2.4MB です。てんてん・まるは、それよりも小さくなります。メールでそのまま送れます。
- ファイル名には ★ などの記号を使っていません。ほかのパソコンでも、ファイル名がこわれにくくなっています。
- GitHub からも保存できます。`kanapuzzle/pdf/` の中のファイルを開き、右上の ⬇（Download raw file）を押します。

### 4. Googleサイトに置くとき

「挿入 → ボタン」で、リンクに `https://zku0395-ops.github.io/hori/kanapuzzle/` を入れます。「埋め込む」では印刷しにくいので、ボタンにしてください。

## 注意事項

- 書き順データ：[KanjiVG](https://kanjivg.tagaini.net/)（© Ulrich Apel、CC BY-SA 3.0）を使っています。プリントの右下にも書いています。
- ロボタンの絵、レイアウト、ことばは、すべてオリジナルです。
- KanjiVG の線の形は、教科書の字形と少しちがうところがあります。
- ピースの形と位置は、KanjiVG の書き順データから自動で作っています。プリントを直したときは、`node kanapuzzle/tools/make-pdf.js` で PDF を作り直します。
