# ロボタンの カナカナパズル（アプリ）

小学校の特別支援学級（1〜4年生）向けの、カタカナの学習アプリです。
カタカナを1画ずつに分けた「ピース」を、わくの中に はめて、カタカナを組み立てます。
プリント「ロボタンの カナカナパズル」（[kanapuzzle/](../README.md)）と、同じ文字の順・同じ色・同じ絵を使っています。

- お話：ロボタンの「もじ ディスプレイ」がこわれて、カタカナがバラバラになってしまいました。ピースを組み立てて、文字を直してあげます。
- 形：Apps Script だけで動くウェブアプリです（カタカナアプリ「ロボタンと カタカナ」と同じ形）。子どもは名簿の名前のボタンを押して始めます。
- 絵：プリント用に Canva で作った絵（103まい）を、GitHub Pages（`kanapuzzle/img/`）から読みこみます。
- おためし：`https://zku0395-ops.github.io/hori/kanapuzzle/app/` を開くと「おためしモード」で動きます（記録はその端末だけに残ります）。

## できること

| 項目 | 内容 |
|---|---|
| 文字 | 清音46文字（プリントと同じ、やさしい形の順）。はってんとして、濁音・半濁音25文字と、ー・ッ・ャ ュ ョ の入ったことば40 |
| 組み立て方 | ピースを **タップ** すると、正しい場所へ動いてはまります。指で **ドラッグ** して置くこともできます。★3 では、ピースを選んでから、わくの中の置きたい場所を押します（◀ ▲ ▼ ▶ ボタンでも動かせます） |
| 色 | 1画目 あか、2画目 あお、3画目 みどり、4画目 オレンジ。「もとの もじ」は灰色、゛゜ー・小さい字は むらさき（プリントと同じ） |
| 書き順 | ピースに ①②③ の番号と、書きはじめの「○」を付けています。★1・★2 は ①から順番に はめます |
| ことば | たて書きのマスに、文字のピースを上から並べます。小さい字はマスの右上、ー はたてに入ります |
| 読み上げ | ロボタンのセリフを読み上げます（はじめは 0.8倍の速さ）。ロボタンをタップするか「🔊 もういちど」で聞き直せます |
| ごほうび | 1文字（1つのことば）できるごとに **ねじ** が1つ。ねじ5つで、ペンキ（ロボタンの色）やシールと交換できます。ステージをクリアすると **大きな部品**（アンテナ・ぼうし・つばさ など33種類）がもらえます |
| ずかん | できた文字のことばの絵が「カタカナ ずかん」に集まります（103まい） |
| つづきから | 途中でやめても、次は続きの問題から始まります |
| 先生用画面 | 暗証番号4けたで開きます。記録（どの文字の、どの段階で、どのピースでまちがえたか）、子どもごとの設定、全体の設定、データ |

## ステージ構成

### 1文字の 段階（どのステージも ★1 → ★2 → ★3 → ★4）

| 段階 | わくの中 | ピース | 操作 |
|---|---|---|---|
| ★1 かげ | 色付きのうすい「かげ」と、書きはじめの点 | 書き順に1つずつ出ます | タップで はまる（ドラッグも できる） |
| ★2 マス | 十字の点線と、書きはじめの点 | 書き順どおりに全部ならびます。次のピース以外は うすく なります | タップで はまる（ドラッグも できる） |
| ★3 じぶんで | わくだけ | ばらばらの順。**まちがいやすいピースが1つ** まざります | ピースを選んで、置く場所を決める |
| ★4 どの もじ？ | ― | ピースだけを見せます | できる文字（ことば）を3つから選ぶ |

- 1回は5問です（そのステージの文字 ＋ 前のステージの ふくしゅう）。5〜10分で終わります。
- ★4 までできると、ステージクリアです。次のステージが開きます。
- ★2・★3 には、小さい「みほん」が出ます（先生用画面で消せます）。

### まちがいやすいピース（★3）・まちがいやすい答え（★4）

| ステージ | まぜるもの |
|---|---|
| カタカナ | にている文字の画（ソ ↔ ン、シ ↔ ツ、ア ↔ マ、ス ↔ ヌ、ヤ ↔ セ、ミ ↔ シ など） |
| てんてん・まる | 「゛」には「゜」、「゜」には「゛」 |
| ことば | 大きい ツ・ヤ・ユ・ヨ、よこの ー（たて書きでは ー は たて）。★4 では「ロケツト」「ケエキ」「ロケト」のような まちがい |

### ステージ（全部で33）

| コース | ステージ | 最初 |
|---|---|---|
| カタカナ（15） | れんしゅう（ノ フ ヘ レ）、その1（ニ ハ ト）、その2（リ ル ヒ）、その3（イ ナ メ）、その4（カ コ ユ）、その5（ク ス ヌ）、その6（マ ム ラ）、その7（ア ヤ セ）、その8（ワ ソ ン）、その9（エ キ テ）、その10（サ チ モ）、その11（ウ ケ タ）、その12（ヨ ロ ヲ）、その13（ミ シ ツ）、その14（オ ネ ホ） | 開いている |
| てんてん・まる（8） | ガぎょう、ザぎょう、ダぎょう、バぎょう、パぎょう、みくらべ1（バ パ ビ ピ）、みくらべ2（ブ プ ベ ペ）、みくらべ3（ボ ポ） | はってん（閉じている） |
| ことば（10） | のばす おと1〜3、ちいさい ッ1・2、ちいさい ャ、ちいさい ュ、ちいさい ョ、まとめ1・2（ことばはプリントと同じ） | はってん（閉じている） |

## 支援の工夫

- **スモールステップ**：かげ（見本の上に置く）→ マス（場所を考える）→ じぶんで（ピースを選ぶ・場所を決める）→ どの もじ？（部分から全体を思いうかべる）。
- **成功の体験から**：★1・★2 はタップだけで はまります。自分で場所を決めるのは ★3 からです。
- **ヒントは3段階**：①ことば（「つぎは 2かくめ。あおの ピースだよ」）→ ②正しい場所が ピースの色で光る → ③ピースが動いて はまるようすを見せる（そのあと自分で はめる）。同じピースで2回まちがえるとヒントボタンが光り、3回まちがえると ③が自動で出ます。
- **まちがえたとき**：ちがう場所に置いたピースは、もとの場所にもどります。まちがいやすいピースを選んだときは、そのピースが消えて「それは ン の ピースだよ。ン の ながい せんは、したから うえへ かくよ」のように、ちがいを教えます。音はブザーではなく、小さな音です。
- **色と番号**：「1画目は いつも あか」なので、色を見るだけで書き順が分かります。色の見分けがむずかしい子のために、番号も付けています。
- **絵でイメージ**：できると「イ！ イルカの イ」と、絵とことばで文字を確かめます。
- **ドラッグがむずかしい子**：タップ、わくを押す、◀ ▲ ▼ ▶ ボタンでも操作できます。先生用画面で、その子の ★3 の はめかたを「ゆるく」（わくの中なら正しい場所に はまる）できます。
- **時間制限はありません**。問題の画面は背景をすっきりさせ、にぎやかな絵はホーム・こうじょう・ずかんだけで使います。

## ファイル構成

```
kanapuzzle/app/index.html   アプリ本体（Apps Script の HTML ファイル「index」に貼り付けます）
kanapuzzle/app/コード.gs     スプレッドシートとつなぐプログラム（Apps Script の「コード.gs」に貼り付けます）
kanapuzzle/img/             ことばの絵（Canva で作成。プリントと同じ。GitHub Pages から読みこみます）
```

- 書き順のデータは `index.html` の中に入っています（プリント・カタカナアプリと同じもの）。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/kanapuzzle/app/` を開きます。
   - 「おためしモード」で動き、できあがったときに絵が出れば、絵の公開はできています。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「カナカナパズル 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `kanapuzzle/app/index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、ピースを動かしにくくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

1. 名前を選ぶ画面の右下（学習中は右上）の **🔒 せんせい** を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「設定」で変えてください。**

| タブ | できること |
|---|---|
| 学級全体 | 子どもごとの いま学習中のステージ・クリアしたステージ数・問題数・1回目でできた割合・ヒントを使った数・最後に学習した日・つまずいている文字。学級全体で つまずきが多い文字と、よくあった まちがい（例：「ンの ピース×3」「ばしょ×2」） |
| 子どもごと | 清音・濁音の表と、ことばの一覧が「1回目でできた」割合で色分けされます（赤60%未満／黄60〜79%／緑80%以上）。文字を押すと、★1〜★4 の段階ごとの結果と、よくあったまちがいが出ます。ステージの進み具合も見られます |
| 子どもごと（ボタン） | 全部開く、はってん：てんてん・まる を開く、はってん：ことば を開く、★3 の はめかたを ゆるくする、始めるステージを選ぶ、この子の記録を消す |
| 設定 | 読み上げの速さ、声の高さ、文字の大きさ、効果音、★3 のピースに番号を出すか、★2・★3 に見本を出すか、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、全員の記録を消す |

- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。
- ★3 の番号を出すと、①から順番に はめます（書き順の練習）。出さないときは、順番は自由です（形と場所だけで考えます）。
- 「始めるステージ」を選ぶと、そのステージまでが開きます。すでにカタカナが書ける子は、とばして始められます。

## 全員の記録を見る

- スプレッドシートの **「きろく」** シートに、1問ごとの結果が入ります。

  | 日時 | なまえ | コース | ステージ | だんかい | もんだい | けっか | まちがい | ヒント | まちがえた ピース | ID |
  |---|---|---|---|---|---|---|---|---|---|---|

  - けっか：○＝まちがえず、ヒントも使わずにできた　△＝まちがえてから、またはヒントを使ってできた
  - まちがい：まちがえた回数　ヒント：使ったヒントの段階（0〜3）
  - まちがえた ピース：「ンの ピース」＝★3 でまちがいやすいピースを選んだ、「ばしょ」＝ちがう場所に置いた、「ソ」「ロケツト」＝★4 で選んだまちがい
- **「まとめ」** シートに、子どもごと・文字（ことば）ごとの「1回目でできた」割合（低い順）と、よくあったまちがいが入ります。先生用画面を開いたとき、またはメニュー **ロボタン → まとめを更新する** で更新されます。
- **「名簿」** シートのB列に、進み具合・ねじ・部品が入ります。ちがう Chromebook を使っても「つづきから」始められます。
- ネットが切れていたときの記録は、その Chromebook にためておき、つながったときに送り直します。同じ記録は二重に書きません。

## 注意事項

- **個人情報**：名簿には、呼び名かひらがなの名前だけを入れてください。
- **絵**：ことばの絵は、先生の Canva で、プリントのために作った画像です（プリントと同じ103まい）。ロボタン・部品・ねじは、このアプリのためのオリジナルの絵（SVG）です。
- **書き順のデータ**：[KanjiVG](https://kanjivg.tagaini.net/)（© Ulrich Apel ほか、CC BY-SA 3.0）を使っています。
- **効果音**：このアプリのためのオリジナルです（プログラムで作っています）。
- 絵は GitHub Pages から読みこむので、ネットにつながっている必要があります。絵が出ないときも、パズルはできます。
- 「止まった」「開かない」ときは、まず `index.html` の貼り付けが最後（`</html>`）まで入っているかを確かめてください。

## これから相談して決めること

- ★3 で、ピースを回す（向きを考える）段階を足すか
- 清音の「ふくしゅう ステージ」（にている文字だけを集めたもの：ソ ン シ ツ など）を足すか
- 部品の種類を増やすこと、ロボタンに名前を付けたり、写真をとったりする機能
- ことばを増やすこと（子どもの生活に合わせて入れかえる）
- プリントとアプリの記録を合わせて見る機能
