# サンカと かたちの おうこく（三角形・四角形の学習アプリ）

小学校の特別支援学級向けの、三角形と四角形の学習アプリです。ロールプレイングゲーム風に進みます。

- まおう「グニャール」が、かたちの おうこくの まっすぐな線を ぐにゃぐにゃに してしまいました。
- 子どもは「ゆうしゃ」になり、ようせいの「サンカ」と いっしょに、7つの場所を たびします。
- 問題に正解すると、まものに こうげきできます。まものを たおすと、コインと たからものが もらえ、レベルが上がります。
- まちがえても、ゆうしゃは ダメージを受けません。時間制限も ありません。

## できること

| 項目 | 内容 |
|---|---|
| 学習内容 | ①点を3つ結んで三角形を作る　②点を4つ結んで四角形を作る　③「へん」と「ちょう点」　④きまり（3本・4本の直線で かこまれた形）から三角形・四角形を見つける　⑤三角形・四角形・どちらでもない を判断し、わけを選ぶ　⑥1本の直線に へんを かき足して形を作る　⑦タングラムで形を作る |
| 進め方 | 7つの場所 × 3ステップ ＝ 21ステージ。1回5問（先生用画面で 3・5・7問に変えられます）。1つのステージで **合わせて10問** 正解すると、次が開きます（5・10・15問に変えられます）。途中でやめても「つづきから」始められます |
| ゆうしゃ | けんし・まほうつかい・たんけんか（男の子・女の子）の6人から選びます |
| ごほうび | 正解1問で コイン1まい と けいけんち。1回おわるごとに コイン5まい。合わせて10問 正解すると たからもの。ヒントを使っても同じように もらえます |
| おみせ | コインで、ぼうし・もちもの・かざり・なかま（15こずつ、合わせて60こ）を買い、ゆうしゃに付けられます。たなのボタンで切りかえます。値段は 10〜200コインです |
| ずかん | たからもの21こ、しょうごう（レベルで変わります） |
| 形のアルバム | 点を結んで作った三角形・四角形が、ステージごとに ならびます（1・2・6 の場所）。ステージをクリアしたときにも、「きみが つくった 三角形」として出ます。地図の「🖼 アルバム」で、いつでも見られます |
| 文字 | ひらがなと分かち書きです。漢字（三角形・四角形・直線・形・線・点）には、すべて ふりがなが付きます |
| 声 | サンカのセリフを読み上げます（サンカか「🔊 もういちど」を押すと聞き直せます） |
| 先生用画面 | 暗証番号4けたで開きます。ステージごとの結果、まちがいの種類、設定、CSV書き出し、バックアップができます |
| 全員の記録 | 1問ごとに、結果が先生のGoogleスプレッドシートへ届きます |

## ステージ構成

| 場所（まもの） | ステップ | 内容 |
|---|---|---|
| 1 はじまりの むら（プルン） | 1-1 | 光る点を順にタッチして、三角形を作る |
| | 1-2 | 点を3つ自由に選んで、三角形を作る |
| | 1-3 | ★の点を使って、三角形を作る |
| 2 かぜの そうげん（ヒュルリ） | 2-1 | 光る点を順にタッチして、四角形を作る |
| | 2-2 | 点を4つ自由に選んで、四角形を作る |
| | 2-3 | ★の点を使って、四角形を作る |
| 3 ささやきの もり（キノッコ） | 3-1 | へんを全部タッチして数える →「なんぼん？」 |
| | 3-2 | ちょう点を全部タッチして数える →「いくつ？」 |
| | 3-3 | 赤いところの名前（へん・ちょう点）、へん・ちょう点の数のクイズ |
| 4 ひかりの どうくつ（ゴロン） | 4-1 | 「3本の直線で かこまれた形」を3つの中から選ぶ |
| | 4-2 | 「4本の直線で かこまれた形」を3つの中から選ぶ |
| | 4-3 | 6つの中から、三角形（四角形）を全部見つける |
| 5 なぞの とう（ホンホン） | 5-1 | 三角形・四角形・どちらでもない を選ぶ |
| | 5-2 | 上に加えて、わけを4つの中から選ぶ |
| | 5-3 | 細長い形、1つの へんだけ まがった形、すきまが小さい形 など |
| 6 かけはしの たに（ガケドリ） | 6-1 | 青い へんに、へんを2本たして三角形（点を1つタッチ） |
| | 6-2 | 青い へんに、へんを3本たして四角形（点を2つタッチ） |
| | 6-3 | ななめの へんから、三角形・四角形を作る |
| 7 まおうの しろ（グニャール） | 7-1 | タングラム（2〜3まい。くぎりの線が見える。むきは自動で合う） |
| | 7-2 | タングラム（4〜7まい。「🔄 まわす」で むきを合わせる） |
| | 7-3 | まおう グニャール。これまでの全部の まとめ |

- 1つのステップで、合わせて10問 正解すると、クリアになり、次が開きます（1回5問なので、2回で開きます）。
  - 場所を押すと、ステップごとに「6／10もん」のように、あといくつかが出ます。
  - 10問にとどく前に1回が終わると、「まものを おいはらった！ たからものまで あと ○もん」と出て、「もう いちど」で続けられます。
  - ヒントを使った正解も、1問に数えます。
  - 「10問」は、先生用画面で 5・10・15問に変えられます（クラス全体と、子どもごと）。
  - 前の版（1回でクリア）でクリアしたステップは、クリアのままです。
- 先生用画面で、子どもごとに「どこまで開くか」を決められます（じゅんばんに／○○ まで／ぜんぶ）。
- クリアしたステージは、何度でもやり直せます（コインも もらえます）。
- わけの選択肢は、次の4つです。
  1. 3ぼんの 直線で かこまれて いるから、三角形
  2. 4ほんの 直線で かこまれて いるから、四角形
  3. まがった 線が あるから、どちらでも ない（かどが まるい形も これです）
  4. 線が つながって いないから、どちらでも ない

## 支援の工夫

- **スモールステップ**
  - 「光る点をタッチ」→「自由に作る」→「★の点を使う」の順に進みます。
  - 「数える」→「名前」→「きまりで見つける」→「わけを言う」の順に進みます。
  - タングラムは、2まいから始め、むきを合わせる操作は あとで出ます。
- **まちがいやすい形を入れる**
  - かどが まるい形、とじていない形、まがった線がある形、五角形、細長い三角形 を まぜます。
  - 「へん」を聞かれて「ちょう点」をタッチする、などの まちがいに 声かけをします。
- **まちがえたとき**
  - 小さな音が鳴り、まちがえた選択肢は うすくなって、もう一度選べます。
  - まちがい方に合わせて声かけをします。
    - 点が一直線：「てんが まっすぐ ならんで いるよ。これだと 三角形に ならないね。」
    - 線が交わる：「線が まじわって いるよ。となりの てんを、ぐるっと じゅんばんに タッチ しよう。」
    - かどが まるい形を三角形と答えた：「かどが まるいね。まがった 線が あるから、三角形では ないよ。」
  - コインは へりません。ゆうしゃも ダメージを受けません。
- **ヒントは3段階**
  1. ことば（きまりを もう一度言う）
  2. 色分け・見本（まっすぐな線に 色と番号を付ける、まがった所や すきまを赤くする、点つなぎは うすい線の見本、タングラムは くぎりの線）
  3. 答えを光らせる（次にタッチする点・正しい選択肢・ピースと置く場所）
  - 2回まちがえると「💡 ヒント」が光り、3回まちがえると 3 のヒントが自動で出ます。
- **画面・操作**
  - 問題の画面は白い背景です。たたかいの絵は、上の細い帯だけに出します。
  - タングラムは、ピースを ひっぱっても、「ピース → 置く場所」の順にタッチしても 置けます。
  - 点つなぎは「↩ 1つ もどす」で やり直せます。

## ファイル構成

```
katachi/
├── index.html        アプリ本体（Apps Script の HTML ファイル「index」に貼り付けます）
├── コード.gs         Apps Script（シートの準備・記録の受け取り・先生用の集計）
├── e_chatgpt.md      ChatGPT で作る絵の注文書
├── img/              ChatGPT で作った絵（78まい。キャラクター・背景18まいと、おみせのアイテム60まい `it_hat01`〜`it_pet15`。GitHub Pages から読みこみます）
└── tools/test_gas.js コード.gs のテスト（node katachi/tools/test_gas.js）
```

- 絵がないときは、絵文字で出します。`img/` に決まった名前で絵を置くと、その絵に変わります（`index.html` は直さなくてよい）。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/katachi/` を開きます。
   - 「おためしモード」で動けば、公開はできています（このページでは記録はスプレッドシートに届きません）。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「かたちの おうこく 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `katachi/index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
   - 種類：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（学校のアカウントだけにできるときは、そちら）
10. 出てきた **ウェブアプリのURL** を控えます。これが子どもに配るURLです。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

名前を選ぶ画面の右下「⚙ せんせい」を押し、暗証番号を入れます。はじめの番号は **1234** です。最初に「設定」で変えてください。

| タブ | できること |
|---|---|
| 記録 | 子どもごとの レベル・コイン・クリアした数・問題数・1回で正解した割合・まちがいの数・ヒント・多いまちがい。名前を押すと、**ステージごとの結果と まちがいの種類** が出ます（60%未満は赤、80%未満は黄色）。クリアまでの進み具合（6／10 など）も出ます。その下に、**その子が作った形**（ステージごと）が出ます |
| 　作った形の見方 | ステージごとに、新しいほうから10こまで残ります。みどり＝三角形、水色＝四角形、青い線＝はじめから あった へん（6 の場所）。v1.2.0 より前に作った形は、のりません |
| 設定（クラス全体） | 読み上げの速さ、文字の大きさ、1回の問題の数（3・5・7問）、次のステージが開くまでの正解の数（5・10・15問）、効果音、暗証番号。「保存する」を押すと変わります |
| 設定（ひとりずつ） | 子どもごとに、1回の問題の数、次が開くまでの数、どこまで開くか（じゅんばんに／2〜6の場所まで／ぜんぶ）、コインを足す（＋10・＋50・＋100）、はじめからにする。えらぶと すぐに保存され、子どもが次に名前を選んだときから変わります |
| データ | CSVで書き出す、バックアップの保存と元にもどす、記録を消す（子どもごと・全員） |

- 「はじめからにする」と「記録を消す」は、その子の記録・進み具合・コイン・たからものを消します。元に戻せません。「ひとりずつの設定」は残ります。
- `コード.gs` と `index.html` を新しくしたときは、Apps Script で両方を貼り直し、「デプロイ → デプロイを管理 → 鉛筆 → バージョン：新バージョン → デプロイ」で更新します（URLは変わりません）。

## 全員の記録を見る

スプレッドシートの「きろく」シートに、1問ごとに1行ずつ記録が届きます。

| 列 | 内容 |
|---|---|
| ステージ | `1-1`〜`7-3`（場所 - ステップ） |
| もんだい | 問題の種類（例：`点をむすぶ(三角形)`、`なかまわけ:三角(かどが丸い)+わけ`、`タングラム:いえ(4まい)`） |
| けっか | ○＝1回で正解、△＝まちがえてから正解 |
| まちがい | 正解するまでに まちがえた数 |
| ヒント | 使ったヒントの段階（0〜3） |
| まちがいの しゅるい | いっちょくせん・せんが まじわる・かどが たりない・★を つかわない・へんと ちょう点・かぞえ まちがい・三角形と 四角形・まがった線の 形・とじて いない 形・五角形・わけの えらび まちがい・ピースの むき・ピースの 形 |
| びょう | その問題にかかった秒数 |

- 「まとめ」シートは、先生用画面を開いたときか、メニュー **かたちの おうこく → まとめを更新する** で作り直されます。
- 子どもの名前は、呼び名かイニシャルで登録してください。

## 注意事項

- 記録は、先生のスプレッドシートとその端末のブラウザに保存されます。ネットにつながらないときは端末にためておき、つながったときに送り直します。
- 同じ子どもが別の Chromebook を使っても、スプレッドシートの進み具合から続きができます。
- お話・キャラクター・まもの・問題は、すべてこのアプリのためのオリジナルです。図形は自作のSVG、品物と たからものは絵文字です。
- 絵（ゆうしゃ6人・サンカ・まもの7ひき・地図・背景2まい）は、ChatGPT の AI で作りました。参考にした市販のゲームの画面は ChatGPT に読みこませず、ことばで特徴だけを伝えています（`e_chatgpt.md`）。ゆうしゃ と まもの は、数人を1まいにまとめて作り、1人ずつに切り分けて、背景を透明にしています。
- 記録の形式（ステージの `1-1` などの番号、シートの見出し、`ID` の列）は、あとから変えないでください。
- 「そらの うえの がっこう」には、さんすうの へや →「かたち・かくど」の たなに 入っています（`sora/apps.js` の `katachioukoku`）。ウェブアプリの URL を 新しく 作りなおしたときは、教えてください。

## これから相談して決めること

- 形のアルバムに、タングラムで作った形や、おしい形（一直線・線が交わる）ものせるか。
- アルバムの形を、印刷できるようにするか。
- 絵の大きさ・位置の調整（地図の絵に合わせて、場所のボタンの位置をもっと動かすか。気に入らない絵を作り直すか）。
- おみせのアイテムを、ゆうしゃが身に付けた すがたの絵にするか（今は、ゆうしゃの絵の上に小さく重ねています）。
- 最初のページの題名の文字（今は、ドットの文字・赤に金のふち）。
- 三角形・四角形の「はってん」（直角三角形・正方形・長方形）を足すか。
- タングラムの形を ふやすか（どうぶつ・ふね など）。ピースを うらがえす操作を入れるか。
- プリント（点つなぎ・なかまわけ）を作るか。
- サンカの声を Gemini-TTS にするか（いまはブラウザの声）。
