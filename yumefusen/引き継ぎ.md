## 1. 作りたいもの

小学校の特別支援学級（1〜4年生）の子どもが、**「〜したい」という願いと、その理由を考えて書く** 学習アプリです。

> かいたい どうぶつは、いぬです。
> そのりゆうは、いっしょに さんぽが できるからです。

子どもは学校の Chromebook をタッチで使います。

## 4. ChatGPT で作る絵（案）

### 作る絵の一覧

| しゅるい | まい数 | 中身 |
|---|---|---|
| フワリさん | 4 | ふつう・よろこぶ（はくしゅ）・かんがえる・ふうせんを わたす |
| 背景 | 3 | ホーム（丘の上の ふうせんやさん）・ゆめの そら（星の夜空）・はっぴょうの ステージ |
| えらぶ もの | 6 | お題ごとに12こを、**4こ×3だん の1まい** にまとめて作る（あとで Claude が1こずつ切り分ける） |

### プロンプトの例（ChatGPT にそのまま貼る）

**フワリさん（ふつう）**
```
オリジナルのキャラクターを作ってください。
ふうせんやさんをしている、やさしいペンギン「フワリさん」。
小学生向けの学習アプリで使います。
・やわらかい水彩風の、明るくかわいいイラスト
・太めのはっきりした線、丸い形
・赤いエプロン、小さな帽子、手に色とりどりのふうせん
・全身、正面、笑顔
・背景は白一色、文字は入れない
・既存のキャラクターに似せない
・正方形
```
（ほかのポーズは、最後の行の前に「両手でぱちぱち はくしゅして よろこんでいる」「首をかしげて かんがえている」「ふうせんを1つ さしだしている」と書きかえ、「さっきと同じキャラクターで」と添えます。）

**えらぶ もの（例：かいたい どうぶつ）**
```
小学生向けの学習アプリで使う、オリジナルのイラストを作ってください。
4こ×3だんの 12マスに、1マスに1つずつ、次のものを描いてください。
いぬ、ねこ、うさぎ、ハムスター、インコ、かめ、
きんぎょ、カブトムシ、パンダ、ライオン、ペンギン、イルカ
・やわらかい水彩風の、明るくかわいいイラスト、太めのはっきりした線
・マスの間を広くあけ、絵がとなりのマスにはみ出さない
・背景は白一色、文字・数字・わく線は入れない
・既存のキャラクターに似せない
・正方形
```

### 絵の受け渡し
- 先生が作った絵を、チャットにアップロードします。
- 絵がそろうまでは、絵文字で仮に作って動かし、あとで入れかえます。
- ほかの人の絵やキャラクターには似せません。README の注意事項に「絵は先生が ChatGPT で作ったオリジナル」と書きます。

## 5. これから相談して決めること

次の順に、番号付きで少しずつ質問してください。

1. 上の「えらぶ もの」の一覧でよいか（入れかえたいもの）
2. 絵の作り方でよいか（12こを1まいにまとめて作る、で ChatGPT がうまく作れるか）
3. 文のはじめの形（お題ごと）
   - 「かいたい どうぶつは、〇〇です。」「いきたい ところは、〇〇です。」「なりたい ものは、〇〇です。」「ほしい ものは、〇〇です。」「たべたい ものは、〇〇です。」「やって みたい ことは、〇〇です。」
   - 「わたしの」「ぼくの」を付けるか
4. 理由のカードの しゅるい（例：みため・できること・きもち・やくに たつ・たのしい こと）と、「合わない カード」の入れ方
5. ごほうび（ゆめの そら の 星、ふうせんカードのアルバム、しょうごう など）
6. 書く方法（画面の50音キーボード／Chromebook のキーボード。ペラリさんのアプリと同じにするか）
7. 先生用画面で見たいこと（どのお題・どのステージでつまずくか、子どもが書いた文 など）
8. アプリの名前と、キャラクターの名前（フワリさん でよいか）
9. フォルダ名（仮：`yumefusen/`）

すべて決まって「ok」が出たら作ります。
