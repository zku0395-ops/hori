# フワリさんの ゆめの ふうせんやさん（「〜したい」と理由を書く学習アプリ）

小学校の特別支援学級（1〜4年生）向けの、国語の「願いと理由を書く」アプリです。
6つのお題から自分の「〜したい」を選び、次の2つの文を書きます。

> ① かいたい どうぶつは、いぬです。
> ② そのりゆうは、いっしょに さんぽが できるからです。

- おはなし：ふうせんを売っている、やさしいペンギン「フワリさん」のお店です。願いと理由を書くと、ゆめが ふうせんに乗って空へとんでいき、「ゆめの そら」に星が1つ増えます。
- お題は6つ（<ruby>飼<rt>か</rt></ruby>いたい どうぶつ・いきたい ところ・なりたい もの・ほしい もの・たべたい もの・やって みたい こと）。お題ごとに ふうせんの色（ピンク・みずいろ・きいろ・みどり・オレンジ・むらさき）が決まっています。1つのお題に12こ、全部で72この「えらぶ もの」があります。
- ペラリさんのアプリ（`sukiwake/`「すきの わけ テレビきょく」）の次に使うアプリです。書き方（50音キーボード）や画面の使い方は、ペラリさんのアプリと同じです。
- 形は「Apps Script だけ」です。子どもは名簿の名前のボタンを押して始めます。
- データと絵は、GitHub Pages（`https://zku0395-ops.github.io/hori/yumefusen/`）から読みこみます。Apps Script に貼り付けるファイルを短くするためです。

## できること

| 項目 | 内容 |
|---|---|
| お題と ものを選ぶ | 6色の ふうせん（お題）→ 12この もの の絵から1つ選びます。1回の中で、ほかのお題に変えることもできます。書いたものには 🎈 が付きます |
| 理由のカード | どの ものも、3つの見方（💪 できること・👀 ようす・💗 きもち）で1まいずつ、合うカードを作っています。見方ごとに色分けします（先生用画面で「なし」にもできます）。全部で216まい |
| 合わないカード | ステージ①では、同じお題の ほかの ものの理由（いぬ に「うみで ジャンプが できる」＝イルカの理由）を1まい まぜます |
| 文のおわり | 「できる**から**です」と「ふわふわ**だから**です」の ちがいを、ステージ②で練習します。「🔊 よんで みる」で両方を読み上げて、自然に聞こえるほうを選びます |
| 書く | 画面の50音キーボードで書きます。先生用画面で、子どもごとに Chromebook のキーボードに切りかえられます |
| 書き出しボタン | 自分で書くステージでは、3つの見方の書き出し（例：かいたい どうぶつ なら「いっしょに …」「みためが …」「いっしょに いると …」）のボタンを出します。押すと、書き出しが入ります |
| 声 | フワリさんのセリフと、できた文を読み上げます（はじめは0.8倍の速さ）。フワリさんか「🔊 もういちど」を押すと聞き直せます |
| はっぴょう | 文ができると、ステージの画面に大きく出ます。3・2・1のあと「どうぞ！」で子どもが読み、「📣 よんだよ！」を押すと はくしゅ の あと、ふうせんが空へとびます（先生用画面で「つかわない」にもできます。そのときは ふうせんが とぶ ところだけ出ます） |
| ゆめの そら（ごほうび） | 1つ書くと 星が1つ増えます。星5こで 🌙 おつきさま、10こで 🌠 ながれぼし、20こで 🌈 にじ が出ます。書いた ふうせんも空に うかびます。6色そろうと「にじいろの ふうせん」がもらえます |
| ふうせんアルバム | 書いた文が「ふうせんカード」（ものの絵と2つの文）になり、お題ごとに12まいの わくに たまります（もの1つに1まい。新しく書くと入れかわります）。カードを押すと大きくなり、「🔊 よむ」「📣 はっぴょう」ができます |
| しょうごう | 星の数で変わります（ふうせん みならい → ふうせん じょうず〈10こ〉→ ふうせん めいじん〈30こ〉→ ゆめの そらの はかせ〈60こ〉） |
| はなまる | 先生が先生用画面で 💮 を押すと、その子の ふうせんカードに はなまるが付きます。子どもが次に開くと、フワリさんが「せんせいから はなまるが とどいたよ！」と伝えます |
| 先生用画面 | 暗証番号4けたで開きます。どのお題・どのステージで つまずくか、合わないカード、よく選ぶ見方、子どもが書いた文が分かります |
| 全員の記録 | 結果は先生のGoogleスプレッドシートへ届きます。子どもが書いた文も届きます。進み具合・星・ふうせんカードも、スプレッドシートに保存します |

## ステージ構成

| ステージ | 学ぶこと | 子どもがすること | 1回 |
|---|---|---|---|
| ⓪ 「〜したい」の ぶん | ①の文の形 | 「いきたい ところ／は、／うみ／です。」のカードを順に押して並べる | 5つ |
| ① りゆうの カード | 理由を選ぶ | 4まいのカード（合うカード3まい＋合わないカード1まい）から、理由を1まい選ぶ。文のおわりはアプリが付ける | 5つ |
| ② ぶんの おわり | 「からです」と「だからです」 | 理由のカードを1まい選び、「からです。」「だからです。」のどちらかを選ぶ（🔊で両方を聞ける） | 5つ |
| ③ じぶんで かく | 理由を自分で書く | 「そのりゆうは、」の あとに理由を書き、「からです。」「だからです。」を選ぶ。書き出しボタンが使える | 3つ |
| ④ まとめ | 2つの文を全部書く | ①の文と②の文を、はじめから全部書く | 3つ |
| はってん① なぜなら | ちがう言い方 | 「なぜなら、〜からです。」で理由を書く | 3つ |
| はってん② りゆうを 2つ | 理由を2つ | 「そのりゆうは、〜からです。それに、〜からです。」で理由を2つ書く | 3つ |

- 前のステージをクリアすると、次が開きます。
- はってんは、はじめは閉じています。先生用画面の「子どもごと」で開きます。はってん② は、はってん① をクリアすると開きます。
- 途中でやめても、次は「つづきから」始められます（残りの数から）。
- お題・もの・理由のカードは `data/yume.js` にあります。

## 支援の工夫

- **自分で選ぶ**：毎回、自分の「〜したい」を選んでから文を作ります。絵を見て選べるので、ことばが浮かばない子も始められます。
- **スモールステップ**：①の文の形 → 理由を選ぶ → 文のおわり → 理由を書く → 全部書く、の順に少しずつ自分で書く部分を増やします。③までは①の文をアプリが出しておき、理由だけを書きます（④だけ全部書きます）。
- **理由を考える手がかり（3つの見方）**：どの ものの理由も「できること・ようす・きもち」の3つの見方で作り、カードの上に小さく見方を書いています。③の書き出しボタンも同じ3つの見方です。いつも同じ見方なので、「どの見方で書こうかな」と考える手がかりになります。
- **合わない理由に気づく**：①には、同じお題の ほかの ものの理由を1まい まぜます。選ぶと、カードは消えて「『うみで ジャンプが できる』は、イルカの りゆう みたいだね」と声をかけます。にている もの（いぬ と ねこ など）の理由は まぜません。
- **「から」と「だから」**：「できる・かわいい」の あとは「からです」、「ふわふわ・きれい・しあわせ」の あとは「だからです」です。
  - ②では「🔊 よんで みる」で両方を読み上げ、自然に聞こえるほうを選びます。
  - まちがえると、1回めは「『ふわふわからです』。こえに だして よんで みよう。ちょっと へんだね。」、2回めからは「『ふわふわ』の あとは『だからです』に なるよ。」と声をかけます。
  - 自分で書いた ことばも、アプリが見分けます。見分けられない ことばは、どちらでも正解にします。
- **漢字**：子どもの画面は ひらがなと分かち書きです。「かいたい どうぶつ」だけ「<ruby>飼<rt>か</rt></ruby>いたい」と漢字1字にして、ふりがなを付けます（「描きたい」と まちがえないため）。フワリさんが「いっしょに くらしたい どうぶつの ことだよ」と説明します。
- **書く支援**：50音キーボードは、教室の50音表と同じ並び（あ が いちばん右）です。「からです」まで書いてしまっても、アプリが読み取ります。文の最後の「。」を書きわすれたときは、アプリが付けます。子どもが入れた わかち書きの あき は、そのまま残します。
- **ヒントは3段階** です。2回まちがえるとヒントボタンが光り、3回まちがえると ヒント③が自動で出ます。

  | ステージ | ヒント① ことば | ヒント② 見本・色 | ヒント③ 答え |
  |---|---|---|---|
  | ⓪ | 次に入る ことばを たずねる | ますに うすい文字で見本 | 次のカードが光る |
  | ① | 「できる ことや、ようす、きもちを おもいだしてね」 | カードを読み上げ、見方の色を付ける | 合うカードが光る |
  | ② | 「〜からです・〜だからです、どっちかな？」 | 「から」と「だから」の きまりを話す | 正しい方が光る |
  | ③・はってん | 3つの見方で たずねる | 理由のカード（3まい）を出す。押すと その ことばが入る | 書き方の例を話す |
  | ④ | 2つの文の形を話す | 2つの文の見本を うすく出す | ①の文と「そのりゆうは、」を入れる |

- **まちがえたとき**：まちがえたときの音は、小さな音です。時間制限はありません。ヒントや書き出しボタンを使っても、ごほうびは同じです。
- **読む・話す**：文ができるたびに、フワリさんが読み上げ、ステージの画面で子どもが声に出して読みます。学級の大きなテレビに映して、発表にも使えます。
- **問題の画面**：問題の画面は、背景をすっきりさせています。にぎやかな絵は、ホーム・はっぴょう・ゆめの そら の画面だけで使います。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/yumefusen/` を開きます。
   - 「おためしモード」で動けば、データと絵の公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「ゆめの ふうせん 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。
4. 画面の文字が小さいときは、先生用画面の「もじの おおきさ」で変えます。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、カードやキーボードが小さくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。
- 「そらの うえの がっこう」には、こくごの へや →「ことばと ぶん」の たなに 入っています（`sora/apps.js` の `yumefusen`）。ウェブアプリの URL を 新しく 作りなおしたときは、教えてください。

## 先生用画面

1. 名前を選ぶ画面の右下（学習中は右上）の **🔒** を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「せってい」で変えてください。**

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの いまのステージ・ふうせんカードの数・星・問題の数・まちがえずに できた割合・多い まちがいの しゅるい・最後に学習した日。クラス全体の「つまずき（お題 × ステージ）」「まちがいの しゅるい」「えらんだ 合わないカード」「よく えらぶ 見方」 |
| 子どもごと | ステージごとの結果、つまずき（お題 × ステージ）、まちがいの しゅるい、えらんだ 合わないカード（「いぬ：うみで ジャンプが できる」など）、よく えらぶ 見方、ふうせんカードの一覧（💮 はなまる）、自分で書いた文 |
| 子どもごと（ボタン） | ステージを全部開く（その子だけ）、はってんを開く、Chromebook の キーボードに する（画面のキーボードに もどす） |
| 📺 はっぴょうかい（右上のボタン） | きょう できた ふうせんカードを、子どもごとに 教室の モニター用の 大きな画面で出します。名前を押す → 1まいずつ 大きく出る（フワリさんが「〇〇さんの ばんです。どうぞ！」と声をかける）→「👏 はくしゅ」。「◀ まえへ」「つぎへ ▶」「🔊 おてほん」「🔄 さいしんに する」「⛶ 画面いっぱい」 |
| 書いた文 | 全員が ③ じぶんで かく・④ まとめ・はってん で書いた文（新しい順）。アプリが確かめるのは「からです・だからです」と④の文の形だけなので、理由として合っているかは、ここで読んで確かめてください。💮 を押すと、その子の ふうせんカードに はなまるが付きます |
| せってい | 読み上げの速さ、文字の大きさ、はっぴょう（つかう・つかわない）、理由のカードの いろわけ（あり・なし）、効果音、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、記録の消去（その子だけ・全員） |

- **つまずき（お題 × ステージ）** の表は、「まちがえずに できた数 / 問題の数」です。色は、まちがえずに できた割合です（赤：60%未満、黄：60〜79%、緑：80%以上）。
- **よく えらぶ 見方** は、①②で選んだ理由のカードと、③の書き出しボタンの見方（できること・ようす・きもち）の数です。いつも同じ見方を選ぶ子には、ほかの見方も声をかけてみてください。
- **はなまる** は、いまの ふうせんカードと同じ文に付きます。子どもが同じ ものを書き直すと、はなまるは新しいカードには付きません（もう一度押してください）。
- **まちがいの しゅるい**

  | しゅるい | 内容 |
  |---|---|
  | あわない カード | ほかの ものの理由のカード（いぬ に「うみで ジャンプが できる」など）を選んだ |
  | だから→から | 「ふわふわ」「きれい」などの あとに「だからです」と書くところを、「からです」にした |
  | から→だから | 「かわいい」「できる」などの あとに「からです」と書くところを、「だからです」にした（かわいいだからです） |
  | ことばの じゅんばん | ⓪で、ことばの順番がちがった |
  | おだいの ことばが ない | ④で、1つめの文に お題（かいたい・いきたい など）がなかった |
  | です が ない | ④で、文の終わりが「です。」になっていなかった |
  | から が ない | ④で、理由の文に「から」がなかった |

- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。
- ボタンで変えたこと（全部開く・はってん・キーボード・はなまる）は、子どもが次に名前を押したときから変わります。

### はっぴょうかい（教室の モニターに うつす）

1. 先生の パソコンを、HDMI ケーブルで 教室の モニター（テレビ）に つなぎます。
   - Windows のときは、Windows キー＋P を押し、「複製」を選びます。
   - Chromebook のときは、つなぐと 自動で 映ります。映らないときは、設定 → デバイス → ディスプレイ で「内蔵ディスプレイをミラーリング」に チェックを入れます。
2. 先生の パソコンで アプリ（ウェブアプリの URL）を開き、右下の 🔒 → 暗証番号 → 右上の **📺 はっぴょうかい** を押します。
3. **⛶ 画面いっぱい** を押します（うまく いかないときは、キーボードの「全画面」キー〈Chromebook〉か F11〈Windows〉を押します）。
4. 子どもの名前を押すと、その子が きょう作った カードが 大きく出ます。子どもは モニターの前で 声に出して読み、終わったら **👏 はくしゅ** を押します。
5. 子どもが Chromebook で いま作った カードを出したいときは、**🔄 さいしんに する** を押します。

- 出るのは、きょう作った ①〜④・はってん の カード（理由の文が ある もの）です。⓪だけの カードは出ません。

## 全員の記録を見る

- スプレッドシートの **「きろく」** シートに、1つの文（1問）ごとの結果が入ります。

  | 日時 | なまえ | ステージ | おだい | もの | つくった ぶん | けっか | まちがい | ヒント | まちがいの しゅるい | えらんだ カード | かいた ことば | みかた | びょう | ID |
  |---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

  - ステージ：0〜4（⓪〜④）、h1・h2（はってん①②）
  - つくった ぶん：できた2つの文（⓪は1つめの文だけ）
  - けっか：○＝まちがえず、ヒントも使わずに できた　△＝まちがえてから、またはヒントを使って できた
  - まちがい：まちがえた回数　ヒント：使ったヒントの段階（0〜3）
  - えらんだ カード：選んだカード。合わないカードには「✖」、まちがえた文のおわりなどには「（ちがう）」が付きます。ヒントのカードには「（ヒント）」、書き出しボタンには「（かきだし）」が付きます
  - かいた ことば：③④・はってんで子どもが書いた ことば（2つあるときは「／」で区切ります）
  - みかた：選んだカードや書き出しの見方（できること・ようす・きもち）
  - びょう：その問題にかかった時間（ものを選んでから文ができるまで）
- **「まとめ」** シートに、子どもごと・ステージごとの結果と、まちがいの しゅるい・合わないカード・よく選ぶ見方、子どもが書いた文の一覧（1人80件まで）が入ります。先生用画面を開いたとき、またはメニュー **ゆめの ふうせんやさん → まとめを更新する** で更新されます。文の一覧は、印刷して掲示や個別の指導計画の記録にも使えます。
- **「名簿」** シートのB列に、進み具合・星・ふうせんカード・はなまるが入ります。ちがう Chromebook を使っても「つづきから」始められます。
- 記録は、1つ書くごと・やめたとき・終わったときに送ります。ネットが切れていたときの記録は、その Chromebook にためておき、つながったときに送り直します。同じ記録は二重に書きません。

## 注意事項

- **個人情報**：名簿には、呼び名かひらがなの名前だけを入れてください。子どもが書いた文は、先生のスプレッドシートにだけ届きます。
- **お題・もの・理由のカード**：このアプリのために作ったオリジナルです。
- **絵**：フワリさん・背景・もの72こ は、先生の ChatGPT で Claude が作った オリジナルの絵です（ほかの人の絵やキャラクターには似せていません）。ふうせん・星などは、自作の絵（SVG）と絵文字です。会社のロゴや既存のキャラクターは使いません。
- **効果音**：このアプリのためのオリジナルです（プログラムで作っています）。
- **ことば**：子どもの画面は ひらがなと分かち書きです。漢字は「<ruby>飼<rt>か</rt></ruby>いたい」の1字だけで、ふりがなを付けています。
- データと絵は GitHub Pages から読みこむので、ネットにつながっている必要があります。
- 「データを よみこめませんでした」と出るときは、`https://zku0395-ops.github.io/hori/yumefusen/` が開けるか確かめてください。
- 「止まった」「開かない」ときは、まず `index.html` の貼り付けが最後（`</html>`）まで入っているかを確かめてください。
- 合うはずの理由が「あわないね」になったり、「から／だから」の見分けがおかしい ことばがあれば、教えてください。データを直します。
