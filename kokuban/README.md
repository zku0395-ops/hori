# チョークんの マイこくばん（文章に線を引いて、黒板にまとめるアプリ）

小学校の特別支援学級（1〜4年生）向けの、国語の「読む」学習で使う道具のアプリです。
物語や説明文を読み、大事なところに線を引き、ことばや文を「マイこくばん」に貼って、自分の考えをまとめます。

- 画面の左に文章、右にマイこくばんが並びます。
- 文章は、先生が自分で入れます。教科書の単元に合わせて使えます。
- 案内役は、チョークの男の子「チョークん」です（オリジナルのキャラクター）。
- 形は「Apps Script だけ」です。子どもは名簿の名前のボタンを押して始めます。
- 正解・不正解はありません。子どもが考えたあとが、そのまま先生に届きます。

## できること

| 項目 | 内容 |
|---|---|
| 文章を読む | たて書き（教科書と同じ）で出ます。先生用画面で、よこ書きに変えられます。漢字には ふりがなを付けられます |
| 読み上げ | 「🔊 ぜんぶ」で、文章を1文ずつ読み上げます。読んでいる文に、点線のわくが付きます。選んだ ことばや文だけを読むこともできます（はじめは0.8倍の速さ） |
| 線を引く | 4色（あか・あお・みどり・きいろ）のペンで、ことばや文に色を付けます。引き方は下の「線の引き方」を見てください |
| こくばんに貼る | 選んだ ことばや文を「📌 こくばんに はる」で、付せんにして貼ります。文章から貼った付せんには 📖 のしるしが付きます |
| 自分で書く | 「✏️ かく」で、画面の50音ボタンか、Chromebook のキーボードで書きます。書いた ことばは、きいろの付せんになります |
| やじるし・わく | 付せんと付せんを やじるしでつないだり、わくで囲んだりできます |
| スタンプ | 気持ちの顔（うれしい・かなしい・おこる など10こ）と、しるし（だいじ・はてな・わかった など8こ）を貼れます |
| とい（めあて） | 先生が文章ごとに、といを5つまで入れられます。画面の上に出て、チョークんが読み上げます。◀ ▶ で切りかえます |
| 画面の分け方 | 「📖 おおきく」「はんぶん」「🟩 おおきく」で、文章とこくばんの大きさを切りかえます |
| 自動で保存 | 何かするたびに、数秒後に自動で保存します。次に開くと「つづきから」始まります |
| できた！ | 「🙌 できた！」で、先生に出します。出したあとも、続けて直せます |
| ごほうび | 活動をするとシールがもらえます。アルバムで集めたシールを見られます |

### 線の引き方

どのやり方でも引けます。子どもに合うやり方を選んでください。

| やり方 | 手順 |
|---|---|
| えらんでから引く | 「👆 えらぶ」→ ことばをタップ → 下に出る色の丸を押す |
| はじめと終わりを選ぶ | 「👆 えらぶ」→ はじめの ことばをタップ → 終わりの ことばをタップ → 色の丸を押す |
| ペンでタップ | 色のペンを押す → ことばをタップ（同じ色のところを もう一度タップすると消えます） |
| ペンでなぞる | 色のペンを押す → 指やマウスで なぞる |
| 文ごと | 「ことば／ぶん」を「ぶん」にすると、タップした ことばをふくむ1文が まるごと選ばれます |

- 「👆 えらぶ」のときは、指で文章を動かせます（スクロール）。ペンのときは、なぞると線になるので、◀ ▶ のボタンで文章を動かします。
- 線を消すときは「🧽 けしゴム」でタップするか、なぞります。
- まちがえたら、こくばんの下の「↩️ もどす」で、1つ前にもどせます。

## ステージ構成

このアプリは「道具」なので、ステージはありません。文章ごとに、1まいのマイこくばんを作ります。
はじめから、れんしゅう用の文章が2つ入っています（オリジナル）。

| 文章 | しゅるい | とい |
|---|---|---|
| くもの ぼうし | ものがたり | ① ポルが あった どうぶつに、あかい せんを ひこう。② ポルの きもちが わかる ぶんを、こくばんに はろう。③ ぼうしは、だれの ものだったかな。じぶんの ことばで かこう。 |
| だんごむしの ひみつ | せつめいぶん | ①「とい」の ぶんに、あおい せんを ひこう。②「こたえ」の ぶんに、あかい せんを ひこう。③ わかった ことを、こくばんに まとめよう。 |

### シール（ごほうび）

1つの文章で、5まいまで もらえます。

| もらえるとき | シール |
|---|---|
| はじめて線を引いた | ふつうのシール（48しゅるい） |
| はじめて こくばんに貼った | 〃 |
| はじめて自分の ことばを書いた | 〃 |
| はじめて やじるし・わく・スタンプを使った | 〃 |
| 「できた！」で先生に出した | とくべつなシール（12しゅるい） |

シールの数で、称号が変わります（こくばん みならい → せんひき めいじん → ふせん はかせ → まとめ せんせい → こくばん マスター → こくばん チャンピオン）。

## 支援の工夫

- **ことばのかたまりで選べる**：1文字ずつ正確になぞらなくても、タップ1回で ことば（文節）が選べます。「ぶん」にすると、1文がまるごと選べます。
- **選んでから決める**：選んだ ことばが下の きいろの おびに出ます。「🔊 よむ」で聞いて確かめてから、線を引いたり貼ったりできます。
- **ドラッグしなくてもよい**：付せんは、指で動かすほかに、◀ ▲ ▼ ▶ のボタンでも動かせます。大きさも「＋ おおきく」「－ ちいさく」のボタンで変えられます。
- **やり直しやすい**：「↩️ もどす」で何回でも前にもどせます。まちがいを気にせず、ためせます。
- **書くのが苦手でも まとめられる**：文章の ことばを貼るだけで、こくばんが作れます。スタンプで気持ちを表すこともできます。
- **線の色と付せんの色がそろう**：あかい線の ことばを貼ると、ピンクの付せんになります（あお → みずいろ、みどり → みどり、きいろ → きいろ）。「あか＝したこと」「あお＝きもち」のように、色で分けて考えられます。
- **読み上げは少しゆっくり**：といも文章も読み上げます。チョークんか、といの おびを押すと、何回でも聞き直せます。
- **画面はすっきり**：文章の画面には、かざりの絵を出しません。にぎやかな絵は、「できた！」のときとアルバムだけです。
- **時間制限なし・自動で保存**：途中でやめても、次は「つづきから」始まります。
- **正解・不正解を出さない**：ブザーや×は出ません。シールは、活動したことに対してもらえます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（Apps Script に `index` という名前で貼り付けます） |
| `コード.gs` | スプレッドシートとつなぐプログラム |
| `tools/test_gas.js` | `コード.gs` のテスト（`node kokuban/tools/test_gas.js`） |

絵は、絵文字と自作のSVG（チョークん）だけです。ほかの素材は使っていません。

## 公開の手順

### 1. GitHub Pages

このアプリは Apps Script だけで動きます。GitHub Pages の設定はいりません。
（`https://zku0395-ops.github.io/hori/kokuban/` を開くと、スプレッドシートにつながらない「おためしモード」で動きを見られます。）

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「マイこくばん 記録」）。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `kokuban/index.html` を開く →「Raw」を押す →（翻訳が出たら「翻訳しない」）→ Ctrl＋A → Ctrl＋C → Apps Script で Ctrl＋A → Ctrl＋V
   - いちばん下の行が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「ぶんしょう」「きろく」「まとめ」「せってい」の5つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが自動で書く欄です。さわらないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、出てきた **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どもにスプレッドシートを共有しなくても記録が届きます。

**`コード.gs` や `index.html` を書きかえたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** で更新します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークか、シェルフ（画面の下）に追加しておきます。
3. 音量を確かめます（読み上げに使います）。

### 4. Googleサイトに置くとき

ウェブアプリのURLを **「ボタン」** で置きます。「埋め込む」は使わないでください（画面が小さくなって、使いにくくなります）。

## 先生用画面

名前を選ぶ画面の右下 **🔒 せんせい** を押し、暗証番号（はじめは `1234`）を入れます。
**暗証番号は「⚙️ 設定」で必ず変えてください。**

### 📋 こくばんを 見る

- 子ども × 文章の表が出ます。「✅ できた」「✏️ とちゅう」のボタンを押すと、その子の **線を引いた文章** と **マイこくばん** が、そのままの見た目で出ます。
- 下の表に、線を引いた ことば・貼った ことば・自分で書いた ことばが、文字で出ます。
- **🖨 いんさつ** で印刷できます（A4よこ。印刷では、文章は よこ書きで全部出ます）。
- 文章の名前の下の **👥 みんなの せん** を押すと、その文章で、どの ことばに何人が線を引いたかが分かります。色は いちばん多かった色、小さい数字は人数です。

### 📖 文章

- **＋ 新しい 文章を 入れる** を押し、だいめい・ほんぶん・とい を入れて **💾 ほぞんする** を押します。
- 右側に、子どもの画面での見え方が出ます。点線のわくが、タップで選べる1つの「ことば」です。

| 書き方 | 意味 | 例 |
|---|---|---|
| 漢字のあとに かっこで読み | ふりがなが付きます | `手紙（てがみ）を 書（か）く` |
| 空白 | そこで ことばを区切ります（すきまが あきます） | `かえるが てがみを かきました。` |
| ／（全角のスラッシュ） | そこで ことばを区切ります（すきまは あきません） | `かえるが／手紙（てがみ）を／書（か）きました。` |
| 行を変える | 段落が変わります | |
| 空の行 | 間が あきます | |

- 「、」「。」のあとは、いつも区切ります。
- **空白も ／ もない行** は、アプリが自動で区切ります。ひらがなから漢字・カタカナに変わるところで区切ります（例：`ポルは｜森へ｜歩いていきました。`）。
- 自動の区切りが合わないときは、**✂️ 自動で 区切る** を押します。区切りに「／」が入るので、足したり消したりして直します。
- 教科書の文章をそのまま貼り付けて使えます。ふりがなは、必要な漢字にだけ `（よみ）` を足してください。
- 「子どもに 見せる」のチェックを外すと、子どもの画面に出なくなります（先に準備しておくときに使います）。
- 子どもが使いはじめたあとで本文を変えると、その子が引いた線は消えます（こくばんは残ります）。

### ⚙️ 設定

| 項目 | 内容 |
|---|---|
| 読み上げの速さ | 0.6〜1倍（はじめは0.8倍） |
| 文字の大きさ | 小さめ・ふつう・大きめ・とても大きい |
| 文章の向き | たて書き・よこ書き |
| 効果音 | 鳴らす・鳴らさない |
| 暗証番号 | 数字4けた |

設定は、次に子どもがアプリを開いたときから変わります。

### 💾 データ

- きろく・まとめを CSV で書き出せます。
- バックアップを保存して、あとでもどせます。
- 子どもを選んで（または全員の）記録を消せます。文章は消えません。

## 全員の記録を見る

スプレッドシートを開きます。

| シート | 内容 |
|---|---|
| 名簿 | 子どもの名前（A列）。B列はシールの記録です（さわらないでください） |
| ぶんしょう | 先生が入れた文章と、とい |
| まとめ | 子ども × 文章で1行。じょうたい（とちゅう／できた）・線を引いた ことば・貼った ことば・自分で書いた ことば。右のはしの「データ」は、こくばんの中身です（さわらないでください） |
| きろく | したことを1行ずつ記録します（日時・なまえ・ぶんしょう・とい・したこと・いろ・ことば） |
| せってい | 暗証番号と設定 |

- 「きろく」を見ると、どの といのときに、どの順番で線を引いたり貼ったりしたかが分かります。
- 文章は「ぶんしょう」シートに直接書くこともできます。ただし、何行もある文章をセルに貼るときは、**セルをダブルクリックしてから** 貼り付けてください（そのまま貼ると、行ごとに別のセルに分かれます）。先生用画面から入れるほうが かんたんです。

## 注意事項

- **教科書の文章には著作権があります。** 入れた文章は、先生のスプレッドシートにだけ保存されます（このリポジトリや GitHub Pages には出ません）。授業の中で使い、アプリのURLやスプレッドシートを、学級の外の人に配らないでください。
- はじめから入っている「くもの ぼうし」「だんごむしの ひみつ」は、このアプリのために書いたオリジナルの文章です。
- チョークんは、オリジナルのキャラクターです。絵は絵文字と自作のSVGだけで作っています。
- 記録は、名簿にある名前の分だけ受け取ります。記録を外から読み出す機能はありません。
- 受け取った文字列は、式として動かないようにしてからシートに書きます。
- ネットが切れているあいだの分は、Chromebook の中にためておき、次に保存するときに送り直します。
- 読み上げは Chromebook に入っている声を使います。漢字の読みは、ふりがなを付けたところは ふりがなのとおりに読みます。
- 「止まった」「開かない」ときは、まず `index.html` の貼り付けが途中で切れていないか（いちばん下が `</html>` か）を確かめてください。

## これから相談して決めること

1. 線の色の意味（例：「あか＝したこと」「あお＝きもち」）を、先生が文章ごとに決めて、画面に出せるようにするか。
2. こくばんのひな形（「はじめ・なか・おわり」の表、「とい → こたえ」の形など）を用意するか。
3. 先生が子どものこくばんに「はなまる」や一言コメントを付けられるようにするか。
4. 教室のモニターに、子どものこくばんを大きく映す「はっぴょう」の画面を作るか。
5. 文章に挿絵（先生が用意した画像）を入れられるようにするか。
6. 手書き（指で自由に書く）のペンを、こくばんに足すか。
