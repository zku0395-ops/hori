# ChatGPT に絵を頼むときの文（チョークんの マイこくばん）

れんしゅう用の2つの文章に付ける絵を、ChatGPT で作るための手引きです。
先生のパソコンで動く Claude（デスクトップアプリの「Local」の会話）が、この手引きを読んで作業します。先生が自分で ChatGPT に頼むときも、同じ文を使えます。

## 作る絵（2まい）

| 文章 | ファイル名 | 置き場所 |
|---|---|---|
| くもの ぼうし（ものがたり） | `s1.webp` | `kokuban/img/s1.webp` |
| だんごむしの ひみつ（せつめいぶん） | `s2.webp` | `kokuban/img/s2.webp` |

- 形：よこ長（4：3）。**800 × 600 ピクセル**、WebP、1まい 100KB くらいまで。
- 絵の中に、文字・数字・ロゴを入れません。
- ほかの人の絵や、既存のキャラクターには似せません（オリジナル）。

## Claude がすること（先生のパソコンで）

1. 先生がいつも使っているブラウザで ChatGPT を開きます（先生のアカウントでログイン済みのもの）。
2. 「はじめに 1回だけ はる文」を送ります。
3. ①・② の文を1つずつ送り、できた絵を保存します。
   - 絵に文字が入った・顔がこわい・形が4：3でない などのときは、作り直しを頼みます。
4. 元の絵（PNG）を、デスクトップの「アプリ用画像素材 → 02_ChatGPT生成 →（年-月）→ マイこくばん」に保存します。
5. 800 × 600 の WebP にして、`kokuban/img/s1.webp`・`kokuban/img/s2.webp` に置きます。
6. `kokuban/index.html` をブラウザで開き、次の2か所に絵が出るか確かめます（スクリーンショットを先生に見せます）。
   - ホームの文章カード
   - 文章のはじめ（題名のとなり。たて書きでは右はし）
7. `kokuban/README.md` の「絵（ChatGPT で作りました）」に、元の絵の置き場所（年-月）を書きます。
8. `node toshokan/tools/mokuroku.js` で としょかん の目録を作り直します。
9. コミットします。先生に「プルリクエストを作ってマージしてください」と頼まれたら、`main` に入れます。

- `index.html` と `コード.gs` は、変えなくてかまいません。絵は GitHub Pages（`https://zku0395-ops.github.io/hori/kokuban/img/`）から読みこむので、**Apps Script に貼り直さなくても**、`main` に入れば子どもの画面に出ます。
- 絵がまだないときは、アプリは絵を出さないだけで、今までどおり動きます。

## はじめに 1回だけ はる文

```
これから、小学校の特別支援学級の子ども（1〜4年生）が使う、国語の学習アプリの挿絵を、2まい作ってもらいます。
次のルールを、すべての絵で守ってください。
・絵本のような、やさしい色の、子ども向けのイラスト。太めの、やわらかい線。水彩のような あたたかい ぬり。
・こわくない、かわいい顔。
・既存のアニメ・ゲーム・絵本・キャラクターに似せない、オリジナルのデザイン。
・絵の中に、文字・数字・ロゴ・ふきだしを入れない。
・よこ長（4：3）の絵。まわりに白いふちを付けず、絵を はしまで描く。
・2まいの絵柄（線の太さ・色合い）をそろえる。
わかったら「OK」とだけ答えてください。
```

```
・画面の左下に、こぐまの「ポル」。茶色の小さな子ぐま。服は着ていない。空を見上げて、片手を大きくふって、うれしそうに わらっている。
・画面の右上の空に、小さな白い雲が1つ。雲には にこにこした顔があり、白い つばのある ぼうしを かぶっている。
・ポルと雲が、おたがいを見ている。
・風が ふいている ようす（草が少し なびいている）。
・文字は入れない。よこ長（4：3）。
```

## ② だんごむしの ひみつ

```
説明文「だんごむしの ひみつ」の挿絵を描いてください。
・にわの 地面を、近くから見た絵。茶色の土、おちば が数まい、まるい石が1つ。
・だんごむしが2ひき。1ぴきは、おちばの上を歩いている（こい灰色の、ふしのある せなか。短い あしと しょっかく）。もう1ぴきは、ボールのように まるくなっている。
・だんごむしは、こわくない、かわいい顔（小さな黒い目）。本物の形がわかるように、せなかの ふしは しっかり描く。
・だんごむしを大きめに描き、まわりは すっきりさせる。
・文字は入れない。よこ長（4：3）。
```

## 作り直したいとき

「もっと やさしい顔に」「線を太く」「ポルを もう少し大きく」のように、ChatGPT に続けて頼みます。
できた絵を同じファイル名で置きかえると、アプリの絵も入れかわります。
