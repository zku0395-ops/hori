# スミまると ふでの どうじょう

小学校の特別支援学級向けの、書写（毛筆）の学習アプリです。
先生が大型テレビに映して、授業の流れにそって進めます。
筆を持つ前に、子どもが自分の Chromebook で、指で線をなぞる練習もできます。

はじめの画面で「きょうの かだい」を選びます。

| かだい | 中身 |
|---|---|
| せんの れんしゅう | 横画（「一」「二」）と、左はらい・右はらい（「大」） |
| ふじ山 | 「ふ」「じ」「山」を、1字ずつ、書き順どおりに一画ずつ |
| 平和 | 「平」（5画）「和」（8画）を、1字ずつ、書き順どおりに一画ずつ |

公開先：https://zku0395-ops.github.io/hori/shosha/

## できること

| できること | 内容 |
|---|---|
| いま どこ | 画面の上に、授業の流れ（8まいのカード）がいつも出ます。いまのカードが光ります。カードを押すと、そこへ移れます。 |
| 案内役 | すみの しずくの 子「スミまる」が、ことばで教えます。スミまるか「🔊 もういちど」を押すと、もう一度読み上げます。 |
| じゅんび | 道具の置き方・すわり方・筆の持ち方を、絵で見せます。名前のふだを押すと、名前を読み上げます。 |
| 筆の動きの見本 | 筆が動いて線ができるようすを、アニメーションで見せます。「トン」「スー」「ピタッ」のことばが、動きに合わせて光ります。「🐢 ゆっくり」もあります。右の ぼうで、筆の力（つよい・よわい）が分かります。 |
| 指なぞり | 指でなぞると、すみの線が出ます。線の太さは、場所に合わせて自動で変わります。 |
| まい数 | 「おてほんを 見て かく」のまい数（1〜5まい）を選び、1まい書くごとに「できた」のはんこを押します。 |
| はっぴょう | 「わたしは、＿＿＿。」の言い方を、5つの中から選んで読み上げます。 |
| きょうの かだい | はじめの画面で「せんの れんしゅう」「ふじ山」「平和」から選びます。選んだ かだい に合わせて、2〜6の中身が切りかわります。 |
| はんこちょう | 指なぞりができると、はんこがもらえます（ぜんぶで35こ。たいそう3、線12、ふじ山12、平和8）。 |

## ステージ構成

授業の流れ（上のカード）です。

| じゅん | カード | 中身 |
|---|---|---|
| 1 | じゅんび | 道具の置き方 → すわり方 → 筆の持ち方 |
| 2 | ふでの れんしゅう | ゆびの たいそう（ぎざぎざ・なみなみ・うずまき）と、筆の動きの見本（横画・左はらい・右はらい） |
| 3 | ゆびで なぞる | 横画・左はらい・右はらいを、4つのステップでなぞる |
| 4 | かみを おいて なぞる | お手本の上に紙を置いてなぞる（ここからは、テレビに映すだけ）。右がわに、お手本の筆の動きが出る |
| 5 | ふでで なぞる | お手本（プリント）を筆でなぞる。右がわに、お手本の筆の動きが出る |
| 6 | 見て かく | お手本を見て、決めたまい数を書く。右がわに、お手本の筆の動きが出る |
| 7 | はっぴょう | がんばったところを発表する |
| 8 | かたづけ | 筆をふく → すずりをふく → 道具をしまう |

4〜6では、右がわに「書き方のお手本の図」が出ます。筆を動かす向き（赤い点線と矢印）と、「①トン ②スー ③ピタッ」のことばが、線のどこなのかが分かります。
横画・左はらい・右はらいのボタンで、見せるお手本を切りかえます。「▶ おてほんを 見る」「🐢 ゆっくり」で、筆の動きを何度でも見られます。動きが終わると、図にもどります。
「ふじ山」「平和」を選んだときは、横画・左はらい・右はらいのかわりに、字（「ふ」「じ」「山」や「平」「和」）のボタンが出ます。

- 2 ふでの れんしゅう：字を選ぶと、書き順どおりに一画ずつ、筆が動きます。
- 3 ゆびで なぞる：青い番号のしるしから、一画ずつなぞります。一画できると、次の画に進みます。全部の画ができると、はんこがもらえます。
- 4〜6：「ぜんぶ」を選ぶと、書き順（番号）と筆の向き（矢印）の図が出ます。「①②③…」（画の番号）を選ぶと、その画の ことばの図が出ます。「▶ おてほんを 見る」で、選んだところの筆の動きを見られます。

指なぞりのステップです。プリントと同じように、手がかりをだんだん減らします。

| ステップ | 手がかり |
|---|---|
| 1 | 外わく ＋ 穂先の形 ＋ 赤い線 |
| 2 | 外わく ＋ 穂先の形 |
| 3 | 赤い線だけ |
| 4 | なにもなし（小さなお手本を見て書く） |

筆の動きのことばです。

| 線 | ことば |
|---|---|
| 横画 | トン（筆をおく）→ スー（横にすすむ）→ ピタッ（とめる） |
| 左はらい | トン → スー（だんだん よわく）→ スーッ（ゆっくり はらう） |
| 右はらい | トン → グー（だんだん つよく）→ ピタッ（いちど とめる）→ スー（右へ はらう） |
| ふ ①③④（てん） | トン → スッ（はらう）。てんの おわりを、つぎの 画へ むけて はらいます |
| ふ ②（まん中） | トン → スー（下へ）→ クルッ（まがる）→ ピョン（はねる） |
| じ ①（「し」） | トン → スー（下へ）→ クルッ（まがる）→ スーッ（上へ はらう） |
| じ ②③（てんてん） | トン → ピタッ |
| 山 ①③（たて） | トン → スー（下へ）→ ピタッ |
| 山 ②（たて から よこ） | トン → スー（下へ）→ カクッ（おれる）→ スー（よこへ）→ ピタッ |
| 平・和の よこ画（平①④、和②⑧） | トン → スー（よこへ）→ ピタッ |
| 和の たて画（和③⑥） | トン → スー（下へ）→ ピタッ |
| 平 ⑤（まん中の たて） | トン → スー（下へ）→ スーッ（ほそく ぬく）。お手本に合わせて、終わりを細くぬきます |
| 平・和の てん（平②、和⑤） | トン → ピタッ |
| 平・和の はらい（平③、和①④） | トン → スーッ（はらう） |
| 和 ⑦（よこ から たて） | トン → スー（よこへ）→ カクッ（おれる）→ スー（下へ）→ ピタッ |

## 支援の工夫

- ひらがなと分かち書きが中心です。漢字にはふりがなを付けています。
- 読み上げは、少しゆっくり（0.8倍）です。先生用画面で変えられます。
- 時間制限はありません。
- 指なぞりは、前のステップができると、次のステップが開きます。
- まちがえたとき（とちゅうで指をはなしたとき）は、小さな音が鳴り、線が消えて、もう一度できます。
- ヒントは3段階です。
  1. ことば（「トン、スー、ピタッ。ゆっくりで いいよ」）
  2. 赤い線を出す
  3. スミまるが、筆で書いて見せる
- 2回まちがえると「💡 ヒント」が光ります。3回まちがえると、スミまるが自動で書いて見せます。
- ドラッグがむずかしい子は、「スミまるの おてほん」を押すと、筆の動きを見られます。
- ヒントを使っても、はんこは同じようにもらえます。

## ファイル構成

| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体です。これ1つで動きます。 |
| `images/` | 絵です（スミまる3まい、道具の置き方、すわり方、筆の持ち方、片付け3まい）。 |
| `video/` | Canva などで作った動画を置く場所です（なくても動きます）。 |
| `tools/kvg.js` | 字の線を、書き順データ（`kanji1/data/strokes.js`）から作る道具です。字を足すときに Claude が使います。 |

動画を入れるときは、`video/yoko.mp4`（横画）、`video/hidari.mp4`（左はらい）、`video/migi.mp4`（右はらい）という名前で置きます。
置くと、「ふでの れんしゅう」の画面に「🎬 どうが」のボタンが出ます。

## 公開の手順

### 1. GitHub Pages

1. このフォルダ（`shosha/`）が `main` に入ると、自動で公開されます。
2. 公開先は https://zku0395-ops.github.io/hori/shosha/ です。

### 2. Apps Script とスプレッドシート

使いません。記録はとらないアプリです。

### 3. Chromebook の準備

1. Chrome で公開先のURLを開きます。
2. 右上の「︙」→「キャスト、保存、共有」→「ショートカットを作成」を押すと、たなに置けます。
3. 音が出るか、「🔊 もういちど」を押して確かめます。

### 4. Googleサイトに置くとき

1. Googleサイトの編集画面で「挿入」→「ボタン」を押します。
2. 名前に「ふでの どうじょう」、リンクに公開先のURLを入れます。
3. 「埋め込む」ではなく「ボタン」で置いてください。

## 先生用画面

1. 右上（ホームでは下）の「⚙️」を押します。
2. 暗証番号（はじめは `1234`）を入れます。

| できること | 内容 |
|---|---|
| 記録 | その端末で、どの線・どの字の どのステップが できたか（◎）と、やり直しの回数が分かります。やり直しが多いところが、つまずいているところです。 |
| 読み上げの速さ | 0.5〜1.2倍で変えられます。 |
| 文字の大きさ | 小・中・大から選べます。 |
| ステップを全部開く | 指なぞりの4つのステップを、はじめから全部選べるようにします。 |
| 暗証番号 | 4けたの数字に変えられます。 |
| 記録を消す | はんこと、やり直しの回数を消します。 |

## 全員の記録を見る

このアプリは、記録を集めません。
子どもごとの はんこ は、その子の Chromebook の先生用画面で見られます。
書いた作品そのものを、記録として残してください。

## 注意事項

- 設定と はんこ は、その端末のブラウザの中だけに保存されます。ほかの端末には移りません。
- 絵（スミまる・道具の置き方・すわり方・筆の持ち方・片付け）は、ChatGPT で作ったオリジナルの絵です。ほかの人の絵は読みこませず、ことばで特徴を伝えて作りました。
- 「ふ」「じ」「山」「平」「和」の字の形と書き順は、[KanjiVG](https://kanjivg.tagaini.net/)（© Ulrich Apel ほか、CC BY-SA 3.0）の書き順データから作っています。教科書の字に近い形です。筆の太さ（とめ・はね・はらい）は、このアプリでつけました。
- 学校で使うお手本（ほかの会社が作ったもの）の字は、アプリに入れていません。形が少しちがうので、紙に書くときは、学校のお手本も見せてください。
- 筆の動きのアニメーションと、線の形は、このアプリのために作ったものです。学校のプリント（「一、二」「大」の書き方）の、ことばと進め方を参考にしています。
- 筆の持ち方は、単鉤法（たんこうほう。おや指と人さし指で持ち、中指でささえる）です。
- 筆の持ち方・片付けの手順は、学校や学級のやり方に合わせて、先生がことばで補ってください。

## これから相談して決めること

- 筆の動きの動画を Canva で作るかどうか（いまは、アプリの中のアニメーションで見せています）。
- 片付けの手順（筆を水で洗うか、紙でふくか）を、学級のやり方に合わせる。
- 字の筆の太さや はらい の形を、もっと直すかどうか。
- Canva で、印刷して配る「ふじ山」「平和」のお手本（半紙の大きさ）を作るかどうか。
- 第2回からの内容（おれ・はね、曲がり・そり）を足す。
- 「一」「二」「大」の文字全体をなぞる練習を足すかどうか。
- 記録をスプレッドシートに残すかどうか。
