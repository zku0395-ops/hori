# ChatGPT に絵を頼むときの文（ピカリせんせいの ものがたりの もり）

## つかいかた

1. ChatGPT を開き、下の「はじめに 1回だけ はる文」を貼って送ります。
2. つぎに、作りたい絵の文（①〜③）を1つずつ貼って送ります。
3. できた絵を保存します（右クリック →「名前を付けて画像を保存」）。
4. 保存した絵を、このチャット（Claude）に貼ってください。
   - こちらで、切り分け・背景をすかす・名前を付ける・軽くする をして、アプリに入れます。
   - ファイル名を付けなくても大丈夫です。「ピカリせんせい の にっこり」「おはなし2 の さしえ」のように、どの絵かを書いてください。
5. 気に入らない絵は、「もっと やさしい顔に」「線を太く」のように ChatGPT に頼んで作り直します。

- 絵がそろうまでは、アプリの中の仮の絵（自作の絵と絵文字）で動きます。全部そろえなくても使えます。
- おすすめの順番：① ピカリせんせい → ③ さしえ → ② もりの背景。

## はじめに 1回だけ はる文

```
これから、小学校の特別支援学級の子ども（1〜4年生）が使う、国語の学習アプリの絵を、何まいか続けて作ってもらいます。
アプリは、夜の森に住む ホタルの先生と いっしょに、短い物語を読むアプリです。
次のルールを、すべての絵で守ってください。
・絵本のような、やさしい色の、子ども向けのイラスト。太めの、やわらかい線。
・こわくない、やさしい顔。
・既存のアニメ・ゲーム・キャラクターに似せない、オリジナルのデザイン。
・絵の中に、文字・数字・ロゴを入れない。
・キャラクターの絵は、背景を真っ白（または透明）にして、全体が切れないように入れる。
・すべての絵で、絵柄（線の太さ・色合い・頭身）をそろえる。
わかったら「OK」とだけ答えてください。
```

## ① ピカリせんせい（3まい）

```
アプリの案内役「ピカリせんせい」を描いてください。
・ホタルの 先生。2頭身くらいの、まるくて かわいい からだ。
・頭は大きくて まるい。顔は やわらかい はだいろ。大きな まるい目、ほっぺが少し赤い。
・頭に、ホタルらしい あかい ベレーぼう（ぼうしの まん中に 小さな 黄色い ほし）。
・頭に 2本の しょっかく。先が 小さな 黄色い まる。
・こげちゃ色の 小さな からだに、すきとおった 水色の はね が4まい。
・おしりが 黄色く、やさしく ひかって いる（まわりが ほんのり 光る）。
・正面を向いて、空中に うかんで いる。背景は白。正方形。
・表情を3まい：1まいめ「ふつう（やさしく ほほえむ）」、2まいめ「にっこり（目を細めて 大きく 笑う、両手を 広げる）」、3まいめ「おどろく（目を まるくして、口を 小さく 開ける）」。
3まいを横にならべて、1まいの絵にしてください。
```

## ② もりの背景（ホームの 画面。1まい）

```
アプリの ホーム画面の背景を描いてください。
・夜の しずかな 森。こわくない、やさしい夜。
・空は こん色から むらさきの グラデーション。星と 三日月。
・下の方に、まるい 木や 草の しげみ、小さな 小道。
・画面の 左下と 右下は、ボタンを置くので、くらい しげみ だけにして、こまかい ものを 置かない。
・キャラクターや 動物は 描かない（アプリが あとから 置きます）。
・よこ長（16：9）。
```

## ③ さしえ（おはなしごとに 1まい）

さしえは、文章の左に小さく出します。おはなしの「いちばん 心に のこる 場面」を1つ描きます。
どれも、**よこ長（4：3）**、背景あり、文字なし です。

### おはなし1「こぶたの ブーちゃんの おべんとう」

```
物語のさしえを描いてください。
・ピンク色の こぶた の 男の子（ブーちゃん）が、山の 下の 原っぱで、おにぎりと いっしょに ぺたんと すわって、にっこり 笑って いる。
・うしろに、みどりの 山と、山の 上から 下へ 続く さかみち。
・日曜日の 朝の、明るい 青空。
・よこ長（4：3）。
```

### おはなし2「ねこの ミケと あめの ひ」

```
物語のさしえを描いてください。
・三毛ねこ（白・茶・黒）の ミケが、家の中の まどべで、しっぽで リズムを とりながら、にこにこ 笑って いる。
・まどの外は、雨が やんで、夕方の 空に にじが かかって いる。やねから しずくが ぽつんと 落ちて いる。
・よこ長（4：3）。
```

### おはなし3「きつねの コンと まいごの ほし」

```
物語のさしえを描いてください。
・夏の 夜。高い おかの 上で、子ぎつねの コンが ジャンプして いる。
・コンの 上から、顔のある 小さな 黄色い 星の子（ピカ）が、ふわりと 夜空へ のぼって いく。ピカは うれしそうに 笑って、ぴかぴか 光って いる。
・まわりは 星いっぱいの 夜空と、草の おか。
・よこ長（4：3）。
```

> おはなし4〜10 の さしえの文は、おはなしが できたときに ここに 足します。
