# ピカリせんせいの ものがたりの もり（物語を読み取る学習アプリ）

小学校の特別支援学級（1〜4年生）向けの、物語の読み取りの学習アプリです。
ホタルの「ピカリせんせい」と、夜の「ものがたりの もり」で、200字ほどの短い物語を読みます。

- 文章は **たて書き** です。読み聞かせの声（Gemini）に合わせて、読んでいる **行に色** がつきます。
- 文章の下の **①〜⑤のボタン** を押すと、文章のどこに書かれているかに色がつきます。
  - ① だれが いった（せりふと、言った人の名前）　② いつ　③ どこ　④ きもち　⑤ オノマトペ
- いまは6話です。あとから物語を足していきます（全部で10話の予定）。

## できること

| 画面 | できること |
|---|---|
| なまえ | 名簿にある名前（ひらがな）のボタンを押して始めます |
| もり（ホーム） | 「おはなしを よむ」（つぎの話）・「つづきから」・「おはなしを えらぶ」・「おはなし ずかん」。話を読み終えるごとに、もりに なかま（ホタル・光る花など）がふえ、もりが だんだん明るくなります |
| ① きく | 読み方を2つから選べます。**「📖 ぜんぶ とおして」**：「🔊 よんで」で最後まで続けて読みます（「⏹ とめる」で止まる）。**「☝️ 1ぎょうずつ」**：「🔊 この ぎょう」「つぎの ぎょう ▶」「◀ まえの ぎょう」で、1行ずつ読みます。読んでいる行は黄色になります。どちらでも、行をさわると その行だけ読みます |
| ② さがす | ①〜⑤のボタンを選ぶと、ピカリせんせいが「いつ を あらわす ことばは どこかな」と聞きます。**子どもが自分で考えて、文章の ことばを さわって選びます**（選んだ ことばは黄色のわく。もう一度さわると取り消し）。「🔍 たしかめる」を押すと、**答えの所に色がつきます**。見つけた所に ⭕、ちがう所は灰色になり、見つけた数・のこりの数を ピカリせんせいが話します。「🔁 もういちど」で やり直せます。**やり直しのときは、答えのある行が光ります**（ヒント）。ボタンを全部たしかめると「つぎへ」が光ります |
| ③ たしかめ | 「いつの おはなし かな？」などの問題が5問。3つから選びます（先生用画面で「しない」にもできます） |
| もどる・やりなおす | 上の「① きく」「② さがす」「③ たしかめ」を押すと、その段階に何回でも もどれます（いまの段階を押すと、はじめから やり直し）。下の「◀ もどる」で1つ前の段階へ。読み終えた画面の「🔁 もういちど よむ」で、同じ話を はじめから読めます |
| ごほうび | 正解で「ほしの かけら」1こ（ヒントを使っても同じ）。② さがす では、1こでも見つけて たしかめると1こ。1話読み終えると、かけら3こと、もりの なかま |
| おはなし ずかん | 読んだ話の表紙（さしえ）・読んだ日・回数。もりの なかまの一覧 |
| ぶんしょうの プリント | 先生用画面の「プリント」から、文章を **B4よこ・たて書き** で印刷・PDFで保存します。「いろなし」（子どもが自分で色をぬる。上に「ぬる いろ」の見本）と「いろつき」（アプリと同じ所に色）。印刷用ページでは、①〜⑤の好きな組み合わせで色をつけられます。なまえ・がつ にち の欄つき |

### 色としるし

| ボタン | 色 | しるし | 色がつくところ |
|---|---|---|---|
| ① だれが いった | あか | 🗣️ | 「 」の せりふと、言った人の名前（せりふの すぐ前後で、だれが言ったかを表す名前だけ）。人ごとに色のこさを変え、せりふの頭に その人の絵文字（🦊⭐ など）を付けます |
| ② いつ | あお | 🕐 | 時間や季節を表す ことば（あさ・なつの よる など） |
| ③ どこ | みどり | 📍 | 場所を表す ことば（やまの うえ・はらっぱ など） |
| ④ きもち | ピンク | 💗 | 気持ちを表す ことば（うれしい・かなしい など）。表情や動きは、はってんで あとから足します |
| ⑤ オノマトペ | オレンジ | 🎵 | 音や様子を表す ことば（ころころ・ざあざあ など） |

## ステージ構成

| 話 | だいめい | 字数 | 出る ボタン | 登場人物 |
|---|---|---|---|---|
| 1 | こぶたの ブーちゃんの おべんとう | 約190字 | ② ③ ⑤ | 1人 |
| 2 | ねこの ミケと あめの ひ | 約190字 | ② ③ ⑤ | 1人 |
| 3 | きつねの コンと まいごの ほし | 約210字 | ② ③ ⑤ | 2人 |
| 4 | かえるの ゲロタの うんどうかい | 約240字 | ①〜⑤ ぜんぶ | 2人（ゲロタ・ミミ）。きもちが「くやしい → うれしい」とかわる |
| 5 | ゆきだるまの ふしぎな よる | 約240字 | ①〜⑤ ぜんぶ | 2人（ユキオ・ソラ）。きもちが「わくわく → さみしい」とかわる。いつ が3つ（ふゆの よる・まよなか・あさ） |
| 6 | くまの おじいさんの ふうせん | 約250字 | ①〜⑤ ぜんぶ | 2人（おじいさん・チロ）。きもちが「しんぱい → ほっと」とかわる。どこ が4つ（こうえん・パンやさんの まえ・はしの うえ・おかの うえ） |
| 7〜10 | （これから足します）うさぎと かめの おまつり たいかい／ちいさな ロケット ピコピコごう／わすれんぼうの まほうつかい／おばあちゃんの さくらの き | 約200字 | ①〜⑤ ぜんぶ | 2人〜 |

- 前の話を読み終えると、次の話が開きます。先生用画面で「ぜんぶの おはなしを開く」もできます。
- はじめの3話は、②いつ・③どこ・⑤オノマトペ だけです。①だれ・④きもち は少しむずかしいので、4話めから出します。
- 1話は「① きく → ② さがす → ③ たしかめ」で、5〜10分ほどです。途中でやめても「つづきから」始められます。

## 支援の工夫

- **たて書き・分かち書き**：教科書と同じ たて書きです。ことばの間を少しあけています。漢字は少しだけで、すべてに ふりがな を付けています。
- **読んでいる行が分かる**：読み聞かせに合わせて、その行が黄色になります。文章が画面に入りきらないときは、読んでいる行まで自動で動きます。
- **字の大きさ**：いちばん長い行が1列に入る大きさに、自動で合わせます。先生用画面で上限を変えられます。
- **自分で さがしてから 確かめる**：② さがす では、すぐに答えを見せません。子どもが自分で選んでから「たしかめる」で答えに色がつくので、自分の考えと答えを くらべられます。
- **読み方を選べる**：とおして聞く・1行ずつ聞く を、子どもに合わせて選べます（その Chromebook で最後に選んだ方を覚えます）。
- **スモールステップ**：まず聞く → 色で見る → 自分で選ぶ、の順です。
- **ヒントは3段階**（③ たしかめ）
  1. ことば（「いつ は、あさ・よる・なつ のような ことばだよ」）
  2. 答えのある **行が光る**
  3. 答えの ことばに **色がつき**、正しい選択肢が光る
  - 2回まちがえると ヒントのボタンが光り、3回まちがえると 3段階めのヒントが自動で出ます。
- **まちがいやすい選択肢**：ほかの種類の ことば（「いつ」の問題に「やまの うえ」など）や、同じ種類の べつの ことば（「てくてく」と「ころころ」）を入れています。
  - まちがえた選択肢は消えて、もう一度選べます。「『やまの うえ』は どこ を あらわす ことばだよ」「『ころころ』は、ころがる ようすだよ」のように、まちがい方に合わせて声をかけます。
  - まちがえたときの音は、小さな やさしい音です。
- **時間制限はありません。**
- **読み上げ**：ピカリせんせいのセリフも読み上げます。ピカリせんせい や 吹き出しの「🔊 もういちど」を押すと聞き直せます。
- 問題の画面は、背景をすっきりさせています。にぎやかな絵は、もり（ホーム）と ごほうびの画面だけです。

### 物語のデータの書き方（物語を足すとき）

`data/monogatari.js` の `STORIES` の うしろに足します。1行は、たて書きの1列（読み上げも1行ずつ）です。

| 書き方 | 意味 |
|---|---|
| `[山:やま]` | ふりがな |
| `{t:あさ}` | ② いつ |
| `{p:はらっぱ}` | ③ どこ |
| `{k:うれしい}` | ④ きもち |
| `{o:ころころ}` | ⑤ オノマトペ |
| `{s1:「だれ？」}` | ① せりふ（1ばんめの人が言った） |
| `{n1:コン}` | ① せりふを言った人の名前（1ばんめの人） |

物語は、先生のご希望を聞いて Claude が作り、色をつける場所も一緒に決めます。足したら `node monogatari/tools/check.js` で点検します。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/monogatari/` を開きます。
   - 「おためしモード」で動けば、物語のデータと絵の公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。
3. ぶんしょうの プリントは `https://zku0395-ops.github.io/hori/monogatari/print.html` です。先生用画面の「プリント」からも開けます。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「ものがたりの もり 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 2-2. Gemini の声（読み聞かせ）

読み聞かせとピカリせんせいの声を、Gemini で作るための準備です。しなくても、アプリはブラウザの声で動きます。

1. 先生の Google アカウントで「Google AI Studio」（aistudio.google.com）を開きます。
2. 左の「Get API key（API キーを取得）」→「APIキーを作成」を押し、できた長い文字列をコピーします。
   - ほかのアプリ（音読・つりマスター）で作ったキーを、そのまま使ってもかまいません。
   - 学校のアカウントで作れないときは、学校の情報担当の先生に相談してください。
3. このアプリの Apps Script を開き、左の ⚙（プロジェクトの設定）を押します。
4. いちばん下の「スクリプト プロパティ」→「スクリプト プロパティを追加」を押します。
5. 「プロパティ」に **GEMINI_API_KEY**、「値」に コピーしたキーを貼り、「スクリプト プロパティを保存」を押します。
6. 左の「<>（エディタ）」にもどり、関数の選択欄で **ttsTest** を選んで「▶ 実行」を押します。
   - はじめは「承認が必要です」と出ます。ドライブと外部サービスを使う許可を求められるので、許可します。
   - 下の「実行ログ」に「OK：こえが できました」と出れば準備できています。「うまく いきません」と出たら、その文をそのまま教えてください。
7. 「デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ」を押します。

- 作った声は、先生のドライブの「ものがたりの もり こえ」フォルダに保存して、使い回します。消すと、また作り直します。
- 声は、1行ずつ作ります。同じ行は2回作りません。その Chromebook にも覚えておくので、2回目からは すぐに出ます。
- 声が6びょうで まにあわないとき・子どもの名前が入るセリフは、ブラウザの声で読みます。
- **前もって声を作る**：先生用画面 →「せってい」の「🎙️ おはなしと セリフの 声を まとめて つくる」を押すと、物語のすべての行と、よく出るセリフの声を作ります（いまは百数十文）。
  - 1つ作るごとに7びょう待つので、全部で20分ほどかかります。画面を開いたままにしてください。
  - 物語を足したときや「声の しゅるい」を変えたときは、もう一度押します（できている声は とばします）。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。
4. 文字が小さいときは、先生用画面の「文字の大きさ」で変えます。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、たて書きの文章が小さくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。
- 「そらの うえの がっこう」に置くときは、URLを教えてください。こちらで `sora/apps.js` に足します。

## 先生用画面

1. 名前を選ぶ画面の右下（もり・物語の画面では 🔒）を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「せってい」で変えてください。**

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの いまの話・読んだ話の数・ほしの かけら・**①〜⑤ごとの「まちがえずに できた割合」と、まちがえた回数（✖）・ヒント（💡）**・にがてな種類・最後に学習した日。クラス全体の①〜⑤ |
| 子どもごと | **話ごと × ①〜⑤ごと** の表、まちがえた・ヒントを使った問題（選んだ順。新しい順に15問まで） |
| 子どもごと（ボタン） | ぜんぶの おはなしを開く（その子だけ）、この子の記録を消す |
| プリント | 話ごとに「🖨 いろなし」「🖨 いろつき」（印刷用ページを新しいタブで開く）と、できている PDF。印刷用ページで「🖨 いんさつ ・ PDFで ほぞん」を押し、PDFにするときは 送信先を「PDFに保存」にします。用紙は「B4」・「横」、「背景のグラフィック」にチェックを入れると色が出ます |
| せってい | 読み上げの速さ、文字の大きさ、③ たしかめ（する・しない）、効果音、読み聞かせの声（Gemini を つかう・つかわない、声の しゅるい6つ と「ためす」、APIキーが入っているか・きょう作った声の数・ドライブにある声の数・さいごのエラー、声を まとめて つくる）、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、全員の記録を消す |

- **まちがえずに できた割合** は、まちがえず、ヒントも使わずに できた問題の割合です（赤：60%未満、黄：60〜79%、緑：80%以上）。
- **にがて** は、2問以上といた種類のうち、割合がいちばん低い種類です（80%以上なら出しません）。
- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。

## 全員の記録を見る

- スプレッドシートの **「きろく」** シートに、1問ごとの結果が入ります。

  | 日時 | なまえ | おはなし | だいめい | しゅるい | もんだい | こたえ | けっか | まちがい | ヒント | えらんだ こたえ | びょう | ID |
  |---|---|---|---|---|---|---|---|---|---|---|---|---|

  - おはなし：話の番号（1〜）
  - しゅるい：①だれが いった・②いつ・③どこ・④きもち・⑤オノマトペ。「おわり」は、その話を読み終えた しるしです
  - もんだい：③ たしかめ の問題文。「さがす（ぶんしょうから さがす）」は ② さがす の結果です（こたえ＝答えの ことば、えらんだ こたえ＝子どもが選んだ ことば、まちがい＝見つけられなかった数＋ちがう所を選んだ数）
  - けっか：○＝まちがえず、ヒントも使わずに できた　△＝まちがえてから、またはヒントを使って できた
  - まちがい：その問題で まちがえた回数　ヒント：使ったヒントの段階（0〜3）
  - えらんだ こたえ：選んだ順（「うみ→やま」）
  - びょう：その問題にかかった時間
- **「まとめ」** シートに、子どもごと・種類ごと・話ごとの結果が入ります。先生用画面を開いたとき、またはメニュー **ものがたりの もり → まとめを更新する** で更新されます。
- **「名簿」** シートのB列に、進み具合・ほしの かけら・もりの なかま が入ります。ちがう Chromebook を使っても「つづきから」始められます。
- 記録は、1問ごと・段階が進んだとき・読み終えたときに送ります。ネットが切れていたときの記録は、その Chromebook にためておき、つながったときに送り直します。同じ記録は二重に書きません。

## 注意事項

- **個人情報**：名簿には、呼び名かひらがなの名前だけを入れてください。
- **Gemini の声**：物語の文と、ピカリせんせいのセリフが Google（Gemini API）に送られます。子どもの名前が入るセリフは送りません。無料で使える回数には上限があり、こえると有料になるか、しばらく使えなくなります（そのあいだはブラウザの声で読みます）。料金や回数は Google AI Studio で確かめてください。
- **物語**：6話とも、このアプリのために作った **オリジナル** の物語です。
- **絵**：ピカリせんせい・もりの なかま・もりの背景は、いまは自作のSVGと絵文字です。先生が ChatGPT で このアプリのために作ったオリジナルの絵に、順に入れかえます（`e_chatgpt.md`）。
- **効果音**：このアプリのためのオリジナルです（プログラムで作っています）。
- 物語のデータと絵は GitHub Pages から読みこむので、ネットにつながっている必要があります。
- 「データを よみこめませんでした」と出るときは、`https://zku0395-ops.github.io/hori/monogatari/` が開けるか確かめてください。
- 「止まった」「開かない」ときは、まず `index.html` の貼り付けが最後（`</html>`）まで入っているかを確かめてください。
