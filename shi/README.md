# オノマトペの 詩の 音読（5へん）

オノマトペ（ようすや 音を あらわす ことば）が たくさん出てくる詩を、1行ずつ 読んでいく 提示用のアプリです。
詩は5へんあり、どれも同じ形で動きます。

| 詩 | フォルダ | URL |
|---|---|---|
| ☔ あめの ひの おさんぽ | `ame/` | `https://zku0395-ops.github.io/hori/shi/ame/` |
| 🥁 どうぶつ たちの おまつり | `matsuri/` | `https://zku0395-ops.github.io/hori/shi/matsuri/` |
| 🛁 おふろ だいすき | `ofuro/` | `https://zku0395-ops.github.io/hori/shi/ofuro/` |
| 🏃 わくわく うんどうかい | `undoukai/` | `https://zku0395-ops.github.io/hori/shi/undoukai/` |
| ⛄ ゆきの ひ | `yuki/` | `https://zku0395-ops.github.io/hori/shi/yuki/` |

## できること

| こと | 内容 |
|---|---|
| 1行ずつ出す | 「つぎの ぎょう ▶」を押すと、詩が1行ずつ たて書きで出ます。「◀ もどる」「はじめから」「ぜんぶ だす」もあります |
| かくれた オノマトペ | オノマトペは、はじめの1文字だけ見えていて、残りは青いシートで かくれています。シートを押すと、ふわっと消えます |
| シートを もどす | 「シートを もどす」で、もう一度 かくせます |
| 行ごとの さしえ | 左に、その行の ようすを表す さしえが出ます（はじめの画面は 題名の さしえ） |
| さしえを いれる | 先生が、行ごとの さしえを 自分の画像に かえられます（その端末だけに保存） |
| おおきく | 画面いっぱいに 広げます |

## ステージ構成

ステージは ありません。1つの詩は 題名と9行です。

## 支援の工夫

- 1行ずつ出すので、どこを読むかが分かりやすいです。
- オノマトペの はじめの1文字を見せて、残りを考えてから シートを めくれます。
- 文字は UD デジタル 教科書体（なければ Klee One）で、画面に合わせて大きさが変わります。題名と本文は同じ大きさです。
- 行ごとの さしえで、ことばと ようすを結びつけます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 5へんの詩を選ぶ ページ（`https://zku0395-ops.github.io/hori/shi/`）。としょかん の「▶ アプリを ひらく」も ここを開きます |
| `ame/index.html` ほか | 詩ごとのアプリ（1ファイルで動きます。ビルドはしません） |
| `ame/img/e0.jpg`〜`e9.jpg` ほか | さしえ（e0 は 題名、e1〜e9 は 1〜9行目） |
