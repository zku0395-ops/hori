# 仮想職員室

特別支援学級の担任ひとりが使う「仮想職員室」です。
予定・週案・時間割・交流学級・単元計画・教材を1か所で管理します。
データは、学校の Google アカウントのスプレッドシートに保存します。

## 部屋と できること（第1版）

| 部屋 | できること |
|---|---|
| 🏠 ロビー（円卓の間） | 円卓のまわりの席には、部屋ごとの係のキャラクターが座っています。席を押すと、その部屋に入ります。キャラクターは順番に、その部屋の いまのようすを吹き出しで話します。まん中の地球儀には、時計・日付・「いま／つぎの時間」・「締め切りまで あと○日」が出ます。三角の入口の「🌙 あしたの確認」で、次の登校日の時間割・準備・予定・近い締め切りを確かめられます |
| | その下に、きょうの時間割（学習内容・交流に行く子）、2週間以内の予定（締め切りは「あと○日」）、進行中の単元と時数 |
| 📅 予定の部屋 | **週案**：1週間の表。マスを押して学習内容・単元・ふりかえりを書きます。印刷（A4横）、その週の教科ごとの時数も出ます |
| | **月の予定**：カレンダー。行事・会議・出張・締め切り・保護者・交流・休業日・その他の8種類。祝日は自動で表示します |
| | **基本の時間割**：ふだんの1週間。週案は、この時間割をもとに表示します |
| | **交流学級**：子どもごとに、交流学級へ行く時間を登録します。一覧で「いつ・だれが・どこへ」「教室に残る人数」が分かります |
| 📚 学習の部屋 | **単元計画**：教科・期間・計画時数・対象・ねらい。週案で単元を選んだ時間が、実施した時数として自動で数えられます |
| | **教材の置き場**：プリント・スライド・アプリなどのリンク集。教科・種類・単元で絞りこめます。「音読はかせ」も最初から入っています |
| 📝 公務・🧒 子ども・🤝 連携 | 準備中です。相談しながら作ります |
| ⚙️ 設定 | 学級名、校時と時刻（朝の会なども足せます）、教科・領域の並び |

### 円卓の間の キャラクター

| 席 | キャラクター | 吹き出しで話すこと |
|---|---|---|
| 📅 予定の部屋 | チクタク（時計のロボット） | つぎの予定 |
| 📚 学習の部屋 | ホーホーはかせ（音読はかせと同じフクロウ） | 進行中の単元の、計画時数まであと何時間か |
| 📝 公務の部屋 | ペンタ（ネクタイのペンギン） | いちばん近い締め切りまであと何日か |
| 🧒 子どもの部屋 | ミミ（エプロンのうさぎ） | きょう交流学級へ行く子の人数 |
| 🤝 連携の部屋 | モコ（ヘッドセットのくま） | 近い「交流」「保護者」の予定 |
| ⚙️ 設定 | ネジまる（歯車のロボット） | 設定でできること |

キャラクターは、この仮想職員室のために描いたオリジナルです。

## ファイル

```
shokuinshitsu/Code.gs    Google Apps Script：スプレッドシートへの読み書き
shokuinshitsu/app.html   Google Apps Script：画面
```

## 準備のしかた（学校のアカウントで、最初に1回）

1. 学校のGoogleアカウントで、**新しい** Google スプレッドシートを作ります（名前の例：「仮想職員室」）。
   - 「音読はかせ 記録」のスプレッドシートとは別にしてください。
2. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、`Code.gs` の内容を貼り付けます。
4. 左の「ファイル」の「＋」→「HTML」を選び、名前を `app` にします。中身をすべて消し、`app.html` の内容を貼り付けます。
5. 上の保存ボタン（💾）を押します。
6. 右上の「デプロイ」→「新しいデプロイ」を押します。
   - 左の歯車から種類「ウェブアプリ」を選びます。
   - 「次のユーザーとして実行」：**自分**
   - 「アクセスできるユーザー」：**自分のみ**
7. 「デプロイ」を押します。アクセスの承認を求められたら、自分のアカウントを選んで「許可」します。
   - 「このアプリは Google で確認されていません」と出たときは、「詳細」→「（プロジェクト名）に移動」を押します。
8. 表示された「ウェブアプリ」のURLを開くと、仮想職員室が開きます。ブックマークしておくと便利です。
   - スプレッドシートのメニュー「仮想職員室 → 職員室を開くURLを表示」でも確認できます（スプレッドシートを開き直すとメニューが出ます）。

**更新したとき**：`Code.gs` や `app.html` を新しいものに貼り替えたら、「デプロイ」→「デプロイを管理」→ 鉛筆のアイコン →「バージョン：新バージョン」→「デプロイ」で更新します（URLは変わりません）。

## スプレッドシートの中身

最初に開いたときに、次のシートが自動で作られます。

| シート | 中身 |
|---|---|
| 行事予定 | 月の予定 |
| 基本の時間割 | 曜日（1＝月〜5＝金）と校時ごとの教科 |
| 週案 | 週案に書きこんだ時間だけ（書いていない時間は基本の時間割で表示します） |
| 子ども | 呼び名・学年・交流学級 |
| 交流 | 子どもごとの交流の時間 |
| 単元計画 | 単元 |
| 教材 | 教材のリンク |
| 設定 | 学級名・校時・教科（中身は画面用の形式です） |

- シートは見るのは自由ですが、書きかえは仮想職員室の画面から行ってください。
- 見出しの右に自分用の列を足すことはできます（画面からの保存で消えることはありません）。
- 「ID」の列は、記録どうしを結びつけるためのものです。変えないでください。

## 大切なこと（個人情報）

- 「アクセスできるユーザー：自分のみ」にしているので、開けるのは自分のアカウントだけです。
- 子どもの名前は、呼び名やイニシャル（例：Aさん）で登録するのがおすすめです。
  - 障害名・診断・検査の結果などのくわしい情報は入れないでください。
- 勤務校の情報セキュリティの決まり（校外への持ち出し、私物の端末での利用など）に合わせて使ってください。
- このリポジトリ（GitHub）には、プログラムだけを置きます。予定や子どもの情報は置きません。

## 試作モード

`app.html` を Apps Script を通さずにブラウザで直接開くと、「試作モード」で動きます。

- サンプルのデータ（ひまわり学級・Aさん〜Cさん）が入った状態で始まります。
- 画面の色は、パソコンの設定に合わせて明るい画面と暗い画面が切りかわります（試作モードでも同じです）。
- データはその端末のブラウザの中にだけ保存されます。子どもの本当の情報は入れないでください。
- 設定の「データの保存場所」から、サンプルを入れなおしたり、すべて消したりできます。
