# 仮想職員室

特別支援学級の担任ひとりが使う「仮想職員室」です。
予定・週案・時間割・交流学級・単元計画・教材を1か所で管理します。
データは、学校の Google アカウントのスプレッドシートに保存します。

## 部屋と できること（第1版）

| 部屋 | できること |
|---|---|
| 🏠 ロビー（円卓の間） | 円卓のまわりの席には、部屋ごとの係のキャラクターが座っています。席を押すと、その部屋に入ります。キャラクターは順番に、その部屋の いまのようすを吹き出しで話します。まん中の地球儀には、時計・日付・「いま／つぎの時間」・「締め切りまで あと○日」（期限切れのやることがあるときは、その件数）が出ます。三角の入口の「🌙 あしたの確認」で、次の登校日の時間割・準備・予定・近い締め切りを確かめられます。締め切りには研修の報告書も、「これからの予定」には研修・研究授業も入ります |
| | その下に、きょうの時間割（学習内容・交流に行く子）、やること（締め切りの近い順、チェックで完了）、2週間以内の予定、進行中の単元と時数 |
| 📅 予定の部屋 | **週案**：1週間の表。マスを押して教科・時数・①単元（と週案簿の1行目：学習形態・場所など）・②めあて・③学習内容・ふりかえりを書きます。「🪜 段階表から選ぶ」では、段階・領域をしぼって選び、「入れる」でめあてと学習内容を入れかえ、「＋足す」で学習内容に①②…の行を足せます（子どもを選ぶと「Aさん：」がつくので、段階のちがう子の学習を1時間に並べて書けます）。「📋 一覧から選ぶ」で、その教科・単元の「めあて・学習内容の一覧」や、前に書いた週案から選ぶと、単元・めあて・学習内容がまとめて入ります（単元の次の時には「つぎ」の印）。「一覧にも入れる」にチェックすると、書いたものを一覧に足せます。週案簿と同じく、今週の重点、モジュール（⅓時間）、1時間を2つの教科に分ける書き方（例：行事 ⅓＋学級 ⅔）、日ごとの休み時間・備考・記録欄も書けます。出張の日は見出しに「🚗 出張」、補教の時間はマスに「🚗 補教：◯◯先生」が出て、備考にも「出張：…／補教：…」が入ります（週案簿に貼るファイルの備考にも入ります）。日の備考を押すと、出張以外の休みでも補教の計画を入れられます。下に、教科ごとの「この週・累計・標準・達成率」が出ます。印刷（A4横）もできます |
| | **時数**：年度の時数の集計表（週案簿の時数集計表と同じ形）。教科ごとに月別・学期別・累計・残り・達成率。国語計（図書・書写をふくむ）、各教科等と行事・児童会等の小計も出ます |
| | **月の予定**：カレンダー。行事・会議・出張・締め切り・保護者・交流・休業日・その他の8種類。祝日は自動で表示します。学校の月行事予定（Excel）を取りこめます |
| | **基本の時間割**：ふだんの1週間。週案は、この時間割をもとに表示します |
| | **交流学級**：子どもごとに、交流学級へ行く時間を登録します。一覧で「いつ・だれが・どこへ」「教室に残る人数」が分かります |
| 📚 学習の部屋 | **単元計画**：教科・期間・計画時数・対象・ねらい。週案で単元を選んだ時間が、実施した時数として自動で数えられます |
| | **🪜 段階表**：教科ごとに、領域×段階の表で、スモールステップのめあてと学習内容を並べます。国語・算数・体育・図工は、特別支援学校（知的障害）小学部の1〜3段階から小学校3年まで、音楽・生活は小学部の1〜3段階、自立活動（6区分）・日常生活の指導・生活単元学習はステップ1〜3の目安です（学習指導要領（平成29年告示）の内容をもとに、1時間で扱える大きさに分けたもの。はじめに253件入っています）。段階でしぼると一覧に、印刷もできます。押すと直したり、単元の「めあて・学習内容」に入れたりできます。足したり消したりも自由です（「はじめの段階表で足りないものを足す」で、消したものを戻せます） |

| 📝 公務の部屋 | **やること**：提出物や準備を、締め切りの近い順に「期限切れ／きょう・あした／1週間以内／それより先／締め切りなし」に分けて並べます。チェックで完了。上の欄に入れて Enter ですぐ追加できます |
| | **校務分掌**：担当の分掌ごとに、1年の仕事の流れを月ごとに入れます。「今月と来月の仕事」が一覧で出て、ボタン1つで「やること」に入れられます（時期が上旬・中旬・下旬なら、締め切りの日も自動で入ります） |
| | **会議メモ**：会議の内容と「自分がやること」を書きます。「自分がやること」の1行ずつを、ボタン1つで「やること」に入れられます |
| | **文書のひな形**：学級だより・お知らせ・申し送りなどのひな形。「下書きを作る」で {学級名} {日付} {年度} {曜日} が入った文ができ、コピーして使えます |
| 🧒 子どもの部屋 | **一人ひとり**：子どもを選ぶと、好きなこと・得意なこと、配慮・支援のポイント、個別の指導計画（願い・長期目標・学期ごとの目標）、教科ごとの段階、交流の時間、日々の記録、保護者との連絡が 1ページで見られます |
| | **🪜 教科ごとの段階**：段階表のどの段階を学習しているか（例：国語 3段階、算数 2段階）を入れます。段階表から立てた目標が「◎」になると「次の段階へ進めますか？」と案内が出て（子どもの部屋のミミも知らせます）、押すと段階が上がり、「📈 段階のあゆみ」に日付と段階が残ります（所見のたねにも入ります）。週案で段階表から選ぶときに子どもを選ぶと、その子の段階に切りかわります。段階表の見出しにも、その段階の子が出ます。押すと、その教科・段階の段階表を開きます |
| | **日々の記録**：子どもと分類（よかったこと・学習・生活・コミュニケーション・行動・体・健康）を選び、ひとこと書いて Enter で記録。学期ごとの記録の数も出るので、記録の少ない子に気づけます |
| | **指導計画**：学期ごと（年間・1学期・2学期・3学期）に、領域・目標・手立て・達成（◎○△）・評価を書きます。一覧で、だれの評価がすんでいるかが分かります。目標を足すときは「段階表から選ぶ」で、その子の段階のステップを目標にできます（段階表の各ステップからも「子どもの学期の目標に入れる」ができます） |
| | **保護者連絡**：連絡帳・電話・面談などの記録。「次にすること」はボタン1つで「やること」に入れられます |
| | **🌱 所見のたね**：その学期の指導計画・日々の記録・保護者との連絡を、1つの文にまとめます。コピーして、通知表の所見や指導計画の評価を書く材料にします |
| 🤝 連携の部屋 | **交流学級**：子どもの「交流学級」から、学級ごとのカードを自動で作ります。担任の先生の名前、その週にだれが何の時間に行くか、最近の申し送りが見られます。「交流の予定を 送る文」で、交流学級の担任の先生に渡す文ができ、コピーして使えます |
| | **申し送り**：交流学級への申し送り（日付・学級・子ども・内容・返事や次にすること）の記録。学級でしぼりこめます |
| | **支援員さん**：支援員・介助員さんなどの名前・役割・勤務曜日を入れます。「基本の動き」に曜日ごとの毎週の動きを入れておくと、その日の表に自動で出ます。その日だけの変更は表で書きかえるだけ（空にすると基本にもどる、「—」でその日はなし）。「支援員さんへの 文」でコピー、印刷もできます。ロビーの「きょうの時間割」にも 👥 で出ます |
| | **関係機関**：放課後等デイサービス・相談機関などの名前・担当者・電話・関係する子ども・メモ。連絡の記録（日付・子ども・方法・内容・次にすること）を残し、「次にすること」はボタン1つで「やること」に入れられます |

## ファイル

```
shokuinshitsu/Code.gs    Google Apps Script：スプレッドシートへの読み書き
shokuinshitsu/app.html   Google Apps Script：画面
shokuinshitsu/tools/     版を作るときの道具（Apps Script には貼り付けません）
```

`app.html` を直したら、`node shokuinshitsu/tools/stamp.js` を動かします（起動の見守りが、貼り付けでこわれた場所を見つけるための しるしを書きこみます）。

## 準備のしかた（学校のアカウントで、最初に1回）

1. 学校のGoogleアカウントで、**新しい** Google スプレッドシートを作ります（名前の例：「仮想職員室」）。
   - 「音読はかせ 記録」のスプレッドシートとは別にしてください。
2. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、`Code.gs` の内容を貼り付けます。
4. 左の「ファイル」の「＋」→「HTML」を選び、名前を `app` にします。中身をすべて消し、`app.html` の内容を貼り付けます。
5. 上の保存ボタン（💾）を押します。
   - 左の歯車「プロジェクトの設定」で、タイムゾーンが「(GMT+09:00) 日本標準時」になっているか確かめます（「Etc/GMT-9」など、日本時間と同じ ＋9時間 の 時間帯なら 大丈夫です）。
   - スプレッドシートの「ファイル」→「設定」の タイムゾーンも「(GMT+09:00) Tokyo」にしておきます。
   - **読みこみを速くする（おすすめ）**：左の「サービス」の「＋」→「Google Sheets API」を選んで「追加」します。すべてのシートを1回でまとめて読むので、開くのが速くなります（足していないときは、1枚ずつ読みます）。
6. 右上の「デプロイ」→「新しいデプロイ」を押します。
   - 左の歯車から種類「ウェブアプリ」を選びます。
   - 「次のユーザーとして実行」：**自分**
   - 「アクセスできるユーザー」：**自分のみ**
7. 「デプロイ」を押します。アクセスの承認を求められたら、自分のアカウントを選んで「許可」します。
   - 「このアプリは Google で確認されていません」と出たときは、「詳細」→「（プロジェクト名）に移動」を押します。
8. 表示された「ウェブアプリ」のURLを開くと、仮想職員室が開きます。ブックマークしておくと便利です。
   - はじめて開くときは、スプレッドシートに 30枚ほどのシートと 段階表（253件）を作るので、1分ほどかかることがあります。
   - 開いたら「⚙️ 設定」のいちばん上の「🩺 動作チェック」→「チェックする」を押します。⚠ が出たところがあれば、下の「結果の文」をコピーして相談してください（個人の情報は入っていません）。「ダウンロードのテスト」「Word のテスト」で、小さなファイルがダウンロードされるかも確かめます。
   - スプレッドシートのメニュー「仮想職員室 → 職員室を開くURLを表示」でも確認できます（スプレッドシートを開き直すとメニューが出ます）。

**更新したとき**：`Code.gs` や `app.html` を新しいものに貼り替えたら、「デプロイ」→「デプロイを管理」→ 鉛筆のアイコン →「バージョン：新バージョン」→「デプロイ」で更新します（URLは変わりません）。

**貼り付けの しかた（こわれないように）**：
1. GitHub の `app.html` の ページで、右上の「Raw」を押します（文字だけの ページが 開きます）。ブラウザが「翻訳しますか」と 出しても、翻訳は しないでください。
2. その ページで Ctrl＋A（すべて選択）→ Ctrl＋C（コピー）。Word や メモ帳を 間に はさまず、そのまま 次へ 進みます。
3. Apps Script の `app` を 開き、中を 一度 クリックしてから Ctrl＋A → Delete → Ctrl＋V。貼り付けが 終わるまで、数秒 待ちます。
4. いちばん下が `</html>` で、その 行番号が、この 版の 行数（下の「止まった とき」の 画面にも 出ます）と 同じか 確かめて、💾 で 保存します。

**「職員室の かぎを あけています…」で 止まった とき**：25秒ほど 待つと、考えられる 理由が 画面に 出ます。
- 「app.html の ○〜○行目 あたりが、正しい 版と ちがいます」と 出たら、貼り付けの とちゅうで 中身が 変わっています。上の しかたで、もう一度 全文を 貼り付けて 保存し、「新バージョン」で デプロイしてください。Apps Script の 画面で その 行を 見ると、変わった ところが 分かります。
- 「中身は 正しい 版と 同じです」と 出たら、ブラウザが 古い ことが 考えられます。新しい Chrome か Edge で 開いてください。
- 「サーバー（Apps Script）から 返事が ありません」と 出たら、画面の 案内に したがって、アカウントや 許可を 確かめてください。

**教材置き場に ファイルを 保存する とき**：新しい版にして「デプロイ」すると、Google ドライブを 使う 許可を 求められます（「仮想職員室 教材置き場」フォルダに ファイルを 保存・表示する ため）。自分の アカウントを 選んで「許可」してください。

**火曜日の朝の 自動作成を 使う とき（最初に 1回）**：スプレッドシートを 開き直し、メニュー「仮想職員室」→「火曜日の朝の 週案の自動作成を オンにする」を 押します。「承認が必要です」と 出たら、自分の アカウントを 選んで「許可」します（トリガーの 管理と、下書きの スプレッドシートを 作るための 許可です）。

## スプレッドシートの中身

最初に開いたときに、次のシートが自動で作られます。

## 週案の 下書きを 週案簿（Excel）に 貼る

### 毎週火曜日の朝に、次の週の 下書きを 自動で 作る

- **毎週火曜日の朝（6時台）に、仮想職員室を 開かなくても**、Apps Script の 時間主導型トリガーが 次の週の 週案の 下書きを 作ります（例：10月6日（火）の朝に、10月12日（月）からの 週の 下書き）。
  - あわせて、週案簿に 貼る 形の スプレッドシート「仮想職員室 週案の下書き」（自分の Google ドライブ）も 作りなおします。
  - トリガーは、仮想職員室を はじめて 開いたときに 自動で つきます。「⚙️ 設定」の「週案の 下書き」や、スプレッドシートの メニュー「仮想職員室」→「火曜日の朝の 週案の自動作成を オンにする／オフにする」で 切りかえられます。メニューの「次の週の 週案の下書きを いま作る」で、すぐに 作ることも できます。
  - 前の 版で つけた トリガー（木曜日の朝）は、次に 動いたときか、仮想職員室を 開いたときに、火曜日の朝に つけなおします。
  - 時刻は、Apps Script の「プロジェクトの設定」の タイムゾーンで 決まります。「(GMT+09:00) 日本標準時」に なっているか 確かめてください。
  - 下書きの 計算は、画面と 同じものを 使います（`app.html` の「共通ここから」〜「共通ここまで」の 部分を、`Code.gs` が 読みこんで 使います）。
- 朝の 自動作成が 動かなかった週も、火曜日〜日曜日に 仮想職員室を 開けば 作ります。
- 下書きには、次のものが 入ります。
  - 教科：基本の時間割（週案簿の 時間割Ａ）から。月行事予定の 授業時数が 4時間の日は 5・6校時を 空け、5校時の欄に「B時程12:50下校」などを 書きます（週案簿と 同じ書き方）
  - 学習内容：単元に「めあて・学習内容の一覧」が あれば、次の 時の 1行目・めあて・学習内容。なければ、先週の 同じ曜日・同じ校時が 同じ教科なら その内容、なければ いちばん近い 前の 同じ教科の 内容を 写します（単元計画が あれば 単元とも つなぎます）
  - 行事：月行事予定から（1行目に 1つめ、2行目に のこり）。祝日は 名前を 1字ずつ 縦に、長い休みは 空白にします（週案簿と 同じ）
- 週案簿から 取りこんだ週や、自分で 書きこんだ時間は 変えません。
- できると、ロビーに「次の週の 週案の 下書きが できています」と出ます。「⚙️ 設定」の「週案の 下書き」で、自動で作るか、学習内容を写すかを 選べます。週案の画面の「📝 下書きを作る」で、いつでも その週の下書きを作れます。

### 週案簿に 貼り付ける

1. 週案の画面（またはロビー）の「📤 週案簿に貼る」→「📥 Excelファイルを作る」で、ファイルを ダウンロードします。週案簿の 週の シートと 同じ形（同じ セルの 結合）に なっています。
2. そのファイルを Excel で開き、左上の 名前ボックスに **B7:K73**（土曜授業が ある週は **B7:M73**）と入れて Enter → コピー（Ctrl＋C）。
3. 週案簿の その週の シート（「第28週」なら「28」）で **B7** を選び、右クリック →［形式を選択して貼り付け］→［値］→［OK］。

- 行事・教科・時数・学習内容・休み時間・備考・記録欄が 入れかわります。右側の 時数の集計は、週案簿が 自動で 計算します。
- 学習内容の 欄は「1行目／○めあて／学習内容」の 順に 入ります。1行目は、週案で 書いた「1行目（学習形態・場所など）」、空なら 選んだ 単元の 名前です。単元名を 入れるか、めあての しるし（○・◎・めあて：・なし）は「設定」→「週案の 下書き」で 変えられます。
- 今週の重点は、「📋 今週の重点を コピー」で コピーして、週案簿の G3 に 貼ってください。
- 1時間を 2つの教科に 分けた時間は、1つめの教科だけが 入ります（週案簿で 分けてから、2つめの教科を 入れてください）。週案簿で 分けた 時間が ある シートに 貼ると、セルの 結合が ちがうため 貼り付けられません。
- ダウンロードが できないときは、「Googleスプレッドシートに 書き出す」で 開き、［ファイル］→［ダウンロード］→［Microsoft Excel］で 保存してから、同じように 貼り付けてください（自分の Google ドライブに「仮想職員室 週案の下書き」という ファイルが 1つ できます）。
- シートの 番号（第◯週）は、週案簿の 第1週の 月曜日から 数えます。週案簿を 取りこむと 自動で 入ります（「設定」でも 直せます）。

## 学校の ファイルを 取りこむ

「⚙️ 設定」の「📥 学校の ファイルを 取りこむ」（または 月の予定の「📥 行事予定を取りこむ」）から、次の2つの Excel ファイルを取りこめます。ファイルの種類は自動で見分けます。

| ファイル | 取りこむもの |
|---|---|
| 月行事予定（.xlsx、「新4月」〜「新3月」のシート） | 児童に関する行事等・会議・研修・16:15〜の会・出張等・20分休み（朝の活動・ランチ給食は選べば）を「月の予定」へ。「当日時間割」の学年の列を選ぶと、その日の授業時数も入り、授業のない日（長期休業・始業式前など）や 4時間授業の日が週案と時数の集計に反映されます |
| 週案簿（.xlsm） | 学級名、教科・領域と標準時数（教科一覧）、時間割Ａ、週ごとの週案（教科・時数・学習内容・モジュール・今週の重点・休み時間のメモ）。備考・記録欄は、選んだときだけ取りこみます |

- ファイルは、仮想職員室の画面の中で読みとるだけです。ファイルそのものは、どこにも送りません。取りこんだ内容だけが、自分のスプレッドシートに保存されます。
- 週案簿の「児童名簿」のシートは読みこみません。
- 備考・記録欄には、子どもや保護者の名前、ほかの先生の予定などが書かれていることがあります。取りこむ前に、学校の情報セキュリティの決まりを確かめてください。学習内容にも名前が入っていることがあるので、気になるところは取りこんだあとで直してください。
- 同じファイルを何度取りこんでも、予定や週案は増えません（同じ月・同じ日の分を入れかえます）。行事予定が新しくなったら、もう一度取りこめば最新になります。自分で入れた予定はそのままです。
- 読みとりには SheetJS（cdnjs.cloudflare.com から読みこみます）を使います。学校の設定でこのサイトが止められていると、取りこめません。

## 大切なこと（個人情報）

- 「アクセスできるユーザー：自分のみ」にしているので、開けるのは自分のアカウントだけです。
- 子どもの名前は、呼び名やイニシャル（例：Aさん）で登録するのがおすすめです。
  - 障害名・診断・検査の結果などのくわしい情報は入れないでください。
  - 子どもの部屋の 記録・指導計画・保護者との連絡は、事実と 支援を 必要なだけ 短く 書きます。個別の教育支援計画など 正式な 書類は、学校で 決められた 書式・保存場所で 作ってください。
  - 子どもを消すと、その子の記録・指導計画・保護者との連絡・交流の時間・申し送りも すべて消えます（関係機関との連絡の記録は残り、子どもとのつながりだけ外れます）。
  - 関係機関と子どもの情報をやりとりするときは、保護者の同意など、学校の決まりに従ってください。支援員さんの名前は、校内で使う呼び方で十分です。
- 勤務校の情報セキュリティの決まり（校外への持ち出し、私物の端末での利用など）に合わせて使ってください。
- このリポジトリ（GitHub）には、プログラムだけを置きます。予定や子どもの情報は置きません。

## 試作モード

`app.html` を Apps Script を通さずにブラウザで直接開くと、「試作モード」で動きます。

- サンプルのデータ（ひまわり学級・Aさん〜Cさん）が入った状態で始まります。
- 画面の色は、パソコンの設定に合わせて明るい画面と暗い画面が切りかわります（試作モードでも同じです）。
- データはその端末のブラウザの中にだけ保存されます。子どもの本当の情報は入れないでください。
- 設定の「データの保存場所」から、サンプルを入れなおしたり、すべて消したりできます。
