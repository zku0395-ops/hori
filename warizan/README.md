# ミノリせんせいの わけわけ のうえん（わり算の学習アプリ）

小学校の特別支援学級向けの、わり算の学習アプリです。
さるの「ミノリせんせい」の くだもの のうえんで、とれた くだものを どうぶつの なかまと わけます。

- くだものを おさらに **1こずつ くばる**（等分除）、**〇こずつ ふくろに つめる**（包含除）操作から始めます。
- 操作した えを しきに すること、お話から しきを つくること、くくで こたえを もとめることへ、少しずつ進みます。
- 最後に、わる数ごとの **けいさん れんしゅう** で、わり算に なれます。
- 正解すると くだもの（🍎）が1こ もらえます。くだもので「おみせ」の品物を買い、のうえんに ならべます。
- だんかいを クリアすると、どうぶつの なかまが のうえんに やってきます（なかま ずかん、12ひき）。
- 形は、漢字・ローマ字のアプリと同じ「Apps Script だけ」です。子どもは名簿の名前のボタンを押して始めます。
- 問題のデータと絵は、GitHub Pages（`https://zku0395-ops.github.io/hori/warizan/`）から読みこみます。Apps Script に貼り付けるファイルを短くするためです。

## できること

| 項目 | 内容 |
|---|---|
| ステージ | 本編37（⓪〜⑨の10だんかい）と、はってん3（あまりの ある わり算・0や1の わり算） |
| 1回の長さ | 5問（先生用画面で 3問・10問 にもできます）。⑨けいさん れんしゅう は 5問（10問・20問 にもできます）。途中でやめても「つづきから」始められます |
| くばる | かごの くだものを、おさらを押して1こずつ くばります。くだものを おさらまで ドラッグしても くばれます。まだ もらって いない どうぶつが いるのに、同じ どうぶつに くばろうとすると、止めて声をかけます |
| つめる | 「⬇ 1こ いれる」か くだものを押して ふくろに入れ、〇こに なったら「🎀 とじる」を押します。ふくろの中の くだものを押すと、かごに もどります |
| こたえ方 | ⓪〜⑥は「えらぶ」、⑦〜⑨と はってん②③は「すうじの ボタン（0〜9）」です |
| 数の大きさ | ⓪〜④は 20こまで。⑤〜⑨は くくの はんい（こたえは1けた） |
| 声 | ミノリせんせいのセリフと問題を読み上げます（はじめは0.8倍の速さ）。「12 ÷ 3」は「じゅうに わる さん」、「3びき」「6こ」なども正しい読み方で読みます。ミノリせんせいか「🔊 もういちど」を押すと、もう一度聞けます |
| ごほうび | 1問で くだもの1こ（ヒントを使っても同じ）。ステージを初めてクリアすると5こ、だんかいを クリアして なかまが来ると さらに10こ |
| のうえん | おみせで買った品物（はたけ・き と はな・たてもの・どうぐ と のりもの）と、なかまの どうぶつが のうえんの絵に ならびます。「だす・しまう」で かざりを えらべます |
| おみせ | 4つの たな × 10こ。どのたなも ふつう4こ（5こ）・ごうか3こ（15こ）・ちょうごうか2こ（30こ）・でんせつ1こ（60こ） |
| なかま ずかん | だんかい⓪〜⑨を クリアするごとに1ぴき（うさぎ・くま・ねこ・いぬ・ぶた・ひよこ・たぬき・きつね・パンダ・ぞう）。はってんで2ひき（ひつじ・かめ）。なかまに なった どうぶつは、問題の中にも出てきます |
| しょうごう | なかまの数で上がります（みならい のうか → くばり じょうず（2ひき）→ つめつめ じょうず（4ひき）→ しきの たつじん（6ぴき）→ けいさん めいじん（8ぴき））。本編を全部クリアすると「わけわけ はかせ」 |
| 先生用画面 | 暗証番号4けたで開きます。記録の確認（まちがいの しゅるい、わる数ごとの結果、まちがえた問題）、設定、記録の送信、CSV書き出し、バックアップ、記録の消去ができます |
| 全員の記録 | 結果は先生のGoogleスプレッドシートへ届きます。進み具合・くだもの・買ったもの・なかまも、スプレッドシートに保存します |

## ステージ構成

| だんかい | ステージ | 内容 | こたえ方 |
|---|---|---|---|
| ⓪ おなじ かずずつ | 0-1 おなじ？ ちがう？／0-2 おなじに しよう／0-3 3びきで おなじ？ | 2〜3びきの おさらの くだものが同じ数かを見分けます。0-2は、おおい ほうから1こ うごかして同じ数にします | えらぶ・うごかす |
| ① 1こずつ くばる | 1-1 2ひき（10こまで）／1-2 3びき（12こまで）／1-3 4・5ひき（20こまで） | 1こずつ じゅんばんに くばります（等分除の操作） | くばる |
| ② 1ぴき なんこ？ | 2-1 2・3びき／2-2 4・5ひき／2-3 よそうして たしかめる | くばったあと「1ぴき なんこ？」に こたえます。2-3は、さきに よそうしてから くばります | くばる → えらぶ |
| ③ 〇こずつ つめる | 3-1 2こずつ／3-2 3こずつ・4こずつ／3-3 5こずつ（なんびき？） | 〇こずつ ふくろに つめて「なんふくろ？」「なんびきに あげられる？」に こたえます（包含除の操作） | つめる → えらぶ |
| ④ くらべっこ | 4-1 どっちの え？／4-2 おなじ 12こでも／4-3 まぜて | お話を聞いて、「くばる え」と「つめる え」のどちらに合うかを えらびます。4-2・4-3は、えを えらんでから こたえも えらびます。4-2は、同じ12こを「くばる」と「つめる」で じゅんばんに出します | えらぶ |
| ⑤ しきの であい | 5-1「÷」の よみかた／5-2 つめた え → しき／5-3 しきを みて くばる | くばった え・つめた えに合う しきを えらびます。5-3は、しき（6 ÷ 2）を見て くばり、こたえを見つけます | えらぶ・くばる |
| ⑥ しきを つくる | 6-1 しきを えらぶ（くばる）／6-2 しきを えらぶ（つめる）／6-3 しきを くみたてる | お話から しきを えらびます。6-3は、すうじと きごうの カードを ならべて しきを作ります | えらぶ・ならべる |
| ⑦ こたえを もとめる | 7-1 かけざんの □（3 × □ ＝ 12）／7-2 くくで わりざん（12 ÷ 3 と 3 × □ ＝ 12 を ならべて出す）／7-3 しきと こたえ | わる数は 2〜5 | すうじの ボタン |
| ⑧ まとめ | 8-1 くばる おはなし／8-2 つめる おはなし／8-3 まぜて | お話 → しきを えらぶ → こたえを すうじで入れる。わる数は 2〜6 | えらぶ → すうじ |
| ⑨ けいさん れんしゅう | ÷2・÷5・÷3・÷4・÷6・÷7・÷8・÷9（くくの 段と同じ順）→ まぜて（÷2〜÷5）→ まぜて（ぜんぶ） | わり算の しきだけを たくさん ときます | すうじの ボタン |
| はってん① | あまりの ある くばりかた | くばって、みんなに くばれなく なったら「✋ もう くばれない」。1ぴき なんこ？ と のこり（あまり）を こたえます | くばる → えらぶ |
| はってん② | あまりの ある しき | 14 ÷ 3 ＝ □ あまり □ | すうじの ボタン |
| はってん③ | 0や 1の わり算 | 0 ÷ 3、5 ÷ 1、4 ÷ 4 を、えを見ながら考えます | すうじの ボタン |

- 前のステージをクリアすると、次のステージが開きます。
- はってんは、はじめは閉じています。先生用画面の「子どもごと」で開きます。
- ステージの一覧・お話・おみせの品物は `data/mondai.js` にあります。

## 支援の工夫

- **操作から しきへ**：はじめは くだものを実際に うごかし、えと しきを つなげてから、しきだけの けいさんに進みます。
- **2つの わけかたを くらべる**：「1ぴき なんこ？」（くばる）と「なんふくろ？」（つめる）を、④で えを見て くらべます。同じ 12こでも こたえが ちがうことに気づけるようにしています。
- **色分け**：しきの ぜんぶの かず（わられる数）は あか、わる数は あお、こたえは みどりです。お話の中の数にも、ヒントで同じ色を付けます。
- **まちがいやすい答えを選択肢に入れる**：「1ぴき なんこ？」では、どうぶつの数（わる数）や ぜんぶの数を まぜます。しきでは、入れちがい（2 ÷ 6）や ＋・−・× を まぜます。
- **まちがえたとき**：まちがえた選択肢は うすくなって、もう選べなくなります。まちがい方に合わせて声をかけます（例：「3は どうぶつの かずだね。1ぴきの おさらを みよう」「2 ÷ 6 だと、2こを 6に わける ことに なるよ」「3 × 5 ＝ 15。12に なるかな？」）。まちがえたときの音は小さな音です。
- **ヒントは3段階** です。同じところで2回まちがえるとヒントボタンが光り、3回まちがえると一番くわしいヒントが自動で出ます。

  | 学習 | ヒント1（ことば） | ヒント2（色分け・見本） | ヒント3（いっしょに） |
  |---|---|---|---|
  | くばる | 「1こずつ じゅんばんに」 | 次に くばる おさらが光る | 1まわり くばるのを見せる |
  | つめる | 「〇こずつ だよ」 | ふくろに 〇この わくを出す | いっしょに つめて、「とじる」を光らせる |
  | しきを つくる | 「ぜんぶで なんこ？」「いくつに わける？」 | ぜんぶの数＝あか、わる数＝あお に色分け | お話の えを出し、答えを光らせる |
  | こたえを もとめる・けいさん | 「3 × □ ＝ 12」 | くくの 段の表を出す | 答えの くくを光らせる |

- 時間制限はありません。
- 問題の画面は背景をすっきりさせています。にぎやかな絵は、はじめの画面・のうえん・ずかんだけで使います。
- くだもの・おさら・ふくろは、絵文字を白い丸で囲んだ スタンプにしています。形がそろっていて数えやすくするためです。

## ファイル構成

```
warizan/index.html          アプリ本体（Apps Script の HTML ファイル「index」に貼り付けます）
warizan/コード.gs            スプレッドシートとつなぐプログラム（Apps Script の「コード.gs」に貼り付けます）
warizan/data/mondai.js      ステージ・お話・どうぶつ・くだもの・おみせの品物・しょうごうのデータ
warizan/img/                ミノリせんせいの絵・のうえんの背景・どうぶつの絵（Canva で作成）
warizan/tools/check.js      問題データの点検（node warizan/tools/check.js）
warizan/tools/test_gas.js   コード.gs のテスト（node warizan/tools/test_gas.js）
```

- `data/` と `img/` は、GitHub Pages から読みこみます。お話や品物を直したときは、`data/mondai.js` を直して `main` に入れるだけで、Apps Script を貼り直さなくても全員の画面に反映されます。
- 絵が読みこめないときは、ミノリせんせいは自作の絵（SVG）、どうぶつは絵文字が出ます。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/warizan/` を開きます。
   - 「おためしモード」で動けば、問題のデータと絵の公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「わり算 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、くだものや ボタンが小さくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

1. 名前を選ぶ画面の右下（学習中は右上）の **🔒** を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「せってい」で変えてください。**

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの クリアしたステージの数（いま やっている ステージ）・なかまの数・くだもの・問題の数・まちがえずに できた割合・多い まちがいの しゅるい・にがてな わる数・最後に学習した日。クラス全体の まちがいの しゅるい と、わる数ごとの結果 |
| 子どもごと | ステージごとの結果（クリア・問題の数・まちがえずに できた割合）、まちがいの しゅるい、わる数ごとの結果（÷2〜÷9）、まちがえた問題（多い順） |
| 子どもごと（ボタン） | 全部開く（その子だけ、すべてのステージを開く）、はってんを開く、くだものを足す・引く、この子の記録を消す |
| せってい | 読み上げの速さ、文字の大きさ、1回の問題の数（3・5・10）、⑨けいさん れんしゅう の問題の数（5・10・20）、効果音、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、全員の記録を消す |

- **まちがえずに できた割合** は、まちがえず、ヒントも使わずに できた問題の割合です。
- **にがてな わる数** は、3問以上といて、まちがえずに できた割合が60%未満の わる数です。
- **まちがいの しゅるい**

  | しゅるい | 内容 |
  |---|---|
  | かぞえまちがい | 数を数えまちがえた（おなじ？ ちがう？、ふくろに入れる数 など） |
  | とりちがい | 「1つぶんの数」と「いくつ分」、わる数や ぜんぶの数を取りちがえた。「くばる え」と「つめる え」の取りちがいも入ります |
  | いれちがい | わられる数と わる数を入れちがえた（例：2 ÷ 6） |
  | ちがう けいさん | ＋・−・× を選んだ |
  | くく | わり算の答え（くく）の まちがい |
  | かたより | 1こずつ じゅんばんに くばれなかった |
  | あまり | あまりの まちがい（あまりが わる数より大きい、まだ くばれるのに「もう くばれない」を押した など） |

- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。

## 全員の記録を見る

- スプレッドシートの **「きろく」** シートに、1問ごとの結果が入ります。

  | 日時 | なまえ | ステージ | だんかい | もんだい | こたえ | けっか | まちがい | ヒント | まちがいの しゅるい | えらんだ こたえ | わる数 | びょう | ID |
  |---|---|---|---|---|---|---|---|---|---|---|---|---|---|

  - ステージ：0-1〜9-10、はってん1〜はってん3
  - だんかい：「① 1こずつ くばる」など
  - もんだい：「くばる 12こを 3びき」「12÷3（くばるの おはなし）」「3×□＝12」など
  - こたえ：正しい答え（例：「4」「4こずつ」「14÷3 の 4 あまり 2」）
  - けっか：○＝まちがえず、ヒントも使わずに できた　△＝まちがえてから、またはヒントを使って できた
  - まちがい：まちがえた回数　ヒント：使ったヒントの段階（0〜3）
  - まちがいの しゅるい：上の表の しゅるい（2つ以上のときは「・」で区切ります）
  - えらんだ こたえ：まちがえて選んだ答え・入れた答え（例：「3・12」「2 ÷ 6」）
  - わる数：くくを使う問題（⑦⑧⑨・はってん②）の わる数
  - びょう：その問題にかかった時間
- **「まとめ」** シートに、子どもごと・ステージごとの結果と、まちがいの しゅるい・わる数ごとの結果・まちがえた問題が入ります。先生用画面を開いたとき、またはメニュー **ミノリ → まとめを更新する** で更新されます。
- **「名簿」** シートのB列に、進み具合・くだもの・買ったもの・なかまが入ります。ちがう Chromebook を使っても「つづきから」始められます。
- 記録は、やめたとき・終わったとき・1問ごとの区切りで送ります。ネットが切れていたときの記録は、その Chromebook にためておき、つながったときに送り直します。同じ記録は二重に書きません。

## 注意事項

- **個人情報**：名簿には、呼び名かひらがなの名前だけを入れてください。
- **絵**：ミノリせんせい・のうえんの背景・どうぶつの なかまは、先生の Canva で、このアプリのために作った画像です（Canva のデザイン「ミノリせんせい わけわけ のうえん え（書き出し用）」に保存しています）。くだもの・おさら・ふくろ・おみせの品物は絵文字です。
- **お話**：すべて、このアプリのためのオリジナルです。
- **効果音**：このアプリのためのオリジナルです（プログラムで作っています）。
- **ことば**：子どもの画面は ひらがなと分かち書きです。漢字は「人」だけを使い、ふりがなを付けています。
