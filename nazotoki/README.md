# ワンダせんせいの なぞとき たんていじむしょ（文章の読み取りアプリ）

小学校の特別支援学級（1〜4年生）向けの、国語の読み取りの学習アプリです。
犬の探偵「ワンダせんせい」といっしょに、短い文章を読んで、**いつ・どこで・だれが・なにを した** の4つの「手がかり」を見つけます。

- アプリ本体：`https://zku0395-ops.github.io/hori/nazotoki/`
- レベル1は、4つの選択肢から答えを選びます。
- レベル2は、50音表（ひらがな・カタカナ）から答えを入力します。
- 文章は、レベルごとに50（合計100）あります。すべての文章に、Canva で作った挿絵が付いています。

## できること

| 項目 | 内容 |
|---|---|
| 文章 | レベル1・レベル2 で 50ずつ、合計100。身近な生活の場面（学校・家・公園・お店・季節の行事）と、動物のお話です |
| 文字 | ひらがなと分かち書きが中心です。漢字は1年生で習うものだけを使い、すべてにふりがなを付けています（先生用画面で、ふりがなを消すこともできます） |
| 挿絵 | 1つの文章に1まい。Canva で作った画像です |
| レベル1 | 4つの選択肢から選びます。選択肢には、まちがいやすい答えを入れています |
| レベル2 | 50音表から入力します。答えの字の数だけ □ が出ます。「なにを した」は、大事なことばだけを入れます（例：「ボールを □□ました」） |
| 読み上げ | 文章と問いを、ワンダせんせいが少しゆっくり読み上げます。読んでいる文は黄色くなります |
| ヒント | 3段階です（ことば → 色の線 → 答えを光らせる） |
| 正解したとき | 「せいかい！」とファンファーレ。文章の4つの手がかりを全部見つけると「じけん かいけつ！」で、シールが1まいもらえます |
| シール | 8しゅるい（たべもの・のみもの・のりもの・どうぶつ・くだもの・やさい・デザート・ぶんぼうぐ）× 13まい ＝ 104まい。コレクションシートで見られます |
| 称号 | 解いた文章の数で上がります。上がると「たんていバッジ」がもらえます |
| 先生用画面 | 暗証番号4けたで開きます。記録（どの手がかりでつまずいているか）、設定、データ（送信・CSV・バックアップ・消去） |
| 全員の記録の一覧 | 答えるたびに、先生のGoogleスプレッドシートへ結果が届きます |

## ステージ構成

レベル1・レベル2とも、10ステージ × 5つの文章です。1ステージは5〜10分で終わります。

| ステージ | 文章 | 聞くこと | 例 |
|---|---|---|---|
| 1 | 1文 | だれが（1つだけ） | あさ、ゆうとくんは こうえんで ボールを けりました。 |
| 2 | 1文 | どこで（1つだけ） | |
| 3 | 1文 | いつ（1つだけ） | |
| 4 | 1文 | なにを した（1つだけ） | |
| 5 | 1文 | 4つとも | |
| 6 | 1文（ことばの順番を入れかえる） | 4つとも | ゆきさんは、あさ、にわで ちょうちょを みつけました。 |
| 7 | 2文 | 4つとも | なつの よるでした。けんたくんは にわで はなびを しました。 |
| 8 | 2文（にていることばが2つ） | 4つとも | あさ、…いえで ごはんを たべました。ひるに、こうえんで サッカーを しました。 |
| 9 | 3文 | 4つとも | |
| 10 | 3文（にていることばが いくつも） | 4つとも | |

- 前のステージを終えると、次のステージが開きます。
- レベル2は、レベル1のステージ4（4つの手がかりを1つずつ練習）を終えると開きます。
- 先生用画面で「すべて開く」にすることもできます。
- 途中でやめても、次は「つづきから」始められます（文章の単位で続きから）。
- 文章・答え・選択肢の一覧は [ichiran.md](ichiran.md) にあります。

## 支援の工夫

- **4つの手がかりの色**：いつ＝🔴赤、どこで＝🟢緑、だれが＝🔵青、なにを した＝🟡黄。問い・ヒントの線・手がかりカードで、いつも同じ色を使います。
- **手がかりカード**：答えた手がかりが、挿絵の下のカードにたまっていきます。最後に「じけん かいけつ！」で4つをまとめて読み上げます。
- **ヒントは3段階**
  1. ことば：「いつ」は じかんの ことば。「あさ」「きのう」みたいな ことばを さがそう。
  2. 色の線：文章の中の、答えのところに色の線を引きます。
  3. 答えを光らせる：答えのところが光り、読み上げます。レベル1は正しい選択肢が、レベル2は次に押す字のボタンが光ります。
  - 同じ問いで2回まちがえるとヒントボタンが光り、3回まちがえると一番くわしいヒントが自動で出ます。
- **まちがえたとき**：まちがえた選択肢は消えます。まちがい方に合わせて声をかけます。
  - 手がかりの取りちがえ（「いつ」に場所を答えた）：「それは『どこで』の ことばだよ。『いつ』は じかんや ひを あらわす ことばだよ」
  - 文の中の別のことば（2文・3文で、ほかの時間や場所を選んだ）：「その ことばも 文の なかに あるね。でも、もんだいを もう いちど よんで みよう」
  - レベル2で途中まで合っているとき：合っているところまで残し、「ここまでは あってるよ！」
  - 音はブザーではなく、小さなやさしい音です。
- **ひらがな・カタカナ**：50音表はいつも「ひらがな」から始まります。カタカナの答えをひらがなで入れたときも正解にして、「『パンダ』は カタカナで かくよ」と伝えます。
- **50音表**：「゛」「゜」「小さく」は、前の字に付けます（は → ぱ）。「1字けす」「ぜんぶ けす」もあります。
- **読み上げ**：文章は1文ずつ読み、読んでいる文を黄色くします。ワンダせんせいをタップするか「🔊」で、何度でも聞き直せます。
- **ごほうび**：ヒントを使っても、同じようにシールがもらえます。時間制限はありません。
- **画面**：問題の画面は背景をすっきりさせ、にぎやかな絵はホームとごほうびの画面だけにしています。ボタンは大きく、押すと沈む立体ボタンです。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（これ1つで動きます。React と Babel を読み込んでいます） |
| `img/` | 挿絵（`1-01.webp` 〜 `2-50.webp`）と、ワンダせんせいの絵（`wanda*.webp`） |

| `gas/start.html` | 入口ページ |
| `ichiran.md` | 文章と答えの一覧表 |
| `tools/mondai.js` | 文章と答えのデータ（もと） |
| `tools/build.js` | データを確かめて、選択肢を作り、`index.html` と `ichiran.md` に書き出します |

文章を直すときは、`tools/mondai.js` を直してから、次のコマンドを動かします。

```
node nazotoki/tools/build.js --app
```

## 公開の手順

### 1. GitHub Pages でアプリ本体を公開する

音読アプリと同じリポジトリの `nazotoki` フォルダに入っています。

- 音読アプリの手順で GitHub Pages を公開していれば、変更を `main` に取り込む（Pull Request をマージする）だけで、数分後に `https://zku0395-ops.github.io/hori/nazotoki/` で開けるようになります。
- まだ公開していないときは、リポジトリの `README.md` の「GitHub Pages でアプリ本体を公開する」を先に行ってください。

### 2. Apps Script とスプレッドシート（学校のアカウントで）

ほかのアプリとは**別のスプレッドシート**を使います。

1. 学校のGoogleアカウントで、新しい Google スプレッドシートを作ります（名前の例：「なぞとき 記録」）。
2. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、`nazotoki/gas/Code.gs` の内容を貼り付けます。
4. 左の「ファイル」の「＋」→「HTML」を選び、名前を `start` にします。中身をすべて消し、`nazotoki/gas/start.html` の内容を貼り付けます。
5. 上の保存ボタン（💾）を押します。
6. 右上の「デプロイ」→「新しいデプロイ」を押します。
   - 左の歯車から種類「ウェブアプリ」を選びます。
   - 「次のユーザーとして実行」：**自分**
   - 「アクセスできるユーザー」：**全員**
7. 「デプロイ」を押します。アクセスの承認を求められたら、自分のアカウントを選んで「許可」します。
   - 「このアプリは Google で確認されていません」と出たときは、「詳細」→「（プロジェクト名）に移動」を押します。
8. 表示された「ウェブアプリ」のURL（`https://script.google.com/macros/s/…/exec`）を、Classroom などで子どもに配ります。
9. スプレッドシートを開き直すと、メニューに「ワンダせんせい」が出ます。

**貼り付けのしかた（GitHub から）**

1. GitHub で `nazotoki/gas/Code.gs` を開き、右上の「Raw」を押します。
2. ブラウザーが「翻訳しますか？」と聞いてきたら「翻訳しない」を選びます。
3. Ctrl＋A（全部選ぶ）→ Ctrl＋C（コピー）を押します。
4. Apps Script で中身を全部消してから、Ctrl＋V で貼ります。
5. `start.html` も同じようにします。貼ったあと、いちばん下が `</html>` になっているか確かめます。

**大切なこと**

- 子どもは、配ったURL（入口ページ）の「はじめる」から開いてください。こうすると、記録の送り先と合言葉がアプリに自動で設定されます。
- アプリは新しいタブで開きます。開かないときは、ボタンの下に出る「このページで ひらく」を押してください。
- 一度設定されれば、次からは GitHub Pages のURLを直接開いても記録は届きます。
- `Code.gs` や `start.html` を書き換えたときは、「デプロイ」→「デプロイを管理」→ 鉛筆のアイコン →「バージョン：新バージョン」→「デプロイ」で更新します（URLは変わりません）。

### 3. Chromebook の準備（1台ずつ、最初に1回）

1. 入口ページの「はじめる」でアプリを開きます。
2. 最初の画面で、先生が次のことを行います。
   - 子どもの名前（呼び名・ひらがな）を入れる
   - 先生用の暗証番号（4けた）を決める
   - 「🔊 声と音を確かめる」で、ワンダせんせいの声とファンファーレが聞こえるか確かめる
3. 先生用画面の「データ」タブで、送り先が「設定ずみ」になっているか確かめます。

### 4. Googleサイトに置くとき（必要なときだけ）

Googleサイトでは、入口ページを「埋め込む」で貼らずに、**「ボタン」**を使ってください。

- 埋め込むと、入口ページがGoogleサイトの枠の中に入ります。この枠の中からは、新しいタブを開くことが止められるため、「▶ はじめる」を押しても何も起きません。
- ボタンは、リンク先を新しいタブで開くので止められません。

**ボタンの置き方**

1. Googleサイトの編集画面で、右側の「挿入」→「ボタン」を押します。
2. 次のように入れて、「挿入」を押します。
   - 名前：例「▶ ワンダせんせいの なぞとき」
   - リンク：入口ページのURL（`https://script.google.com/macros/s/…/exec`）
3. 右上の「公開」を押します。

## 先生用画面

ホームの右上にある「⚙️ せんせい」を押し、暗証番号を入れると開きます。

| タブ | できること |
|---|---|
| 📊 記録 | といた文章の数・シールの数・称号。**手がかりごとの様子**（いつ・どこで・だれが・なにを した の、1回で正解した割合・まちがえた回数・ヒントを使った数）。まちがい方の回数。ステージごとの様子。**つまずいた問い**（まちがいが多い順。文章・問い・正しい答え・答えた内容）。最近の記録 |
| 🛠️ 設定 | 下の表のとおり |
| 💾 データ | スプレッドシートへの送信（状態・今すぐ送る・全部を送り直す）、CSV書き出し、バックアップと元に戻す、記録の消去 |

### 設定

| 設定 | 内容 |
|---|---|
| ワンダせんせいの声 | あり／なし |
| 読み上げの速さ | とても ゆっくり（0.6）〜 はやめ（1.0）。はじめは「少し ゆっくり（0.8）」です |
| 文章の自動読み上げ | する（はじめ）／しない（🔊ボタンを押したときだけ読みます）。自分で読む練習をするときは「しない」にします |
| ふりがな | つける／つけない |
| 文字の大きさ | ふつう／大きい／とても大きい |
| 効果音・ファンファーレ | あり／なし |
| ステージ | 順番に開く／すべて開く |
| 子どもの名前・暗証番号の変更 | ― |

## 全員の記録を見る（先生のスプレッドシート）

| シート | 内容 |
|---|---|
| いちらん | 1人1行で、名前・称号・といた文章の数・1回で正解した文章の数・シールの数・最後の学習日時・いまのステージを表示します。青の列は、手がかりごとの「1回で正解した割合」です（赤＝50%未満、黄＝80%未満）。ステージの列（1-1＝レベル1のステージ1）は「◎＝クリア」「2/5＝挑戦中」です。右側のオレンジの列は、まちがい方ごとの回数です |
| きろく | 全員の1問ごとの結果です（日時・名前・レベル・ステージ・文章番号・手がかり・問い・正しい答え・答えた内容・結果・まちがえた回数・ヒントの段階・かかった時間・つまずき） |

まちがい方の種類は次のとおりです。

- 手がかりの取りちがえ（「いつ」に場所を答える など）
- 文の中の別のことば（2文・3文で、ほかの時間や場所を選んだ）
- にていることば（「あさ」と「よる」など）
- 入力のまちがい（レベル2）
- ひらがな・カタカナのちがい（レベル2。正解として数えます）

記録について：

- 「いちらん」は記録が届くたびに作り直されます。手で書き込んだ内容は消えるので、メモは別のシートに書いてください。
- インターネットにつながっていないときの記録は端末にためておき、次につながったときに送ります。同じ記録が二重に書き込まれることはありません。
- 子どもは名前で区別します。名前は1人ずつ違うものにしてください。

## 注意事項

- **データの保存場所**：記録・進み具合・シール・設定は、そのChromebookのブラウザの中（IndexedDB と localStorage）に保存します。Chromeの閲覧データを消すと記録も消えるので、ときどき「バックアップ」で保存してください。
- **スプレッドシートへの送信**：送り先が設定されている場合は、名前と問題の結果だけを先生のスプレッドシート（Apps Script）に送ります。
- **読み上げ**：Chrome の音声合成を使います。日本語の声が入っていない端末では読み上げられません。
- **暗証番号を忘れたとき**：元にもどす機能はありません。Chromeの設定からこのサイトのデータを消すと最初からやり直せますが、記録も消えます。
- **文章に出てくる名前**：先生の希望で、ゆき・たける・とうしん・りょうま・ゆうま の名前も入れています。アプリはインターネットに公開されるので、文章に入れた名前はだれでも見られます。
- **教材の出典**：文章・問い・選択肢は、すべてこのアプリのためのオリジナルです。
- **絵と音**：挿絵とワンダせんせいの絵は、先生の Canva で、このアプリのために作った画像です（Canva のデザイン「ワンダせんせい さしえ用 空白ページ」「ワンダせんせい さしえ (2)」に保存しています）。シールは絵文字です。ファンファーレの曲は、このアプリのためのオリジナルです（プログラムで作っています）。
- **使っているもの**：React と Babel（unpkg）、BIZ UDPゴシック（Google Fonts）をインターネット経由で読み込んでいます。

## これから相談して決めること

- レベル2を開く時期（いまは、レベル1のステージ4を終えたら開きます）
- 文章の自動読み上げを、はじめから「する」にするか「しない」にするか（いまは「する」）
- 1台の Chromebook を何人かで使うとき、名前を切りかえる機能が必要か
- 発展の内容（例：「なぜ」「どのように」を聞く問い、4文以上の文章）を加えるか
- 文章や挿絵の入れかえ・追加
