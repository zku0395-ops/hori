# ペラリさんの すきの わけ テレビきょく（理由を伝える文を書く学習アプリ）

小学校の特別支援学級（1〜4年生）向けの、国語の「理由を伝える文を書く」アプリです。
町の中から自分の好きなもの（食べ物・乗り物・動物・おもちゃ・電化製品・モンスターなど）を選び、次の2つの文で紹介します。

> ① わたし（ぼく）は、〇〇が すきです。
> ② そのりゆうは、〇〇からです。

- おはなし：子どもは、テレビきょくの「ちびっこ レポーター」です。オウムのレポーター「ペラリさん」と一緒に町を歩き、好きなものを見つけて、テレビで紹介します。
- 町は13か所（やおや・くだものやさん・レストラン・ケーキやさん・カフェ・おもちゃやさん・でんきやさん・どうぶつえん・モンスターの もり・えき・くるまや・みなと・ひこうじょう）。1か所に15こ、ぜんぶで195この ものがあります。場所は、はじめから全部開いています。
- 理由は、カードを選ぶことから始めて、ステージが進むと自分で書きます。
- できた文は「テレビに うつる」画面で大きく出し、ペラリさんの「どうぞ！」の合図で、子どもが声に出して読みます。
- 形は、ぶんぶん・九九と同じ「Apps Script だけ」です。子どもは名簿の名前のボタンを押して始めます。
- ものと理由のカードのデータ・絵は、GitHub Pages（`https://zku0395-ops.github.io/hori/sukiwake/`）から読みこみます。Apps Script に貼り付けるファイルを短くするためです。

## できること

| 項目 | 内容 |
|---|---|
| ものを選ぶ | 町の地図（13か所のボタン）→ 場所の たな（15こ）→ 好きなものを押します。1回の中で、ほかの場所に行くこともできます。紹介したものには ⭐ が付きます |
| わたし・ぼく | はじめに1回だけ、「わたし」か「ぼく」を選びます。文の「〇〇は、」に入ります |
| 理由のカード | 5つの しゅるいで色分けします（👀 みため・👅 あじ・におい・✋ おと・さわった かんじ・💪 できること・💗 きもち）。先生用画面で「なし」にもできます。カードは100まい。ものごとに「合うカード」と「合わないカード」を決めています |
| 文のおわり | 「あまい**から**です」と「しずか**だから**です」の ちがいを、ステージ②で練習します。自分で書くステージでも、アプリが見分けて声をかけます |
| 書く | 画面の50音キーボード（ひらがな・カタカナ、゛゜、ちいさく、あき、けす）で書きます。先生用画面で、子どもごとに Chromebook のキーボードに切りかえられます |
| 声 | ペラリさんのセリフと、できた文を読み上げます（はじめは0.8倍の速さ）。ペラリさんか「🔊 もういちど」を押すと聞き直せます |
| はっぴょう | 文ができると、テレビの画面（オンエア）に大きく出ます。3・2・1のあと「どうぞ！」で子どもが読み、「📣 よんだよ！」を押すと はくしゅ と ハートが出ます。「🔊 おてほん」で読み上げも聞けます（先生用画面で「つかわない」にもできます） |
| ごほうび | 1つ紹介すると ハート3こ（ヒントを使っても同じ）。ステージを初めてクリアすると ハート10こ |
| しょうかいカード | 紹介したものが「しょうかいカード」（ものの絵と2つの文）になり、アルバムにたまります（もの1つに1まい。新しく作ると入れかわります）。場所ごとに 15まいの わくがあり、集める楽しみがあります |
| いんさつ | しょうかいカードを、A4よこ1まいに大きく1つ、または A4よこに4つ並べて印刷します |
| スタジオ | ハートで スタジオの かざり（かべ・ライト・つくえの うえ・ゆか・ペラリさんの もちもの、各6こ）を買い、スタジオを かざります。かざりは ホームと はっぴょうの画面に出ます |
| しょうごう | 紹介したものの数で変わります（みならい レポーター → かけだし → げんきな → にんきの → スター → ベテラン → でんせつの レポーター → すきすき マスター） |
| 先生用画面 | 暗証番号4けたで開きます。どのステージで、どんな まちがい（合わないカード・から／だから など）が多いかと、子どもが書いた文が分かります |
| 全員の記録 | 結果は先生のGoogleスプレッドシートへ届きます。進み具合・ハート・しょうかいカード・スタジオも、スプレッドシートに保存します |

## ステージ構成

| ステージ | 学ぶこと | 子どもがすること | 1回 |
|---|---|---|---|
| ⓪ 「すきです」の ぶん | ①の文の形 | 「ぼく／は、／トマト／が／すきです。」のカードを順に押して並べる | 5つ |
| ① りゆうの カード | 理由を選ぶ | 4まいのカード（合うカード3まい＋合わないカード1まい）から、すきな理由を1まい選ぶ。文のおわりはアプリが付ける | 5つ |
| ② ぶんの おわり | 「からです」と「だからです」 | 理由のカードを1まい選び、「からです。」「だからです。」のどちらかを選ぶ | 5つ |
| ③ カード 2まい | 理由をくわしくする | カードを2まい選ぶ（1まいめは「あかい → あかくて」のように つなぐ形に変わる）→ 文のおわりを選ぶ | 3つ |
| ④ じぶんで かく | 理由を自分で書く | 「そのりゆうは、」の あとに理由を書き、「からです。」「だからです。」を選ぶ | 3つ |
| ⑤ まとめ | 2つの文を全部書く | ①の文と②の文を、はじめから全部書く | 3つ |
| はってん① なぜ すきかと いうと | ちがう言い方 | 「なぜ すきかと いうと、〜からです。」で理由を書く | 3つ |
| はってん② りゆうを 2つ | 理由を2つ | 「そのりゆうは、〜からです。それに、〜からです。」で理由を2つ書く | 3つ |

- 前のステージをクリアすると、次が開きます。
- はってんは、はじめは閉じています。先生用画面の「子どもごと」で開きます。
- 途中でやめても、次は「つづきから」始められます（残りの数から）。
- ものと理由のカードは `data/sukiwake.js` にあります。

## 支援の工夫

- **自分で選ぶ**：毎回、自分の好きなものを選んでから文を作ります。「すき」という気持ちから書き始められるようにしています。
- **スモールステップ**：①の文の形 → 理由を選ぶ → 文のおわり → 理由を2つつなぐ → 理由を書く → 全部書く、の順に少しずつ自分で書く部分を増やします。書くステージでも、①の文はアプリが出しておき、理由だけを書きます（⑤だけ全部書きます）。
- **理由を考える手がかり**：カードを「みため・あじ・におい・おと・さわった かんじ・できること・きもち」で色分けし、カードの上に小さく しゅるいを書いています。ヒントでも「いろや かたちは どう？」「なにが できる？」と、しゅるいで たずねます。
- **合わない理由に気づく**：①③には、その ものに合わないカード（トマトに「そらを とぶ」など）を1まい まぜます。選ぶと、カードは消えて「『そらを とぶ』は、トマトには あわないね」と声をかけます。食べ物には「できること」から、ほかの ものには「あじ」と「できること」から、はっきり合わないカードだけを まぜます。
- **「から」と「だから」**：「あまい・はやく はしる」の あとは「からです」、「しずか・ふわふわ・きれい」の あとは「だからです」です。まちがえやすいので、ステージ②で練習します。
  - まちがえると、1回めは「『しずかからです』。こえに だして よんで みよう。ちょっと へんだね。」、2回めからは「『しずか』の あとは『だからです』に なるよ。」と声をかけます。
  - 自分で書いた ことばも、アプリが見分けます（「〜い」で終わる ことば・うごきの ことば → からです、「すき・きれい・しずか・ふわふわ」や カタカナの ことば → だからです）。見分けられない ことばは、どちらでも正解にします。
- **書く支援**：50音キーボードは、教室の50音表と同じ並び（あ が いちばん右）です。「゛」「゜」「ちいさく」は、最後の文字に付けます（もう1回押すと元にもどります）。「からです」まで書いてしまっても、アプリが読み取ります。文の最後の「。」を書きわすれたときは、アプリが付けます。
- **ヒントは3段階** です。2回まちがえるとヒントボタンが光り、3回まちがえると ヒント③が自動で出ます。

  | ステージ | ヒント① ことば | ヒント② 見本・色 | ヒント③ 答え |
  |---|---|---|---|
  | ⓪ | 次に入る ことばを たずねる | ますに うすい文字で見本 | 次のカードが光る |
  | ①③ | 「〇〇の いろや あじを おもいだしてね」 | カードを読み上げ、しゅるいの色を付ける | 合うカードが光る |
  | ②③のおわり | 「あまいからです・あまいだからです、どっちかな？」 | 「から」と「だから」の きまりを話す | 正しい方が光る |
  | ④・はってん | 「どんな ところが すき？」としゅるいで たずねる | 理由のカード（6まい）を出す。押すと その ことばが入る | 書き方の例を話す |
  | ⑤ | 2つの文の形を話す | 2つの文の見本を うすく出す | ①の文と「そのりゆうは、」を入れる |

- **まちがえたとき**：まちがえたときの音は、小さな音です。時間制限はありません。ヒントを使っても、ごほうびは同じです。
- **読む・話す**：文ができるたびに、ペラリさんが読み上げ、テレビの画面で子どもが声に出して読みます。学級の大きなテレビに映して、発表にも使えます。
- **問題の画面**：問題の画面は、背景をすっきりさせています。にぎやかな スタジオの かざりは、ホームと はっぴょうの画面だけに出します。

## ファイル構成

```
sukiwake/index.html          アプリ本体（Apps Script の HTML ファイル「index」に貼り付けます）
sukiwake/コード.gs            スプレッドシートとつなぐプログラム（Apps Script の「コード.gs」に貼り付けます）
sukiwake/data/sukiwake.js    場所・もの（195こ）・理由のカード（100まい）・おみせ・しょうごうのデータ
sukiwake/data/img.js         img/ に入れた絵の名前の一覧（ここにある絵だけを読みこみます）
sukiwake/img/                ChatGPT で作った絵（これから入れます）
sukiwake/e_chatgpt.md        ChatGPT に絵を頼むときの文（コピーして使います）
sukiwake/tools/check.js      データの点検（node sukiwake/tools/check.js。node sukiwake/tools/check.js y01 で、その ものの「合うカード」「合わないカード」を出します）
sukiwake/tools/test_gas.js   コード.gs のテスト（node sukiwake/tools/test_gas.js）
```

- `data/` と `img/` は、GitHub Pages から読みこみます。ものや理由のカードを直したときは、`data/` を直して `main` に入れるだけで、Apps Script を貼り直さなくても全員の画面に反映されます。
- 絵がまだないところは、自作の絵（ペラリさん・モンスター・のみもの・電化製品など）と絵文字が出ます。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/sukiwake/` を開きます。
   - 「おためしモード」で動けば、データと絵の公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「すきの わけ 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。
4. 画面の文字が小さいときは、先生用画面の「もじの おおきさ」で変えます。
5. しょうかいカードを印刷するときは、印刷の画面で「送信先」（プリンター）を選び、「レイアウト：横」になっているか確かめます。「PDFに保存」も選べます。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、カードやキーボードが小さくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。
- 「そらの うえの がっこう」に置くときは、URLを教えてください。こちらで `sora/apps.js` に足します。

## 先生用画面

1. 名前を選ぶ画面の右下（学習中は右上）の **🔒** を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「せってい」で変えてください。**

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの いまのステージ・紹介したものの数・ハート・問題の数・まちがえずに できた割合・多い まちがいの しゅるい・最後に学習した日。クラス全体の「まちがいの しゅるい」と「えらんだ 合わないカード」 |
| 子どもごと | ステージごとの結果、まちがいの しゅるい、えらんだ 合わないカード（「トマト：そらを とぶ」など）、しょうかいカードの文の一覧、自分で書いた文 |
| 子どもごと（ボタン） | ステージを全部開く（その子だけ）、はってんを開く、Chromebook の キーボードに する（画面のキーボードに もどす）、ハートを足す・引く |
| 書いた文 | 全員が ④ じぶんで かく・⑤ まとめ・はってん で書いた文（新しい順）。アプリが確かめるのは「からです・だからです」と⑤の文の形だけなので、理由として合っているかは、ここで読んで確かめてください |
| せってい | 読み上げの速さ、文字の大きさ、はっぴょう（つかう・つかわない）、理由のカードの いろわけ（あり・なし）、効果音、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、記録の消去（その子だけ・全員） |

- **まちがえずに できた割合** は、まちがえず、ヒントも使わずに できた問題の割合です（赤：60%未満、黄：60〜79%、緑：80%以上）。
- **まちがいの しゅるい**

  | しゅるい | 内容 |
  |---|---|
  | あわない カード | その ものに合わない理由のカード（トマトに「そらを とぶ」など）を選んだ |
  | だから→から | 「しずか」「ふわふわ」などの あとに「だからです」と書くところを、「からです」にした |
  | から→だから | 「あまい」「はしる」などの あとに「からです」と書くところを、「だからです」にした（あまいだからです） |
  | は・が | ⓪で、「わたし は」「〇〇 が」の「は」と「が」を入れかえた |
  | ことばの じゅんばん | ⓪で、ことばの順番がちがった |
  | すきです が ない | ⑤で、1つめの文に「すき」がなかった |
  | です が ない | ⑤で、文の終わりが「です。」になっていなかった |
  | から が ない | ⑤で、理由の文に「から」がなかった |

- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。
- キーボードの切りかえは、子どもが次に名前を押したときから変わります。

## 全員の記録を見る

- スプレッドシートの **「きろく」** シートに、1つの紹介（1問）ごとの結果が入ります。

  | 日時 | なまえ | ステージ | ばしょ | もの | つくった ぶん | けっか | まちがい | ヒント | まちがいの しゅるい | えらんだ カード | かいた ことば | びょう | ID |
  |---|---|---|---|---|---|---|---|---|---|---|---|---|---|

  - ステージ：0〜5（⓪〜⑤）、h1・h2（はってん①②）
  - つくった ぶん：できた2つの文（⓪は1つめの文だけ）
  - けっか：○＝まちがえず、ヒントも使わずに できた　△＝まちがえてから、またはヒントを使って できた
  - まちがい：まちがえた回数　ヒント：使ったヒントの段階（0〜3）
  - えらんだ カード：選んだカード。合わないカードには「✖」、まちがえた文のおわりなどには「（ちがう）」が付きます。ヒントのカードを使ったときは「（ヒント）」が付きます
  - かいた ことば：④⑤・はってんで子どもが書いた ことば（2つあるときは「／」で区切ります）
  - びょう：その問題にかかった時間（ものを選んでから文ができるまで）
- **「まとめ」** シートに、子どもごと・ステージごとの結果と、まちがいの しゅるい・合わないカードが入ります。先生用画面を開いたとき、またはメニュー **すきの わけ テレビきょく → まとめを更新する** で更新されます。
