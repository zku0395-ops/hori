# ChatGPT に絵を頼むときの文（ペラリさんの すきの わけ テレビきょく）

## つかいかた

1. ChatGPT を開き、下の「はじめに 1回だけ はる文」を貼って送ります。
2. つぎに、作りたい絵の文（①〜④）を1つずつ貼って送ります。
3. できた絵を保存します（右クリック →「名前を付けて画像を保存」）。
4. 保存した絵を、このチャット（Claude）に貼ってください。
   - こちらで、切り分け・背景をすかす・名前を付ける・軽くする をして、アプリに入れます。
   - ファイル名を付けなくても大丈夫です。「ペラリさんの にこにこ」「やおやの 15こ」のように、どの絵かを書いてください。
5. 気に入らない絵は、「もっと やさしい顔に」「線を太く」のように ChatGPT に頼んで作り直します。

- 絵がそろうまでは、アプリの中の仮の絵（自作の絵と絵文字）で動きます。全部そろえなくても使えます。
- おすすめの順番：① ペラリさん → ② タイトル → ③ スタジオ → ④ もの（場所ごと。子どもがよく選ぶ場所から）。
- もの の絵は、1つの場所の15こを **1まいの絵にまとめて**（よこ5こ × たて3だん）頼みます。195こを1つずつ頼まなくてよいようにするためです。こちらで1こずつに切り分けます。

## はじめに 1回だけ はる文

```
これから、小学校の特別支援学級の子ども（1〜4年生）が使う、国語の学習アプリの絵を、何まいか続けて作ってもらいます。
次のルールを、すべての絵で守ってください。
・絵本のような、やさしい色の、子ども向けのイラスト。太めの、やわらかい線。
・こわくない、かわいい顔。モンスターも、にこにこした ゆかいな顔。
・既存のアニメ・ゲーム・キャラクター・会社の商品に似せない、オリジナルのデザイン。乗り物や電気製品にも、会社のロゴやマークを入れない。
・絵の中に、文字・数字・ロゴを入れない。
・キャラクターや ものの絵は、背景を真っ白（または透明）にして、切れないように入れる。
・すべての絵で、絵柄（線の太さ・色合い）をそろえる。
わかったら「OK」とだけ答えてください。
```
