# フデリュウの かんじ ワークシート（漢字の冒険アプリの ワークシート）

小学校の特別支援学級向けの、漢字の **ワークシート** です。
アプリ「フデリュウと かんじの ぼうけん」（[kanjiquest/](../kanjiquest/README.md)）と同じステージ・同じ例文で作っています。

| 学年 | もとにした データ | PDF の 場所 |
|---|---|---|
| 1年生（80字・16ステージ・ボス4） | 「ことばの しま」（kanji1） | `kanjiquestprint/pdf/` |
| 2年生（160字・32ステージ・ボス8） | 「にじいろの しま」（kanji2） | `kanjiquestprint/pdf/2nen/` |
| 3年生（200字・40ステージ・ボス10） | 「ほしぞらの しま」（kanji3） | `kanjiquestprint/pdf/3nen/` |

- ワークシートを作るページ：`https://zku0395-ops.github.io/hori/kanjiquestprint/`（2年生は `…/kanjiquestprint/?g=2`、3年生は `…/kanjiquestprint/?g=3`）
- できあがった PDF：ステージごと・ボスごとに1つのファイルです。全部をまとめた「ぜんぶ」もあります。
- 用紙は **A4よこ**、文は **たて書き**、カラーです。

## できること

| 項目 | 内容 |
|---|---|
| ステージの ワークシート | 1ステージ（5字）で2まいです。1まいめ「えらぶ」10問、2まいめ「かく」10問です |
| 1まいめ　えらぶ | 「よみを えらぼう」5問 ＋ 「かんじを えらぼう」5問。どれも3つから えらんで ○を つけます |
| 2まいめ　かく | 「よみを かこう」5問 ＋ 「かんじを かこう」5問 |
| ボスの ワークシート | 4ステージごとに1まい（まとめ）。その20字から10問です（よみを えらぶ2・かんじを えらぶ2・よみを かく3・かんじを かく3） |
| こたえ | ステージごと・ボスごとに1まいです。答えは赤です。名前の欄はなく、「せんせい よう」と出ます |
| 欄 | どのシートにも「　ねん」「　がつ　にち」「なまえ」の欄があります |
| まもの | 右に、そのステージの まものの絵と名前があります（アプリと同じ絵）。ボスのシートは ボスの まものです |
| HPゲージ | まものの下に10マスあります。1問できたら1マス ぬります。ぜんぶ ぬれたら「なかまに なった！」の まるに しるしを つけます |
| ヒントの まど | 左に、そのステージの5字と読みがあります（ボスは20字）。点線で うしろに折ると、かくせます |

## ステージ構成

アプリのステージ・エリアと同じです。

| PDF | ページ | 内容 |
|---|---|---|
| ステージ01〜（1年生16・2年生32・3年生40） | 3 | 1まいめ えらぶ、2まいめ かく、こたえ |
| ボス1〜（1年生4・2年生8・3年生10） | 2 | まとめ、こたえ |
| ぜんぶ | 1年生56・2年生112・3年生140 | ステージ1〜4 → ボス1 → ステージ5〜8 → ボス2 → … の順 |

### 2年生「にじいろの しま」・3年生「ほしぞらの しま」

- エリアとステージは、アプリと同じです。くわしくは [kanjiquest/README.md](../kanjiquest/README.md) の「ステージ構成」を見てください。
- ボスの番号は、エリアの順です（2年生はボス1〜8、3年生はボス1〜10）。
- 「今日」「明日」のような とくべつな読みの例文は、アプリと同じく、よみの問題だけで出します。

## 支援の工夫

- アプリの「わざ」と同じ順（よみを えらぶ → かんじを えらぶ → よみを かく → かんじを かく）です。えらぶ問題を先にして、かく問題を あとにしています。
- 文は分かち書きで、ほかの漢字には ふりがなを付けています（アプリと同じ例文）。
- えらぶ問題には、まちがいやすい答えを入れています（同じ字の ほかの読み、形の にている字など。アプリと同じ作り方です）。
- 「よみを かこう」の わくは、1字ずつ点線で区切っています。読みの字数が分かります。
- 「かんじを かこう」は、十字の点線が入った大きなマスです。
- ヒントの まどは、はじめは見ながら、なれたら折って かくして とりくめます。

  | | 文字の大きさ | 読みを書くわく（1字ぶん） | 漢字を書くマス |
  |---|---|---|---|
  | 1年生 | 約6.6mm | 約9mm | 約17mm角 |
  | 2・3年生 | 約6.2mm | 約8mm | 約15mm角 |

- 問題は、決まった しかたで えらんでいます。何回 作り直しても、同じ問題になります。

## ファイル構成

```
kanjiquestprint/index.html          ワークシートを作るページ（?g=2 で2年生、?g=3 で3年生）
kanjiquestprint/pdf/                1年生の PDF（ステージ16ファイル ＋ ボス4ファイル ＋ ぜんぶ）
kanjiquestprint/pdf/2nen/           2年生の PDF（ステージ32ファイル ＋ ボス8ファイル ＋ ぜんぶ）
kanjiquestprint/pdf/3nen/           3年生の PDF（ステージ40ファイル ＋ ボス10ファイル ＋ ぜんぶ）
kanjiquestprint/tools/make-pdf.js   PDF を作るプログラム
```

- 漢字と例文は `kanji1/data/mondai.js`（2年生は kanji2、3年生は kanji3）を使います。
- エリア・まものの名前と絵は `kanjiquest/data/` と `kanjiquest/img/` を使います。
- アプリの例文を直したら、PDF も作り直してください。PDF は、パソコンの Edge（または Chrome）で作ります。
  - `node kanjiquestprint/tools/make-pdf.js` … 1・2・3年生の全部
  - `node kanjiquestprint/tools/make-pdf.js 1` … 1年生の全部（`2` なら2年生、`3` なら3年生）
  - `node kanjiquestprint/tools/make-pdf.js 1 s3` … 1年生のステージ3だけ
  - 2年生は `pdf/2nen/`、3年生は `pdf/3nen/` に できます。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入ると、`https://zku0395-ops.github.io/hori/kanjiquestprint/` で開けます。
2. ページの上の PDF のボタンから、PDF を保存できます。

### 2. Apps Script とスプレッドシート

- このワークシートは記録をとらないので、Apps Script とスプレッドシートは使いません。

### 3. 印刷のしかた

1. 印刷したいステージの PDF を開きます。
2. 印刷の画面で、次のようにします。
   - 用紙サイズ：**A4**
   - 向き：**横**
   - 倍率：**100%**（「実際のサイズ」）
3. カラーで作っています。白黒で印刷しても とりくめますが、まものの絵と赤い線は うすくなります。

- ワークシートを作るページで印刷するときは、学年とステージを選んで「🖨️ 印刷する」を押します。余白は「なし」にして、「背景の グラフィック」に チェックを入れてください。

### 4. Googleサイトに置くとき

- 「ボタン」を置き、リンクに PDF か、ワークシートを作るページのURLを入れてください。

- このワークシートは記録をとりません。アプリの記録は、アプリのスプレッドシートで見られます。

## 注意事項

- **例文**：アプリ（kanji1〜3）と同じ、オリジナルの文です。
- **絵**：フデリュウと まものの絵は、アプリのために ChatGPT で作った絵です。
- 1年生の「よみを かこう」で、読みが長い問題（4字以上）は、わくが となりの問題の はばに 1mmほど かかることがあります。わくの外には出ません。
