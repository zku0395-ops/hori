# ピコロボの タイピング パトロール（タイピング練習アプリ）

小学校の特別支援学級向けの、キーボード（ローマ字入力）のタイピング練習アプリです。
ロボットの「ピコ」と一緒に、いろいろな場所をパトロールします。

- 文字や ことばを書いた「いきもの」が、上からゆっくり落ちてきます。
- 同じキーを打つと、ピコからハートが飛びます。いきものはハートに包まれて、ピコの「なかま」になります。
- 下まで落ちても失敗にはしません。また上から出てきます。時間制限もありません。
- なかまにした いきものは「いきもの ずかん」に集まります。1つの場所に5しゅるいいて、そのうち1しゅるいは「きんいろの めずらしい いきもの」です。
- コインで「おみせ」の品物（6しゅるい × 10こ ＝ 60こ）を買い、「ピコの へや」でピコを着せかえます。
- 形は、タイピングアプリ（キャプテン・キーボ）と同じ「Apps Script だけ」です。子どもは名簿の名前のボタンを押して始めます。
- 問題のデータ・ローマ字のしくみ・絵は、GitHub Pages（`https://zku0395-ops.github.io/hori/pico/`）から読みこみます。Apps Script に貼り付けるファイルを短くするためです。
- 参考にしたのは、ユーザーからもらったタイピング練習アプリ「タイピングロボ」（いきものを打ってたおす形）です。このアプリでは、たおすかわりに「なかまにする」形にしました。

## できること

| 項目 | 内容 |
|---|---|
| だんかい（場所） | 本編15（はらっぱ〜うちゅう）と、はってん2（ほしの おしろ・ロボットの まち） |
| 入力 | ローマ字入力。画面には教科書と同じ書き方（し＝si、ち＝ti、つ＝tu、ふ＝hu、じ＝zi、しゃ＝sya）を出します。shi・chi・tsu・fu・ji・sha・cha・ja と打っても正解です |
| 「ん」「っ」 | 「ん」は画面に nn と出します。次の音が あいうえお・や行・な行 でなければ、n 1つでも正解です。「っ」は次の音のはじめのキーを2回（xtu・ltu でも正解） |
| 文 | ことばの あいだの すきま（分かち書き）は打たなくてよいです。「、」はコンマ、「。」はピリオドのキーです |
| 1回の長さ | キー・1もじの だんかいは30ぴき、ことば・ぶんの だんかいは10ぴき（先生用画面で 10・20・30ぴき／5・10・15ひき にできます）。途中でやめても「つづきから」始められます |
| 落ちる速さ | 5段階（とても ゆっくり・ゆっくり・ふつう・はやい・とても はやい）。はじめは「とても ゆっくり」です。子どもが 🐢🐇 のボタンで選びます。遊んでいるあいだに、自動で速くなることはありません |
| いっしょに出る数 | はじめは1ぴきです。先生用画面で2〜3びきにできます（ぶんの だんかいは いつも1ぴき） |
| ねらう いきもの | 打ちかけの いきもの → いちばん下の いきもの の順です。ねらっている いきものは、黄色いわくで光ります |
| 画面のキーボード | 学校の Chromebook と同じ並び（JIS）です。次に押すキーが光ります。キーは指ごとに色分けします（こゆび＝ピンク、くすりゆび＝きいろ、なかゆび＝みどり、ひとさしゆび＝あお） |
| 手の絵 | 次に押す指を、手の絵で光らせます |
| 声 | ピコのセリフと、ねらっている いきものの文字を読み上げます（はじめは0.8倍の速さ）。ふきだしか、ピコを押すと、もう一度聞けます |
| ごほうび | キー・1もじ＝1コイン、ことば＝2コイン、ぶん＝5コイン。きんいろの いきものは さらに5コイン。ヒントを使っても同じです。場所を初めてクリアすると、ボーナスで5コイン |
| きょうの プレゼント | その日はじめて開いたとき、プレゼントの箱が出ます（コイン3〜10まい、またはおみせの品物）。「あそんだ日」も数えます。休みの日があっても0にはもどしません |
| レベルアップ | なかまにした数（同じ いきものも数えます）でレベルが上がり、称号が変わります。みならい たいいん（0）→ パトロール たいいん（30）→ なかよし たいいん（80）→ がんばり たいいん（150）→ ベテラン たいいん（250）→ ふくたいちょう（400）→ パトロール たいちょう（600）→ スーパー たいちょう（850）→ ゴールド たいちょう（1200）→ でんせつの たいちょう（1600） |
| おみせ | 6しゅるい × 10こ。ぼうし・からだの いろ・アクセサリ・はいけい・かざり・えんしゅつ。値段は ふつう 4こ（5コイン）・ごうか 3こ（15コイン）・ちょうごうか 2こ（30コイン）・でんせつ 1こ（60コイン）。1つのたなを全部そろえると称号（例：「ぼうし はかせ」）がもらえます |
| ピコの へや | 買ったもの（ぼうし・からだの いろ・アクセサリ・はいけい・えんしゅつ）を付けかえます。かざりは3つまで置けます。「おとも」は、なかまにした いきものを1ぴき選んで、ピコのとなりに連れて歩けます（買わなくても選べます） |
| いきもの ずかん | 場所ごとに5しゅるい、ぜんぶで85しゅるい。会ったことのない いきものは、かげだけ見えます。なかまにした回数も出ます |
| 先生用画面 | 暗証番号4けたで開きます。記録の確認（まちがえやすいキー・音、速さ、正しく打てた割合）、設定、記録の送信、CSV書き出し、バックアップ、記録の消去ができます |
| 全員の記録 | 結果は先生のGoogleスプレッドシートへ届きます。進み具合・コイン・集めたもの・ずかんも、スプレッドシートに保存します |

## 支援の工夫

- **ヒントは3段階**です。同じ音で2回まちがえるとヒントボタンが光り、3回まちがえると一番くわしいヒントが自動で出ます。

  | | 内容 |
  |---|---|
  | まちがえたとき | 「おしいね」と声をかけ、押したキー（赤い ✕）と正しいキー（光る）を見せます。音は小さな音です。**ねらっている いきものは、その場で止まって待ってくれます**（正しいキーを押すと、また動きます） |
  | ヒント1（ことば） | 例：「『か』は、はじめに K、つぎに あいうえおの A だよ」「ちいさい『っ』は、つぎの もじの はじめの キーを 2かい おすよ」。ローマ字を消しているときは、ローマ字を出します |
  | ヒント2（指） | 手の絵で指を光らせ、「みぎての ひとさしゆびで U を おそう」と声で知らせます |
  | ヒント3（つづり） | 「『け』は K、E。つぎは K だよ」と、つづりを1文字ずつ読みます |

- 下まで落ちても失敗にしません。また上から出てきます。時間制限もありません。
- 始める前に「スタート」の画面が出ます。ピコの説明を聞いてから、ボタンか Enter キーで始めます。
- 速さは遊びながらでも 🐢🐇 で変えられます。先生は「いちばん速くて ここまで」を決められます。
- 「⏸ ひとやすみ」で止められます。画面の外を押してキーボードがきかなくなったときは、自動で止まり「がめんを タッチしてね」と出ます。
- 日本語入力（かな）のままのときは、「『英数』キーを おしてね」と知らせます。
- 問題の画面（パトロール）の背景は、うすくして すっきりさせています。にぎやかな絵は、マップ・おみせ・ピコの へやだけで使います。
- 上達してきたら、先生用画面で「キーを光らせない」「ゆびの いろわけを ださない」「ローマ字を ださない」にすると、キーボードを見ないで打つ練習になります（まちがえてヒントが出たときは見えます）。

## ファイル構成

```
pico/index.html          アプリ本体（Apps Script の HTML ファイル「index」に貼り付けます）
pico/コード.gs            スプレッドシートとつなぐプログラム（Apps Script の「コード.gs」に貼り付けます）
pico/data/romaji.js      ローマ字のしくみ（タイピングアプリと同じ。どの打ち方でも正解にする）
pico/data/mondai.js      だんかい・いきもの・ことば・文・おみせの品物・レベルのデータ
pico/img/                ピコ・いきもの・場所の背景の絵（Canva で作成）
pico/tools/check.js      問題データの点検（node pico/tools/check.js）
pico/tools/test_gas.js   コード.gs のテスト（node pico/tools/test_gas.js）
```

- `data/` と `img/` は、GitHub Pages から読みこみます。ことばや いきものの名前を直したときは、`data/mondai.js` を直して `main` に入れるだけで、Apps Script を貼り直さなくても全員の画面に反映されます。
- 絵は、`img/` に置いて、`data/mondai.js` の いちばん下の `IMAGES` に ファイル名を足すと使われます。絵がないあいだは、絵文字と自作の絵（ピコ）で動きます。
  - ピコ：`pico.webp`（ふつう）・`pico_happy.webp`（よろこぶ）・`pico_think.webp`（かんがえる）
  - いきもの：`c_<だんかい>_<ばんごう>.webp`（例：はらっぱの うさぎ＝`c_1_1.webp`、はってんAの きんいろ＝`c_A_5.webp`）
  - 場所の背景：`bg_<だんかい>.webp`（例：`bg_1.webp`、`bg_A.webp`）

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/pico/` を開きます。
   - 「おためしモード」で動けば、問題のデータと絵の公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「ピコ タイピング 記録」）。ほかのアプリ（キャプテン・キーボのタイピングもふくむ）とは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `pico/index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。
4. **入力モードを「英数」にしておきます。** 「にほんごの モードに なって いるよ」と出たら、キーボードの「英数」キーを押します。
5. 画面の外（アドレスバーなど）を押すと、キーボードがきかなくなります。そのときは、アプリの画面を1回タッチします。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、いきものが落ちる場所とキーボードの絵が小さくなります。また、キーを打つ前に毎回画面をタッチする必要が出ます。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

1. 名前を選ぶ画面の右下（マップなどでは右上）の **🔒** を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「せってい」で変えてください。**

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの クリアした だんかいの数・レベル・なかまにした数（ずかんの しゅるい）・コイン・うった数・正しく打てた割合・はやさ・最後に学習した日・まちがえやすいキー（上位3つ）・まちがえやすい音（上位3つ）。クラス全体の まちがえやすいキー（キーボードの絵で、まちがいが多いキーほど赤い）と、まちがえやすい音の一覧 |
| 子どもごと | だんかいごとの結果（数・まちがえずにできた割合・正しく打てた割合・はやさ）、はやさの のび（日ごと）、まちがえやすいキー（キーボードの絵と、どの指のキーか）、まちがえやすい音、あそんだ日 |
| 子どもごと（ボタン） | 全部開く（その子だけ、すべての だんかいを開く）、はってんを開く、コインを足す・引く、この子の記録を消す |
| せってい | 読み上げの速さ、文字の大きさ、1回の数（キー・1もじ／ことば・ぶん）、いちばん速くて ここまで、いっしょに出る いきもの の数、キーを光らせるか、指の色分け、ローマ字を出すか、効果音、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、全員の記録を消す |

- **はやさ** は、1分間に押したキーの数です。考えて止まっている時間は、1回5秒までしか数えません。
- **正しく打てた割合** は、押したキーのうち、まちがえなかったキーの割合です。
- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。

## 全員の記録を見る

- スプレッドシートの **「きろく」** シートに、いきもの1ぴきごとの結果が入ります。

  | 日時 | なまえ | だんかい | はやさ | もんだい | けっか | まちがい | ヒント | まちがえた キー | まちがえた おと | うった キー | びょう | ID |
  |---|---|---|---|---|---|---|---|---|---|---|---|---|

  - だんかい：1〜15、はってんA・はってんB
  - はやさ：その いきものを打ったときの、落ちる速さ（とても ゆっくり〜とても はやい）
  - けっか：○＝まちがえず、ヒントも使わずに打てた　△＝まちがえてから、またはヒントを使って打てた
  - まちがい：まちがえて押したキーの数　ヒント：使ったヒントの段階（0〜3）
  - まちがえた キー：「k>j」は「K を押すところで J を押した」という意味です
  - まちがえた おと：まちがえたときに打っていた音（例：「か」「っ」「しゃ」）
  - うった キー：その いきものを打ったキーの数　びょう：打つのにかかった時間
- **「まとめ」** シートに、子どもごと・だんかいごとの結果と、まちがえやすいキー・音が入ります。先生用画面を開いたとき、またはメニュー **ピコ → まとめを更新する** で更新されます。
- **「名簿」** シートのB列に、進み具合・コイン・集めたもの・ずかん・ピコの きせかえ が入ります。ちがう Chromebook を使っても「つづきから」始められます。
- 記録は5ひきごとと、やめたとき・終わったときに送ります。ネットが切れていたときの記録は、その Chromebook にためておき、つながったときに送り直します。同じ記録は二重に書きません。

## 注意事項

- **個人情報**：名簿には、呼び名かひらがなの名前だけを入れてください。
- **絵**：ピコ・いきもの・場所の背景は、先生の Canva で、このアプリのために作る画像です（絵がそろうまでは、絵文字と自作の絵で動きます）。品物の絵は絵文字です。手とキーボードの絵は、このアプリのための自作の絵（SVG）です。
- **ことば・文**：タイピングアプリ（キャプテン・キーボ）と同じ、オリジナルのものです。いきものの名前も、このアプリのためのオリジナルです。
- **効果音**：このアプリのためのオリジナルです（プログラムで作っています）。
- 参考にしたタイピング練習アプリ（「いきもの」を打ってたおす形）の考え方をもとにしていますが、キャラクター・絵・ことば・プログラムは、すべてこのアプリのために作りました。
- 問題のデータと絵は GitHub Pages から読みこむので、ネットにつながっている必要があります。
- 「データを よみこめませんでした」と出るときは、`https://zku0395-ops.github.io/hori/pico/` が開けるか確かめてください。
- 「止まった」「開かない」ときは、まず `index.html` の貼り付けが最後（`</html>`）まで入っているかを確かめてください。
