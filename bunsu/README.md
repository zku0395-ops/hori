# モカせんせいの ケーキやさん（分数の学習アプリ）

小学校の特別支援学級向けの、分数の大きさの学習アプリです。
くまのパティシエ「モカせんせい」と一緒に、「円を○等分したうちの△つ分が △/○（○分の△）」であることを、スモールステップで学びます。

- ケーキやさんが舞台です。問題の円は、ケーキを上から見た形です。
- 正解すると「せいかい！」の文字とファンファーレが出て、コインが1枚もらえます。
- 5問（1かい）を終えるごとに、ボーナスのコインが3枚もらえます。
- コインはショップで使えます。乗り物・動物・食べ物・果物・野菜・デザートの6分類に20個ずつ、全部で120個のグッズを、1〜10コインで買えます。
- 買ったグッズはコレクションシートで見られます。1つの分類の20個がそろうとメダルがもらえます。

## できること

| 項目 | 内容 |
|---|---|
| 学習内容 | 等分、分けた数を数える、単位分数（1/○）を読む・つくる、△/○を読む・つくる、分母と分子、全部ぬると1、大きさくらべ（発展） |
| 問題 | ステージ0〜7が各50問（全400問）、とくべつステージ「おおきさくらべ」が50問。やさしい順に並んだ、いつも同じ問題です |
| 進め方 | 5問で「1かい」（5〜10分）。1ステージは10かいです。途中でやめても、次は続きから始められます |
| ステージが開く条件 | 前のステージの50問を全部終えると、次のステージが開きます |
| 分数の書き方 | 教科書と同じ縦の分数（横線の上に分子、下に分母）。読み方「5ぶんの2」も表示し、読み上げます |
| 文字 | ひらがなと分かち書きが中心です。漢字は「分数」「分母」「分子」だけで、すべてにふりがなを付けています |
| 声 | モカせんせいのセリフを読み上げます（モカせんせいをタップするか「🔊 もういちど」で聞き直せます） |
| 操作 | Chromebook のタッチ操作向けです。ピースやケーキをタップして答えます。ドラッグはありません |
| 先生用画面 | 暗証番号4けたで開きます。記録の確認、設定、CSV書き出し、バックアップができます |
| 全員の記録 | 1問とくたびに、結果が先生のGoogleスプレッドシートへ自動で届きます（音読アプリ・角のアプリとは別のスプレッドシートを使います） |

## ステージ構成

各ステージの50問は、10問ごとに少しずつむずかしくなります。

| ステージ | 内容 | 50問の流れ |
|---|---|---|
| 0 おなじ おおきさに わけよう | 等分 | 1〜10「ひとしく分けてある？」はい／いいえ　11〜20 2つから選ぶ　21〜30 3つから選ぶ　31〜40 少しだけ大きさがちがうものを見分ける　41〜50 大きさがちがうピースを見つける |
| 1 いくつに わけた？ | 分けた数を数える（分母の素地） | 分母 2〜4 → 3〜6 → 5・6・8 → 6〜12 → まぜて出す。後半は色の付いたピースもまぜます |
| 2 1/○ を よもう | 単位分数を読む | 1〜10 1/2（はんぶん）　11〜20 1/3・1/4　21〜30 1/5・1/6　31〜40 1/8・1/10・1/12　41〜50 まぜて出す。「どのケーキかな？」と絵を選ぶ問題もまぜます |
| 3 1/○ を つくろう | 1つに色をぬる | 分母はステージ2と同じ順。「どのケーキを使う？」と分け方を選んでからぬる問題もまぜます |
| 4 △/○ を よもう | 「○つに分けた△つ分」を分数で表す（資料3〜6枚目） | 分母 2〜4 → 5・6 → 8 → 10・12 → まぜて出す。1〜40問は3つの段階で答えます |
| 5 △/○ を つくろう | 色をぬって分数をつくる（資料8〜12枚目） | 分母はステージ4と同じ順。資料の 3/5、4/6、6/8、7/10、7/12 も入っています |
| 6 分母と 分子 | 名前としくみ | 1〜10 名前（下の数は分母、上の数は分子）　11〜20「分母5・分子2の分数は？」　21〜30 円を見て分母だけ・分子だけ答える　31〜40「分けた数」「色の数」は分母？分子？　41〜50 全部ぬると1（4/4＝1 など） |
| 7 まとめ チャレンジ | 読む・つくる・絵を選ぶをまぜて出す | 分母 2〜12。3つの段階の手がかりはありません |
| とくべつ おおきさくらべ（先生が開く） | 発展（資料14〜18枚目） | 1〜10 分母が同じ分数をくらべる　11〜20 分子が1の分数をくらべる　21〜30 同じ大きさ（1/2と2/4など）　31〜40「大きい？同じ？」の3つから選ぶ　41〜50 同じ大きさの分数を全部見つける |

- ステージ0から順に、前のステージの50問を終えると次が開きます。
- 50問を終えたステージは、何度でもやり直せます（2周目もコインがもらえます）。
- とくべつステージは、先生用画面の設定で開きます。
- 先生用画面の設定で、全部のステージを最初から開くこともできます。

## 支援の工夫

- **3つの段階で答える**（ステージ2・4）
  - 資料の「○つに分けた △つ分」の型を、①「いくつに わけた？」②「いろは いくつ？」③「分数で あらわすと？」の3つに分けて答えます。
  - 画面には「[5]つに わけた [2]つぶん」の文ができていき、最後に分数を選びます。
  - 各ステージの最後の10問とまとめチャレンジでは、手がかりを外して分数だけを選びます（設定で「いつも出す」「出さない」にもできます）。
- **まちがいやすい答えを選択肢に入れる**
  - 正解が 2/5 のとき、選択肢には次のようなものが入ります。
    - 分母と分子の入れちがい（5/2）
    - 色のない部分の数を答える（3/5）
    - 色ありと色なしの数をくらべる（2/3）
  - まちがえた選択肢は消えて、もう一度選べます。まちがい方に合わせた声かけをします（例：「うえと したが ぎゃくだよ」）。
- **数えやすくする**
  - ピースをタップすると、1、2、3…と番号が付きます。
  - 色をぬる問題では、ぬったピースに番号が付き、「ぬった かず」が表示されます。
- **ヒントは3段階**
  - 言葉 → 一緒に数えるアニメーション（等分の問題では、ピースを重ねてくらべるアニメーション）→ 答えを光らせる。
  - 同じところで2回まちがえるとヒントボタンが光り、3回まちがえると一番くわしいヒントが自動で出ます。
- **分母と分子の覚え方**：「分母の『母』はおかあさん。下でささえているよ。分子の『子』はこども。上にのっているよ。」という絵のヒントを出します。
- **ごほうび**：ヒントを使っても、正解すればコインは同じようにもらえます。時間制限はありません。
- **やさしい音**：まちがえたときの音は、ブザーではなく小さな音にしています。

## 公開の手順

### 1. GitHub Pages でアプリ本体を公開する

音読アプリと同じリポジトリの `bunsu` フォルダに入っています。

- 音読アプリの手順で GitHub Pages を公開していれば、変更を `main` に取り込む（Pull Request をマージする）だけで、数分後に `https://zku0395-ops.github.io/hori/bunsu/` で開けるようになります。
- まだ公開していないときは、リポジトリの `README.md` の「GitHub Pages でアプリ本体を公開する」を先に行ってください。

### 2. Google Apps Script とスプレッドシートの準備（学校のアカウントで）

音読アプリ・角の学習アプリとは**別のスプレッドシート**を使います。

1. 学校のGoogleアカウントで、新しい Google スプレッドシートを作ります（名前の例：「分数の学習 記録」）。
2. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、`bunsu/gas/Code.gs` の内容を貼り付けます。
4. 左の「ファイル」の「＋」→「HTML」を選び、名前を `start` にします。中身をすべて消し、`bunsu/gas/start.html` の内容を貼り付けます。
5. 上の保存ボタン（💾）を押します。
6. 右上の「デプロイ」→「新しいデプロイ」を押します。
   - 左の歯車から種類「ウェブアプリ」を選びます。
   - 「次のユーザーとして実行」：**自分**
   - 「アクセスできるユーザー」：**全員**
7. 「デプロイ」を押します。アクセスの承認を求められたら、自分のアカウントを選んで「許可」します。
   - 「このアプリは Google で確認されていません」と出たときは、「詳細」→「（プロジェクト名）に移動」を押します。
8. 表示された「ウェブアプリ」のURL（`https://script.google.com/macros/s/…/exec`）を、Classroom などで子どもに配ります。
9. スプレッドシートを開き直すと、メニューに「モカせんせい」が出ます。

**大切なこと**

- 子どもは、配ったURL（入口ページ）の「はじめる」から開いてください。こうすると、記録の送り先と合言葉がアプリに自動で設定されます。
- アプリは新しいタブで開きます。開かないときは、ボタンの下に出る「このページで ひらく」を押してください。
- 一度設定されれば、次からは GitHub Pages のURLを直接開いても記録は届きます。
- `Code.gs` や `start.html` を書き換えたときは、「デプロイ」→「デプロイを管理」→ 鉛筆のアイコン →「バージョン：新バージョン」→「デプロイ」で更新します（URLは変わりません）。

### 3. Chromebook の準備（1台ずつ、最初に1回）

1. 入口ページの「はじめる」でアプリを開きます。
2. 「はじめての設定」画面で、先生が次のことを行います。
   - 児童の名前を入れる
   - 先生用の暗証番号（4けた）を決める
   - 「声と音を確認する」で、モカせんせいの声とファンファーレが聞こえるか確かめる
3. 先生用画面の「データ」タブで、「先生のスプレッドシートへの送信」の送り先が「✅ 設定ずみ」になっているか確かめます。

### 4. Googleサイトに置くとき（必要なときだけ）

Googleサイトでは、入口ページを「埋め込む」で貼らずに、**「ボタン」**を使ってください。

- 埋め込むと、入口ページがGoogleサイトの枠の中に入ります。この枠の中からは、新しいタブを開くこともページを切りかえることも止められるため、「▶ はじめる」を押しても何も起きません。
- ボタンは、リンク先を新しいタブで開くので止められません。

**ボタンの置き方**

1. Googleサイトの編集画面で、右側の「挿入」→「ボタン」を押します。
   - すでに埋め込んだ枠があるときは、枠を押して選び、ゴミ箱のアイコンで消します。
2. 次のように入れて、「挿入」を押します。
   - 名前：例「▶ モカせんせいの ケーキやさん」
   - リンク：入口ページのURL（`https://script.google.com/macros/s/…/exec`）
3. 右上の「公開」を押します。
4. 公開したサイトでボタンを押すと、入口ページが新しいタブで開きます。そこで「▶ はじめる」を押すと、アプリが開きます。

**1回でアプリを開きたいとき**

ボタンのリンクを次のURLにすると、ボタンを1回押すだけでアプリが開きます。記録の送り先と合言葉も自動で設定されます。

1. 入口ページのURLを、ブラウザーで直接開きます。
2. 「▶ はじめる」の上で右クリック（Chromebook では2本指でタップ）し、「リンクのアドレスをコピー」を選びます。
   - `https://zku0395-ops.github.io/hori/bunsu/#rec=…&key=…` という長いURLがコピーされます。
3. このURLを、Googleサイトのボタンの「リンク」に貼ります。

- このURLには合言葉が入っています。ただ、入口ページから開いたときにアプリへ渡しているものと同じなので、子どもが見ても問題ありません。
- 1回で開くボタンで記録が届かないときは、入口ページのURLを使うボタンにもどしてください。
- 「新しいデプロイ」を作ってウェブアプリのURLが変わったときは、このURLもコピーし直してください。

## 全員の記録を見る（先生のスプレッドシート）

| シート | 内容 |
|---|---|
| いちらん | 1人1行で、名前・称号・クリアしたステージ数・といた問題数・1回で正解した割合・コイン・グッズの数・最後の学習日時・いまのステージを表示します。ステージの列は「◎＝クリア（数字はクリアした回数）」「23/50＝挑戦中（50問のうち23問まで終わった）」です。右側のオレンジの列は、つまずきの種類ごとのまちがえた回数です |
| きろく | 全員の1問ごとの結果です（日時・名前・ステージ・問題番号・問題・正しい答え・答えた内容・結果・まちがえた回数・ヒントの回数・かかった時間・つまずき・分母の範囲・手がかりの有無） |

つまずきの種類は次のとおりです。

- 分母と分子の入れちがい
- 色のない部分を数えた
- 色ありと色なしをくらべた
- 数えまちがい
- 等分の見落とし
- 分母・分子の名前のまちがい
- 全部（1）のまちがい
- 大きさくらべのまちがい
- その他

記録について：

- 「いちらん」は記録が届くたびに作り直されます。手で書き込んだ内容は消えるので、メモは別のシートに書いてください。
- 途中でやめた問題も、答えたことがあれば「とちゅうでやめた」として記録されます。
- インターネットにつながっていないときの記録は端末にためておき、次につながったときに送ります。同じ記録が二重に書き込まれることはありません。
- 子どもは名前で区別します。名前は1人ずつ違うものにしてください。

## 注意事項

- **データの保存場所**：記録・進み具合・コイン・グッズ・設定は、そのChromebookのブラウザの中（IndexedDB と localStorage）に保存します。Chromeの閲覧データを消すと記録も消えるので、ときどき「バックアップを書き出す」で保存してください。
- **スプレッドシートへの送信**：送り先が設定されている場合は、名前と問題の結果だけを先生のスプレッドシート（Apps Script）に送ります。
- **読み上げ**：Chrome の音声合成を使います。日本語の声が入っていない端末では読み上げられません。
- **暗証番号を忘れたとき**：元にもどす機能はありません。Chromeの設定からこのサイトのデータを消すと最初からやり直せますが、記録も消えます。
- **絵と音**：モカせんせい、ケーキやさん、ケーキ、コインなどの絵と、ファンファーレの曲は、すべてこのアプリのためのオリジナルです（画像や音声のファイルは使わず、プログラムで作っています）。参考資料のスライドの絵は使っていません。ショップのグッズは絵文字です。
- **使っているもの**：React と Babel（unpkg）、BIZ UDPゴシック（Google Fonts）をインターネット経由で読み込んでいます。
