# ニジーせんせいの ビーズ こうぼう（アイロンビーズのネームプレート）

小学校の特別支援学級（1〜4年生）向けの、アイロンビーズの **ネームプレートの見本を作るアプリ** です。
生活単元学習で、子どもが自分の名前（ひらがな・カタカナ・ローマ字）のネームプレートを作るときに使います。
カメレオンの「ニジーせんせい」が案内します。ニジーせんせいの体の色は、子どもが選んだビーズの色に変わります。

- アプリ：`https://zku0395-ops.github.io/hori/beads/`
- 子どもは、名前のボタンを押して、文字の色・まわりの色・かざりを選びます。
- 先生は、できた作品の見本を印刷したり、PDF で保存したりします。見本には、実物大と、大きい見本があります。

## できること

| 項目 | 内容 |
|---|---|
| 名前 | かな（ひらがなか カタカナ。濁音・半濁音・小さい字・ー もつかえます）とローマ字。「かなだけ」「ローマ字だけ」「2段（上にかな、下にローマ字）」から選べます。名前はひらがなで入れ、カタカナにするときは「かな」で「カタカナ」を選びます |
| ローマ字 | ひらがなから自動で作ります（ヘボン式）。先生が直せます。「大文字（TARO）」と「はじめだけ大文字（Taro）」を選べます |
| 文字の大きさ | かなは 大（16マス・線の太さ2マス）、中（8マス）、小（6マス）。プレートに入りきらないときは、自動で小さくします。ローマ字は 大（14マス）、中（7マス）、小（5マス）です |
| プレート | 30×30ピン（155×155mm）が基本です。よこ・たてに、それぞれ3まいまでつなげます。ピンの数とピンのあいだの長さは、先生用画面で変えられます |
| 作品の形 | 4つから選べます。<br>・ふちどり：文字のまわりを1マス囲む<br>・背景をうめる：作品のまわりまで全部うめる<br>・わくでかこむ（長方形）：名前のまわりを四角いわくで囲み、わくの中を同じ色のビーズでうめる<br>・わくでかこむ（正方形）：上と同じで、わくを正方形にする<br>わくでかこむ形では、③で「わくの なかの いろ」、④で「わくの いろ」を選びます。かざりは、わくの外に置き、1つぶのビーズでわくとつなぎます |
| ばらばらにならない | 文字・かざり・わくがはなれているときは、まわりの色のビーズで自動でつなぎます。アイロンをかけたあと、作品が1つにまとまります |
| かざり | 17種類（下の表）。名前の左右、または上下に、2つまで置けます。まわりの「わく」もつけられます |
| ビーズの色 | パーラービーズ（カワダ）の13色。先生用画面で、色を外したり、足したりできます |
| 見本の印刷・PDF | 5種類の見本（下の表）を、1人ずつでも、全員分まとめてでも、印刷や PDF の保存ができます |
| 読み上げ | ニジーせんせいのセリフと色の名前を、ゆっくり読み上げます（はじめは 0.8倍） |

### 子どもの画面の流れ

| 順番 | 画面 | すること |
|---|---|---|
| ① | なまえ | 自分の名前のボタンを押します |
| ② | もじの いろ | 「ぜんぶ おなじ いろ」か「1もじずつ」を選びます。1もじずつのときは、文字のボタンを押してから色を選びます。「🌈 にじいろ」もあります |
| ③ | まわりの いろ | ふちどり（または背景）の色を選びます。文字と同じ色は選べません（✕ が出ます） |
| ④ | かざり | かざりを2つまで選びます。「わく」もつけられます |
| ⑤ | できあがり | 大きく見せて、ニジーせんせいがほめます。使うビーズの色と数が出ます |

- 1つの画面で、1つのことだけを選びます。「◀ もどる」で、いつでも前にもどれます。
- 途中でやめても、次に名前を押すと、つづきから始まります。

### かざり（17種類）

| なかま | かざり |
|---|---|
| きほん | ハート・ほし・にこにこ・おんぷ |
| どうぶつ | いぬ・ねこ・うさぎ・くま・さかな・ことり |
| はな | チューリップ・はな・ひまわり |
| きせつ | さくら（春）・すいか（夏）・もみじ（秋）・ゆきだるま（冬） |

### 印刷する見本（5種類）

| 見本 | 用紙 | 中身 |
|---|---|---|
| ビーズの じゅんび | A4たて | 使う色・番号・数の表と、「よういした」のチェック欄。ぜんぶの数も出します |
| じっさいの おおきさ | A4たて | プレートと同じ大きさ（ピンのあいだ 5mm）。紙の上にプレートをのせて、同じところにビーズを置けます。プレート1まいに1ページです。下に「10cm の ものさし」があります |
| おおきい みほん | A4よこ | 作品のところを大きく出します（1マス 最大13mm）。5マスごとに線があります |
| 1いろずつ | A4よこ | 1つの色だけを濃く出し、ほかの色はうすくします。「あか を 24こ」のように数も出します。色の数だけページがあります |
| 1ぎょうずつ | A4よこ | 行ごとに、ビーズの数とチェック欄があります。1行おきに、うすい色の帯をつけています |

- どの見本にも、行と列の番号（プレートの上からと左から数えた番号）と、色の番号（丸の中の数字）がついています。白黒で印刷しても、番号で色が分かります。
- 番号は、もじの色 → ローマ字の色 → かざりの色 → まわりの色 → わくの色 の順です。

## 支援の工夫

- **スモールステップ**：作る（アプリ）→ ビーズを用意する（じゅんびの表）→ 置く（1いろずつ・1ぎょうずつ）と、分けて進められます。
- **1いろずつ置く**：同じ色を集めて置くと、まちがいが少なく、終わりも分かりやすくなります。その色だけ濃く出すので、どこに置くかが目で分かります。
- **1ぎょうずつ置く**：行ごとのチェック欄と、行の帯で、いまどこを置いているかが分かります。
- **実物大の見本**：プレートを紙の上にのせると、見本と同じところにビーズを置けます。数えなくても置けます。
- **選ぶだけで作れる**：文字の形は自動で作ります。子どもは、色とかざりを選ぶだけです。自分で決めたところ（色・かざり）があるので、「自分の作品」と思えます。
- **まちがえにくい作り**：文字と同じ色は、まわりの色に選べません。選ぼうとすると、ニジーせんせいが「もじが よめなく なるよ」と教えます。かざりがまわりと同じ色のときも、「みえにくく なるよ」と教えます。
- **作品がばらばらにならない**：はなれた部分は、自動でつなぎます。ななめにしかつながっていないところも、ふちどりでつながります。
- **画面**：ボタンは大きく、押すと沈む立体ボタンです。ドラッグはありません。問題の画面（色選び）は、背景をすっきりさせています。にぎやかな絵はホームだけです。
- **読み上げ**：ニジーせんせいをタップするか「🔊 もういちど」で、何度でも聞けます。
- **ごほうび**：できあがりの画面で、紙ふぶき（ビーズ）とニジーせんせいのほめことばが出ます。ホームの名前のボタンに「✓ できた」がつきます。ごほうびは、本物のネームプレートです。

## 公開の手順

### 1. GitHub Pages

ほかのアプリと同じです。`main` ブランチに入ると `https://zku0395-ops.github.io/hori/beads/` で開けます。新しい設定はいりません。

### 2. Apps Script とスプレッドシート

このアプリは、記録をスプレッドシートに送りません。Apps Script やスプレッドシートは使いません。

### 3. Chromebook の準備（最初に1回）

1. Chromebook で `https://zku0395-ops.github.io/hori/beads/` を開きます。
2. 「はじめに、先生が設定をします」の画面が出ます。先生用の暗証番号（4けたの数字）を2回入れて、「はじめる」を押します。
3. 右上の「🔐 せんせい」を押し、暗証番号を入れます。
4. 「👧 名簿と作品」で、子どもの名前をひらがなで入れて、「＋ 追加」を押します。全員分くり返します。
5. 「🟦 プレート」で、ふだん使うプレートの枚数（よこ・たて）を選びます。
6. 「✕ 子どもの画面にもどる」を押します。名前のボタンが並びます。
7. ブックマーク（☆）しておくと、次から開きやすくなります。

- 作品は、その Chromebook の中に保存されます。子どもが1台ずつ別の Chromebook を使うときは、それぞれの Chromebook で 2〜4 を行います。
  - 先生の Chromebook で名簿を作り、「💾 データ」→「バックアップを保存」したファイルを、子どもの Chromebook で「バックアップから読みこむ」と、同じ名簿になります。
- 印刷は、どの Chromebook からでもできます。子どもの作品が入っている Chromebook で、先生用画面から印刷します。

### 4. Googleサイトに置くとき

**おすすめ：ボタンで置く**
1. Googleサイトの編集画面で、右の「挿入」→「ボタン」を押します。
2. 「名前」に「ビーズ こうぼう」、「リンク」に `https://zku0395-ops.github.io/hori/beads/` を入れて、「挿入」を押します。
3. ボタンを押すと、新しいタブでアプリが開きます。

- 「埋め込む」で置くと、Googleサイトの枠の中では、印刷や PDF の保存ができないことがあります。そのときは、上に出る「▶ あたらしいタブで ひらく」を押します。

## 先生用画面

右上の「🔐 せんせい」を押し、4けたの暗証番号を入れると開きます。

| タブ | できること |
|---|---|
| 👧 名簿と作品 | 名前の追加・変更・削除。子どもごとに、ローマ字（直すとき）、ローマ字の形、文字（かなだけ／ローマ字だけ／2段）、かな（ひらがな／カタカナ）、文字の大きさ（自動／大／中／小）、形（ふちどり／背景をうめる／わくでかこむ（長方形）／わくでかこむ（正方形））、プレートの枚数を選べます。作品の小さな絵と「✓ できた」が出ます。「🖨 見本を見る・印刷・PDF」で、その子の見本を開きます。「作品をリセット」で、色とかざりをはじめにもどします |
| 🟦 プレート | ふだん使うプレートの枚数（よこ・たて 各1〜3まい）。プレート1まいのピンの数（はじめは 30×30）と、ピンとピンのあいだ（はじめは 5mm） |
| 🎨 ビーズの色 | 使う色のチェック（持っていない色を外します）。色の名前と見本の色の変更。色を足すこともできます（はいいろ・こん・クリーム・こげちゃ は、はじめは外しています） |
| 🖨 印刷・PDF | だれの見本を作るか（はじめは全員）と、どの見本を入れるかを選び、「見本を見る（印刷・PDF）」を押します |
| ⚙️ 設定 | 読み上げのオン／オフと速さ、効果音、画面の文字の大きさ、新しく名簿に入れる子のはじめの設定、暗証番号の変更 |
| 💾 データ | バックアップの保存と読みこみ、全員の作品のリセット、すべて消す |

### 印刷のしかた

1. 先生用画面の「🖨 印刷・PDF」で、子どもと見本を選び、「見本を見る（印刷・PDF）」を押します。
2. 見本のページが並びます。上の「🖨 いんさつ」を押します。
3. 印刷の画面で、次のように選びます。
   - 倍率：**100%**（または「実際のサイズ」）
   - 余白：**なし**
   - 「背景のグラフィック」に **チェック**
4. 「印刷」を押します。
5. 「じっさいの おおきさ」のページの下にある ものさしを、本物のものさしで測ります。**10cm** なら、プレートと同じ大きさで印刷できています。

### PDF で保存する

1. 見本のページの上の「📄 PDFで ほぞん」を押します。
2. PDF が「ダウンロード」フォルダに入ります。ファイル名は「ビーズこうぼう_（名前）.pdf」、全員分のときは「ビーズこうぼう_（人数）にんぶん.pdf」です。
   - Chromebook：左下の ○（ランチャー）→「ファイル」→「ダウンロード」
3. PDF は、大きさを mm で正しく作っています。印刷するときは、PDF の印刷の画面で倍率を「100%」（または「実際のサイズ」）にします。
4. メールに付けて送れば、自宅のパソコンでも開けます。

### 実物大がプレートとずれるとき

1. ものさしで、プレートのいちばん左のピンから、いちばん右のピンまでの長さを測ります（ピンのまんなかからまんなかまで）。
2. 測った長さを（ピンの数 − 1）でわります。例：ピン30こで 145mm なら、145 ÷ 29 = 5mm です。
3. 先生用画面の「🟦 プレート」→「ピンとピンのあいだ（mm）」に、その数を入れます。
4. 印刷の倍率が 100% になっているかも、確かめます。

## 全員の記録を見る

このアプリは、記録をスプレッドシートに送りません。だれが作り終わったかは、先生用画面の「👧 名簿と作品」（「✓ できた」）と、ホームの名前のボタンで分かります。

## 注意事項

- **保存場所**：作品と設定は、その Chromebook のブラウザの中（localStorage）に保存します。ブラウザの「閲覧履歴データの削除」で「Cookie と他のサイトデータ」を消すと、作品も消えます。ときどき「💾 データ」→「バックアップを保存」をしてください。
- **名前**：外には送りません。呼び名でもかまいません。
- **文字の形**：ビーズのひらがな・カタカナ（8×8マスと 6×6マス）は、先生からいただいたビーズ用のひらがな一覧・カタカナ表をもとにしています。小さい「ゃ ゅ ょ っ」「ャ ュ ョ ッ」と、てんてん（゛）・まる（゜）のつけ方は、このアプリで足しました。ローマ字（5×7マスと 3×5マス）とかざりのドット絵は、このアプリのために作ったオリジナルです。
- **ひらがな一覧・カタカナ表の出典**：いただいた一覧と表の出典（本やサイトの名前）が分かったら、ここに書きます。
- **文字の大きさの目安**（ふちどりのとき）

  | プレート | かなだけ・大 | かなだけ・中／小 | 2段（かな＋ローマ字） |
  |---|---|---|---|
  | 1まい（30×30） | 1文字 | 中で3文字、小で4文字 | 中のかな3文字＋小のローマ字6文字 |
  | よこ2まい（60×30） | 3文字 | 中で6〜7文字、小で8文字 | 大のかな3文字＋中のローマ字6文字 |

- **ビーズの色**：画面と見本の色は、パーラービーズ（カワダ）の色に近い色にしています。本物のビーズと少しちがって見えることがあります。色の名前は、先生用画面で変えられます。
- **ニジーせんせい**の絵と、ホームの絵は、このアプリのためにSVGで描いたオリジナルです。
- **使っているもの**：React と Babel（unpkg）、jsPDF（unpkg。「PDFで ほぞん」を押したときだけ読みこみます）、BIZ UDPゴシック（Google Fonts）を、インターネット経由で読みこみます。インターネットにつながっていないと開けません。

## これから相談して決めること

- かざりの追加（給食・のりもの・行事のもの など）。学級の子の好きなものを入れるか
- 子どもが1マスずつ自由に色をぬれる「じゆう モード」を入れるか
- かざりの位置を子どもが選べるようにするか（いまは左右、または上下に自動で置きます）
- 「中」の文字の大きさ（10マス）を、手で作った字で足すか
- 名字と名前を2段にする（例：上に「たなか」、下に「ゆうと」）か
- 見本に、アイロンのかけ方（大人がする）の手順のページを入れるか
