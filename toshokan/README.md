# ショコの まなびの としょかん（アプリとプリントの倉庫）

これまでに作った学習アプリやプリントを、教科ごとの本棚に整理して開くための、先生用のアプリです。
Canva のデザインや、Google ドキュメントの指導案・Google スライドなどの「しりょう」も、URL を貼って登録できます。
案内役のロボット「ショコ」が、近未来の図書館で案内します。
アプリのURL・コード・説明書・PDF は、GitHub のリポジトリから **自動で** 読みこみます。新しいアプリを作ると、本棚にも自動で本が増えます。

## できること

| 項目 | 内容 |
|---|---|
| 本棚 | 国語・算数・生活単元・音楽・図工・総合・体育・道徳・成績・校務 の10このたなに、アプリやプリントを1さつずつ「本」として並べます |
| 自動で読みこむ | GitHub のリポジトリから、フォルダとファイルの一覧を読みこみます。`README.md` があるフォルダを1さつの本にします |
| あたらしい本 | どの たなにも入っていない新しいアプリは、まず「✨ あたらしい本」の台に置きます。本を開いて、たな（教科）を選びます |
| アプリを開く | GitHub Pages のアプリは、そのまま開けます。Apps Script のアプリと入口ページは、先生が1回だけURLを登録すると開けます |
| コード | ファイルの一覧と中身が見られます。「📋 ぜんぶ コピー」「Raw を ひらく」ボタンがあります。Apps Script に貼るファイルには 📋 のしるしが付きます。いちばん下の行も出るので、貼り付けたあとに確かめられます |
| 説明書 | 各アプリの `README.md` を読みやすい形で出します |
| しりょう | Canva・Google ドキュメント・スライド・スプレッドシート・フォーム・ドライブの PDF・YouTube・ほかのサイトを、URL を貼って登録できます。種類は URL から自動で見分け、種類ごとのマーク（🎨📄📽️📊📝📕▶️🔗）を表紙にします |
| かんけいする しりょう | しりょうに「つかう アプリ」を選ぶと、そのアプリの本の画面に「📎 かんけいする しりょう」として出ます。たなも そのアプリと同じになります（あとから変えられます） |
| しぼりこみ | たなの上の「ぜんぶ・アプリ・プリント・しりょう」で、出す本をしぼりこめます |
| PDF・絵 | プリントの PDF と、アプリの絵の一覧を開けます |
| さがす | 🔍 に「かんじ」「プリント」「指導案」などを入れると、当てはまる本やしりょうが出ます |
| おきにいり・さいきん | ☆ を押した本は「⭐ おきにいり」に、開いた本は「🕘 さいきん ひらいた」に入ります |
| メモ | 本ごとに メモを残せます（例：2学期に使う） |
| 保存 | たな・URL・メモ・おきにいりは、スプレッドシートに保存します。学校の Chromebook でも自宅のパソコンでも同じものが見られます |

## 画面の構成

| 画面 | 内容 |
|---|---|
| ホール | 図書館の絵の上に、教科ごとの光る本棚が並びます。右下にショコがいて、ふきだしで話します |
| たな | その教科の本（表紙・なまえ・アプリ／プリント／しりょうのしるし）が並びます。「ぜんぶ・アプリ・プリント・しりょう」でしぼりこめます。「＋ しりょうを ふやす」もあります |
| 本 | アプリを開くボタン、URLの登録、たなの変更、説明書・コード・PDF・絵、📎 かんけいする しりょう、メモ |
| しりょう | ▶ ひらく（新しいタブ）、つかう アプリ、メモ、✏️ なおす、🗑️ けす |
| しりょうを ふやす | ① URL → ② なまえ → ③ つかう アプリ（なくてもよい）→ ④ たな → ⑤ メモ（なくてもよい）→ 💾 とうろく |
| せってい | ショコの声・読み上げの速さ・文字の大きさ、Apps Script のURLのまとめて登録、🩺 動作チェック |

## 使いやすくする工夫

- ボタンは大きく、押すと沈む形です。Chromebook のタッチでも押しやすくしています。
- ショコの表情は、場面に合わせて変わります。
  - 🙇 ごあいさつ：としょかん を開いたとき
  - 🙂 ふつう：たなや本を開いたとき
  - 😄 よろこぶ：しりょうや URL を登録できたとき、たなを決めたとき、おきにいりに入れたとき
  - 🤔 かんがえる：さがして見つからないとき、一覧が読めないとき、保存できなかったとき
  - 😲 びっくり：「ほんとうに けしますか？」のとき
  - ふつう以外の表情は、少したつと ふつうに もどります。
- ショコの声は、はじめは **オフ** です（職員室などでも使えるように）。「⚙️ せってい」でオンにできます。ふきだしを押すと、1回だけ読み上げます。
- 本やたなを開いているときは、ショコが小さくなり、ふきだしは5秒で消えます（ボタンに重ならないように）。
- GitHub の一覧が読めないときは、予備の目録（`mokuroku.json`）や、前に読んだ一覧を使います。

## しりょうの登録のしかた

1. ホールの「＋ しりょう」か、たなの「＋ しりょうを ふやす」か、アプリの本の画面の「＋ しりょうを ふやす」を押します。
2. 登録したいファイルの URL をコピーします。
   - Canva：デザインを開き、右上の「共有」→「リンクをコピー」を押します。
   - Google ドキュメント・スライドなど：ファイルを開き、右上の「共有」→「リンクをコピー」を押します。
3. としょかん の「① URL を 貼り付ける」に貼り付けます。種類（🎨 Canva など）が自動で出ます。ちがうときは、右のメニューで選びなおします。
4. なまえを入れ、たなを選んで、「💾 とうろく」を押します。
- 「🗑️ けす」で消えるのは、としょかん の登録だけです。Canva や Google のファイルそのものは消えません。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面（Apps Script の HTML ファイルとして貼り付けます） |
| `コード.gs` | Apps Script（スプレッドシートへの保存、予備の読みこみ） |
| `img/shoko.webp` | ショコの絵（Canva で作成。GitHub Pages から読みこみます） |
| `img/shoko_bow.webp` ほか | ショコの表情の絵：ごあいさつ（`_bow`）・よろこぶ（`_happy`）・かんがえる（`_think`）・びっくり（`_surprise`）。Canva で作成 |
| `img/library.webp` | 図書館の絵（Canva で作成） |
| `mokuroku.json` | 予備の目録（ファイルの一覧と本のなまえ）。`node toshokan/tools/mokuroku.js` で作ります |
| `tools/mokuroku.js` | 目録を作る道具 |

## 公開の手順

### 1. GitHub Pages

- 絵（`img/`）と目録（`mokuroku.json`）は GitHub Pages とリポジトリから読みこみます。`main` に入ると公開されます。先生の作業はいりません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで、新しいスプレッドシートを作ります。名前は「ショコの としょかん」などにします。
2. 「拡張機能 → Apps Script」を開きます。
3. `コード.gs` の中身をすべて消して、このリポジトリの `toshokan/コード.gs` を貼り付けます。
   - GitHub で `toshokan/コード.gs` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を押します。
   - Ctrl＋A（ぜんぶ選ぶ）→ Ctrl＋C（コピー）します。
   - Apps Script の `コード.gs` で Ctrl＋A → Ctrl＋V（貼り付け）します。
4. 左の「ファイル」の「＋」→「HTML」を押し、名前を `index` にします（`.html` は自動で付きます）。
5. `index.html` の中身をすべて消して、`toshokan/index.html` を同じやり方で貼り付けます。いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 右上の「デプロイ → 新しいデプロイ」を押します。
   - 歯車 →「ウェブアプリ」を選びます。
   - 「次のユーザーとして実行」：**自分**
   - 「アクセスできるユーザー」：**自分のみ**
   - 「デプロイ」を押し、許可の画面が出たら、自分のアカウントを選んで「許可」します。
8. 出てきた「ウェブアプリ」のURLをブックマークします。これが としょかん の入口です。

- `コード.gs` や `index.html` を書き換えたときは、「デプロイ → デプロイを管理 → 鉛筆 → バージョン：新バージョン → デプロイ」で更新します。URLは変わりません。

### 3. Apps Script のURLを登録する（1回だけ）

1. としょかん を開き、「⚙️ せってい」を押します。
2. 「🔗 Apps Script の URL を まとめて とうろく」に、アプリの名前が並んでいます。
3. それぞれのアプリのスプレッドシートで「拡張機能 → Apps Script → デプロイ → デプロイを管理」を開き、ウェブアプリのURLをコピーします。
4. としょかん の その行に貼り付けて、「💾 とうろく」を押します。
   - 音読・角・分数・なぞとき・ひっ算・たんけんたい は「入口ページ」のURLを登録します。
   - 本の画面からも、1さつずつ登録できます。

### 4. Chromebook の準備

- 学校の Chromebook でも、自宅のパソコンでも、同じ Google アカウントでログインしてブックマークを開けば使えます。
- 「アクセスできるユーザー：自分のみ」なので、子どもの Chromebook では開けません。

### 5. Googleサイトに置くとき

- 先生だけが使うアプリなので、Googleサイトには置かないでください。

## 先生用画面

- このアプリは、ぜんぶが先生用です。「自分のみ」で公開するので、暗証番号はありません。
- 「⚙️ せってい → 🩺 どうさ チェック」で、スプレッドシート・GitHub・URLの登録の様子が分かります。うまく動かないときは、この結果を Claude に貼り付けてください。

## 全員の記録を見る

- このアプリは、子どもの記録はとりません。
- スプレッドシートの「ほんだな」シートに、本ごとの たな・URL・メモが入ります。「しりょう」シートに、登録した しりょう（ID・なまえ・URL・しゅるい・たな・つかう アプリ・メモ）が入ります。ID の列は書き換えないでください。「せってい」シートに、声・文字の大きさ・おきにいり・さいきん ひらいた が入ります。シートを直接書き換えてもかまいません（たなは「国語」「算数」などの名前で書きます）。

## 注意事項

- コードは GitHub の公開リポジトリから読みこみます。インターネットにつながっていないと読めません。
- GitHub の一覧の窓口は、1つのネットワークから1時間に60回までです。こえたときは、予備の目録（`mokuroku.json`）を使います。新しいアプリを足したときは、`node toshokan/tools/mokuroku.js` で目録も作り直します（Claude が作るときに一緒に行います）。
- 新しいフォルダに `README.md` があると、本として出ます。
- ショコと図書館の絵は、Canva で作ったオリジナルです。参考にしたロボットや図書館の写真の絵は使っていません。
- 個人情報（子どもの名前など）は、メモに書かないでください。
