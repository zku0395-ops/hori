# そらの うえの がっこう

特別支援学級の子どもが、たくさんの学習アプリの中から、自分で選んで学習するためのページです。
空に うかぶ 島の学校の、7つの部屋に、教科ごとにアプリが置いてあります。
案内役は、くもの子の「フワリこうちょうせんせい」です。

## できること

| こと | 内容 |
|---|---|
| 学校の絵から部屋を選ぶ | 学校の絵の部屋（7つ）を押すと、その部屋に入ります |
| 空にうかぶ島 | 学校の島が、空の上で ゆっくり左右に向きを変え、ふわっと上下に動きます。動いている間も部屋を押せます。「⏸ とめる」で止められます |
| 部屋の中の「たな」 | こくご・さんすうは、たなに分かれています（例：ひらがな・カタカナ・かんじ…） |
| アプリを開く | アプリを押すと、名前を読み上げます。「▶ はじめる」で、新しいタブで開きます |
| きょうの おすすめ ⭐ | 先生が選んだアプリを、学校の絵の下に出します（4つまで） |
| さいきん つかった | その Chromebook で最近開いたアプリを3つ出します |
| 読み上げ | フワリこうちょうせんせいのセリフを読み上げます。キャラクターか「🔊 もういちど」を押すと、もう一度読みます |
| 先生用画面 | プリントの一覧、アプリを かくす、おすすめを選ぶ、文字の大きさ、読み上げの速さ、暗証番号 |

## 部屋の構成

| 部屋 | たな | アプリの数 |
|---|---|---|
| 📚 こくごの へや | ひらがな／カタカナ／かんじ／ことばと ぶん／よむ | 50 |
| 🔢 さんすうの へや | かず／たしざん・ひきざん／かけざん・わりざん／とけい・じかん／ながさ・かさ／かたち・かくど／ぶんすう・しょうすう | 35 |
| 💻 パソコンの へや | （ローマ字・タイピング・プログラミング） | 7 |
| 🔭 しらべる へや | （とどうふけん しらべ） | 1 |
| 🎨 つくる へや | （アイロンビーズ） | 1 |
| ⚽ あそぶ へや | （ゲーム） | 4 |
| 🎪 ぎょうじの へや | まだ ありません（「じゅんびちゅう」と出ます） | 0 |

- もとにしたのは、Google サイト「アプリ集②」のホームにあるアプリです。
- くっつきことばマスターは、同じものが3つあったので、1つにまとめました。
- 名前の「NEW」は取りました。漢字には ふりがなを付けています。
- プリント（ひっ算・カタカナ・漢字1〜3年・文の読解）は、子どもの画面には出さず、先生用画面に置いています。
- 「★書庫（教材）」は先生用の倉庫なので、入れていません。

## 支援の工夫

- 選ぶ数を減らすために、部屋 → たな → アプリ の順に しぼりこみます。
- アプリを押すと、すぐには開かず、名前を読み上げてから「▶ はじめる」を押します。まちがえて押しても「もどる」で もどれます。
- たなの中のアプリには、①②③…の番号を付けています。「かずの ③を やろう」のように、先生が番号で伝えられます（かくした アプリがあると、番号は つめて付けなおします）。
- 部屋の名前とアプリの名前には、絵文字を付けています。字を読むのが むずかしい子も、絵で見分けられます。
- 「きょうの おすすめ」を使うと、部屋をさがさなくても、学校の絵の下から すぐ始められます。
- ボタンは大きく、押すと沈む立体ボタンです。
- 島の動きは ゆっくり（1往復36秒）にしています。動きが苦手な子は、学校の画面の「⏸ とめる」で自分で止められます。先生用画面で、はじめから止めておくこともできます。端末で「視差効果を減らす」を選んでいるときは、はじめから止まっています。
- 部屋の中は、まん中に白い板を置いて、アプリのボタンを見やすくしています。

## 公開の手順

### 1. GitHub Pages

1. `main` ブランチに入ると、自動で公開されます。
2. URL は `https://zku0395-ops.github.io/hori/sora/` です。

### 2. Apps Script とスプレッドシート

このページは記録をとらないので、Apps Script もスプレッドシートも いりません。

### 3. Chromebook の準備

1. Chromebook で URL を開きます。
2. ブックマーク（☆）に入れるか、Google サイトにボタンで置きます。
3. 「⚙️ せんせい」→ 暗証番号 → 「⚙️ せってい」で、読み上げの速さと文字の大きさを決めます。
4. 「きょうの おすすめ」や「かくす」は、Chromebook ごとに設定します。

### 4. Google サイトに置くとき

1. Google サイトの編集画面で、右の「挿入」→「ボタン」を押します。
2. 名前に「そらの うえの がっこう」、リンクに `https://zku0395-ops.github.io/hori/sora/` を入れます。
3. 「埋め込む」では置かないでください。アプリが新しいタブで開けなくなることがあります。

## 先生用画面

1. 学校の絵の右上の「⚙️ せんせい」を押します。
2. 暗証番号（はじめは `1234`）を押します。
3. 次のことができます。
   - 🖨️ プリント：印刷するページ（ひっ算・カタカナ・漢字・文の読解）を開きます。
   - 📱 アプリ：「👁 みせる」で、子どもの画面から かくします。「⭐ おすすめ」で、きょうの おすすめに出します。「ひらく」で、先生がためしに開けます。
   - ⚙️ せってい：学校の島の動き（うごかす・とめる）、読み上げ（する・しない、速さ）、文字の大きさ、「さいきん つかった」を消す、暗証番号を変える。

## 全員の記録を見る

このページは、アプリを選ぶ入口です。記録はとりません。
学習の記録は、それぞれのアプリの先生用画面やスプレッドシートで見てください。

## 注意事項

- 設定（おすすめ・かくす・文字の大きさなど）は、その Chromebook のブラウザの中だけに保存されます。全部の Chromebook に同じ「おすすめ」を出したいときは、Claude に頼んで `apps.js` の `osusume` に書いてもらいます。
- アプリを足す・消す・部屋を変えるときは、Claude に「〇〇を さんすうの へやの かず の たなに足して（URL は …）」のように頼みます。
- claude.ai のアーティファクト（詩の音読・タイピング）と NotebookLM（せつめい）は、子どものアカウントで開けるか、先に ためしてください。
- 絵（学校・部屋・フワリこうちょうせんせい）は、ユーザーが ChatGPT で作ったオリジナルです。パソコンの へやの画面に出ていた会社のマークのような絵は、消して使っています。アプリの絵文字は、端末の絵文字です。
