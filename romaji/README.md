# ガジガジせんせいの ローマじ こうぼう（ローマ字の学習アプリ）

小学校の特別支援学級向けの、ローマ字の読み書きの学習アプリです。
ビーバーの大工「ガジガジせんせい」の こうぼう（工房）で、木のピースを組み立てて文字を作ります。

- 「か」は、あおい ピース **k**（子音）と、あかい ピース **a**（母音）を くっつけて作ります。ローマ字が「パズルのように組み合わせてできている」ことが、目で見て分かります。
- ピースはジグソーパズルのように、かみ合う形です。子音は青、母音は赤に色分けしています。
- 正解すると、ピースがカチッとくっつき、「k と a で、か！」と読み上げ、「せいかい！」の声とファンファーレが鳴って、コインが1まいもらえます。
- コインで「おみせ」の品物（6しゅるい × 10こ）を買い、こうぼうの部屋をかざったり、ガジガジせんせいを着せかえたりできます。
- 形は、カタカナ・漢字・タイピングのアプリと同じ「Apps Script だけ」です。子どもは名簿の名前のボタンを押して始めます。
- ローマ字のしくみ・問題のデータ・絵は、GitHub Pages（`https://zku0395-ops.github.io/hori/romaji/`）から読みこみます。Apps Script に貼り付けるファイルを短くするためです。

## できること

| 項目 | 内容 |
|---|---|
| ステージ | 本編15（あ行〜まとめ）と、はってん6（てんてん・まる、きゃ・しゅ・ちょ、ちいさい っ、のばす おと、べつの かきかた、おおもじ） |
| 書き方 | 教科書と同じ書き方（訓令式）です。し＝si、ち＝ti、つ＝tu、ふ＝hu、じ＝zi、しゃ＝sya、を＝wo、ん＝n。shi・chi・tsu・fu・ji などは、はってん「べつの かきかた」で学びます |
| 1つのステージ | ①くみたてる → ②よむ → ③ことば の3つの だんかい。前の だんかいが できると、次が開きます。3つとも できると ステージクリアで、次のステージが開きます |
| ①くみたてる | 「か」と絵（☂️ かさ の か）を見て、あおい ピース（4つから）と あかい ピース（a i u e o の5つ全部）を選んで組み立てます |
| ②よむ | 「ka」のピースを見て、ひらがな4つから「か」を選びます |
| ③ことば | 「かさ」を、ka ＋ sa と1文字ずつ組み立てます（2〜4文字のことば） |
| なかまさがし | 「さいごが a の なかま（か・さ・た…）」「はじめが k の なかま（か・き・く…）」をカードから探します。母音が同じ文字・子音が同じ文字の しくみに気づくためのステージです。カードには、はじめは ひらがな だけを出します。ヒントを押すと、ローマ字のピース（か の下に k a）が出ます。見つけたカード・まちがえたカードにも ローマ字が出ます |
| 1回の長さ | 5問（先生用画面で 3問・10問 にもできます）。途中でやめても「つづきから」始められます |
| ④チャレンジ | 「くみたてる」があるステージ（本編13・はってん①②⑤⑥）に付いています。ランダムに10問で1セット（およそ7割が そのステージの行、3割が それまでに習った行）。①くみたてる が できると開きます。何回でも取り組めます。チャレンジをしなくても、ステージはクリアになります |
| せいさくべや | ちずの「🛠️ せいさくべや」から入ります。「もんだい」は、クリアしたステージの文字ぜんぶから、ランダムに30問（くみたてる）。「せっけいず」を見て、材料がそろうと たてものを建てられます。建てたものを押してから まちのマスを押すと、そこに置けます（動かす・しまう もできます） |
| 操作 | ピースを押すと、わくに はまります。はまった ピースを押すと はずれます（ドラッグは使いません） |
| 声 | ガジガジせんせいのセリフと問題を読み上げます（はじめは0.8倍の速さ）。ローマ字は「ケー」「エー」のように、アルファベットの名前で読みます。ガジガジせんせいか「🔊 もういちど」を押すと、もう一度聞けます |
| ごほうび | 1問で1コイン（ヒントを使っても同じ）。ステージを初めてクリアすると、ボーナスで5コイン |
| ローマじ ひょう | 組み立てた文字が、表（清音46文字）のマスにうまっていきます。はってんを開くと、濁音・拗音の表も出ます |
| しょうごう | ひょうのマスの数で上がります（みならい だいく → ピース だいく（10こ）→ くみたて だいく（20こ）→ いちにんまえ だいく（30こ）→ ベテラン だいく（46こ全部））。本編15ステージを全部クリアすると「ローマじ めいじん」 |
| おみせ | かぐ・かべと ゆか・だいくの どうぐ（こうぼうに かざる）、ぼうし・ふく・もちもの（ガジガジせんせいに つける）。どのたなも ふつう 4こ（5コイン）・ごうか 3こ（15コイン）・ちょうごうか 2こ（30コイン）・でんせつ 1こ（60コイン） |
| ざいりょう | おみせの「ざいりょう」の たなで、1こずつ買います。きの いた（2コイン）・レンガ（3）・いし（3）・まど（4）・ドア（5）・やね（5）・てっこつ（6）・ガラス（6）。建てると なくなります |
| たてもの | こや・いえ・にわつきの いえ・おみせ・がっこう・びょういん・ビル・タワー・おしろ の9しゅるい。同じものを何こでも建てられます |
| こうぼう | 買った かぐ・どうぐを部屋にかざり、かべと ゆかの もようを変え、ガジガジせんせいに ぼうし・ふく・もちものを つけます |
| 先生用画面 | 暗証番号4けたで開きます。記録の確認（まちがえやすい文字、子音と母音のどちらでまちがえたか、まちがえやすいピース）、設定、記録の送信、CSV書き出し、バックアップ、記録の消去ができます |
| 全員の記録 | 結果は先生のGoogleスプレッドシートへ届きます。進み具合・コイン・買ったものも、スプレッドシートに保存します |

| 2 | か行 | ka ki ku ke ko | ①②③ |
| 3 | さ行 | sa si su se so | ①②③ |
| 4 | ふくしゅう① | あ〜さ行 | ①②③ |
| 5 | た行 | ta ti tu te to | ①②③ |
| 6 | な行 | na ni nu ne no | ①②③ |
| 7 | なかまさがし① | あ〜な行 | ①さいごの ピース（母音）②はじめの ピース（子音） |
| 8 | は行 | ha hi hu he ho | ①②③ |
| 9 | ま行 | ma mi mu me mo | ①②③ |
| 10 | ふくしゅう② | た〜ま行 | ①②③ |
| 11 | や行 | ya yu yo | ①②③ |
| 12 | ら行 | ra ri ru re ro | ①②③ |
| 13 | わ・を・ん | wa wo n（ん は n の ピース1つ） | ①②③ |
| 14 | なかまさがし② | 全部 | ①さいごの ピース ②はじめの ピース |

| はってん① | てんてん・まる | ga za da ba pa など | ①②③ |
| はってん② | きゃ・しゅ・ちょ | kya sya tya など（まんなかに y の ピース） | ①②③ |
| はってん③ | ちいさい っ | kitte rappa など（つぎの 子音を もう1つ） | ①ことば ②ことばを よむ |
| はってん④ | のばす おと | okâsan bôsi など（「＾」の ついた あかい ピース） | ①ことば ②ことばを よむ |
| はってん⑤ | べつの かきかた | shi chi tsu fu ji sha cha ja など | ①②③ |

- はってんは、はじめは閉じています。先生用画面の「子どもごと」で開きます。
- 行ごとのステージ（1〜3・5・6・8・9・11〜13）の ①②は、はじめに その行の文字を順に出します（か・き・く・け・こ）。
- ③ことばは、そのステージまでに習った文字だけで作っています（`node romaji/tools/check.js` で点検できます）。
- ことばの一覧は `data/mondai.js` にあります。

## 支援の工夫

- **ピースの形と色**：子音は青、母音は赤です。子音のピースには右に でっぱり、母音のピースには左に くぼみがあり、かみ合う形になっています。「ローマ字は2つのピースでできている」ことを、形で分かるようにしました。
- **母音はいつも5つ全部**：あかい ピースは、いつも a i u e o の順に並べます。並び順が自然に身につきます。
- **子音はまちがえやすいものをまぜる**：あおい ピースは、正しいピース・まちがえやすいピース（k と h、n と m、s と t など）・ほか の4つです。
- **まちがえたとき**：まちがえて作った文字を見せて、声をかけます（例：「s と a だと『さ』に なるよ。『か』を つくろう」）。正しいピースは わくに残り、まちがえたピースだけが はずれます。答えに使わないピースは うすくなって、もう選べなくなります。まちがえたときの音は小さな音です。
- **ヒントは3段階**です。同じ問題で2回まちがえるとヒントボタンが光り、3回まちがえると一番くわしいヒントが自動で出ます。

  | | 内容 |
  |---|---|
  | ヒント1（ことば） | 例：「『か』を のばして いうと『かあ』。さいごは『あ』の おとだね」 |
  | ヒント2（ひょう） | ローマじ ひょうを出し、「か」のマスを光らせます。同じ行（k）と同じ段（a）にも色をつけます |
  | ヒント3（こたえ） | 答えのピースを光らせます |

- 時間制限はありません。
- 問題の画面は背景をすっきりさせています。にぎやかな絵は、ちず・おみせ・こうぼうだけで使います。

## ファイル構成

```
romaji/index.html          アプリ本体（Apps Script の HTML ファイル「index」に貼り付けます）
romaji/コード.gs            スプレッドシートとつなぐプログラム（Apps Script の「コード.gs」に貼り付けます）
romaji/data/kana.js        ローマ字のしくみ（かな → ローマ字、ピースに分ける、ローマじ ひょう）
romaji/data/mondai.js      ステージ・ことば・絵・おみせの品物・ざいりょう・せっけいずのデータ
romaji/img/                ガジガジせんせいの絵（ふつう・よろこぶ・かんがえる。Canva で作成、背景をすかした 600×600）
romaji/tools/check.js      問題データの点検（node romaji/tools/check.js）
romaji/tools/test_gas.js   コード.gs のテスト（node romaji/tools/test_gas.js）
```

- `data/` と `img/` は、GitHub Pages から読みこみます。ことばを直したときは、`data/mondai.js` を直して `main` に入れるだけで、Apps Script を貼り直さなくても全員の画面に反映されます。
- ガジガジせんせいの絵が読みこめないときは、自作の絵（SVG）が出ます。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/romaji/` を開きます。
   - 「おためしモード」で動けば、問題のデータと絵の公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「ローマ字 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、ピースが小さくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

1. 名前を選ぶ画面の右下（学習中は右上）の **🔒** を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「せってい」で変えてください。**

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの クリアしたステージの数・ひょうのマスの数・コイン・問題の数・まちがえずに できた割合・しいん（あお）の まちがい・ぼいん（あか）の まちがい・まちがえやすい文字（上位3つ）・最後に学習した日。クラス全体の まちがえやすい文字（ローマじ ひょうで、まちがいが多い文字ほど赤い）と、まちがえやすいピースの一覧 |
| 子どもごと | ステージごとの結果（できた だんかい・問題の数・まちがえずに できた割合・子音と母音の まちがい）、まちがえやすい文字（ひょう）、まちがえやすいピース |
| 子どもごと（ボタン） | 全部開く（その子だけ、すべてのステージを開く）、はってんを開く、コインを足す・引く、この子の記録を消す |
| せってい | 読み上げの速さ、文字の大きさ、1回の問題の数（3・5・10）、効果音、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、全員の記録を消す |

- **まちがえずに できた割合** は、まちがえず、ヒントも使わずに できた問題の割合です。
- **まちがえやすいピース** の「k を h に」は、k の ピースを選ぶところで h を選んだ、という意味です。「－ を k に」は、あ・い・う・え・お に あおい ピースを付けようとした ことを表します。
- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。

## 全員の記録を見る

- スプレッドシートの **「きろく」** シートに、1問ごとの結果が入ります。

  | 日時 | なまえ | ステージ | だんかい | もんだい | けっか | まちがい | ヒント | しいんの まちがい | ぼいんの まちがい | まちがえた もじ | まちがえた ピース | まちがえて できた もじ | びょう | ID |
  |---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

  - ステージ：1〜15、はってん1〜はってん6、せいさくべや
  - だんかい：くみたてる・よむ・ことば・なかまさがし（さいごの ピース）・なかまさがし（はじめの ピース）・ことばを よむ・チャレンジ・もんだい（せいさくべや）
  - もんだい：文字（例：「か」）、ことば（例：「かさ」）、なかまさがしは「a の なかま」など
  - けっか：○＝まちがえず、ヒントも使わずに できた　△＝まちがえてから、またはヒントを使って できた
  - まちがい：まちがえた回数　ヒント：使ったヒントの段階（0〜3）
  - しいんの まちがい・ぼいんの まちがい：まちがえた あおい ピース・あかい ピースの数
  - まちがえた もじ：まちがえたときに作っていた文字（例：「か」）
  - まちがえた ピース：「k>h」は「k の ピースの ところで h を 選んだ」という意味です
  - まちがえて できた もじ：まちがえて作った文字・選んだ文字（例：「は」）
  - びょう：その問題にかかった時間
- **「まとめ」** シートに、子どもごと・ステージごとの結果と、まちがえやすい文字・ピースが入ります。先生用画面を開いたとき、またはメニュー **ガジガジ → まとめを更新する** で更新されます。
- **「名簿」** シートのB列に、進み具合・コイン・買ったもの・こうぼうの かざり・ガジガジせんせいの着せかえ が入ります。ちがう Chromebook を使っても「つづきから」始められます。
- 記録は1問ごとと、やめたとき・終わったときに送ります。ネットが切れていたときの記録は、その Chromebook にためておき、つながったときに送り直します。同じ記録は二重に書きません。

## 注意事項

- **個人情報**：名簿には、呼び名かひらがなの名前だけを入れてください。
- **絵**：ガジガジせんせいは、先生の Canva で、このアプリのために作った画像です。ピース・こうぼうの部屋・かべと ゆかの もよう・ねじりはちまき・コックさんの ぼうし・だいくの エプロン・ヒーローの マントは、このアプリのための自作の絵（SVG と CSS）です。そのほかの品物と、問題の絵は絵文字です。
- **ことば**：すべて、このアプリのためのオリジナルです。
- **効果音**：このアプリのためのオリジナルです（プログラムで作っています）。
- **書き方**：小学校の国語の教科書と同じ訓令式を基本にしています。「を」は、パソコンで打つときと同じ wo にしています。のばす音は、教科書と同じく「＾」を付けます（例：おかあさん＝okâsan）。

- 「データを よみこめませんでした」と出るときは、`https://zku0395-ops.github.io/hori/romaji/` が開けるか確かめてください。

## これから相談して決めること

- ざいりょうの値段と、せっけいずの材料の数（使ってみて、建てにくい・建てやすすぎるときは調整します）
- たてものの しゅるいを ふやすか（えき・こうえん・どうぶつえん など）

- ことばの見直し（子どもの生活に合わせて入れかえる。`data/mondai.js` を見て、合わないものを教えてください）
- ピースをドラッグして はめる操作も入れるか（いまは押すだけ）
- 「ん」のあとに あ行・や行・な行が続く ことば（例：きんえん＝kin'en）の書き方を入れるか
- 大文字は、ことばの はじめだけ大文字（例：Tôkyô）にするか、全部大文字にするか（いまは全部大文字）
- 品物の値段（使ってみて、たまりすぎ・たりなすぎがあれば調整します）
- タイピングのアプリとのつなぎ方（ローマ字を覚えたあと、キーボードで打つ練習へ進む）
