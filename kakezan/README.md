# ケンジャの カケルさまの ひっさん クエスト（かけ算のひっ算の学習アプリ）

小学校の特別支援学級（3〜4年生ほど）向けの、かけ算のひっ算の学習アプリです。
ロールプレイングゲームのように、子どもが自分で選んだ主人公（ゆうしゃ・まほうつかい・しょうにん・そうりょ）と なかま で冒険します。
ひっ算を1問とくと、モンスターに1回こうげきします。
まおう「バラバーラ」にうばわれた「かけ算の ちから」（9つの ほうせき）を、ひっ算で とりもどします。

- 先生役は、やさしい魔法使いのおじいさん「ケンジャの カケルさま」です。
- 書き方は、先生のプリント（R5「かけざん（ひっ算バージョン）」、R6「かけ算のひっ算」「かけ算」）とスライド「かけ算（ひっさん）マスターになろう」に合わせています。
  - 1の位のかけ算は **きいろ**、10の位のかけ算は **みどり** のマスに書きます。
  - くりあがりは、となりのマスの上に **小さく赤でメモ** してから、あとで足します。
  - 2けた×2けたの2だん目は、1の位の **✕のマスに 0** を書きます。最後に2つのだんを足します。

- 紙で練習する「カケルさまの ひっさん プリント」もあります（[print/README.md](print/README.md)）。

## できること

| 場面 | 内容 |
|---|---|
| はじまりの お話 | カケルさまが、まおうに かけ算の ちからを うばわれた お話をします（3まい）。 |
| キャラクターづくり | ◀ ▶ で しょくぎょう（4つ）→ すがた（3つ）を選びます。名前は名簿の名前です。 |
| はじまりの まち | 上から見た町です。建物を押すと中に入れます（下にも大きなボタンがあります）。とりもどした ほうせきが ふんすいに かざられ、町が だんだん明るくなります。 |
| ワールドマップ | 行きたい場所を押すと、なかまと道を歩いて行きます（矢印の操作はありません）。1つの場所が1つのレベルです。 |
| たたかい | 1つの場所で3回たたかいます（ざこ①・ざこ②・ぬし）。モンスター1ぴきは10問です（先生用画面で、かける数が1けたは3・5問、2けたは2・3・5問にも減らせます）。ひっ算を1問とくと1回こうげきします。まちがえても主人公はやられません。時間制限もありません。 |
| ギルド | カケルさまが、場所ごとに おてほんを といて見せます（1マスずつ説明して書く）。「ひっ算の やくそく」も見られます。 |
| しゅぎょうの ば | 計算に慣れるための練習です（下の表）。何回もすると「わざ」を覚えます。 |
| おみせ | ぶきや・ぼうぐや・どうぐや（各10こ、4段階のねだん）。ゴールドで買って そうびします。ぼうぐやは Lv1、どうぐやは Lv3 の ぬしを たおすと開きます。 |
| じぶんの いえ | つよさ（レベル・しょうごう・けいけんち・そうび・わざ）、なかま（9人）、モンスターずかん（30たい）、しゅぎょうの きろく、すがたの きがえ。 |
| やどや | きょうの がんばり（といた数・けいけんち・ゴールド）。「やすむ」で おわります。 |
| おしろ | とりもどした ほうせきの へや。お話をもう一度見られます。 |

### しゅぎょうの ば

| しゅぎょう | 内容 |
|---|---|
| 🎯 くくの まと | ひっ算の中で使う九九（1けた×1けた）。4つの まと から答えを選びます（10問）。 |
| 🪨 くりあがりの いし | くりあがりの たし算（例：18＋3）。4つの いし から答えを選びます（10問）。 |
| 🌾 かかし れんぞく | クリアした場所までのひっ算を つづけて とく（10問。先生が5問にもできます）。 |
| 🥋 にがての どうじょう | その子が まちがえた問題を もう一度出します（5問）。まちがえずに とけた問題は「にがて」から はずれます。 |

- 問題は、クリアした場所まで です。先生用画面で、子どもごとに はんいを決めることもできます。
- 5回すると、その しゅぎょうの「わざ」を覚えます。たたかいで ときどき わざの えんしゅつが出ます。

|---|---|---|---|
| じゅんび | はじまりの そうげん | 九九をひっ算の形で（1けた×1けた） | 6×3、8×6 |
| Lv1 | ささやきの もり | 2けた×1けた　くりあがり なし | 23×3 |
| Lv2 | みずうみの ほとり | 1の位で くりあがる | 27×3 |
| Lv3 | いわやまの どうくつ | 答えが3けた | 54×4、71×4、16×9 |
| Lv4 | すなかぜの さばく | くりあがって0になる | 34×3＝102、18×6 |
| Lv5 | こおりの たに | ×10・×何十（ざこ①は ×10） | 34×10、42×20 |
| Lv6 | ほのおの やま | ×11〜19 | 34×12、63×12 |
| Lv7 | くらやみの ぬま | 2けた×2けた（ざこ①は くりあがりの少ない問題） | 23×26、92×84、49×49 |
| ボス | まおうの しろ | まとめ（ざこ①は かける数が1けた、ざこ②・ぬしは2けた） | いろいろ |
| はってん | そらの しま | 3けた×1けた・3けた×2けた（先生が開く） | 123×4、214×32 |

- 前の場所の ぬし を たおすと、次の場所に行けます。先生用画面で「全部開く」こともできます。
- ぬしを はじめて たおすと、ほうせきが1つもどり、なかまが1人ふえます（9人まで）。
- まおうを たおすと、おわりの お話が出ます。そのあとも、何回でも たたかえます。

## 支援の工夫

- **スモールステップ**
  - 1マスずつ、右（1の位）から順に書きます。いま書くマスが光ります。
  - 右の「じゅもん」の まどに、いま計算する式（例：`7 × 3 ＋ 2 ＝ ？`）が出ます。かける数は、きいろ・みどり の色で、メモの数は赤で出ます。
  - かける数の きいろ・みどり、1だん目の きいろ、2だん目の みどり は、プリントと同じ色です。
  - くりあがりのメモの わくは、メモを書く番になってから出ます（くりあがりがあるかを先に見せないため）。
- **こたえかた**：画面の数字ボタン（1〜9・0）を押します。キーボードは使いません。
- **ヒントは3段階**
  1. ことば：「7 × 3 を けいさんしよう。そのあと メモの 2 を たすよ。こたえの 1の位の かずだけ かくよ。」
  2. 式と見本：計算に使う数のマスがピンクに光り、「7 × 3 ＝ 21」「21 ＋ 2 ＝ 23」が出ます。
  3. 答え：書くマスに答えがうすく出て、その数字のボタンが光ります。
  - 同じマスで2回まちがえるとヒントボタンが光り、3回まちがえると 3 のヒントが自動で出ます。
  - ヒントを使っても、ゴールドとけいけんちは同じだけもらえます。
- **まちがえたとき**
  - 小さな音が鳴り、押した数字のボタンは ✕ になって押せなくなります。
  - まちがい方に合わせて声かけをします。
    - くりあがりの たしわすれ（メモの数を足していない）：「おしい！ メモの 2 を たすのを わすれて いるよ。」
    - くらいの まちがい（21 の 2 を書いた）：「ここには こたえの 1の位の かずだけ かくよ。10の位は メモに しよう。」
    - 九九の まちがい：「7 × 3 を もういちど となえて みよう。」
    - 0の かきわすれ（✕のマス）：「2だんめは 10の位の かけ算。1の位には 0 を かこう。」
    - たし算の まちがい・たし算の くりあがり わすれ
- **なかまの声かけ**：たたかいでは、なかまが「くりあがりを メモ しよう！」「さいごは たし算だよ」などと声をかけます。
- **読み上げ**：カケルさまの ことばは、ブラウザの声で ゆっくり読みます。顔か 🔊 を押すと、もう一度聞けます。1マスごとの読み上げを止めることもできます（先生用画面）。
- **ごほうび**：1問とくごとに ゴールドと けいけんち。レベルが上がると しょうごう（みならい → かけだしの → いちにんまえの → ベテラン → えいゆう → ひっさんマスター）が変わります。モンスターずかん、なかま、ほうせき、わざ。
- **画面**：たたかいの画面は、左に場面、右に ひっ算と数字ボタンです。ひっ算の まわりは すっきりさせています。にぎやかな絵は、町・マップ・お店で使います。
- **つづきから**：たたかいの とちゅうで「にげる」を押しても、とけた問題は残ります。町に「▶ つづきから」が出ます。

## ファイル構成

```
kakezan/
├── index.html        アプリ本体（Apps Script の HTML ファイル「index」に貼り付けます）
├── コード.gs         Apps Script（シートの準備・記録の受け取り・先生用の集計・ドライブの絵）
├── data/data.js      場所・モンスター・しょくぎょう・おみせ・しゅぎょう・お話・プリントの問題（GitHub Pages から読みこみます）
├── e_chatgpt.md      ChatGPT で作る絵の注文書（ファイル名と、ChatGPT にわたす文）
├── img/              ChatGPT で作った絵（お店の品物30こ〈シートI〜L〉・しゅじんこう12まい〈シートA〉・カケルさま3まい〈シートB〉・モンスター30たい〈シートC・D・E〉・背景10まい〈シートF・G・H〉・はじまりの まち・ワールドマップ・タイトル・ロゴ・はじまりと おわりの おはなしの背景・たてものの なか8まい・まちの まわり）
├── tools/check.js    ひっ算の しくみと データの 点検（node kakezan/tools/check.js）
├── tools/split_sheet.py まとめて作った絵（シートA〜E）を1まいずつに切り分けて、白い背景を とうめいにする道具（モンスターは --each で1たいずつ大きく。白目などを残す絵は --keep=なまえ）
├── tools/split_bg.py  まとめて作った背景（シートF〜H）を、白いすき間で1まいずつに切り分ける道具
└── tools/test_gas.js コード.gs のテスト（node kakezan/tools/test_gas.js）
```

- 町・ワールドマップ・主人公・カケルさまは、絵がそろうまで自作の SVG で出ます。モンスターと品物は絵文字です。
- 町とワールドマップを ChatGPT の絵（`town`・`worldmap`）にするときは、絵の上の押す場所となかまの歩く道を `data/data.js` の `TOWN_SPOTS`・`MAP_SPOTS`・`MAP_VIA` で合わせます。この2まいは Claude に送ってください。
- 絵の置き場所は2つあります（くわしくは `e_chatgpt.md`）。
  - **Google ドライブの「ひっさんクエスト え」フォルダ**：決まったファイル名で入れるだけで、アプリが自動で読みこみます。一度読みこんだ絵は端末にも保存し、次からは すぐに出ます。
  - **GitHub の `img/`**：置いたら `data/data.js` の `IMAGES` にファイル名を足します。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/kakezan/` を開きます。
   - 「おためしモード」で動けば、データの公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「ひっさんクエスト 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `kakezan/index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. つづけて、関数の選択欄で **`checkImageFolder`** を選び、**▶ 実行** を押します。
   - 「Google ドライブの ファイルを見る」許可を求められるので、許可します（絵を読みこむためです）。
   - マイドライブに「**ひっさんクエスト え**」フォルダができます。
9. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
10. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
11. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
12. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届き、先生のドライブの絵も使えます。子どもにスプレッドシートやフォルダを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 2-2. 絵を入れる（ChatGPT で作った絵）

1. ChatGPT で絵を作ります。ChatGPT にわたす文とファイル名は `e_chatgpt.md` にあります。
   - 人物・モンスター・背景は、何まい分かを1まいにまとめて作れます（`e_chatgpt.md` の「0. まとめて作る」。人物とモンスターはシートA〜E、背景は4まいずつのシートF〜H）。**まとめた絵は Claude に送ってください。** 1人ずつに切り分けて `img/` に入れます。
2. 絵を、**`e_chatgpt.md` の表のファイル名** にします（例：`monster_kusadango.png`）。PNG・JPEG・WebP のどれでもかまいません。
3. Google ドライブの「**ひっさんクエスト え**」フォルダに入れます。
4. アプリを開き直すと、自動で読みこみます（デプロイし直す必要はありません）。
5. 先生用画面の「**絵**」で、どの絵がそろったか確かめられます。「🔄 ドライブの絵を よみこみなおす」で、すぐに読みこむこともできます。

- 同じ名前の絵を入れかえると、新しい絵に変わります。フォルダから消すと、自作の絵にもどります。
- 1まい 8MB より大きい絵は使いません。
- **町（`town`）とワールドマップ（`worldmap`）の絵だけは、ドライブに入れず Claude に送ってください。** 絵に合わせて押す場所と歩く道を決めてから入れます（ちがう並びの絵をドライブに入れると、押す場所がずれます）。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、ひっ算のマスが小さくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

子どもの画面の右上 🔒（名前を選ぶ画面では「🔒 せんせい用」）を押し、暗証番号を入れます。はじめの番号は **1234** です。最初に「せってい」で変えてください。

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの しょくぎょう・レベル・ほうせき・といた数・まちがえずに とけた割合・ヒント・ゴールド・よくある まちがい。クラス全体の 場所ごとの結果と、まちがいの しゅるい |
| 子どもごと | 場所ごとの結果（60%未満は赤、80%未満は黄色）、まちがいの しゅるい、**さいきん まちがえた問題**（どのマスで どの数を押したか。例：「1だんめ 10の位:5→8」）。「全部開く」「はってん（そらの しま）」、しゅぎょうの はんい、ゴールドを足す・へらす、しゅじんこうを作り直す、この子の記録を消す |
| せってい | 読み上げの速さ、文字の大きさ、モンスター1ぴきの問題数（かける数が1けた：3・5・10問、2けた：2・3・5・10問。はじめは どちらも10問）、かかし れんぞくの問題数（5・10問）、ヒントボタン（だす・ださない）、1マスごとの読み上げ（する・しない）、効果音、暗証番号 |
| データ | まだ送れていない記録を送る、CSVで書き出す、バックアップの保存と元にもどす、全員の記録を消す |
| 絵 | ドライブの絵のフォルダの名前と、読みこんだ絵の数。そろっている絵（緑：ドライブ、青：GitHub）と、まだない絵の一覧 |

## 全員の記録を見る

スプレッドシートの「きろく」シートに、1問とくごとに1行ずつ記録が届きます。

| 列 | 内容 |
|---|---|
| ばしょ | 「Lv2 みずうみの ほとり」など。しゅぎょうは「しゅぎょう」 |
| たたかい | ざこ ①・ざこ ②・ぬし。しゅぎょうは「くくの まと」など |
| もんだい | 27×3 など（くりあがりの いし は 18＋3 など） |
| こたえ | 正しい答え |
| けっか | ○＝まちがえずに とけた、△＝まちがえてから とけた |
| まちがい | まちがえて押した数 |
| ヒント | 使ったヒントの段階（0〜3） |
| まちがいの しゅるい | くくの まちがい・くりあがりの たしわすれ・くらいの まちがい・くりあがりの メモ・0の かきわすれ・たし算の まちがい・たし算の くりあがり わすれ |
| まちがえて いれた かず | 「1だんめ 10の位:5→8」のように、マスと、押した数→正しい数 |

- 「まとめ」シートは、先生用画面を開いたときか、メニュー **ひっさんクエスト → まとめを更新する** で作り直されます。子どもごと・場所ごとの結果が出ます。
- 子どもの名前は、呼び名かイニシャルで登録してください。

## 注意事項

- 記録は、先生のスプレッドシートとその端末のブラウザに保存されます。ネットにつながらないときは端末にためておき、つながったときに送り直します。
- 同じ子どもが別の Chromebook を使っても、スプレッドシートの進み具合から続きができます。
- 問題は、先生のプリント・スライドの問題（`data/data.js` の `POOL`）を半分ほど まぜて、のこりは同じ しゅるいの問題を自動で作ります。
- 町・マップ・人物・お話・音は、すべてこのアプリのためのオリジナルです（自作の SVG と絵文字）。
- ChatGPT で作る絵は、ユーザーが作ります。参考に見せてもらった市販のゲームの画面は ChatGPT に読みこませず、ジャンルの ふんいきだけを ことばで伝えます（`e_chatgpt.md`）。
