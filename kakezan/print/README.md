# カケルさまの ひっさん プリント（かけ算のひっ算）

かけ算のひっ算の学習アプリ「ケンジャの カケルさまの ひっさん クエスト」（[kakezan/](../README.md)）と同じ順番で練習する、紙のプリントです。
先生のワークシート（R6.5「かけざん（ひっ算バージョン）」、R6.7「かけ算のひっ算」、R6.6「かけ算」）と同じ書き方にしています。

- プリントを作るページ：`https://zku0395-ops.github.io/hori/kakezan/print/`
- できあがった PDF：`kakezan/print/pdf/` にあります（カラー・しろくろ・こたえ）
- 用紙は **A4たて**、**1まいに5もん** です。記録はとりません。

## できること

| 項目 | 内容 |
|---|---|
| れんしゅう | じゅんび・Lv1〜Lv7・まとめ（ボス）の9段階 × 各10まい（90まい） |
| まとめテスト | 5まい（1の位で くりあがる・0に なる・× 何十・× 11〜19・2けた × 2けた を1問ずつ） |
| 色 | カラー（1の位＝きいろ、10の位＝みどり、メモ＝赤）・しろくろ（きいろ＝うすい はいいろ、みどり＝こい はいいろ） |
| こたえ | すべてのプリントに、こたえのページがあります（答えとメモは 赤） |
| プリントの上 | 段階・その○、タイトル、カケルさま、がつ にち、ねん くみ、なまえ |
| できたかな？ | 3つの顔（にっこり・ふつう・うーん）に○をつけます |
| やりかた | 6ばんめの わくに、その段階の やりかたと おてほん（こたえ入り）があります |
| 名前 | PDF は ねん・くみ・名前の欄が空いています。作るページで入れると、入った形で印刷できます |
| 問題 | PDF は決まった問題です。「べつの もんだいに する」を押すと、新しい問題とこたえを作ります |

## ステージ構成

| 段階 | 内容 | マス |
|---|---|---|
| じゅんび | 九九を ひっ算の かたちで（R6.5 のワークシートと同じ形） | かける数・こたえ |
| Lv1 | 2けた × 1けた　くりあがり なし | メモの だん なし |
| Lv2 | 1の位で くりあがる | 10の位の上に メモ |
| Lv3 | こたえが 3けた | 同じ |
| Lv4 | くりあがって 0に なる | 同じ |
| Lv5 | × 10・× 何十（2問が × 10、3問が × 何十） | 1だんめ・2だんめ・たし算 |
| Lv6 | × 11〜19 | 同じ |
| Lv7 | 2けた × 2けた（2問は くりあがりが すくない問題） | 同じ |
| まとめ（ボス） | かける数が1けた 2問・2けた 3問 | 問題に合わせる |
| まとめテスト | 上のとおり5問 | 問題に合わせる |

- 問題は、アプリと同じ しくみで作っています。先生のワークシート・スライドの問題（27×3、34×3、23×26 など）も、半分ほど まぜています。

## 支援の工夫

- **ワークシートと同じ書き方**：点線の方眼マス、1の位は きいろ・10の位は みどり、答えの上に赤い線、2だんめの1の位は ✕（0）です。
- **くりあがりの メモ（R6.7 と同じ）**：10の位の上の小さな わくに、「かけ算の こたえ」と「くりあがり」の2つを メモし、たしてから書きます（27×3 なら「6　2」とメモして 8）。2けた × 2けたは、だん ごとに メモします。
- **メモの わくは 使うところだけ**：くりあがりの ない Lv1 には、メモの だんがありません。
- **やりかたと おてほん**：6ばんめの わくに、手順と、答えの入った おてほんがあります。
- **マスの大きさ**：2けた × 1けたは約1.4cm、じゅんびは約1.5cm、2けた × 2けたは約0.94cm です。
- ひらがなと分かち書きで書いています。漢字は「九九・算・位・何十」だけで、ふりがなを付けています。

## ファイル構成

```
kakezan/print/index.html          プリントを作るページ（印刷もここから）
kakezan/print/pdf/                できあがった PDF（どれも 95まい・同じ問題・同じ順番）
  かけざんひっさんプリント_1_カラー.pdf
  かけざんひっさんプリント_2_しろくろ.pdf
  かけざんひっさんプリント_3_こたえ.pdf
kakezan/print/tools/make-pdf.js   PDF を作り直すプログラム
```

- ページの順番：じゅんび＝1〜10、Lv1＝11〜20、Lv2＝21〜30、Lv3＝31〜40、Lv4＝41〜50、Lv5＝51〜60、Lv6＝61〜70、Lv7＝71〜80、まとめ（ボス）＝81〜90、まとめテスト＝91〜95ページ。
- 問題の作り方は、アプリの `kakezan/data/data.js`（先生の問題）と、アプリと同じ しくみを使っています。

## 公開の手順

### 1. GitHub Pages で公開する

- 変更を `main` に取り込む（Pull Request をマージする）と、数分後に `https://zku0395-ops.github.io/hori/kakezan/print/` で開けるようになります。
- Apps Script やスプレッドシートは使いません。

### 2. 印刷する

**PDF をそのまま使うとき**

1. 作るページの上にある「📄 カラー」「📄 しろくろ」「📄 こたえ」のボタンを押します。PDF が新しいタブで開きます。
2. 右上の印刷のアイコン（または Ctrl＋P）を押します。
3. 一部だけ印刷するときは、「ページ」で「カスタム」を選び、ページ番号を入れます（例：Lv3 だけなら「31-40」）。

**作るページから印刷するとき（名前入り・べつの問題）**

1. 「1. プリントを えらぶ」で、印刷したい段階にチェックを入れます。何まい目から何まい目までかを選べます。
2. 「🎨 カラー」か「⚫ しろくろ」を選びます。
3. ねん・くみ・名前を入れると、入った形で印刷されます。空けておくと、子どもが手で書けます。
4. こたえも印刷するときは「こたえの ページも つける」にチェックを入れます。
5. 「🖨 いんさつ する」を押します。
6. 印刷の画面で、用紙は「A4」、倍率は「100%（実際のサイズ）」、「背景のグラフィック」をオンにします。

- 「べつの もんだいに する」を押すと、PDF とはちがう問題になります。「もとの もんだいに もどす」で、PDF と同じ問題にもどります。

## 注意事項

- **絵**：カケルさまの絵は、アプリと同じ画像です（ChatGPT で作成）。マス・メモ・顔のしるしは、プログラムで描いています（オリジナル）。
- **問題**：アプリと同じ条件で作った問題に、先生のワークシート・スライドの問題をまぜています。
- **白黒で印刷するとき**：「しろくろ」の PDF を使ってください。きいろ・みどりのマスが、うすい はいいろ・こい はいいろになります。
- **使っているもの**：BIZ UDPゴシック（Google Fonts）をインターネット経由で読み込んでいます。
- **PDF を作り直すとき**：`node kakezan/print/tools/make-pdf.js` を動かします（Playwright と Chromium がいります）。

## これから相談して決めること

- はってん（3けた × 1けた・3けた × 2けた）のプリントを作るか
- テストに点数の欄・つまずきの○×の欄（かけ算・メモ・たし算）を入れるか
- じゅんびのプリントの問題数（いまは5問）を、R6.5 のように多くするか
