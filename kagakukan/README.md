# キラボと かがくかん たんけん（理科見学の事前学習アプリ）

特別支援学級の4年生が、理科見学で **多摩六都科学館** に行く前に使う事前学習アプリです。
ほしの たんけんロボ「キラボ」と、見学の日の予定、プラネタリウム、電気の体験、5つの展示室、館のやくそくを確かめます。
最後に「見たいもの・やってみたいもの ベスト3」を選んで理由を決め、当日持って行く「けんがく カード」を印刷します。

- 見学の日：2026年12月10日（木）
  - 10:00〜11:00　プラネタリウム（みんな）
  - 11:15〜12:00　Aはん：でんきの じっけん　／　Bはん：てんじしつ けんがく
  - 13:30〜14:15　Aはん：てんじしつ けんがく　／　Bはん：でんきの じっけん
- 形：Apps Script のウェブアプリ（形B）。データと絵は GitHub Pages から読みこみます。
- 公開先（おためし）：`https://zku0395-ops.github.io/hori/kagakukan/`

## できること

| こと | 内容 |
|---|---|
| 予定を知る | 見学の日の予定を表で見ます。時間を押すと読み上げます。A班・B班の両方をのせています。 |
| 見学先を知る | プラネタリウム・電気の体験・5つの展示室の 25こを、カードで1つずつ見ます。カードを押すと説明を読み上げます。 |
| 「みたい！」を選ぶ | 見たい・やってみたいカードに 💖 を付けます。 |
| クイズ | ステージごとに3〜5問。3つから選びます。ヒントは3段階です。 |
| ベスト3 | 💖 を付けたものから3つ選び、理由を選びます。 |
| けんがく カード | 名前・予定・ベスト3と理由・「じぶんの ことば」の欄・見学のあとの ふりかえり欄のある A4 のカードを印刷します。 |
| ごほうび | 正解で ⭐、ステージをクリアすると「たんけん パスポート」にスタンプ。⭐ の数で しょうごう（ほしの たまご → うちゅう たんけん マスター）が上がります。 |
| 先生用画面 | 進み具合・つまずいた問題・ベスト3・「みたい！」・学級の にんき ランキング・全員のカードの印刷・設定・データ。 |

## ステージ構成

| ステージ | 名前 | 見るもの | クイズ |
|---|---|---|---|
| 0 | けんがくの 日の よてい | 予定の表 | 5問（日にち・はじめに行く所・時間・A班の午前・B班の午後） |
| 1 | プラネタリウム | サイエンスエッグ・1億4000万この星・解説のおはなし・バーチャル月旅行 | 5問（太陽の動き〈3年のふり返り〉・星の色・星の並び方・月の形） |
| 2 | でんきの じっけん | 体験の予告と、3つのやくそく | 3問（やくそく） |
| 3 | チャレンジの へや | ムーンウォーカー・レインボーシャドー・ボールレース・かいてんブランコ | 4問「〜で できる ことは？」 |
| 4 | からだの へや | かおりあてクイズ・まぼろしのリンゴ・はんしゃしんけい・カプラひろば | 4問 |
| 5 | しくみの へや | ピアノのしくみ・ギアのかべ・リニアモーターカー・エレクトリックタウン | 4問 |
| 6 | しぜんの へや | こんちゅうのひょうほん・とりのはくせい・いきているさかな・むさしののぞうきばやし | 4問 |
| 7 | ちきゅうの へや | かせき・ひかるいし・いんせき・いしのベンチ | 4問 |
| 8 | かがくかんの やくそく | 5つのやくそく（ゆっくり歩く、プラネタリウムでは静かに、など） | 5問 |
| 9 | ベスト3と けんがく カード | 💖 から3つ選び、理由を選ぶ → カードを印刷 | − |

- 前のステージをクリアすると、次が開きます。先生用画面で「全部開く」にもできます。
- 1つのステージは5〜10分です。途中でやめても、つぎに開くと続きから始まります。
- プラネタリウムのクイズは、科学館の「学習投影（小4）」の内容に合わせています。
- 電気の体験は、館のホームページに内容がのっていないため、「とうじつの おたのしみ」として、やくそくだけを確かめます。

## 支援の工夫

- ひらがなと分かち書きが中心です。漢字は「多摩六都科学館」だけで、ふりがなを付けています。
- キラボのセリフは、少しゆっくり（0.8倍）読み上げます。キラボか「🔊 もういちど」を押すと聞き直せます。
- 問題の画面は白い背景にして、にぎやかな星空はホーム・クリア・パスポートだけにしています。
- 選択肢は3つです。まちがえやすい答えを入れています（例：太陽が「のぼる」と「しずむ」方向、午前と午後の入れかわり、ほかの部屋の展示）。
- まちがえた選択肢はうすくなり、もう押せません。まちがい方に合わせて声をかけます（例：「にしは たいようが しずむ ほうだよ」）。
- まちがえたときの音は、小さな やさしい音です。
- **ヒントは3段階** です。① ことば → ② 絵（太陽の通り道・星の色・月の形・予定の表・展示のカード）→ ③ 答えを光らせる。
  - 1回まちがえるとヒントボタンが光ります。選択肢が3つなので、2回まちがえると残りは答えだけになり、そのとき③のヒントが自動で出ます。
- ヒントを使っても、⭐ は同じようにもらえます。
- 時間制限はありません。
- 「みたい！」が3つより少ないときは、ベスト3の画面に全部のカードを並べます。
- ボタンは大きく、押すと沈む立体ボタンです。ドラッグは使いません。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリの画面（Apps Script の `index` に貼り付けます） |
| `コード.gs` | Apps Script（スプレッドシートへの記録・先生用のまとめ） |
| `data/kagakukan.js` | 予定・展示・クイズ・やくそく・理由（GitHub Pages から読みこみます） |
| `data/img.js` | `img/` にある絵の一覧 |
| `img/` | ChatGPT で作った絵（キラボ3まい・ホームの背景・プラネタリウムと部屋の絵6まい・展示25こ） |
| `e_chatgpt.md` | ChatGPT に絵を頼むときの文 |
| `tools/check.js` | データの点検（`node kagakukan/tools/check.js`） |
| `tools/test_gas.js` | `コード.gs` のテスト（`node kagakukan/tools/test_gas.js`） |

- `data/kagakukan.js` と絵は GitHub Pages から読みこむので、直しても Apps Script への貼り付けはいりません（`main` に入ると反映されます）。

### 絵（ChatGPT で作りました）

- 先生のパソコンの Claude が、`e_chatgpt.md` の文で ChatGPT に頼んで作りました。
- 展示の絵は、部屋ごとに1まいにまとめて作り、1こずつに切り分けました。白い背景はすかしてあります。
- もとの絵（PNG）は、ブランチ `claude/kagakukan-img` の `kagakukan/img/raw/` にあります（大きいので `main` には入れていません）。
- 絵を足したり替えたりしたら、`data/img.js` の一覧も直します。一覧にない絵や、読みこめない絵は、自作の絵と絵文字で出します。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/kagakukan/` を開きます。
   - 「おためしモード」で動けば、データの公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「かがくかん たんけん 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。
4. 画面の文字が小さいときは、先生用画面の「もじの おおきさ」で変えます。
5. けんがく カードを印刷するプリンターが使えるか確かめます。子どもの端末で印刷できないときは、先生用画面の「🖨 全員の けんがく カードを いんさつ」で、先生がまとめて印刷できます。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

名前を選ぶ画面の右下 **「🔒 せんせい」** を押し、4けたの暗証番号を入れます（はじめは `1234`。「せってい」で必ず変えてください）。

| タブ | できること |
|---|---|
| 📋 きろく | 子どもごとに、クリアしたステージ・クイズの結果（まちがえずにできた数／全部）・つまずいた問題・ベスト3と理由・「みたい！」が見られます。「全部開く」のチェック、子どもごとのカードの印刷、全員のカードの印刷ができます。下に、学級でつまずきが多い問題と、えらんだ まちがいの答えが出ます。 |
| 💖 にんき | 展示ごとの にんき ランキングです（ベスト3＝3点、みたい！＝1点）。当日まわる順番を決めるときに使えます。 |
| ⚙️ せってい | 見学の日・読み上げの速さ・文字の大きさ・効果音・暗証番号 |
| 💾 データ | まだ送れていない記録を送る・CSVで書き出す・バックアップ・バックアップから戻す・記録を消す |

- 見学の日を変えると、予定の表・クイズの答え・けんがく カードの日にちが変わります。曜日は自動で出ます。
- 時間（10:00〜 など）や、A班・B班の内容を変えるときは、`data/kagakukan.js` の `SCHEDULE` を直します（Claude に頼んでください）。

## 全員の記録を見る

- スプレッドシートの **「まとめ」** シートに、1人1行で、クリアしたステージ・クイズの結果・つまずいた問題・ベスト1〜3と理由・「みたい！」が出ます。その下に **にんき ランキング** が出ます。
  - 先生用画面を開くか、メニュー **かがくかん たんけん → まとめを更新する** で作り直されます。
- **「きろく」** シートには、1問ごとの記録（日時・名前・ステージ・問題・答え・○／△・まちがいの数・ヒント・えらんだ まちがい・秒）が入ります。ベスト3は、ステージ「9」の行に入ります。
- 送れなかった記録は端末にためておき、次に開いたときや、ネットにつながったときに送り直します。

## 注意事項

- 子どもの名前は、呼び名かイニシャルで登録してください。
- 展示の内容は、多摩六都科学館のホームページ（館内ガイド「チャレンジの部屋」「からだの部屋」「しくみの部屋」「自然の部屋」「地球の部屋」、プラネタリウム、学習投影の紹介）をもとに、子ども向けのことばで書き直したものです（2026年11月に確認）。展示は入れかわることがあります。見学の前に、館のホームページや下見で確かめてください。
  - 「ムーンウォーカー」には、身長110cm以上・体重22kg以上（70kg未満）の決まりがあります。
- 科学館の写真や、公式キャラクター「ペガロク」は使っていません。キラボはこのアプリのオリジナルのキャラクターです。絵は、ChatGPT で作ったオリジナルの絵（ことばだけで頼み、ほかの絵は読みこませていません）と、自作の絵（SVG）・絵文字です。
- 音は、このアプリのために作った音です。
