# ChatGPT に絵を頼むときの文（キラボと かがくかん たんけん）

## つかいかた

1. ChatGPT を開き、下の「はじめに 1回だけ はる文」を貼って送ります。
2. つぎに、作りたい絵の文（①〜④）を1つずつ貼って送ります。
3. できた絵を保存します（右クリック →「名前を付けて画像を保存」）。
4. 保存した絵を、このチャット（Claude）に貼ってください。
   - こちらで、切り分け・背景をすかす・名前を付ける・軽くする をして、アプリに入れます。
   - ファイル名を付けなくても大丈夫です。「キラボの にこにこ」「しぜんの へや」のように、どの絵かを書いてください。
5. 気に入らない絵は、「もっと やさしい顔に」「線を太く」のように ChatGPT に頼んで作り直します。

- 絵がそろうまでは、アプリの中の仮の絵（自作のキラボと絵文字）で動きます。全部そろえなくても使えます。
- おすすめの順番：① キラボ → ② ホームの背景 → ③ 部屋の絵 → ④ 展示の絵。
- 科学館の写真や、館の公式キャラクターを ChatGPT に読みこませないでください。ことばで頼みます。

## はじめに 1回だけ はる文

```
これから、小学校の特別支援学級の子ども（4年生）が、科学館の見学の前に使う学習アプリの絵を、何まいか続けて作ってもらいます。
次のルールを、すべての絵で守ってください。
・絵本のような、やさしい色の、子ども向けのイラスト。太めの、やわらかい線。
・こわくない、かわいい顔。
・既存のアニメ・ゲーム・キャラクター・会社の商品や、実在の科学館のキャラクターに似せない、オリジナルのデザイン。
・絵の中に、文字・数字・ロゴを入れない。
・キャラクターや ものの絵は、背景を真っ白（または透明）にして、切れないように入れる。
・すべての絵で、絵柄（線の太さ・色合い）をそろえる。
わかったら「OK」とだけ答えてください。
```

## ① キラボ（3まい）

```
アプリの案内役「キラボ」を描いてください。
・ほしの たんけんロボ。小さな子どもくらいの、まるっこい ロボット。
・あたまは 水色の まるい四角。顔の部分は こい青の画面で、目と口が 水色に 光っている。ほっぺが 少し ピンク。
・あたまの上に 1本の アンテナがあり、先に きいろい ほしが 付いている。
・からだは 水色で、むねに きいろい ほしの マーク。うでと あしは 青。
・正面を向いて、にっこり 立っている。全身。背景は真っ白。
```

つづけて：

```
同じキラボで、両手を上げて よろこんでいる絵を描いてください。目は にこっと 細く。背景は真っ白。
```

```
同じキラボで、片手を あごに当てて 考えている絵を描いてください。頭の横に きいろい「？」の形の光（文字ではなく形）。背景は真っ白。
```

→ アプリでの名前：`kirabo.webp`（ふつう）・`kirabo_happy.webp`（よろこぶ）・`kirabo_think.webp`（考える）

## ② ホームの背景（1まい・よこ長）

```
アプリのホーム画面の背景を描いてください。よこ長（16:9）。
・夜空と 星。下のほうに、大きな たまごの形の 白い ドームのある、未来的な 科学館の たてもの（実在の建物に似せない）。
・まわりに 木が少し。全体は こい青〜むらさきで、まん中の上のほうは 文字やボタンを置くので、すっきりと暗めに。
・キャラクターは入れない。
```

→ `home.webp`
