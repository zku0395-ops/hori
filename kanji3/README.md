# ポンタせんせいの かんじ ショッピングモール（3年生の漢字の読み書きアプリ）

小学校の特別支援学級向けの、3年生で習う漢字（200字）の読み書きの学習アプリです。
1年生の「かんじ マーケット」（[kanji1/](../kanji1/README.md)）、2年生の「かんじ デパート」（[kanji2/](../kanji2/README.md)）に続く **3号店** です。たぬきの店長「ポンタせんせい」と一緒に、文の中で使われる漢字の読みと書きを、スモールステップで練習します。

- 正解すると「せいかい！」の声とファンファーレが流れ、コインが1まいもらえます。
- コインは「おみせ」（ショッピングモール）で使えます。モールの地図から、10のお店（のりもの・たべもの・くだもの・やさい・ぶんぼうぐ・デザート・どうぶつ・うみの いきもの・はな・がっき）に入って、商品（全部で100種類）を買えます。
- 買ったものは「ずかん」に並びます。お店の商品を全部そろえると、称号（例：「がっき はかせ」）がもらえます。
- 3年生の国語で習う **部首（へんと つくり）** の名前を、⓪であう とヒントで知らせます。
- 画数の多い字（10画以上）は、**部品ごとに色分け** して見せます。
- 形は、1・2年生のアプリと同じ「Apps Script だけ」です。子どもは名簿の名前のボタンを押して始めます。
- 1・2年生のアプリとは別のアプリです。コイン・ずかん・記録・スプレッドシートは別になります。
- 問題のデータ・書き順のデータ・絵は、GitHub Pages（`https://zku0395-ops.github.io/hori/kanji3/`）から読みこみます。Apps Script に貼り付けるファイルを短くするためです。

## できること

| 項目 | 内容 |
|---|---|
| 漢字 | 3年生の漢字200字。なかまごとに5字ずつ、40ステージに分けています |
| 学習の段階 | 1つのステージは ⓪であう → ①よみを えらぶ → ③かんじを えらぶ → ②よみを かく → ④かんじを かく の順です（1・2年生のアプリと同じです） |
| 例文 | 1つの字に3つ（全部で600文）。分かち書きで、生活に近い文です。文には絵文字の絵をそえます |
| 読み | ふだんよく使う読みは、音読みと訓読みの両方を例文に入れています（例：「あさ [起]きる」「[起]立」）。あまり使わない読みは入れていません |
| 例文の中の漢字 | 1・2年生の字と、もう習った3年生の字は、漢字にしてふりがなを付けます。まだ習っていない3年生の字は、ひらがなにします。「びょう院」のような、漢字とひらがなが まざった ことばは使いません |
| 部首 | 163字に、部首の形と名前（例：氵 さんずい、扌 てへん、⺮ たけかんむり）を付けています。字そのものが部首の字（皿・豆・羊 など）や、むずかしい部首の字には付けていません |
| はってん | ①とくべつな よみかた（部屋・真っ赤・真っ青・八百屋）、②おくりがな（起きる・曲がる・美しい など12語）、③はんたいの いみの ことば（軽い⇔重い など8組）。最初は閉じています |
| 部品の色分け | 10画以上の字（92字）は、⓪であう と「なぞる」で、部品ごとに色を変えて見せます（例：館＝飠＋官）。先生用画面で「つかわない」にもできます |
| 書く練習 | なぞる → うすい みほん → みほん なし の3段階です。画の数・書き順・向き・だいたいの形を判定します。とめ・はね・はらいは見ません |
| ふくしゅう | 4ステージごとに「まとめ ふくしゅう」があります（全部で10回）。まちがえた字を多めに出します |
| ごほうび | 1問正解で1コイン（ヒントを使っても同じ）。ステージをクリアすると、ボーナスで5コイン。クリアしたステージは何回でもやり直せます |
| おみせ・ずかん | 10のお店 × 10種類＝100種類。値段は3〜20コインです。200字を全部学習すると、だいたい全部買えます |
| 声 | ポンタせんせいのセリフを読み上げます（はじめは0.8倍の速さ）。ポンタせんせいか「🔊 もういちど」を押すと、もう一度聞けます |
| 先生用画面 | 暗証番号4けたで開きます。記録の確認、設定、記録の送信、CSV書き出し、バックアップ、記録の消去ができます |
| 全員の記録 | 1問とくたびに、結果が先生のGoogleスプレッドシートへ届きます。進み具合・コイン・買ったものも、スプレッドシートに保存します |

- 「死」は、ステージ29「いのち」に入れました。例文は、子どもがこわくならない文にしています。
- 例文の一覧は [ichiran.md](ichiran.md) にあります。

1つのステージの進み方です（1回は5問ほど、5〜10分）。

| 段階 | 子どもがすること |
|---|---|
| ⓪ であう | 漢字が書き順どおりに出てきます。読みと例文を聞きます。部首の名前も聞きます。画数の多い字は、部品ごとに色が変わります |
| ① よみを えらぶ | 文の中の赤い字の読みを、4つの中から選びます |
| ③ かんじを えらぶ | 文の □ に入る漢字を、4つの中から選びます（□の上に読みが出ています） |
| ② よみを かく | 赤い字の読みだけを、ひらがなのマスに1文字ずつ書きます。1・2問目は なぞる、3・4問目は うすい みほん、5問目は みほん なし です |
| ④ かんじを かく | □ に入る漢字を、なぞる → うすい みほん → みほん なし の順に3回書きます。2字のことばでも、そのステージの1字だけを書きます |

- 「部屋（へや）」のような とくべつな読みの ことばは、①②の読みの問題だけで出します。③④では、1字の例文を使います。
- はってん②（おくりがな）は、⓪であう → 🖋おくりがなを えらぶ の2段階です。□ の上の読みを見て、送りがなまで正しい書き方を選びます。
- はってん③（はんたいの いみの ことば）は、⓪であう → ↔はんたいの ことばを えらぶ の2段階です。文の中の ことば（例：寒い）の はんたいの いみの ことばを、4つの中から選びます。選択肢には、同じ ことば（寒い）も入れています。
- 前の段階をクリアすると、次の段階が開きます。前のステージをクリアすると、次のステージが開きます。
- 途中でやめても、ホームの「▶ つづきから」で、のこりの問題から始められます。
- 書く練習の進め方（3段階／うすい→みほんなし／みほんなし だけ）は、先生用画面で変えられます。

## 支援の工夫

- **ヒントは3段階**です。同じ問題で2回まちがえるとヒントボタンが光り、3回まちがえると一番くわしいヒントが自動で出ます。

  | | えらぶ問題 | かく問題 | おくりがな | はんたいの ことば |
  |---|---|---|---|---|
  | 1段階目 | ことばで知らせる（例：「て（扌）で ゆびさす じ。… ぶしゅは『てへん』だよ」） | 「1かくめは よこ」のように、次の画を声で知らせる | 「おわりの ほうを よく きいてね」 | 「『さむい』と ぎゃくの ようすを かんがえて みよう」 |
  | 2段階目 | 絵を出す。読みの問題では「さいしょは『ゆ』」も出す | 次の画をオレンジの線で書いて見せる | 「おくりがなは 2もじ」 | 絵と「さいしょは『あ』」を出す |
  | 3段階目 | 正しい答えを光らせる | 書き順を全部見せてから、なぞる練習にする | 正しい答えを光らせる | 正しい答えを光らせる |

- **まちがいやすい答え**を選択肢に入れています。
  - 読み：同じ字のほかの読み（例：「起」の文で「お」と「き」）、形のにた字の読み、同じステージの字の読み。「は」と「ば」のように、てんてんだけがちがう読みは、まちがいの選択肢にしません
  - 漢字：形のにた字（例：「指」と「持」、「暑」と「暗」、「坂」と「板」）
  - とくべつな読み：1字ずつ読んだ読み（例：「部屋」で「ぶや」）
  - おくりがな：よくある書きまちがい（例：「美しい」で「美くしい」、「短い」で「短かい」）
  - はんたいの ことば：同じ ことば（例：「寒い」の はんたいで「寒い」）と、ほかの組の ことば
- **まちがえた選択肢は消えて**、残りから選び直せます。まちがい方に合わせた声かけをします（例：「『もつ』は『持』の よみかただよ。かたちが にて いるね」）。
- まちがえたときの音は、ブザーではなく小さな音です。時間制限はありません。
- **部首（へんと つくり）**
  - ⓪であう で、読みの下に「ぶしゅ：氵 さんずい」のように出し、「ぶしゅは さんずい だよ」と声でも知らせます。
  - 3年生の国語で習う「へんと つくり」と結びつけて、字の形と意味を覚えられるようにしています。
- **部品の色分け**（10画以上の92字）
  - ⓪であう で、字が部品ごとの色で書かれ、「飠 ＋ 官」のように部品を1つずつ見せます。「あかの『しょくへん』、あおの ぶぶんの じゅんに かくよ」と声でも知らせます。
  - ④かんじを かく の「なぞる」では、お手本の線が部品ごとの色になり、横に「ぶぶんの じゅん」が出ます。次の部品に進むと「つぎは あおの ぶぶんだよ」と知らせます。
  - 「うすい みほん」「みほん なし」では色分けしません。最後は自分の力で書けるようにするためです。
  - 部品の区切りは、KanjiVG の部品のデータによります。分かりにくい字（開・問・悲・館・勉）は、手で直しています。
- **絵**：ものの形が分かる字や、意味が絵で分かる字は、Canva で作った絵を出します。絵がない字は、例文の絵文字を出します。
- 書く練習では、書き始めの位置に **緑の丸と番号・向きの矢印** が出ます。向きが逆のときや、書く順番がちがうときは、声で知らせます。
- 問題の画面は背景をすっきりさせています。にぎやかな絵は、ホームとおみせだけで使います。
- 文字の大きさ・読み上げの速さ・効果音・書く判定のきびしさ・部品の色分けは、先生用画面で変えられます。

## ファイル構成

```
kanji3/index.html        アプリ本体（Apps Script の HTML ファイル「index」に貼り付けます）
kanji3/コード.gs          スプレッドシートとつなぐプログラム（Apps Script の「コード.gs」に貼り付けます）
kanji3/data/mondai.js    問題のデータ（漢字・読み・例文・部首・ステージ・はってん）
kanji3/data/strokes.js   書き順データと部品のデータ（KanjiVG より）
kanji3/img/              ポンタせんせい・背景・なりたちの絵（Canva で作成）
kanji3/ichiran.md        例文の一覧
kanji3/tools/check.js    問題データの点検（node kanji3/tools/check.js）
kanji3/tools/ichiran.js  例文の一覧を作る（node kanji3/tools/ichiran.js）
kanji3/tools/strokes.js  書き順データを作る（node kanji3/tools/strokes.js）
```

- `data/` と `img/` は、GitHub Pages から読みこみます。例文を直したときは、`data/mondai.js` を直して `main` に入れるだけで、Apps Script を貼り直さなくても全員の画面に反映されます。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/kanji3/` を開きます。
   - 「おためしモード」で動けば、問題のデータと絵の公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「かんじモール 記録」）。1・2年生のアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。
4. 1・2年生のアプリと両方使うときは、ブックマークの名前を「かんじマーケット（1年）」「かんじデパート（2年）」「かんじモール（3年）」のように分けておくと、まちがえにくくなります。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、書く練習がしにくくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

1. 名前を選ぶ画面の右下（学習中は右上）の **🔒** を押します。
2. 暗証番号（はじめは **1234**）を入れます。**最初に「せってい」で変えてください。**

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの クリアしたステージ数・コイン・解いた数・1回目正解の割合・最後に学習した日・つまずいている字。クラス全体の字ごとの結果（200字の表） |
| 子どもごと | 200字の表が、1回目正解の割合で色分けされます（赤60%未満／黄60〜79%／緑80%以上）。字を押すと、①〜④の段階ごとの結果と、よく選んだまちがいが出ます。つまずいている字と、にがてな段階も出ます |
| 子どもごと（ボタン） | 全部開く（その子だけ、すべてのステージを開く）、はってんを開く（①②③の全部）、コインを足す・引く、この子の記録を消す |
| せってい | 読み上げの速さ、文字の大きさ、効果音、書く判定のきびしさ（やさしい／ふつう）、書く練習の進め方、部品の色分け（つかう／つかわない）、暗証番号 |
| データ | まだ送れていない記録を送る、記録をCSVで書き出す、バックアップの保存と復元、全員の記録を消す |

- 設定は全員の画面に反映されます。子どもの画面は、開き直すと変わります。

## 全員の記録を見る

- スプレッドシートの **「きろく」** シートに、1問ごとの結果が入ります。

  | 日時 | なまえ | ステージ | だんかい | かんじ | もんだい | しゅるい | みほん | けっか | かいすう | まちがえた こたえ | ID |
  |---|---|---|---|---|---|---|---|---|---|---|---|

  - けっか：○＝1回目で、ヒントを使わずに正解　△＝まちがえてから、またはヒントを使って正解
  - みほん：書く問題のとき「なぞる／うすい／なし」
  - しゅるい：「よみを えらぶ」「かんじを えらぶ」「よみを かく」「かんじを かく」「おくりがな」「はんたい」
- **「まとめ」** シートに、子どもごと・字ごとの1回目正解の割合（低い順）が入ります。先生用画面を開いたとき、またはメニュー **ポンタ → まとめを更新する** で更新されます。
- **「名簿」** シートのB列に、進み具合・コイン・買ったものが入ります。ちがう Chromebook を使っても「つづきから」始められます。
- ネットが切れていたときの記録は、その Chromebook にためておき、つながったときに送り直します。同じ記録は二重に書きません。

## 注意事項

- **個人情報**：名簿には、呼び名かひらがなの名前だけを入れてください。
- **絵**：ポンタせんせい（モールの制服）・背景・なりたちの絵は、先生の Canva で、このアプリのために作った画像です。商品と例文の絵は絵文字です。
- **例文**：すべて、このアプリのためのオリジナルです。
- **書き順と部品のデータ**：[KanjiVG](https://kanjivg.tagaini.net/)（© Ulrich Apel ほか、CC BY-SA 3.0）を使っています。
- **ファンファーレ・効果音**：このアプリのためのオリジナルです（プログラムで作っています）。
- 問題のデータと絵は GitHub Pages から読みこむので、ネットにつながっている必要があります。
- 「データを よみこめませんでした」と出るときは、`https://zku0395-ops.github.io/hori/kanji3/` が開けるか確かめてください。
- 「止まった」「開かない」ときは、まず `index.html` の貼り付けが最後（`</html>`）まで入っているかを確かめてください。
