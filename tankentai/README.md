# ツバサせんせいの にっぽん たんけんたい（都道府県の調べ学習）

小学校の特別支援学級（3〜4年生が中心。2年生も使えます）向けの、都道府県の調べ学習のサイトです。
ツバメの「ツバサせんせい」といっしょに「たんけんたいいん」になって都道府県をたずね、説明カードを読んで調べたことを、**B4よこ 1まいの「しらべ しんぶん」** にまとめます。

- アプリ本体：`https://zku0395-ops.github.io/hori/tankentai/`
- いまたずねられるのは **東京都** です。ほかの道府県は、授業で使う順に1つずつ足していきます。
- 説明カードの写真は、Canva で作った実写風の画像です（すべて「イメージ」です）。

## できること

| 項目 | 内容 |
|---|---|
| 調べる項目 | 1つの都道府県に5つ。都庁（県庁）のある ところ・とくさんぶつ・おみやげ・かんこうめいしょ・はしって いる てつどう |
| 1回の流れ | よむ（説明カード4〜6まい）→ たしかめクイズ（2問）→ えらぶ（しんぶんに はる写真を1まい）→ かく（2つの文）。1項目5〜10分です |
| 文字 | ひらがなと分かち書きが中心です。漢字は地名などに使い、すべてにふりがなを付けています（先生用画面で消すこともできます） |
| 読み上げ | カードの文を、ツバサせんせいが少しゆっくり読み上げます。読んでいる文は黄色くなります |
| 文を書く | 文の形が決まっています。①「（写真の なまえ）は、（しらべた こと）。」②「（きもち）と おもいました。」 （　）の中は、ボタンで選びます。自分で書きたい子は、50音表で入れることもできます |
| しんぶん | B4よこ1まい。名前・日づけ、都道府県の場所に色をぬった日本地図、5つの項目のわく（写真と文）。印刷も、画面に大きく映すこともできます |
| ごほうび | 1項目できるとシール1まい。5項目ぜんぶできると、たんけん手帳の日本地図にスタンプ。たずねた都道府県の数で称号が上がります |
| 名簿 | 1台の Chromebook を何人かで使えます。子どもは、名簿にある自分の名前を押して始めます |
| 先生用画面 | 暗証番号4けた（はじめは `1234`）。記録・名簿・設定・データ |
| 全員の記録の一覧 | 項目ができるたびに、書いたシート（1まい1行）とクイズの結果が、先生のGoogleスプレッドシートへ届きます |

## ステージ構成

都道府県ごとに5つの項目があり、順番に開きます（先生用画面で「すべて開く」にもできます）。
東京都の内容は次のとおりです。

| 項目 | 説明カード | たしかめクイズ |
|---|---|---|
| 1 都庁の ある ところ（新宿区） | 東京都庁／新宿駅／新宿御苑／東京都の 島／東京都の 人の かず | 都庁が ある ところは？（新宿区・渋谷区・港区）／のりおりする 人が せかいで いちばん おおい えきは？ |
| 2 とくさんぶつ | こまつな／ねりまだいこん／とうきょう うど／あしたば／えどきりこ／えどふうりん | こまつなの なまえは どこから？（こまつがわ・こまつじま・こまつやま）／とうきょう うどは どこで そだてる？ |
| 3 おみやげ | にんぎょうやき／かみなりおこし／どらやき／くずもち／せんべい | にんぎょうやきの なかに はいって いるのは？／くずもちに かけて たべるのは？ |
| 4 かんこうめいしょ | 東京スカイツリー（634m）／東京タワー（333m）／浅草の かみなりもん／上野動物園／国会議事堂／お台場の レインボーブリッジ | スカイツリーの 高さは？（634m・333m・100m）／上野動物園は どんな どうぶつえん？ |
| 5 はしって いる てつどう | 山手線／ちかてつ／東海道新幹線／ゆりかもめ／都電荒川線／東京モノレール | 山手線の めじるしの いろは？（きみどり・オレンジ・あお）／うんてんする 人が のって いない でんしゃは？ |

- 1つの項目は「よむ → クイズ → えらぶ → かく」の順です。カードを全部見ると、クイズに進めます。
- 途中でやめても、次は「つづきから」始められます（読んでいたカード・クイズの問題から）。
- できた項目は、あとから「しゃしんと ぶんを なおす」で直せます。

## 支援の工夫

- **スモールステップ**：調べる → たしかめる → 選ぶ → 書く、を1項目ずつくり返します。5回でしんぶんができあがります。
- **カードの読み方**：写真を大きく出し、1まいに2〜3文だけにしています。「◀ まえ」「つぎ ▶」のボタンでめくります。まだ読んでいないカードは、下の ● が白いままです。
- **ヒントは3段階**（たしかめクイズ）
  1. ことば：「『こまつな』の カードを みて みよう。ばしょの なまえが かいて あるよ。」
  2. カード：答えが書いてあるカードを出し、答えのところに黄色い線を引きます。
  3. 答えを光らせる：答えのところと、正しいボタンが光ります。
  - 2回まちがえるとヒントボタンが光ります。
  - 選択肢には、まちがいやすい答え（東京タワーの高さ、ほかの路線の色、にている地名など）を入れています。まちがえた選択肢は消えます。音はブザーではなく、小さなやさしい音です。
- **📖 カードを みる**：クイズの途中でも、カードを見直せます（ヒントには数えません）。
- **書くことの支援**：文の形を決め、（　）の中をボタンで選ぶだけで、2つの文が書けます。選ぶと文を読み上げます。自分で書きたい子は「✏️ じぶんで かく」で50音表から入れます（「゛」「゜」「小さく」は、前の字に付けます）。
- **ごほうび**：ヒントを使っても、同じようにシールがもらえます。時間制限はありません。
- **画面**：問題の画面は背景をすっきりさせ、日本地図やスタンプなどのにぎやかな絵は、ホームとごほうびの画面だけにしています。ボタンは大きく、押すと沈む立体ボタンです。大事なボタンは、画面の下にいつも出ています。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（React と Babel を読み込んでいます） |
| `data/tokyo.js` | 東京都の説明カード・たしかめクイズ・文の形のデータ |
| `data/japan-map.js` | 日本地図（都道府県の形）のデータ |
| `img/tokyo/` | 東京都の説明カードの写真28まい（`tocho1.webp` など。800×600） |
| `gas/Code.gs` | Apps Script（入口ページと、記録の受け取り口） |
| `gas/start.html` | 入口ページ |
| `tools/make-map.py` | 日本地図のデータを作るプログラム（ふだんは使いません） |

### 道府県を足すとき（Claude に頼むときのメモ）

1. `data/tokyo.js` と同じ形で `data/<ローマ字>.js` を作ります（例：`data/osaka.js`）。`code` は都道府県の番号（大阪府なら `27`）です。
2. 写真を `img/<ローマ字>/<カードの id>.webp` に入れます。
3. `index.html` の `<script src="data/tokyo.js"></script>` の下に、新しいファイルの行を足します。
4. 地図の、その都道府県が光るようになります。
- カードやクイズの `id` は記録と結びついているので、あとから変えないでください。

## 公開の手順

### 1. GitHub Pages でアプリ本体を公開する

音読アプリと同じリポジトリの `tankentai` フォルダに入っています。

- 音読アプリの手順で GitHub Pages を公開していれば、変更を `main` に取り込む（Pull Request をマージする）だけで、数分後に `https://zku0395-ops.github.io/hori/tankentai/` で開けるようになります。
- まだ公開していないときは、リポジトリの `README.md` の「GitHub Pages でアプリ本体を公開する」を先に行ってください。

### 2. Apps Script とスプレッドシート（学校のアカウントで）

ほかのアプリとは**別のスプレッドシート**を使います。

1. 学校のGoogleアカウントで、新しい Google スプレッドシートを作ります（名前の例：「たんけんたい 記録」）。
2. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、`tankentai/gas/Code.gs` の内容を貼り付けます。
4. 左の「ファイル」の「＋」→「HTML」を選び、名前を `start` にします。中身をすべて消し、`tankentai/gas/start.html` の内容を貼り付けます。
5. 上の保存ボタン（💾）を押します。
6. 右上の「デプロイ」→「新しいデプロイ」を押します。
   - 左の歯車から種類「ウェブアプリ」を選びます。
   - 「次のユーザーとして実行」：**自分**
   - 「アクセスできるユーザー」：**全員**
7. 「デプロイ」を押します。アクセスの承認を求められたら、自分のアカウントを選んで「許可」します。
   - 「このアプリは Google で確認されていません」と出たときは、「詳細」→「（プロジェクト名）に移動」を押します。
8. 表示された「ウェブアプリ」のURL（`https://script.google.com/macros/s/…/exec`）を、Classroom などで子どもに配ります。
9. スプレッドシートを開き直すと、メニューに「ツバサせんせい」が出ます。

**貼り付けのしかた（GitHub から）**

1. GitHub で `tankentai/gas/Code.gs` を開き、右上の「Raw」を押します。
2. ブラウザーが「翻訳しますか？」と聞いてきたら「翻訳しない」を選びます。
3. Ctrl＋A（全部選ぶ）→ Ctrl＋C（コピー）を押します。
4. Apps Script で中身を全部消してから、Ctrl＋V で貼ります。
5. `start.html` も同じようにします。貼ったあと、いちばん下が `</html>` になっているか確かめます。

**大切なこと**

- 子どもは、配ったURL（入口ページ）の「はじめる」から開いてください。こうすると、記録の送り先と合言葉がアプリに自動で設定されます。
- アプリは新しいタブで開きます。開かないときは、ボタンの下に出る「このページで ひらく」を押してください。
- 一度設定されれば、次からは GitHub Pages のURLを直接開いても記録は届きます。
- `Code.gs` や `start.html` を書き換えたときは、「デプロイ」→「デプロイを管理」→ 鉛筆のアイコン →「バージョン：新バージョン」→「デプロイ」で更新します（URLは変わりません）。

### 3. Chromebook の準備（1台ずつ、最初に1回）

1. 入口ページの「はじめる」でアプリを開きます。
2. 最初の画面で、先生が次のことを行います。
   - 子どもの名前（呼び名・ひらがな）を、1人ずつ入れて「＋ 名簿に入れる」を押す（1台を何人かで使うときは、全員分を入れます）
   - 「🔊 声と音を確かめる」で、ツバサせんせいの声とファンファーレが聞こえるか確かめる
   - 「はじめる」を押す
3. 先生用画面（右上の「⚙️ せんせい」→ 暗証番号 `1234`）の「設定」で、暗証番号を変えます。
4. 「データ」タブで、送り先が「設定ずみ」になっているか確かめます。

**しんぶんの印刷**

- しんぶんの画面の「🖨️ いんさつ」を押します。
- 印刷の画面で、用紙サイズを「**B4**」、レイアウト（向き）を「**横**」、余白を「**なし**」にします。
- 「🔍 おおきく」を押すと、しんぶんが画面いっぱいに出ます（発表のときに、テレビやプロジェクターに映せます）。もう一度押すか、Esc キーでもどります。

### 4. Googleサイトに置くとき（必要なときだけ）

Googleサイトでは、入口ページを「埋め込む」で貼らずに、**「ボタン」**を使ってください。

- 埋め込むと、入口ページがGoogleサイトの枠の中に入ります。この枠の中からは、新しいタブを開くことが止められるため、「▶ はじめる」を押しても何も起きません。
- ボタンは、リンク先を新しいタブで開くので止められません。

**ボタンの置き方**

1. Googleサイトの編集画面で、右側の「挿入」→「ボタン」を押します。
2. 次のように入れて、「挿入」を押します。
   - 名前：例「▶ ツバサせんせいの にっぽん たんけんたい」
   - リンク：入口ページのURL（`https://script.google.com/macros/s/…/exec`）
3. 右上の「公開」を押します。

## 先生用画面

右上の「⚙️ せんせい」を押し、暗証番号を入れると開きます（はじめは `1234`）。

| タブ | できること |
|---|---|
| 📊 記録 | 一人ずつの進み具合（◎＝できた、△＝とちゅう）と、クイズで1回で正解した割合。**つまずいたクイズ**（全員分。まちがいが多い順。選んだまちがいの答えも出ます）。**書いたシート**（一人ずつ、項目ごとの写真・書いた文・クイズの結果）。「📰 しんぶんを見る・印刷」で、その子のしんぶんを開けます |
| 👥 名簿 | 名前を入れる・名前を変える・順番を変える・消す（消すと、その子の記録もこの端末から消えます） |
| 🛠️ 設定 | 下の表のとおり。暗証番号の変更もここでします |
| 💾 データ | スプレッドシートへの送信（状態・今すぐ送る・全部を送り直す）、CSV書き出し（シート・クイズの記録）、バックアップと元に戻す、記録の消去 |

### 設定

| 設定 | 内容 |
|---|---|
| ツバサせんせいの声 | あり／なし |
| 読み上げの速さ | とても ゆっくり（0.6）〜 はやめ（1.0）。はじめは「少し ゆっくり（0.8）」です |
| カードの自動読み上げ | する（はじめ）／しない（🔊ボタンを押したときだけ読みます）。自分で読む練習をするときは「しない」にします |
| ふりがな | つける／つけない |
| 文字の大きさ | ふつう／大きい／とても大きい |
| 効果音・ファンファーレ | あり／なし |
| 項目 | 順番に開く／すべて開く |

## 全員の記録を見る（先生のスプレッドシート）

| シート | 内容 |
|---|---|
| いちらん | 1人1行で、名前・称号・たずねた都道府県の数・シールの数・いま調べているところ・クイズで1回で正解した割合（赤＝50%未満、黄＝80%未満）・最後の学習日時を表示します |
| しんぶん | 1まいのしんぶん（子ども × 都道府県）が1行です。できた項目の数と、5つの項目ごとの「写真」と「書いた文」が入ります。項目ができるたびに、同じ行が新しい内容に書きかわります |
| きろく | クイズの1問ごとの結果です（日時・名前・都道府県・項目・問い・正しい答え・答えた内容・結果・まちがえた回数・ヒントの段階・かかった時間） |

記録について：

- 「いちらん」は記録が届くたびに作り直されます。手で書き込んだ内容は消えるので、メモは別のシートに書いてください。
- インターネットにつながっていないときの記録は端末にためておき、次につながったときに送ります。同じ記録が二重に書き込まれることはありません。
- 子どもは名前で区別します。名前は1人ずつ違うものにしてください（同じ子が2台の Chromebook で使うと、「しんぶん」の行はあとから送った内容になります）。

## 注意事項

- **データの保存場所**：名簿・進み具合・書いたシート・シール・設定は、そのChromebookのブラウザの中（localStorage と IndexedDB）に保存します。Chromeの閲覧データを消すと記録も消えるので、ときどき「バックアップ」で保存してください。
- **スプレッドシートへの送信**：送り先が設定されている場合は、名前と、書いたシート・クイズの結果だけを先生のスプレッドシート（Apps Script）に送ります。
- **読み上げ**：Chrome の音声合成を使います。日本語の声が入っていない端末では読み上げられません。
- **暗証番号を忘れたとき**：元にもどす機能はありません。Chromeの設定からこのサイトのデータを消すと最初からやり直せますが、記録も消えます。
- **教材の出典**：説明カードの文・クイズ・文の形は、すべてこのアプリのためのオリジナルです。内容は、2026年10月の時点で確かめました（人口・路線の数などは変わることがあります）。上野動物園のパンダは2026年1月に中国へ帰ったため、カードには入れていません。
- **写真**：説明カードの写真28まいは、先生の Canva で、このアプリのために作った実写風の画像です（Canva のデザイン「ツバサせんせい 東京都 しゃしん（書き出し用）」に保存しています）。本物の写真ではないので、画面としんぶんに「※しゃしんは イメージです」と書いています。建物や電車の細かいところ、看板の文字などは、本物とちがいます。
- **おみやげ**：会社の商品名は使わず、「にんぎょうやき」「かみなりおこし」のような、ものの名前にしています。
- **絵と音**：ツバサせんせいの絵とスタンプは、このアプリのための自作の絵（SVG）です。シールは絵文字です。ファンファーレの曲は、このアプリのためのオリジナルです（プログラムで作っています）。
- **日本地図**：Natural Earth（パブリックドメイン）の地図データを、このアプリ用に簡単にしたものです。小笠原諸島などの遠い島は省き、沖縄県は左上のわくに入れています。
- **使っているもの**：React と Babel（unpkg）、BIZ UDPゴシック（Google Fonts）をインターネット経由で読み込んでいます。

## これから相談して決めること

- 次に足す道府県と、その順番（47都道府県を全部作ると、写真は1,300まいほどになります）
- 県庁所在地の項目の名前（東京都は「都庁」、ほかは「県庁」「府庁」「道庁」）と、その項目で何を調べるか
- 写真の入れかえ（気に入らない写真は、Canva で作り直したり、先生が作った画像に入れかえたりできます）
- しんぶんに「いちばん すきな ところ」のわくを足すか
- 自分で書く文（50音表）を、①と②のほかにも書けるようにするか
- 説明カードの内容を増やすか（例：郷土料理、方言、有名な人）
