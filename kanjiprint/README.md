# ポンタせんせいの かんじ プリント（1・2・3年生の漢字の学習プリント）

小学校の特別支援学級向けの、漢字の **学習プリント** と **テスト** です。
1年生（80字）・2年生（160字）・3年生（200字）があります。

| 学年 | もとにした アプリ | PDF の 場所 |
|---|---|---|
| 1年生（80字） | 「ポンタせんせいの かんじ マーケット」（[kanji1/](../kanji1/README.md)） | `kanjiprint/pdf/` |
| 2年生（160字） | 「ポンタせんせいの かんじ デパート」（[kanji2/](../kanji2/README.md)） | `kanjiprint/pdf/2nen/` |
| 3年生（200字） | 「ポンタせんせいの かんじ ショッピングモール」（[kanji3/](../kanji3/README.md)） | `kanjiprint/pdf/3nen/` |

- アプリと同じステージ・同じ例文で作っています。
- プリントを作るページ：`https://zku0395-ops.github.io/hori/kanjiprint/`（2年生は `…/kanjiprint/?g=2`、3年生は `…/kanjiprint/?g=3`。ページの左上の「がくねん」でも切りかえられます）
- できあがった PDF：ステージごとに1つのファイルです。全部をまとめた「ぜんぶ」もあります。
- 用紙は **A4よこ**、文は **たて書き** です。

## できること

| 項目 | 内容 |
|---|---|
| 学習プリント | 1まいに2字です。ステージ（5字）ごとに3まいで、2字・2字・1字＋ふくしゅう です（全部で48まい） |
| 1字ぶんの中身 | 大きな見本の字、かきじゅん（1画ずつ増える字。新しい画は赤）、よみかた（おん・くん。送りがなは赤）、なぞり書き3つ、「かいて みよう」のマス、ミニテスト（よみを かこう2問・かんじを かこう2問） |
| 見本の字 | 画の番号と、書きはじめの位置（○の番号）を付けています。「とめ」「はね」「はらい」「ながく」「みじかく」の注意を赤い印で入れています（1字に1〜2か所） |
| 音読みと訓読み | 音読みと訓読みの両方がある字は、ミニテストの「よみ」と「かんじ」に、両方の読みの文を入れています |
| ふくしゅう | 3まいめの左半分です。そのステージの5字の よみ5問・かんじ5問 です |
| まとめテスト | ステージごとに1まい（全部で16まい）。よみ5問・かんじ5問で、1問10点です。「／100てん」の欄があります |
| こたえ | ステージごとに1まい。学習プリント・ふくしゅう・まとめテストの答えを、文で並べています（答えは赤） |
| 欄 | どのプリントにも「がつ・にち・なまえ」があります |
| 絵 | ポンタせんせいの小さな絵（アプリと同じ絵）です |

### 2年生のプリントで ちがうところ

1まいの形（2字・2字・1字＋ふくしゅう、まとめテスト、こたえ）は1年生と同じです。次のところが ちがいます。

| 項目 | 内容 |
|---|---|
| 部品の色分け | **10画以上の字**（曜・顔・親 など）は、見本の字を部品ごとに色分けしています（赤・青・緑・むらさき）。見本の下の「ぶぶん」の欄に、部品を番号つきで ならべています（例：①日 ＋ ②⺕⺕ ＋ ③隹）。部品は アプリと同じ KanjiVG の部品です |
| かきじゅん | 画の多い字は、小さなマスを2〜3だんに おりかえして、**全部の画** を出しています（8画までは1だん4マス、9画からは1だん6マス） |
| よみかた | 「おん」「くん」を よこに ならべています（送りがなは赤） |
| まとめ ふくしゅうテスト | **4ステージごとに1まい**（全部で8まい）。その20字から、よみ5問・かんじ5問です（1問10点・100点）。ステージの まとめテストとは ちがう文を えらんでいます。こたえも1まい つけています |
| はってん | アプリの「はってん」と同じ内容です。①とくべつな よみかた（今日・明日・兄さん・姉さん・今年・今朝・時計）1まい、②おくりがな（明るい・少ない・新しい など12語）2まい、こたえ1まい。右に「おぼえよう」、左に問題です |
| 絵 | ポンタせんせいの絵は、2年生のアプリ（デパートの制服）の絵です |

### 3年生のプリントで ちがうところ

1まいの形と、部品の色分け・かきじゅん・まとめ ふくしゅうテストは、2年生と同じです。次のところが ちがいます。

| 項目 | 内容 |
|---|---|
| 部首 | 見本の字の下に「ぶしゅ」の欄があります。部首の形と名前を出します（例：ぶしゅ 氵 さんずい）。部首のデータは アプリと同じです（163字。部首の欄が ない字もあります）。9画以下の字は、見本の字に色を付けません |
| なりたちの絵 | アプリで なりたちの絵がある30字（皿 豆 歯 鼻 指 羊 島 橋 駅 港 湖 畑 箱 笛 筆 柱 氷 坂 波 岸 庭 球 宮 薬 葉 根 炭 湯 皮 面）は、なぞりがきの下に、小さな絵を出します |
| まとめ ふくしゅうテスト | 4ステージごとに1まい（全部で10まい）。部首の問題は入れていません |
| はってん | ①とくべつな よみかた（部屋・真っ赤・真っ青・八百屋）1まい、②おくりがな（12語）2まい、③**はんたいの いみの ことば**（8組）1まい、こたえ1まい |
| はんたいの いみの ことば | 右の「おぼえよう」に、ことばの組（例：軽い ⇕ 重い）を絵と いっしょに ならべています。左の問題は、文の中の ことば（赤い線）の はんたいの ことばを書きます。書く字の読み（例：おもい）を小さく付けています。漢字はマスに、送りがなは わくに書きます |
| 絵 | ポンタせんせいの絵は、3年生のアプリ（モールの制服）の絵です |

## 支援の工夫

- **なぞり書き** は、こい字 → うすい字 → もっとうすい字 の3つです。最初のマスには画の番号も入れています。アプリの「なぞる → うすい みほん → みほん なし」と同じ流れです。
- 読みの問題は、問題の字の左に赤い線を引き、右に答えを書くわくを付けています。わくの長さは、答えの文字の数に合わせています。
- 漢字の問題は、十字の点線のマスに書きます。マスの右に、読みを小さく書いています。
- 文は分かち書きで、ほかの漢字にはすべてふりがなを付けています。習った漢字だけを使っています（アプリと同じ例文）。
- 読みを書くわくが、となりの列の字や ふりがなに重ならないように、列のはばを広くとり、ふりがなの前後にはすきまを空けています。
- 「竹林」「女の子」「十円」のように、問題の字と同じことばの中にある字の ふりがなが わくに かかるときは、その ふりがなを字の **左** に出しています。字と字のあいだを空けないので、ことばが2つに分かれて見えません。
- 答えを書くわくとマスは大きくしています。

  | | 読みを書くわく（1字ぶん） | 漢字を書くマス |
  |---|---|---|
  | 学習プリントのミニテスト | 約11mm | 約16mm角 |
  | ふくしゅう（10問） | 約6.8mm | 約9.6mm角 |
  | まとめテスト | 約13mm | 約19mm角 |

- 問題の文字は、学習プリントで1字およそ7mm、まとめテストで8.4mmです。「よみを かこう」「かんじを かこう」の見出しは、問題の上に よこ書きで出しています。

## ファイル構成

```
kanjiprint/index.html          プリントを作るページ（1・2・3年生。?g=2 で2年生、?g=3 で3年生）
kanjiprint/data/print.js       1年生のプリント用のデータ（よみかた・とめはねはらい・音読み・プリント用の例文）
kanjiprint/data/print2.js      2年生のプリント用のデータ（同じ形）
kanjiprint/data/print3.js      3年生のプリント用のデータ（同じ形）
kanjiprint/pdf/                1年生の PDF（ステージごと16ファイル ＋ ぜんぶ）
kanjiprint/pdf/2nen/           2年生の PDF（ステージごと32ファイル ＋ まとめふくしゅう8ファイル ＋ はってん ＋ ぜんぶ）
kanjiprint/pdf/3nen/           3年生の PDF（ステージごと40ファイル ＋ まとめふくしゅう10ファイル ＋ はってん ＋ ぜんぶ）
kanjiprint/tools/make-pdf.js   PDF を作るプログラム
```

- 例文と書き順のデータは、アプリの `kanji1/data/`（1年生）、`kanji2/data/`（2年生。部品のデータも）、`kanji3/data/`（3年生。部品・部首のデータも）を使います。なりたちの絵は `kanji3/img/n/` の絵です。
- アプリの例文を直したら、PDF も作り直してください。
  - `node kanjiprint/tools/make-pdf.js` … 1・2・3年生の全部
  - `node kanjiprint/tools/make-pdf.js 3` … 3年生だけ（`1` なら1年生だけ、`2` なら2年生だけ）

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入ると、`https://zku0395-ops.github.io/hori/kanjiprint/` で開けます。
2. ページの上の「できあがった PDF」から、PDF を保存できます。

### 2. Apps Script とスプレッドシート

- このプリントは記録をとらないので、Apps Script とスプレッドシートは使いません。

### 3. 印刷のしかた

1. 印刷したいステージの PDF を開きます。
2. 印刷の画面で、次のようにします。
   - 用紙サイズ：**A4**
   - 向き：**横**
   - 倍率：**100%**（「実際のサイズ」）
3. カラーで作っていますが、白黒で印刷しても読めます。

- プリントを作るページで印刷するときは、ステージを選んで「🖨 いんさつ」を押します。余白は「なし」にしてください。

### 4. Googleサイトに置くとき

- 「ボタン」を置き、リンクに PDF かプリントを作るページのURLを入れてください。

## 注意事項

- **例文**：アプリと同じ、このアプリのためのオリジナルの文です。プリント用に足した文（音読みの問題など）も、オリジナルです。
- **書き順のデータ**：[KanjiVG](https://kanjivg.tagaini.net/)（© Ulrich Apel ほか、CC BY-SA 3.0）を使っています。見本の字は、このデータの線で書いているので、教科書の字の形と少しちがうところがあります。
- **とめ・はね・はらいの印**：1字に1〜2か所、作った人が選んで付けたものです。指導のときは、教科書でも確かめてください。
- **絵**：ポンタせんせいの絵と、3年生の なりたちの絵は、アプリのために Canva で作った絵です。
- **2年生のプリント用の例文**：アプリの例文に ない ほうの読みを問題にするため、5つの文を足しています（馬車・昼食・売店・草原・明かり）。どれもオリジナルの文で、習った漢字だけを使っています。
- **部品の色分け**：KanjiVG の部品の分け方を使っています。教科書の部品の分け方と ちがうことがあります。
- **3年生のプリント用の例文**：アプリの例文に ない ほうの読みを問題にするため、4つの文を足しています（暑中みまい・面白い・全く・人気者）。どれもオリジナルの文で、そのステージまでに習った漢字だけを使っています。
- **3年生の よみかた**：見本の「よみかた」には、小学校で習う読みだけを出しています（中学校で習う読みは出していません）。
- **3年生の とめ・はね・はらいの印**：1字に1〜2か所、作った人が選んで付けたものです（「品」は付けていません）。「送」の6画目、「委」の5画目のように、ほかの部分と組み合わさって形が かわる画（はらい→とめ）にも印を付けています。指導のときは、教科書でも確かめてください。
- **部首の字の形**：部首の欄の字（扌・⺮ など）は、パソコンの文字です。教科書の形と少しちがうことがあります。
- 音読みが1年生でほとんど使われない字（雨・夕・川・目・口・貝・糸・玉・青・赤）は、訓読みだけで問題を作っています。訓読みがほとんど使われない字（王・百・千・学・校・文・字・本・気・円）は、音読みだけで問題を作っています。

## これから相談して決めること

- 音読みの問題を足す字（例：青の「せい」、赤の「せき」、目の「もく」）
- こたえを書きこんだ「こたえの プリント」を作るか
- 2年生：画の少ない字（9画以下）も、部品で色分けするか
- 2年生：まとめ ふくしゅうテストを、1ステージずつの まとめテストより 問題を多くするか（いまは10問）
- 3年生：音読みの問題を足す字（例：植の「しょく」、返の「へん」、湖の「こ」。いまは まだ習っていない字を使わないと文が作れないため、入れていません）
- 3年生：部首の問題（「ぶしゅは どれ？」）を、まとめ ふくしゅうテストや はってんに入れるか
- 3年生：なりたちの絵を ふやすか（いまは30字）
