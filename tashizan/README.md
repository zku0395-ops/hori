# たしざん ひっさん クエスト（たし算のひっ算の学習アプリ）

小学校の特別支援学級向けの、たし算のひっ算（2けたまで。くりあがりあり、答えが3けたの問題もあります）の学習アプリです。
まほうつかいになって ぼうけんの ちずを進み、ひっ算を1問とくごとに モンスターに こうげきします。
レベルを上げながら、コインと たからものを集めます。

- いまは **試作中** です。GitHub Pages だけで動き、記録はその端末の中だけに残ります。
- 形が固まったら、Apps Script にうつして、名前で始める形とスプレッドシートへの記録にする予定です（先生と確認ずみ）。

## できること

| 項目 | 内容 |
|---|---|
| 学習内容 | 2けた＋1けた から、答えが3けたになる 2けた＋2けた まで（下の表） |
| 問題 | アプリが毎回ちがう問題を作ります。1回の中で同じ問題は出しません |
| 進め方 | 1ステージ10問です。10問とくとモンスターをたおし、次のステージが開きます |
| 答え方 | 光る□に、画面の数字ボタン（0〜9）で入れます。一のくらい → くりあがりの小さい□ → 十のくらい → 百のくらい の順に光ります |
| ごほうび | 1問ごとにコイン10まいと経験値10。モンスターをたおすと たからばこ（はじめては たからもの、ボーナスのコイン30まい、ボスは60まい）。経験値50ごとにレベルアップ |
| まち | 「まちの そとへ」（ちず）、「あなたの いえ」（もちもの・レベル）、「おみせ」（コインで買い物）、「たからの へや」 |
| 文字 | ひらがな中心です。「一・十・百」には すべて ふりがなを付けています |

## 支援の工夫

- くりあがりの小さい□は、たす数（下の段）の十のくらいの右下、横線のすぐ上にあります。くりあがりのないステージでは出しません。
- 百のくらいへの くりあがりは、小さい□を使わず、答えの百のくらいに直接 1 を入れます。
- 「💡 ヒント」を押すと、いまの くらいの数だけ丸が出ます（上の数＝赤、下の数＝青、くりあがり＝黄）。丸を押すと番号がつき、一緒に数えられます。
- まちがえても減点はありません。2回まちがえると、ヒントのボタンが光ります。
- まちがえたときの音は、小さく低い音です。
- 時間制限はありません。

## これから相談して決めること

1. 絵
   - いまの絵は、チャットに貼った小さい画像（横549ピクセル）から作った **仮のもの** です。Canva から元の大きさの画像をダウンロードしてファイルで送ってもらい、同じ名前で入れかえます。
   - モンスターの絵は、このままで使う（先生確認ずみ）。様子を見て、こわがる子がいたら作り直す。
   - まちの背景が暗め。明るい昼間の色で作り直すか。
2. ごほうびの量：10問になったので、1ステージでコイン100まい＋ボーナス、レベルが2回上がる。値段やレベルの上がり方を変えるか。
3. ひっ算の答え方：百のくらいへの くりあがりの入れ方、くりあがりのないステージで小さい□を出さないこと、ヒントが数字を1つ入れるたびに閉じること、丸の番号のしくみ。このままでよいか。
4. ちずの移動：いまは「丸をタップして歩く」形。上下左右に自由に歩く形にするか。
5. ほかのアプリと同じ しくみ を足すか：キャラクターのセリフの読み上げ、ヒント3段階（3回まちがえると自動で出る）、まちがえた答えに合わせた声かけ、先生用画面（暗証番号・記録・設定）、つづきから。
6. Apps Script にうつす（名前で始める、スプレッドシートに記録）。
