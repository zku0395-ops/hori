# たしざん ひっさん クエスト（たし算のひっ算の学習アプリ）

小学校の特別支援学級向けの、たし算のひっ算（2けたまで。くりあがりあり、答えが3けたの問題もあります）の学習アプリです。
まほうつかいになって ぼうけんの ちずを進み、ひっ算を1問とくごとに モンスターに こうげきします。
レベルを上げながら、コインと たからものを集めます。

- Apps Script のウェブアプリとして動かします。子どもは名前のボタンを押して始め、記録は先生のスプレッドシートに届きます。
- 絵は GitHub Pages から読みこみます。
- 同じ順番で練習できる紙のプリント（A4たて、PDF）もあります：[tashizan/print/README.md](print/README.md)
- GitHub Pages のページ（`https://zku0395-ops.github.io/hori/tashizan/`）をそのまま開くと、「おためしモード」で動きます。名前は選ばず、記録はその端末の中だけに残ります。

## できること

| 項目 | 内容 |
|---|---|
| 学習内容 | 2けた＋1けた から、答えが3けたになる 2けた＋2けた まで（下の表） |
| 問題 | アプリが毎回ちがう問題を作ります。1回の中で同じ問題は出しません |
| 進め方 | 1ステージ10問です。10問とくとモンスターをたおし、次のステージが開きます |
| 答え方 | 光る□に、画面の数字ボタン（0〜9）で入れます。一のくらい → くりあがりの小さい□ → 十のくらい → 百のくらい の順に光ります |
| ごほうび | 1問ごとにコイン5まいと経験値10。モンスターをたおすと たからばこ（はじめては たからもの、ボーナスのコイン30まい、ボスは60まい）。経験値100ごと（10問ごと）にレベルアップ |
| 主人公 | ゆうしゃ・しょうにん・まほうつかい・かくとうか の、男性4人と女性4人（あわせて8人）から選びます。画面には「おとこ・おんな」の文字は出さず、絵を見て選びます。はじめて開いたときに選び、「あなたの いえ」の「しゅじんこうを かえる」で いつでも変えられます。ちがうのは、見た目と こうげきの ことばだけです（問題と ごほうびは同じ） |
| おみせ | 品物は50こです。「そうび・どうぐ・たべもの・なかま・のりもの」の5つのボタンで切りかえます（10〜500まい）。買った品物は「あなたの いえ」の もちものに、なかまごとに ならびます |
| まち | 「まちの そとへ」（ちず）、「あなたの いえ」（もちもの・レベル）、「おみせ」（コインで買い物）、「たからの へや」 |
| 先生用画面 | 暗証番号4けたで開きます。子どもごとの記録の確認、設定、CSV書き出しができます |
| 全員の記録 | 1問とくたびに、結果が先生のスプレッドシートへ自動で届きます。どの Chromebook で開いても、名前を押せば つづきから始められます |
| 文字 | ひらがな中心です。「一・十・百」には すべて ふりがなを付けています |
| 声 | メッセージ・ヒント・ちずの説明・ごほうびの画面を読み上げます（0.85倍の速さ）。メッセージや主人公、ちずの説明を押すと、もう一度聞けます。上の 🔊／🔇 で、効果音と一緒に消せます |

## 支援の工夫

- くりあがりの小さい□は、たす数（下の段）の十のくらいの右下、横線のすぐ上にあります。くりあがりのないステージでは出しません。
- 百のくらいへの くりあがりは、小さい□を使わず、答えの百のくらいに直接 1 を入れます。
- 「💡 ヒント」を押すと、いまの くらいの数だけ丸が出ます（上の数＝赤、下の数＝青、くりあがり＝黄）。丸を押すと番号がつき、一緒に数えられます。
- まちがえても減点はありません。
  - 2回まちがえると、ヒントのボタンが光ります。
  - 3回まちがえると、ヒントが自動で出ます。丸に1つずつ番号がつき、声で「ぜんぶで ○」と一緒に数えます（くりあがりの1や百のくらいでは、答えの書き方を読み上げます）。
- まちがえたときの音は、小さく低い音です。
- 時間制限はありません。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/tashizan/` を開きます。
   - 「おためしモード」で動き、絵が出れば、絵の公開はできています（このページでは、記録はスプレッドシートに届きません）。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「たし算ひっ算 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、ひっ算や数字ボタンが小さくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

画面の右上の 🔒 を押し、暗証番号（4けた）を入れると開きます。はじめの番号は **1234** です。最初に「設定」で変えてください。

| タブ | できること |
|---|---|
| 記録 | 上の名前のボタンで子どもを選びます。ステージごとに、とけた問題の数、まちがえた問題の数、**どの位でまちがえたか**（一の位・くりあがり・十の位・百の位）、ヒントを使った回数が分かります。いちばん まちがいが多い位は、赤くなります。2回以上まちがえた問題は、「つまずいた問題」に式と一緒に出ます |
| 設定 | 読み上げの速さ（5段階）、文字の大きさ（ふつう・おおきい）、ステージ（じゅんばんに開く・ぜんぶ開く）、暗証番号の変更。全員に共通で、「せってい」シートに保存します |
| データ | 全員の記録のCSV書き出し、えらんだ子（または全員）の記録とゲームの消去 |

- 暗証番号を忘れたときは、スプレッドシートの「せってい」シートの「暗証番号」の右の ます を見ます。そこで書きかえることもできます。
- おためしモード（GitHub Pages のページ）の先生用画面では、その端末の中の記録を見ます。バックアップの保存と もどす もできます。

## 全員の記録を見る

スプレッドシートを開きます。

| シート | 内容 |
|---|---|
| 名簿 | A列が名前、B列が進み具合（コイン・レベル・クリア・たから・主人公）。B列は さわりません |
| きろく | 1問につき1行。日時・なまえ・ステージ・もんだい・こたえ・位ごとの まちがいの回数・ヒント・じどうヒント・ID |
| まとめ | 子どもごと・ステージごとの、とけた問題の数、まちがえずに とけた わりあい（赤：60%未満、黄：60〜79%、緑：80%以上）、位ごとの まちがいの回数 |
| せってい | 暗証番号、読み上げの速さ、文字の大きさ、ステージ |

- 「まとめ」は、先生用画面を開いたときか、スプレッドシートのメニュー **たしざん → まとめを更新する** で作り直します。
- ネットにつながらず 送れなかった記録は、Chromebook の中にためておき、つながったときや 次に開いたときに送り直します。画面の右上に「☁️ ほぞん ずみ」と出ていれば、届いています。
- 「きろく」シートの見出しと「ID」の列は、変えないでください。

## 注意事項

- 記録は、先生のスプレッドシートにだけ送ります。おためしモードでは、ブラウザの中（localStorage の `tashizanHissanQuest_v1`）にだけ保存します。
- 子どもの名前は、呼び名を ひらがな で入れてください。
- 絵は、先生が Canva と ChatGPT の AI で作ったオリジナルです。問題とことばは、このアプリのためのオリジナルです。
