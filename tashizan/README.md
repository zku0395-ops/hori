# たしざん ひっさん クエスト（たし算のひっ算の学習アプリ）

小学校の特別支援学級向けの、たし算のひっ算（2けたまで。くりあがりあり、答えが3けたの問題もあります）の学習アプリです。
まほうつかいになって ぼうけんの ちずを進み、ひっ算を1問とくごとに モンスターに こうげきします。
レベルを上げながら、コインと たからものを集めます。

- いまは **試作中** です。GitHub Pages だけで動き、記録はその端末の中だけに残ります。
- 形が固まったら、Apps Script にうつして、名前で始める形とスプレッドシートへの記録にする予定です（先生と確認ずみ）。

## できること

| 項目 | 内容 |
|---|---|
| 学習内容 | 2けた＋1けた から、答えが3けたになる 2けた＋2けた まで（下の表） |
| 問題 | アプリが毎回ちがう問題を作ります。1回の中で同じ問題は出しません |
| 進め方 | 1ステージ10問です。10問とくとモンスターをたおし、次のステージが開きます |
| 答え方 | 光る□に、画面の数字ボタン（0〜9）で入れます。一のくらい → くりあがりの小さい□ → 十のくらい → 百のくらい の順に光ります |
| ごほうび | 1問ごとにコイン5まいと経験値10。モンスターをたおすと たからばこ（はじめては たからもの、ボーナスのコイン30まい、ボスは60まい）。経験値100ごと（10問ごと）にレベルアップ |
| 主人公 | ゆうしゃ・しょうにん・まほうつかい・かくとうか の4人から選びます。はじめて開いたときに選び、「あなたの いえ」の「しゅじんこうを かえる」で いつでも変えられます。ちがうのは、見た目と こうげきの ことばだけです（問題と ごほうびは同じ） |
| まち | 「まちの そとへ」（ちず）、「あなたの いえ」（もちもの・レベル）、「おみせ」（コインで買い物）、「たからの へや」 |
| 先生用画面 | 暗証番号4けたで開きます。記録の確認、設定、CSV書き出し、バックアップができます |
| 文字 | ひらがな中心です。「一・十・百」には すべて ふりがなを付けています |
| 声 | メッセージ・ヒント・ちずの説明・ごほうびの画面を読み上げます（0.85倍の速さ）。メッセージや主人公、ちずの説明を押すと、もう一度聞けます。上の 🔊／🔇 で、効果音と一緒に消せます |

## 支援の工夫

- くりあがりの小さい□は、たす数（下の段）の十のくらいの右下、横線のすぐ上にあります。くりあがりのないステージでは出しません。
- 百のくらいへの くりあがりは、小さい□を使わず、答えの百のくらいに直接 1 を入れます。
- 「💡 ヒント」を押すと、いまの くらいの数だけ丸が出ます（上の数＝赤、下の数＝青、くりあがり＝黄）。丸を押すと番号がつき、一緒に数えられます。
- まちがえても減点はありません。
  - 2回まちがえると、ヒントのボタンが光ります。
  - 3回まちがえると、ヒントが自動で出ます。丸に1つずつ番号がつき、声で「ぜんぶで ○」と一緒に数えます（くりあがりの1や百のくらいでは、答えの書き方を読み上げます）。
- まちがえたときの音は、小さく低い音です。
- 時間制限はありません。

### 2. Apps Script とスプレッドシート

### 3. Chromebook の準備
- 特別な準備はいりません。上のURLを開きます。
- 記録は、その Chromebook のブラウザの中に残ります。別の Chromebook では、はじめからになります。

## 先生用画面

画面の右上の 🔒 を押し、暗証番号（4けた）を入れると開きます。はじめの番号は **1234** です。最初に「設定」で変えてください。

| タブ | できること |
|---|---|
| 記録 | ステージごとに、とけた問題の数、まちがえた問題の数、**どの位でまちがえたか**（一の位・くりあがり・十の位・百の位）、ヒントを使った回数が分かります。いちばん まちがいが多い位は、赤くなります。2回以上まちがえた問題は、「つまずいた問題」に式と一緒に出ます |
| 設定 | 読み上げの速さ（5段階）、文字の大きさ（ふつう・おおきい）、ステージ（じゅんばんに開く・ぜんぶ開く）、暗証番号の変更 |
| データ | 記録のCSV書き出し、バックアップの保存と もどす、記録の消去、ゲームを さいしょに もどす |

- 記録は、1問とくたびに、その Chromebook の中にたまります（新しいものから3000問まで）。
- 暗証番号を忘れたときは、Chrome の設定から このサイトのデータを消すと、最初からやり直せます。ただし、記録も消えます。

## 注意事項

- 記録は、ブラウザの中（localStorage の `tashizanHissanQuest_v1`）に保存します。外には送りません。
- 絵は、先生が Canva で作ったオリジナルです。問題とことばは、このアプリのためのオリジナルです。

## これから相談して決めること

1. 絵
   - モンスターの絵は、このままで使う（先生確認ずみ）。様子を見て、こわがる子がいたら作り直す。
   - まちの背景が暗め。明るい昼間の色で作り直すか。
2. ごほうびの量：1問5まい・経験値100でレベルアップ。おみせの値段は このまま（先生確認ずみ）。
3. ひっ算の答え方：百のくらいへの くりあがりの入れ方、くりあがりのないステージで小さい□を出さないこと、ヒントが数字を1つ入れるたびに閉じること、丸の番号のしくみ。このままでよいか。
4. ちずの移動：いまは「丸をタップして歩く」形。上下左右に自由に歩く形にするか。
5. ほかのアプリと同じ しくみ を足すか：ヒントを3段階に分けること、まちがえた答えに合わせた声かけ、つづきから。（読み上げ、3回で自動のヒント、先生用画面は入れた）
6. Apps Script にうつす（名前で始める、スプレッドシートに記録）。
7. 主人公の絵：ゆうしゃ・しょうにん・かくとうか は、まだ絵文字です。先生が Canva で、まほうつかいと同じ絵柄の絵（白い背景、3人を1まい）を作ったら、`img/hero-yusha.png` などに切り分け、`index.html` の `HEROES` の `img` に入れます。
