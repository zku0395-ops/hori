# たしざん ひっさん プリント（たし算のひっ算）

たし算のひっ算の学習アプリ「たしざん ひっさん クエスト」（[tashizan/](../README.md)）と同じ順番で練習する、紙のプリントです。

- プリントを作るページ：`https://zku0395-ops.github.io/hori/tashizan/print/`
- できあがった PDF：`tashizan/print/pdf/` にあります（カラー・しろくろ・こたえ）
- 用紙は **A4たて**、**1まいに6もん** です。記録はとりません。

## できること

| 項目 | 内容 |
|---|---|
| れんしゅう | アプリのステージ1〜11 × 各10まい（110まい） |
| 色 | カラー（一のくらい＝きいろ、十のくらい＝みどり、百のくらい＝みずいろ）・しろくろ（きいろ＝うすい はいいろ、みどり＝こい はいいろ） |
| こたえ | すべてのプリントに、こたえのページがあります（答えと くりあがりの 1 は 赤） |
| プリントの上 | ステージ・その○、タイトル、主人公（まほうつかい）の絵、がつ にち、ねん、なまえ の わく |
| プリントの下 | 「できたかな？」の3つの顔（にっこり・ふつう・うーん）に○をつけます |
| 名前 | PDF は ねん・なまえの わくが空いています。作るページで入れると、入った形で印刷できます |
| 問題 | PDF は決まった問題です。「べつの もんだいに する」を押すと、新しい問題とこたえを作ります |

## ステージ構成

| ステージ | 内容 | 例 | くりあがりの 小さい わく | PDF のページ |
|---|---|---|---|---|
| 1 | 2けた＋1けた（くりあがりなし） | 23＋4 | なし | 1〜10 |
| 2 | 2けた＋2けた（くりあがりなし） | 23＋14 | なし | 11〜20 |
| 3 | なん十＋なん十 | 30＋40 | なし | 21〜30 |
| 4 | くりあがり①（2けた＋1けた） | 28＋5 | あり | 31〜40 |
| 5 | くりあがり②（2けた＋2けた） | 28＋15 | あり | 41〜50 |
| 6 | 答えが なん十 | 26＋14 | あり | 51〜60 |
| 7 | ボス：まとめ（ステージ1〜6を1問ずつ） | いろいろ | あり | 61〜70 |
| 8 | 答えが3けた①（なん十＋なん十） | 70＋50 | なし | 71〜80 |
| 9 | 答えが3けた②（十のくらいだけ くりあがる） | 82＋43 | なし | 81〜90 |
| 10 | 答えが3けた③（どちらも くりあがる） | 85＋47 | あり | 91〜100 |
| 11 | だいボス：ぜんぶ（答えが3けたの問題が かならず3問） | いろいろ | あり | 101〜110 |

## 支援の工夫

- マスの形は、アプリと同じです。
  - 上に「百・十・一」の見出しがあります（ふりがなつき）。
  - くりあがりの 小さい わく（点線）は、たす数の十のくらいの右下、横線のすぐ上にあります。くりあがりのないステージでは出しません。
  - 百のくらいへの くりあがりは、小さい わくを使わず、答えの百のくらいに直接 1 を書きます。
  - 答えが3けたになる問題だけ、百のくらいのマス（みずいろ）が出ます。
- 1まいの中に、同じ問題は出ません。ほかの まいとも、できるだけ重ならないようにしています（ステージ3と8は、問題の種類が少ないので、べつの まいに同じ問題が出ることがあります）。
- 数字は大きく（マスは18ミリ）、1まいに6問だけです。
- 漢字は「百・十・一」だけで、ふりがなを付けています。

## ファイル構成

```
tashizan/print/index.html          プリントを作るページ（印刷もここから）
tashizan/print/img/hero-gray.png   しろくろ用の 主人公の絵
tashizan/print/pdf/                できあがった PDF（どれも 110まい・同じ問題・同じ順番）
  たしざんひっさんプリント_1_カラー.pdf
  たしざんひっさんプリント_2_しろくろ.pdf
  たしざんひっさんプリント_3_こたえ.pdf
tashizan/print/tools/make-pdf.js   PDF を作り直すプログラム
```

- 問題の作り方（条件）は、アプリ `tashizan/index.html` と同じです。
- PDF を作り直すとき：`node tashizan/print/tools/make-pdf.js`

## 公開の手順

### 1. GitHub Pages で公開する

- 変更を `main` に取り込む（Pull Request をマージする）と、数分後に `https://zku0395-ops.github.io/hori/tashizan/print/` で開けるようになります。
- Apps Script やスプレッドシートは使いません。

### 2. 印刷する

**PDF をそのまま使うとき**

1. 作るページの上にある「📄 カラー」「📄 しろくろ」「📄 こたえ」のボタンを押します。PDF が新しいタブで開きます。
2. 右上の印刷のアイコン（または Ctrl＋P）を押します。
3. 一部だけ印刷するときは、「ページ」で「カスタム」を選び、ページ番号を入れます（例：ステージ5 だけなら「41-50」）。

**作るページから印刷するとき（名前入り・べつの問題）**

1. 「1. プリントを えらぶ」で、印刷したいステージにチェックを入れます。その○ から その○ まで、を選べます。
2. 「🎨 カラー」か「⚫ しろくろ」を選びます。
3. ねん・なまえを入れると、入った形で印刷されます。空けておくと、子どもが手で書けます。
4. こたえも印刷するときは「こたえの ページも つける」にチェックを入れます。
5. 「🖨 いんさつ する」を押します。
6. 印刷の画面で、用紙は「A4」、倍率は「100%（実際のサイズ）」、「背景のグラフィック」をオンにします。

- 「🎲 べつの もんだいに する」を押すと、PDF とはちがう問題になります。「もとの もんだいに もどす」で、PDF と同じ問題にもどります。

## 注意事項

- 問題は、このプリントのためのオリジナルです。主人公の絵は、先生が Canva で作ったオリジナルです。
- 記録はとりません。名前を入れても、どこにも送りません。

## これから相談して決めること

1. やりかたの説明と おてほん（こたえ入りの見本）を、各ステージに入れるか。
2. その段階のモンスターの絵を入れるか（「いもむしくんを たおそう！」など）。
3. まとめテスト（ステージをまたいだテスト）を足すか。
4. 「そらの うえの がっこう」の先生用のプリント一覧と、としょかんの 算数の たなに入れるか。
