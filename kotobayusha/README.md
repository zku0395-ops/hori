# ことばの勇者

小学校の特別支援学級（2〜5年生）向けの、文を書く学習アプリです。
絵を見て「だれが」「どこで」「なにを している」を入れた文を書きます。
ロールプレイングゲーム風の冒険で、宝物を集め、モンスターを仲間にします。

公開先：https://zku0395-ops.github.io/hori/kotobayusha/

## できること

| できること | 内容 |
|---|---|
| 主人公をつくる | 子どもが自分で名前をつけ、8人の中から見た目を選びます。 |
| ワールドマップ | 10のエリアを、1本の道でじゅんに進みます。 |
| 問題 | 1エリア10問、ぜんぶで100問です。生活の場面と冒険の場面の両方があります。 |
| 入力 | ひらがな一覧表、ローマ字入力、てがき（指で1文字ずつ書く）から選べます。 |
| ごほうび | 3問目と7問目で宝物、5問目と10問目（ボス）でモンスターが仲間になります。 |
| ずかん | 集めた宝物と仲間のモンスターを見られます。 |
| 読み上げ | 問題文を日本語の声で読み上げます。 |

## ステージ構成

| 1 | 町 |
| 2 | 草原 |
| 3 | 学校の塔 |
| 4 | 市場 |
| 5 | 森 |

| 9 | お城 |
| 10 | 空の島 |

レベルは4つあります。先生用画面で、子どもごとに選びます。

| レベル | やること |
|---|---|
| Lv1 | 「だれが」「どこで」「なにを している」を、それぞれ選びます。 |
| Lv2 | ことばのカードと「が」「で」を、じゅんに並べます。 |
| Lv3 | 文の1か所だけを書きます。 |
| Lv4 | 文をぜんぶ書きます。 |

## 支援の工夫

- 「だれが」は赤、「どこで」は緑、「なにを している」は青で色分けします。
- 書いた文は、カタカナとひらがな、「〜ています」「〜てる」などのちがいがあっても正解にします。
- ヒントを押すと、まちがえている所や次に置くカードが光ります。Lv3・Lv4では、1回目で書き出しの1文字、2回目で答えが出ます。
- 時間制限はありません。
- Lv3・Lv4で書いた文は、先生が見て判定できます（くわしくは「先生用画面」）。「男の子が」と「おとこのこが」のように、書き方がちがっても正しい文を ○ にできます。

## 公開の手順

### 1. GitHub Pages
1. このフォルダが `main` ブランチに入ると、自動で公開されます。
2. 公開先は https://zku0395-ops.github.io/hori/kotobayusha/ です。

### 2. Apps Script とスプレッドシート
使いません。記録は、それぞれの Chromebook の中だけに残ります。

### 3. Chromebook の準備
1. Chrome で公開先のURLを開きます。
2. アドレスバーの右にある「インストール」のマーク（またはメニューの「キャスト、保存、共有」→「ページをアプリとしてインストール」）を押します。
3. ランチャーに「ことばの勇者」のアイコンが出ます。全画面で開きます。
4. 一度開くと、絵や問題が Chromebook に保存されます。ネットにつながっていなくても動きます。

### 4. Googleサイトに置くとき
「埋め込む」ではなく、「ボタン」で公開先のURLにつなぎます。

## 先生用画面

1. タイトル画面の右下にある「せんせい用」を押します。
2. 出てきたボタンを長押しします。
3. 次のことができます。
   - 子どもごとのレベルと入力方法（ひらがな表・ローマ字・てがき）の設定
   - 子どもごとの「書いた文の判定」の設定
   - 全部のエリアを開く
   - 子どもが書いた文の確認と、○・× の判定
   - 絵を作るときの ChatGPT への指示文（コピーボタンつき）

### 書いた文の判定（Lv3・Lv4）

「書いた文の判定」で、子どもごとに選びます。

| 設定 | どうなるか |
|---|---|
| じどう | アプリが判定します。 |
| せんせいが はんてい | 子どもが「できた！」を押すと、「せんせいに みて もらおう」の画面が出ます。 |

「せんせいが はんてい」のときは、次のようにします。
1. 子どもに呼ばれたら、画面の文を見ます。こたえの例と、アプリの判定も出ています。
2. 「○ せいかい」か「× もういちど」を長押しします（子どもがうっかり押さないように、長押しにしています）。
3. ○ にすると、正解の画面になり、宝物やモンスターももらえます。
4. × にすると、書いた文が残ったまま問題にもどります。子どもは直して出しなおせます。
5. その場で見られないときは、子どもが「あとで みて もらう」を押すと、つぎの問題に進みます。その問題は、先生が ○ にするまでクリアになりません。

### あとから判定を直す

1. 先生用画面で、子どもの「記録」を押します。まだ判定していない文があると、赤い「未判定」の数が出ます。
2. 書いた文の表の「判定を直す」で、○ か × を押します。
3. ○ にすると、その問題はクリアになり、宝物やモンスターももらえます（「じどう」で △ になった文も直せます）。
4. ○ でクリアにした文を × にもどすと、クリアと、そのときもらった宝物・モンスターも元にもどります。

### てがき入力

1. 「てがき」を選ぶと、ますに指で1文字ずつ書けます。
2. 書いた字は、Chromebook に入っている文字を読み取るしくみで文字にします。読み取りは Chromebook の中で行い、書いた字は外に送りません。
3. 字の候補が4つまで出ます。子どもは、書きたい字を選んで押します。カタカナで読み取ったときは、ひらがなも出します。
4. 字が出てこないときは「✋ かきなおす」で書き直します。「゛」「゜」「小」で、にごる字や小さい字にできます。
5. 子どもも、問題の画面の「にゅうりょく」で、ひらがな表やローマ字に切りかえられます。
6. 読み取りのしくみがない Chromebook や、パソコンの Chrome では、文字を入れる欄が出ます。欄を押して、画面キーボードの ✍（手書き）で書きます。
   - 画面キーボードが出ないときは、Chromebook の「設定」→「ユーザー補助」→「キーボードとテキスト入力」→「画面キーボード」をオンにします。
   - 画面キーボードの手書きは、日本語の入力（「設定」→「デバイス」→「キーボードと入力」→「入力方法」の「日本語」）を足すと使えます。
   - 設定の名前や場所は、Chromebook の版によって少しちがいます。学校の Chromebook は、情報担当の先生が設定を止めていることもあります。

## 全員の記録を見る

記録は、それぞれの Chromebook の中にあります。先生用画面で、子どもごとに確かめてください。

## 注意事項

- 記録はその Chromebook の Chrome の中に保存されます。閲覧データを消すと、記録も消えます。
- 絵は、すべて ChatGPT で作ったオリジナルです。問題文もオリジナルです。
- 絵を直したら、`sh tools/sw.sh` を動かして `sw.js` を作り直します（新しい絵が Chromebook に保存されるようにするため）。
