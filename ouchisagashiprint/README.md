# ホーせんぱいの おうちさがし プリント（文を読んで家をさがす学習プリント）

小学校の特別支援学級向けの、文の読み取りの **学習プリント** です。
アプリ「ホーせんぱいと おうちさがし たんていだん」（[ouchisagashi/](../ouchisagashi/README.md)）で学習したことを、紙で ためします。
じゅうにんの話す文を読んで、ならんだ6けんの家から、合う家を1けん見つけます。

- プリントを作るページ：`https://zku0395-ops.github.io/hori/ouchisagashiprint/`
- できあがった PDF：`ouchisagashiprint/pdf/` に入っています（ページの上の「できあがった PDF」からも開けます）。
- 用紙は **A4たて・カラー** です。

## できること

| 項目 | 内容 |
|---|---|
| まい数 | 30まい（60もん）。1まいに2もんです |
| 1もんの形 | 上に、じゅうにんの絵と「わたしの いえを さがして ください。」の文（1〜3文）。下に、①〜⑥の番号が付いた家が6けん。合う家の番号に ○ をつけます |
| 見ための文（1〜13まいめ） | 家を 3けん×2だん にならべます。やね・かべ・ドアの色、まどの形、にわの もの、のりもの の文です |
| 場所のことば（14〜30まいめ） | 小さな町の絵（あおい みち・きいろい みち と、めじるし1つ）の上に、家を6けん ならべます。みち・となり・むかい・みぎ／ひだり どなり・なんけんめ・あいだ の文です |
| 欄 | 「　ねん」「なまえ」「　がつ　にち」「できたかな？（😊 😐 😟 に ○）」 |
| 読んだ しるし | 文の頭に □ と ①②③ が あります。読んだ文の □ に ✓ をつけられます |
| こたえ | 子ども用と同じ形で、合う家の番号に **赤い ○** をつけています。右上に「こたえ」の はんこ |
| 出すまいを選ぶ | ページの上で「○まいめ から ○まいめ まで」を選んで、その分だけ印刷できます |

## ステージ構成

アプリのステージの順に ならべています。家と文は、アプリと同じものです。

| まいめ | アプリの ステージ | だい | 文 |
|---|---|---|---|
| 1 | 1-1 | やね・ドア・まど | 1文 |
| 2 | 1-2 | かべ・にわ・のりもの | 1文 |
| 3 | 1-3 | 1つの ぶん | 1文 |
| 4〜8 | 2-1〜2-3 | 2つの ぶん | 2文 |
| 9〜13 | 3-1〜3-3 | 3つの ぶん | 3文 |
| 14・15 | 4-1 | みち と となり | 「あおい みちに あります」「とうだいの となり」＋ 見ための文 |
| 16・17 | 4-2 | となり と むかい | 「あかい やねの いえの となり」「みちを はさんで、〜の むかい」＋ 見ための文 |
| 18・19 | 4-3 | ばしょの ことば | みち・となり・むかい を まぜる |
| 20・21 | 5-1 | みぎ・ひだり・なんけんめ | 「〜の みぎ どなり」「ならんで いる いえの、ひだりから 2けんめ」 |
| 22・23 | 5-2 | あいだ | 「〜と 〜の あいだ」「むかい」「みぎ／ひだり どなり」 |
| 24・25 | 5-3 | ばしょ と みため | 場所の文 ＋ 見ための文2つ |
| 26〜28 | 6-1・6-2 | まとめ | これまでの文を まぜる |
| 29・30 | 6-3 | めいたんていの しけん | 場所の文と 見ための文を まぜる |

- アプリの「はってん」（「〜では ありません」・いらない文）は、入れていません。
- アプリでは家が 6〜10けん ですが、プリントは どのもんだいも 6けん です（絵を大きくして、ドアと まどが見えるようにするためです）。

## 支援の工夫

- **スモールステップ**：1文 → 2文 → 3文 → 場所のことば の順に進みます。
- **絵を大きく**：1もんの家を6けんにして、ドアの色と まどの形が見分けられる大きさにしています。
- **よく にた家を入れる**：1つだけ ちがう家（やねも かべも同じで、ドアの色だけ ちがう家など）をまぜています。さいごの文まで読まないと決まりません。
- **読んだ文に しるし**：文ごとに □ が あります。「1つ読んだら ✓」で、読みとばしを ふせぎます。
- **町に すきまを作らない**：場所のことばの町は、どの だんも家と めじるしを つめて ならべています。「となり」「ひだりから 2けんめ」を取りちがえにくくするためです。
- **「なんけんめ」**：同じ だんに ならんでいる家を、はしから数えます。めじるしをまたいで数えるもんだいは出しません。めじるしも数えてしまったときでも、答えが同じ1けんになるようにしています。
- **「むかい」**：あおい みちの 上がわの家と 下がわの家が、道をはさんで向かい合います。きいろい みちは、上がわだけに家があります。
- **同じことばを2回 言わない**：「あおい ドアの いえの となり」と「ドアの いろは、あおです」のように、まぎらわしい組み合わせは さけています。
- **こたえの番号**：1まいの2もんで、同じ番号にならないようにしています。
- 漢字は使っていません。ひらがな・カタカナの分かち書きです。行は、ことばの まとまりの間でだけ かわります。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | プリントを作るページ（出すまいを選ぶ・こたえを出す・印刷する） |
| `data/print.js` | もんだい（30まい・60もん）。`tools/make_mondai.js` が作ります。手では直しません |
| `img/` | 印刷用の絵（アプリの絵を、白い紙にのせた小さな JPEG にしたもの）。家60・じゅうにん60・めじるし12・ホーせんぱい3 |
| `pdf/おうちさがしプリント.pdf` | 子ども用（30ページ） |
| `pdf/おうちさがしプリント_こたえ.pdf` | こたえ（30ページ） |
| `tools/make_mondai.js` | もんだいを作る道具。アプリの `ouchisagashi/data/data.js` の家と文を使います |
| `tools/check.js` | もんだいを点検する道具（合う家が1けんだけか、文がアプリと同じか、絵があるか） |
| `tools/make_img.js` | 印刷用の絵を作る道具 |
| `tools/make-pdf.sh` | `pdf/` の PDF を作り直す道具 |

## 公開の手順

### 1. GitHub Pages

`main` に入ると、`https://zku0395-ops.github.io/hori/ouchisagashiprint/` で開けます。ほかに することは ありません。

### 2. Apps Script とスプレッドシート

使いません（記録はとりません）。

### 3. 印刷のしかた

**PDF から印刷する（おすすめ）**

1. ページの上の「📄 できあがった PDF」を押します。
2. 印刷の画面で、用紙「A4」、向き「縦」、カラーを選びます。
3. 1まいだけ出すときは、「ページ」に そのまいめの数字を入れます（まいめ と PDF のページは同じです）。

**ページから印刷する（出すまいを選ぶとき）**

1. 「だす まい」で、「○ から ○ まで」を選びます。
2. 「🖨️ いんさつ する」を押します。
3. 印刷の画面で、「余白：なし」「背景のグラフィック：オン」にします。

### 4. Googleサイトに置くとき

1. Google サイトの編集画面で、右の「挿入」→「ボタン」を押します。
2. 名前に「おうちさがし プリント」、リンクに上の URL を入れます。

## 注意事項

- **しろくろでは使えません**。やね・かべ・ドアの「色」を見るもんだいが多いためです。カラーで印刷してください。
- 9〜13まいめ・26まいめ（3文で、見ための文だけのもんだい）の一部は、2つの文だけで答えが決まります（60もんのうち 8もん）。3つめの文は、たしかめに使えます。
- アプリの家や文（`ouchisagashi/data/data.js`）を変えたときは、次の順で作り直します。
  1. `node ouchisagashiprint/tools/make_mondai.js`（もんだい）
  2. `node ouchisagashiprint/tools/check.js`（点検。「ぜんぶ OK」と出れば よい）
  3. 家の絵を変えたときは `node ouchisagashiprint/tools/make_img.js`（`sharp` が いります）
  4. リポジトリの いちばん上を `http://localhost:8765/` で見られるようにして、`bash ouchisagashiprint/tools/make-pdf.sh`（Edge を使います）
- もんだいは、たねの数（`make_mondai.js` の `SEED`）で決まります。同じなら、いつも同じもんだいです。
- 絵は、アプリと同じく ChatGPT で作ったオリジナルの絵です。文もオリジナルです。

## これから相談して決めること

- 「はってん」（「〜では ありません」・いらない文）のプリントを足すか。
- 家を 8けん・10けん にしたプリント（1まいに1もん）を足すか。
- 「どうして その いえだと おもったか」を書く欄を足すか。
- しろくろでも解ける版（色を聞かず、まど・にわ・のりもの・場所のことば だけ）を作るか。
- としょかん のどの たなに入れるか（いまは「あたらしい本」に出ます）。
