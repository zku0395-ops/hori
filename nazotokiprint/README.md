# ワンダせんせいの なぞとき プリント（文章の読み取りの学習プリント）

小学校の特別支援学級向けの、文章の読み取りの **学習プリント** と **テスト** です。
アプリ「ワンダせんせいの なぞとき たんていじむしょ」（[nazotoki/](../nazotoki/README.md)）で学習したことを、紙で ためします。
短い文章を読んで、**いつ・どこで・だれが・なにを した** を答えます。

- プリントを作るページ：`https://zku0395-ops.github.io/hori/nazotokiprint/`
- できあがった PDF：`nazotokiprint/pdf/` に入っています（ページの上の「できあがった PDF」からも開けます）。
- 用紙は **A4よこ** です。

## できること

| 項目 | 内容 |
|---|---|
| れんしゅう（えらぶ） | アプリのレベル1と同じ文章・同じ挿絵で 20まい（各ステージから2つ）。4つの問いに、ア・イ・ウ・エ から1つ選んで ○ を つけます |
| れんしゅう（かく） | アプリのレベル2と同じ文章・同じ挿絵で 20まい。答えを □ に1字ずつ書きます（「□□くん」「きのみを □□ ました」の形） |
| テスト（えらぶ・かく） | アプリに ない **新しい文章** で 5まいずつ。1文 → 1文（ことばの順番が ちがう）→ 2文 → 3文 → 3文（にている ことばが いくつも）の順です |
| 1まいの形 | 左に挿絵（カラー）と文章、右に4つの問い（いつ・どこで・だれが・なにを した）。どのプリントも4つとも聞きます |
| 欄 | 「　がつ　にち」「なまえ」「できたかな？（😊 😐 😟 に ○）」 |
| こたえ | 子ども用と同じ形で、答えを **赤** で入れています（えらぶ は赤い ○、かく は赤い字）。右上に「こたえ」の はんこ |
| 白黒印刷 | 手がかりは色ではなく、しるし（🕐 いつ・📍 どこで・👤 だれが・🏃 なにを した）で見分けます |

## ステージ構成

れんしゅうは、アプリの各ステージから2つずつ、順に ならべています（ばんごう1・2が ステージ1、3・4が ステージ2 …）。

| ばんごう | アプリの ステージ | 文章 |
|---|---|---|
| 1〜8 | 1〜4 | 1文（アプリでは手がかりを1つずつ聞く文章。プリントでは4つとも聞きます） |
| 9・10 | 5 | 1文 |
| 11・12 | 6 | 1文（ことばの順番を入れかえる） |
| 13・14 | 7 | 2文 |
| 15・16 | 8 | 2文（にている ことばが2つ） |
| 17・18 | 9 | 3文 |
| 19・20 | 10 | 3文（にている ことばが いくつも） |

テストは5まいずつです。

| ばんごう | 文章 |
|---|---|
| 1 | 1文 |
| 2 | 1文（ことばの順番を入れかえる） |
| 3 | 2文 |
| 4 | 3文 |
| 5 | 3文（にている ことばが いくつも） |

- 文章と答えの一覧は [ichiran.md](ichiran.md) にあります。

## 支援の工夫

- アプリと同じ文章・同じ挿絵なので、アプリで学習したことを そのまま紙で ためせます。テストは新しい文章で、本当に読み取れているかを見ます。
- 文章は分かち書きで、漢字（1年生で習う字だけ）には、すべてふりがなを付けています。ことばの とちゅうで 行が かわらないようにしています。
- 選ぶ問題には、まちがいやすい答え（ほかの手がかりの ことば、文章の中の べつの場面の ことば）を入れています。
- 書く問題は、答えの字の数だけ □ を出します。「くん」「さん」「〜ました」は はじめから書いてあります。□ は 約1.5cm で、十字の点線が入っています。
- 2文・3文の文章では、「どこで ザリガニを つかまえましたか？」のように、くわしく聞きます。
- 文章が長いときは、字を少し小さくして、1まいに入るようにしています。
- 選択肢の順番は いつも同じです（プリントと こたえで 順番が かわりません）。

## ファイル構成

```
nazotokiprint/index.html          プリントを作るページ（?set=practice1 など。&ans=1 で こたえ）
nazotokiprint/data/tests.js       テストの文章（新しい文章10こ）
nazotokiprint/data/print.js       プリント用のデータ（tools/make-data.js が作ります）
nazotokiprint/img/                テストの挿絵（T1-1.webp など）
nazotokiprint/pdf/                PDF（8ファイル）
nazotokiprint/ichiran.md          文章と答えの一覧表
nazotokiprint/tools/make-data.js  データと一覧表を作るプログラム（れんしゅうに使う文章も ここで決めます）
nazotokiprint/tools/make-pdf.js   PDF を作るプログラム
```

- れんしゅうの文章と挿絵は、アプリの `nazotoki/tools/mondai.js` と `nazotoki/img/` を使います。
- 文章を直したら、次の順で作り直します。
  1. `node nazotokiprint/tools/make-data.js`
  2. `node nazotokiprint/tools/make-pdf.js`（1つだけなら `node nazotokiprint/tools/make-pdf.js test1` のように）

PDF のファイル：

| ファイル | まい数 |
|---|---|
| なぞときプリント_れんしゅう_えらぶ.pdf（と _こたえ） | 20 |
| なぞときプリント_れんしゅう_かく.pdf（と _こたえ） | 20 |
| なぞときプリント_テスト_えらぶ.pdf（と _こたえ） | 5 |

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入ると、`https://zku0395-ops.github.io/hori/nazotokiprint/` で開けます。
2. ページの上の「できあがった PDF」から、PDF を保存できます。

### 2. Apps Script とスプレッドシート

- このプリントは記録をとらないので、Apps Script とスプレッドシートは使いません。

### 3. 印刷のしかた

1. 印刷したい PDF を開きます。
2. 印刷の画面で、次のようにします。
   - 用紙サイズ：**A4**
   - 向き：**横**
   - 倍率：**100%**（「実際のサイズ」）
3. 挿絵はカラーですが、白黒で印刷しても問題は解けます。
4. 1まいだけ印刷するときは、印刷の画面の「ページ」で番号を入れます（例：3まいめ なら「3」）。

- プリントを作るページで印刷するときは、上のボタンで プリントを選んで「🖨 いんさつ」を押します。余白は「なし」、「背景のグラフィック」は オン にしてください。

### 4. Googleサイトに置くとき

- 「ボタン」を置き、リンクに PDF かプリントを作るページのURLを入れてください。

## 先生用画面

- このプリントには、先生用画面はありません。

## 全員の記録を見る

- このプリントは記録をとりません。アプリの記録は、アプリのスプレッドシートで見られます。

## 注意事項

- **文章**：アプリと同じ文章と、テスト用に新しく作った文章です。どれも、このアプリのためのオリジナルの文です。
- **挿絵**：アプリのために Canva で作った絵と、テストのために Canva で作った絵です。
- 子どもの名前（とうしんくん・ゆきさん など）は、アプリと同じ名前です。

## これから相談して決めること

- れんしゅうを ふやすか（いまは各ステージ2つ。アプリには各ステージ5つ あります）
- テストに点数の欄（例：／4もん）を付けるか
- 1まいに 2つの文章を入れた「ふくしゅうプリント」を作るか
