# ChatGPT で作った絵の注文書（ホーせんぱいと おうちさがし たんていだん）

このアプリの絵は、すべて ChatGPT で作りました（Claude が、このパソコンの Chrome で ChatGPT を操作して作りました）。
作り直すときや、絵を足すときのために、頼み方と設計表を残しておきます。
このファイルは `node ouchisagashi/tools/make_chumon.js` で作り直せます（設計表は `data/data.js` から出しています）。

## 絵の感じ

- **リアルな3DCG**。高品質なゲームの背景のような、本物らしい質感（かわら屋根、しっくいの壁、木のドア、石の土台）。
- **ななめ上から見下ろした角度**（屋根・正面の壁・横の壁が見える）。
- 参考にしたゲームの画面は、ChatGPT に読みこませていません。ことばだけで頼んでいます。
- 家・たんてい・めじるし・じゅうにんは背景を透明に、はいけいだけは画像いっぱいに描いてもらいます。
- 同じチャットの中で続けて頼むと、家の形や絵の感じがそろいます。

## 作って入れる手順

1. ChatGPT に頼み文を送り、できた絵を設計表と1けんずつ くらべます。
2. 合っていたら、絵を開いて「ダウンロード」で保存します（ChatGPT が絵を2まい出したときは、1まい選んでから「ダウンロード → 画像をダウンロード」を押します）。
3. `tools/kiriwake.js` で切り分けて `img/` に入れます（`sharp` が必要です）。
   - 家：`node ouchisagashi/tools/kiriwake.js ie <画像> machi-01 machi-02 machi-03 machi-04`
   - 家（2けん）：`node ouchisagashi/tools/kiriwake.js ie <画像> machi-09 machi-10 --cols=2 --rows=1`
   - じゅうにん：`node ouchisagashi/tools/kiriwake.js hito <画像> machi-01 … machi-10`
   - 町のかざり：`node ouchisagashi/tools/kiriwake.js cut <画像> d_taru d_iwa d_benchi d_gaito d_ido d_kirikabu --cols=3 --rows=2 --w=400 --h=400`
   - めじるし・たんてい・ホーせんぱい：`node ouchisagashi/tools/kiriwake.js auto <画像> m_funsui m_basutei --w=460 --h=460`
   - はいけい：`node ouchisagashi/tools/kiriwake.js bg <画像> machi`
4. 道具が `data/data.js` の `IMAGES` を書き直します。
5. `index.html` の `var V = '3';` の数字を1つ上げます（新しいデータを読みこませるため）。Apps Script の `index` も貼り直します。
6. デスクトップの「アプリ用画像素材」フォルダの整理スクリプトを動かして、元の絵も整理しておきます。

**設計表（`data/data.js` の `HOUSES`）を変えると、家の絵も作り直しになります。**

## 気をつけること

- 家のまどは、1けんの中では ぜんぶ 同じ形です（まる・しかく・さんかく）。まどの下の花かざりは付けていません。「にわの もの」は、家の左にあるものだけです。
- ドアと かべが 同じ色の家は ありません。ドアと やねが 同じ色の家は あります（色のことばに つられないかを 見るためです）。
- まちの かざり（たる・いわ・ベンチ・がいとう・いど・きりかぶ）は、にわの ものと まちがえない ものだけに しています。木や花は かざりに 使いません。
- 自転車は、どの場所でも赤い自転車です。「あかい くるま」とは形で見分けます。
- バスていの標識は、赤い丸に白い線の形です。
