# ホーせんぱいと おうちさがし たんていだん（文を読んで家をさがすアプリ）

小学校の特別支援学級向けの、国語の読み取りの学習アプリです。
子どもは「たんてい」になります。じゅうにん（どうぶつ）が話す「じぶんの家の ヒント」の文を読み、ななめ上から見た立体的な町を歩いて、その人の家を1けん見つけます。
フクロウの先ぱい探偵「ホーせんぱい」が、声をかけて助けます。

- まち・もり・はやし・みなと・むら・やま の6つの場所に、家が10けんずつ、合わせて60けんあります。
- ヒントは「やねの いろは、あかです。」「ドアの いろは、あおです。」「まどの かたちは、まるです。」「ふんすいの となりに あります。」のような文です。1文から始めて、2文、3文とふやします。
- よく にた家（やねも かべも同じで、ドアの色だけ ちがう家など）が あるので、さいごの文まで読まないと決まりません。
- 文に ぜんぶ合う家は、いつも1けんだけです。
- 家を見つけると、その じゅうにんから「おれいの シール」がもらえます。60人ぶん集めます。

## できること

| 項目 | 内容 |
|---|---|
| 学習内容 | 文を読み、書いてあることと絵をくらべて、合うものを1つ決める。2つ・3つの文を ぜんぶ たしかめる。場所のことば（あおい みち・きいろい みち・あかい みち、となり、みぎ・ひだり、あいだ）。はってんで「〜では ありません」と、いらない文 |
| さがし方 | 行きたい所をタッチすると、たんていがそこまで歩きます。◀▲▼▶ のボタン（キーボードの矢印）でも歩けます。家の前で「🔍 しらべる」を押すと、家が大きく出ます。町は広く、道は くねくね曲がっています。行き止まりの こみち（井戸・ベンチなどが ある）も あります |
| 家 | 60けん。ちがうのは「やねの色・かべの色・ドアの色・まどの形・にわの もの・のりもの」の6つです（設計表は `e_chatgpt.md`）。場所ごとに、1つだけ ちがう「ふたごの家」が 5〜6組 あります |
| 進め方 | 1かい5問。5問で1つのステージをクリアします（5〜10分）。途中でやめても、次は続きの問題から始められます |
| 時間 | 時間制限はありません |
| ごほうび | 1けん見つけるたびに、じゅうにんの シールが1まい。ヒントを使っても、まちがえても同じようにもらえます |
| たんてい てちょう | 60人の シールのアルバムです。集めた数で しょうごう が上がります（みならい → かけだし → まちの → うでききの → めいたんてい → でんせつの めいたんてい） |
| 文字 | ひらがなと分かち書きです。漢字は使っていません |
| 声 | じゅうにんの文と、ホーせんぱいの声かけを読み上げます。**じゅうにんの文を読み上げるかどうかは、先生用画面で切りかえられます**（自分で読ませたいときは「読み上げない」） |
| 先生用画面 | 暗証番号4けたで開きます。どの しゅるいの文で つまずいているか、設定、CSV書き出し、バックアップができます |
| 全員の記録 | 1問とくたびに、結果が先生のGoogleスプレッドシートへ届きます |

## ステージ構成

| ステージ | 場所 | 出る家 | ヒントの文 |
|---|---|---|---|
| 1-1 やね・ドア・まど | まち | 6けん | 1文（やねの色・ドアの色・まどの形 のどれか） |
| 1-2 かべ・にわ・のりもの | まち | 6けん | 1文（かべ・にわ・のりもの・まど・ドア のどれか） |
| 1-3 6けんから さがす | まち | 6けん | 1文 |
| 2-1・2-2 2つの ぶん | もり | 8けん | 2文 |
| 2-3 10けんから さがす | もり | 10けん | 2文 |
| 3-1 3つの ぶん | はやし | 8けん | 3文 |
| 3-2・3-3 3つの ぶん | はやし | 10けん | 3文 |
| 4-1 みち と となり | みなと | 10けん | 「あおい みちに あります」「とうだいの となり」＋ 見ための文 |
| 4-2 となり と むかい | みなと | 10けん | 「あかい やねの いえの となり」「みちを はさんで、〜の むかい」＋ 見ための文 |
| 4-3 ばしょの ことば | みなと | 10けん | みち・となり・むかい を まぜる |
| 5-1 みぎ・ひだり | むら | 10けん | 「〜の みぎ どなり」「ならんで いる いえの、ひだりから 2けんめ」 |
| 5-2 あいだ | むら | 10けん | 「〜と 〜の あいだ」「むかい」「なんけんめ」 |
| 5-3 ばしょ と みため | むら | 10けん | 場所の文 ＋ 見ための文2つ |
| 6-1・6-2 まとめ | やま | 10けん | これまでの文を まぜる |
| 6-3 めいたんていの しけん | やま | 10けん | みちの文と 場所の文が 両方入る問題も出る |
| はってん 1 | 6つの場所 | 10けん | 「やねの いろは、あかでは ありません。」「ドアの いろは、あかでも あおでも ありません。」など |
| はってん 2 | 6つの場所 | 10けん | 「すきな いろは、あかです。」など、家に関係のない文が1つまざる |

- 1-1 から順に、前のステージをクリアすると次が開きます。
- 6けん・8けんのステージは、道が2本の小さな町です。その問題に出る家だけが建っています。
- 10けんのステージは、3本の道（あおい みち・きいろい みち・あかい みち）の町です。道の おくがわ と てまえがわ に家が建っていて、道をはさんだ「むかい」の家があります。道と道は、たての道でつながっています。家のならびは、場所ごとに決まっています。
- 「ひだりから 2けんめ」は、同じがわに ならんで いる家を、はしから数えます。めじるし（ふんすい など）は数えません。めじるしをまたいで数える問題は出しません。
- 町の広さは、先生用画面の「せってい → まちの ひろさ」で変えられます。「ひろい」（はじめの設定）は、道が曲がり、家の間が広く、行き止まりの こみちが あります。「ふつう」は、道がまっすぐで、家が近くに ならびます。家のならびは、どちらも同じです。
- カメラの向きは変わりません。「みぎ どなり・ひだり どなり」は、画面で見た右・左です。
- ステージの「-1」は じゅうにん1〜5、「-2」は じゅうにん6〜10、「-3」は10人から5人が出ます。-1 と -2 をクリアすると、その場所の10人のシールがそろいます。
- はってんは、最初は閉じています。先生用画面で、子どもごとに開きます。
- クリアしたステージは、何度でもやり直せます（問題は毎回変わります）。

## 支援の工夫

- **スモールステップ**
  - 家の数を 6けん → 8けん → 10けん とふやします。
  - 文の数を 1文 → 2文 → 3文 とふやします。
  - 見ための文（やね・かべ・ドア・まど・にわ・のりもの）に慣れてから、場所のことばに進みます。
  - 場所のことばは「みち・となり・むかい」→「みぎ・ひだり・なんけんめ」→「あいだ」の順です。
  - はじめは道が2本の小さな町で、歩いて調べるやり方に慣れます。
- **ぜんぶの文を読まないと決まらない**
  - 2文・3文の問題では、「1つめの文には合うが、2つめの文には合わない家」を必ずまぜます。さいしょの文だけで決めると、まちがえるようになっています。
- **まちがいやすい家を入れる**
  - 1つだけ ちがう「ふたごの家」を、設計表に入れてあります（やね・かべ・にわ・のりものが同じで、ドアの色だけ ちがう など）。
  - 「ドアの いろは、あかです。」のとき、やねが あかい家や、あかい くるま の家をまぜます。
  - 「やねの いろは、あかです。」のとき、あかい くるま の家や、かべが同じ色の家をまぜます（色のことばだけで選ぶと まちがえる）。
- **歩いてさがすときの支え**
  - ヒントの文は、いつも画面の左に出ています。歩いている間に忘れても、すぐ読み直せます。
  - 家をタッチすると、たんていがその家の前まで歩きます。着くと、家が大きく出ます（🔍 この いえかな？）。「この いえ です！」で決め、「ほかの いえを みる」でもどれます。
  - ドラッグは使いません。タッチか、◀▲▼▶ のボタンだけで歩けます。道から外れることはありません。
  - 調べて ちがった家には、大きな ✕ が付きます。同じ家を何度も調べなくてすみます。
  - 「🗺️ ちず」で、町全体を上から見られます。ちずの家をタッチすると、そこまで歩きます。先生用画面で「つかわない」にもできます。
- **まちがえたとき**
  - 小さな音が鳴り、その家は うすくなって ✕ が付き、えらべなくなります。のこりの家から、もう一度えらべます。
  - まちがい方に合わせて、ホーせんぱいが声をかけます。
    - 色のとりちがえ：「それは やねの いろだよ。ドアの いろを みて みよう。」
    - 1つだけ合わない：「おしい！ にわを みて みよう。りんごの きは あるかな。」
    - 場所：「ばしょが ちがうよ。みちを はさんで、あかい やねの いえの むかいを みて みよう。」「ならんで いる いえを、ひだりの はしから じゅんに かぞえて みよう。」
    - いらない文に つられた：「『すきな いろは、あかです。』は、いえの ことでは ないよ。」
- **ヒントは3段階**
  1. ことば：「ぶんを 1つずつ よんで、いえを たしかめよう。ぜんぶ あう いえは、1けん だけだよ。」
  2. 色：文の中の大事なことば（あか・となり など）に色が付きます。
  3. いっしょに たしかめる：ちずが開き、ホーせんぱいが文を1つずつ読んで、合わない家を消していきます。さいごに答えの家が光ります（ちずの家をタッチして、そこまで歩いて答えます）。
  - 2回まちがえるとヒントボタンが光り、3回まちがえると 3 のヒントが自動で出ます。
- **画面・操作**
  - 左に文、右に町、と分けています。町の はいけいは うすくして、家が見やすいようにしています。
  - 文には ①②③ の番号が付きます。
  - じゅうにんの顔か「🔊 もういちど」で、文を聞き直せます。ホーせんぱいを押すと、声かけを聞き直せます。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入っていることを確かめます。
2. `https://zku0395-ops.github.io/hori/ouchisagashi/` を開きます。
   - 「おためしモード」で動けば、データの公開はできています（このページでは記録はスプレッドシートに届きません）。
   - GitHub Pages の設定（`main` ブランチの `/ (root)`）は、ほかのアプリと同じです。新しく設定する必要はありません。

### 2. Apps Script とスプレッドシート

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「おうちさがし 記録」）。ほかのアプリとは別のスプレッドシートにします。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
   - GitHub で `ouchisagashi/index.html` を開き、「Raw」を押します。
   - 翻訳のおしらせが出たら「翻訳しない」を選びます。
   - Ctrl＋A → Ctrl＋C でコピーし、Apps Script で全部消してから Ctrl＋V で貼り付けます。
   - いちばん下が `</html>` になっているか確かめます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。
9. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
10. 種類の選択（⚙）で **ウェブアプリ** を選び、次のようにします。
    - 次のユーザーとして実行：**自分**
    - アクセスできるユーザー：**（学校のドメイン）内の全員**
11. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。

> 「次のユーザーとして実行：自分」にすると、子どものアカウントからでも先生のスプレッドシートに記録が届きます。子どもにスプレッドシートを共有する必要はありません。

**`コード.gs` や `index.html` を書き換えたとき** は、**デプロイ → デプロイを管理 → ✏（鉛筆）→ バージョン：新バージョン → デプロイ** を押します。URLは変わりません。

### 3. Chromebook の準備

1. 子どもの Chromebook で、ウェブアプリのURLを開きます。
2. ブックマークやショートカットにしておきます。
3. 音量を確かめます。はじめに名前のボタンを押すと、声が出るようになります。

### 4. Googleサイトに置くとき

- ページに「埋め込む」と、画面がせまくなり、町が小さくなります。
- **「ボタン」** を置き、リンクにウェブアプリのURLを入れてください（新しいタブで開きます）。

## 先生用画面

子どもの画面の右上 🔒（名前を選ぶ画面では「🔒 せんせい用」）を押し、暗証番号を入れます。はじめの番号は **1234** です。最初に「せってい」で変えてください。

| タブ | できること |
|---|---|
| クラス全体 | 子どもごとの クリアしたステージ・シール・といた数・1回で見つけた割合・まちがえた数・ヒントを使った数・つまずきやすい文。クラス全体の、文の しゅるいごとの「出た数・つまずいた数」 |
| 子どもごと | 文の しゅるいごと（やね・かべ・ドア・まど・にわ・のりもの・みち・となり・むかい・みぎ／ひだり・なんけんめ・あいだ・うちけし・いらない ぶん）の、1回で見つけた割合と、まちがえた回数。よく まちがえた家。はってんを開く・ぜんぶのステージを開く |
| せってい | じゅうにんの文の読み上げ（読み上げる／読み上げない）、読み上げの速さ、文字の大きさ、「🗺️ ちず」ボタン、**まちの ひろさ（ひろい／ふつう）**、効果音、暗証番号 |
| データ | まだ送れていない記録を送る、CSVで書き出す、バックアップの保存と元にもどす、全員の記録を消す |

- 「読み上げない」にしても、ホーせんぱいの声かけとヒントは読み上げます。ヒント3では、ホーせんぱいが文を読みます。
- 歩くのが大変な子がいるときは、「まちの ひろさ」を「ふつう」にします。子どもごとには変えられません（クラス全体の設定です）。
- 設定は、スプレッドシートの「せってい」シートでも変えられます。

## 全員の記録を見る

スプレッドシートの「きろく」シートに、1問とくたびに1行ずつ記録が届きます。

| 列 | 内容 |
|---|---|
| ステージ | `s1a`〜`s6c`（1-1 が `s1a`、1-2 が `s1b`、1-3 が `s1c`）。はってんは `h1`・`h2` |
| もん | そのかいの何問めか（1〜5） |
| ばしょ | まち・もり・はやし・みなと・むら・やま |
| じゅうにん | 家をさがした じゅうにん（うさぎ など） |
| ヒントの ぶん | 出た文の しゅるい。「やね・にわ」のように、文の順に「・」でつなぎます |
| けっか | ○＝1回で見つけた、△＝まちがえてから見つけた |
| まちがい | 見つけるまでに、まちがえて えらんだ家の数 |
| ヒント | 使ったヒントの段階（0〜3） |
| まちがえた いえ | まちがえて えらんだ家の じゅうにん |
| まちがいの しゅるい | まちがえた家が、どの しゅるいの文に合っていなかったか（さいしょに合わなかった文）。いらない文に つられたときは「いらない ぶん」 |
| よみあげ | じゅうにんの文の読み上げが「あり」か「なし」か |
| びょう | その問題にかかった時間 |

- 「まとめ」シートは、先生用画面を開いたときか、メニュー **おうちさがし → まとめを更新する** で作り直されます。子どもごと・文の しゅるいごとの結果が出ます。
- 子どもの名前は、呼び名かイニシャルで登録してください。

## 注意事項

- 記録は、先生のスプレッドシートとその端末のブラウザに保存されます。ネットにつながらないときは端末にためておき、つながったときに送り直します。
- 同じ子どもが別の Chromebook を使っても、スプレッドシートの進み具合から続きができます。
- 文・家・じゅうにん・ホーせんぱい・音は、すべてこのアプリのためのオリジナルです。
- 家のまどは、1けんの中では ぜんぶ同じ形です。「にわの もの」は、家の左にあるものだけです。町のかざり（井戸・ベンチ・いわ・たる・きりかぶ・がいとう）は、にわの ものと まちがえないものだけにしています。
- ドアと かべが同じ色の家は ありません。ドアと やねが同じ色の家は あります。
- 絵は ChatGPT で作ります。参考にしたゲームの画面などは ChatGPT に読みこませず、「明るい3Dのおもちゃ風」のように、ことばだけで頼みます（`e_chatgpt.md`）。
- 家の設計表（`data/data.js` の `HOUSES`）は、ChatGPT の家の絵と結びついています。絵を作り始めたあとは変えないでください。
- 記録の形式（ステージの `id`、文の しゅるいの名前、シートの見出し）は、あとから変えないでください。
