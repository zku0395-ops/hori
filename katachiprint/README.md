# サンカの かたち ワークシート

小学校の特別支援学級向けの、三角形・四角形のワークシートです（A4たて）。
学習アプリ「サンカと かたちの おうこく」（`katachi/`）と同じ順番で、紙に書いて学びます。

公開先：`https://zku0395-ops.github.io/hori/katachiprint/`

## できること

| こと | 内容 |
|---|---|
| ワークシート | ①〜⑧の8しゅるい。それぞれ50まい（1まいごとに問題がちがいます）。合わせて400まい |
| 学年と名前 | どのまいにも、いちばん上に「　ねん　なまえ」の枠があります |
| 番号 | 右上に「③−07」のような番号があります。答えと合わせるときに使います |
| 答え | しゅるいごとに、答えの PDF があります（1ページに4まい分。13ページ） |
| PDF で保存 | 「この まい」「50まい まとめて」「こたえ」を、ボタン1つで PDF にして保存できます |
| べつの問題 | 「🔄 べつの もんだい」を押すと、50まいが まるごと新しい問題に変わります |
| 白黒でも使える | 色で答えを見分けるところはありません。「あお」「あか」は文字で書いてあります |
| 文字 | ひらがなと分かち書きです。漢字（三角形・四角形・直線・線・点・形・字）には、ふりがなが付きます |

## ワークシートの内容

| しゅるい | 内容 | アプリの場所 |
|---|---|---|
| ① 三角形を かこう | 点を じょうぎで結んで、三角形をかく。（1）番号の順 →（2）大きな点 →（3）★を使う →（4）すきな点 | 1 はじまりの むら |
| ② 四角形を かこう | 同じ進め方で、四角形をかく | 2 かぜの そうげん |
| ③ へんと ちょう点 | へんを青でなぞり、ちょう点に赤で○をつける（4もん）。上に見本があります | サンカの きょうしつ |
| ④ かずを かぞえよう | へんの数と、ちょう点の数を□に書く（6もん） | 3 ささやきの もり |
| ⑤ 三角形・四角形を みつけよう | 9つの形から、三角形を赤、四角形を青でぬる。数も書く | 4 ひかりの どうくつ |
| ⑥ なまえと わけ | 形の名前（三角形・四角形・どちらでも ない）と、わけ（あ〜え）に○をつける（4もん） | 5 なぞの とう |
| ⑦ へんを かきたそう | 太い へん1本に、へんをかき足して、三角形・四角形にする（4もん） | 6 かけはしの たに |
| ⑧ まとめ | うすい字（へん・ちょう点・三角形・四角形・直線）をなぞる。へん・ちょう点の数を書く | まとめ |

- ⑥の「わけ」は、アプリと同じ4つです。
  - あ　3ぼんの 直線で かこまれて いる。
  - い　4ほんの 直線で かこまれて いる。
  - う　まがった 線が ある。（かどが まるい形も これです）
  - え　線が つながって いない。
- ①②⑦は、答えが1つに決まらない問題があります。答えには「（れい）」と書いてあります。
- ⑧は、書くことばが少ないので、にた まい が多くなります。図の形と、文の順番・しゅるいが変わります。

## 支援の工夫

- 1まいに1つのことだけを練習します。①→⑧の順に、少しずつむずかしくなります。
- ①②は、1まいの中でも「番号の順に結ぶ → 大きな点を結ぶ → ★を使う → 自分で選ぶ」と進みます。
- 書く答えは、数字・○・線が中心です。ことばを書くのは⑧だけで、うすい字をなぞります。
- ⑤⑥の「どちらでも ない」には、まちがえやすい形を入れています（1つの へんだけ まがった形、かどが まるい形、線が切れている形、まるい形）。
- 文字は大きく、問題の まわりは すっきりさせています。絵は、上に小さく1つだけです（サンカと、アプリの まもの）。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 印刷用ページ（問題を作る・見る・PDF で保存する） |
| `img/` | サンカと まもの の絵（7まい。`katachi/img/` と同じもの） |
| `pdf/` | 作ってある PDF（①〜⑧ × 50まい と、こたえ。16ファイル） |
| `tools/make-pdf.sh` | `pdf/` の PDF を作り直す道具 |

## 使い方

### 1. 作ってある PDF を使う（かんたん）

1. `https://github.com/zku0395-ops/hori/tree/main/katachiprint/pdf` を開きます。
2. 使いたいファイル（例：`かたちワークシート_3_へんとちょうてん.pdf`）を押します。
3. 右上の「↓（Download raw file）」を押して保存します。
4. PDF を開いて、印刷します。使いたい まい だけ印刷するときは、印刷の画面の「ページ」に番号を入れます（例：`7` や `1-5`）。ページの番号は、右上の番号（③−07 なら 7）と同じです。

### 2. 印刷用ページで PDF を作る

1. `https://zku0395-ops.github.io/hori/katachiprint/` を開きます。
2. 上のボタンで、しゅるい（①〜⑧）を選びます。
3. 「◀ まえ」「つぎ ▶」で、1まいずつ見られます。「✅ こたえを 見る」で、答えが横に出ます。
4. 保存するボタンを押します。「ダウンロード」に PDF が入ります。
   - 「📄 この まいを PDF で ほぞん」… 今 見えている1まい（`katachi_3-07.pdf`）
   - 「📚 50まい まとめて PDF で ほぞん」… その しゅるい の50まい（`katachi_3_50mai.pdf`）
   - 「✅ こたえを PDF で ほぞん」… その しゅるい の答え（`katachi_3_kotae.pdf`）
5. 「🖨 この まいを 印刷」で、そのまま印刷することもできます。

### 3. べつの問題にする

1. 「🔄 べつの もんだい」を押します。50まいが まるごと変わります。
2. 画面と、紙の右下に「くみ 1234」のような番号が出ます。問題と答えは、同じ「くみ」のものを使ってください。
3. 同じ問題をもう一度出したいときは、そのときのページのアドレス（`?type=3&n=7&set=1234`）をブックマークしておきます。

## 先生用画面

このページは、先生が使う印刷用のページです。暗証番号や記録はありません。子どもの名前などは、どこにも送りません。

## 注意事項

- 作ってある PDF（`pdf/`）は、文字や線がくっきりしています。ページのボタンで作る PDF は、絵（画像）として入るので、少しだけ ぼやけます。印刷して使うには十分です。
- ボタンで「50まい まとめて」作る PDF は、7MB ほどあります。
- 文字は、パソコンに入っている字（Windows は BIZ UDゴシック、Chromebook は Noto Sans）で出ます。
- 問題・図・文は、すべてこのワークシートのためのオリジナルです。絵は、アプリ「サンカと かたちの おうこく」のために ChatGPT の AI で作ったものです。
- `index.html` の問題の作り方を変えると、同じ番号でも問題が変わります。そのときは `pdf/` も作り直します。
  1. リポジトリのいちばん上を `http://localhost:8765/` で見られるようにします。
  2. `bash katachiprint/tools/make-pdf.sh` を動かします（Edge を使います）。

## これから相談して決めること

- しゅるいを足すか（タングラム、身のまわりの物から へん・ちょう点をさがす、直角三角形・正方形・長方形 など）。
- ⑧まとめ に、手本なしで書くまい（ことばの はこ から選ぶ）を足すか。
- ①②⑦の点の数（今は 5×5）を、4×4 や 6×6 にも変えられるようにするか。
- 絵をなくした「図形だけ」の版や、文字をもっと大きくした版を作るか。
- 「としょかん」のどの たな に置くか。
