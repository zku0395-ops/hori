# ぶんすう さがし カード（分数の カード）

小学校の特別支援学級向けの、分数の **カード** です。
4×6マスの長方形を区切って、そのうちの 1つを オレンジに ぬっています。
「1/4 の カードを さがそう」「おなじ 大きさに わけていない カードは どれ？」のように使います。

カードは3しゅるいです。どれも セットA・B・C の 50まいずつで、作りかたの きまりは おなじです。

| しゅるい | さがす 分数 | もとに した カード |
|---|---|---|
| 1/4 の カード | オレンジが 全体の 1/4（6マス）の カードが 1セット5まい | 先生の「分数さがしカード（1/4）」 |
| 1/2 の カード | オレンジが 全体の 1/2（12マス）の カードが 1セット5まい | 先生の「分数さがしカード（1/2）」 |
| 1/8 の カード | オレンジが 全体の 1/8（3マス）の カードが 1セット5まい | 1/4・1/2 の カード |

- カードを作るページ：`https://zku0395-ops.github.io/hori/bunsucard/`
- できあがった PDF：`bunsucard/pdf/` に入っています（ページの上の「できあがった PDF」からも開けます）。
- 用紙は **A4たて**、1まいに **8まい**（1まい 100mm × 70mm）です。うら面と一緒に両面印刷します。

## できること

| 項目 | 内容 |
|---|---|
| カード | セットA・B・C、各50まい（ぜんぶで150まい）。**3つのセットは おなじ カード**です（A-1・B-1・C-1 は おなじ図） |
| おもて | 4×6マスの長方形。左上に カードの番号（A-1 など） |
| オレンジ | どのカードも、オレンジは **1つの形** です。オレンジの形の まわりは太い線、中のマスは 細く うすい色の線です（オレンジの中は うすい オレンジ色） |
| のこりの ところ | オレンジに できるだけ近い形で区切ります（例：オレンジが たて長の 2×4 なら、のこりも 2×4 を2つ → 全体を3つに わける） |
| さがす カード | 1/4 の カードでは、オレンジが 全体の 1/4 の大きさ（6マス）の カードが 1セットに **5まい** だけです。1/2 の カードでは、1/2 の大きさ（12マス）の カードが 5まい だけです |
| 切りかえ | カードを作るページの上の「さがす 分数」で 1/4・1/2・1/8 を えらびます |
| まちがいやすい カード | おなじ大きさに わけていない カード（例：4つに わけたが 大きさが ちがう）が まざっています。どれも オレンジは さがす 分数の 大きさでは ありません。1/2 の カードには、「半分に みえるけれど 半分では ない」ななめの線の カードが 多く 入っています |
| うら面 | 「ぶんすう カード」・ピザの せんせいの絵・「セット A」と ？マーク（水玉）。セットで 色が ちがいます（A＝ピンク、B＝水色、C＝黄緑。1/4・1/2・1/8 とも おなじ） |
| こたえの いちらん | どのカードが いくつ分か（1/3 など）。× は おなじ大きさに わけていない カード、★ は さがす 分数（1/4・1/2・1/8）の 大きさの カード |

## 支援の工夫

- オレンジは いつも1つの形で、まわりだけが太い線です。「全体の どれだけか」に目を向けやすくしています。
- のこりも オレンジに近い形で区切るので、「おなじ形が いくつ ならぶか」で 分数が分かります。
- 太い線 いがいの 線は 細く うすい色に して、1つ1つの 形が はっきり 見えるように しています。マスを数えて大きさを くらべることも できます。
- おなじ大きさに わける カードは、どの パーツも 重ねると ぴったり 同じ形に なります（向きを かえたり、うらがえしたり して よい）。形が ちがって 大きさだけ おなじ パーツ（例：2×3 と よこの帯）は 入れていません。
- 4つに区切っていても 大きさが ちがう カードを まぜて、「おなじ 大きさに わける」ことを たしかめられます。
- 3つのセットが おなじなので、グループごとに 1セットずつ くばって、おなじ問題で 学習できます。
- 白黒で印刷しても、オレンジは 灰色で 分かります。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入ると、`https://zku0395-ops.github.io/hori/bunsucard/` で開けます。
2. ページの上の「できあがった PDF」から、PDF を保存できます。

### 2. Apps Script とスプレッドシート

- このカードは記録をとらないので、Apps Script とスプレッドシートは使いません。

### 3. 印刷のしかた

1. 印刷したい PDF を開きます。
2. 印刷の画面で、次のようにします。
   - 用紙サイズ：**A4**、向き：**たて**
   - 倍率：**100%**（「実際のサイズ」）
   - 両面印刷：**オン**（「長辺とじ」）
3. 点線で 切りはなします。厚めの紙に印刷すると 使いやすいです。
4. うら面が いらないときは、カードを作るページで うら面の「なし」を押して印刷します。

- カードを作るページで印刷するときは、上のボタンで さがす 分数（1/4・1/2・1/8）と セットを選んで「🖨 いんさつ」を押します。余白は「なし」、「背景のグラフィック」は オン にしてください。

### 4. Googleサイトに置くとき

- 「ボタン」を置き、リンクに PDF か カードを作るページのURLを入れてください。
