# ぶんすう さがし カード（分数の カード）

小学校の特別支援学級向けの、分数の **カード** です。
長方形を いくつかに区切って、そのうちの いくつかを オレンジに ぬっています。
「1/4 の カードを さがそう」「おなじ 大きさに わけていない カードは どれ？」のように使います。

- カードを作るページ：`https://zku0395-ops.github.io/hori/bunsucard/`
- できあがった PDF：`bunsucard/pdf/` に入っています（ページの上の「できあがった PDF」からも開けます）。
- 用紙は **A4たて**、1まいに **8まい**（1まい 100mm × 70mm）です。うら面と一緒に両面印刷します。

## できること

| 項目 | 内容 |
|---|---|
| カード | セットA・B・C、各50まい（ぜんぶで150まい） |
| おもて | 区切った長方形。左上に カードの番号（A-1 など） |
| 線 | 区切った形の **まわりは太い線**、その中のマスは **細い線**。いちばん外の わくは もっと太い線 |
| ぬりかた | ぬったところは、いつも ひとかたまりの 形（長方形・三角形・台形）。階段の形や、ばらばらに ぬることは しません |
| うら面 | 「ぶんすう カード」・ピザの せんせいの絵・「セット A」と ？マーク（ピンクの水玉） |
| まちがいやすい カード | おなじ大きさに わけていない カード（例：大きい形と小さい形で 1つだけ ぬる）が まざっています |
| こたえの いちらん | どのカードが いくつ分か（4/6（＝2/3）など）。× は おなじ大きさに わけていない カード |

## ステージ構成

カードは セットごとに まとめています。

| セット | ばんごう | まい数 |
|---|---|---|
| A | A-1 〜 A-50 | 50 |
| B | B-1 〜 B-50 | 50 |
| C | C-1 〜 C-50 | 50 |

区切りかたの しゅるい：

| しゅるい | れい |
|---|---|
| たて・よこの 帯 | 1/3、5/6、7/8（たてに8本） |
| 長方形の かたまり | 2×2 で 1/6、3×2 で 1/4 |
| 形のちがう パーツ（おなじ大きさ） | よこ長の帯3つ＋たて長の帯1つ で 1/4 |
| ななめの線 | ×の線で 1/4、ななめ1本で 1/2（三角形・台形） |
| おなじ大きさに わけていない | 大きい形と小さい形で 1つだけ ぬる（分数で あらわせない） |

## 支援の工夫

- 区切った形の まわりだけを太くして、「いくつに わけたか」が すぐ 分かるようにしています。中のマスは細い線なので、マスを数えて 大きさを くらべることも できます。
- ぬったところは ひとかたまりに しています。階段の形や、はなれた ところを ぬると、数えるのが むずかしくなるためです。
- 形はちがっても 大きさが おなじ パーツ（例：よこ長と たて長）で区切った カードを 入れています。「形が ちがっても、大きさが おなじなら 分数で あらわせる」ことに気づけます。
- おなじ大きさに わけていない カードを まぜて、「おなじ 大きさに わける」ことを たしかめられます。
- 白黒で印刷しても、ぬったところは 灰色で 分かります。

## 2026年11月に 直したこと

先生の手書きの見本（○の形）をもとに、次のように直しました。カードの番号は そのままです。

1. **1マスずつ区切った カード（18まい）**：線が全部 太くなっていたので、2マス以上の形で区切り直しました。分数の大きさは そのままです（例：6/20 → 1×2の形で 3/10）。まとめられない 5/24・7/24 の カードは、手書きの ○ の形（形のちがう4つ・ななめの台形・たての4つ・×・よこの3つ）に入れかえました。
2. **ぬったところが 階段・ばらばらの カード（28まい）**：ぬる場所を ひとかたまりに しました。ぬった数と 区切った数は そのままです。そのままでは まとめられない 5/8・7/8・5/6・7/10・7/12 は、たての帯（8本・6本・10本・12本）か、形のちがう パーツ（おなじ大きさ）に しました。

- 直した カードは、ページの「直した カードに しるし」を押すと、画面で「なおした」と 出ます（印刷には 出ません）。こたえの いちらんでは ★ が つきます。
- どう直したかは、`cards.js` の それぞれの カードの `kaeta` に 書いてあります。

## ファイル構成

```
bunsucard/index.html          カードを作るページ（?set=A でセットAだけ、&ura=0 で うら面なし、?kotae=1 で こたえの いちらん）
bunsucard/cards.js            150まいの カードの データ（区切りかたと ぬるところ）

bunsucard/pdf/                PDF（5ファイル）
```

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入ると、`https://zku0395-ops.github.io/hori/bunsucard/` で開けます。
2. ページの上の「できあがった PDF」から、PDF を保存できます。

### 2. Apps Script とスプレッドシート

- このカードは記録をとらないので、Apps Script とスプレッドシートは使いません。

### 3. 印刷のしかた

1. 印刷したい PDF を開きます。
2. 印刷の画面で、次のようにします。
   - 用紙サイズ：**A4**、向き：**たて**
   - 倍率：**100%**（「実際のサイズ」）
   - 両面印刷：**オン**（「長辺とじ」）
3. 点線で 切りはなします。厚めの紙に印刷すると 使いやすいです。
4. うら面が いらないときは、カードを作るページで うら面の「なし」を押して印刷します。

- カードを作るページで印刷するときは、上のボタンで セットを選んで「🖨 いんさつ」を押します。余白は「なし」、「背景のグラフィック」は オン にしてください。

### 4. Googleサイトに置くとき

- 「ボタン」を置き、リンクに PDF か カードを作るページのURLを入れてください。
