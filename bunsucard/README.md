# ぶんすう さがし カード（分数の カード）

小学校の特別支援学級向けの、分数の **カード** です。
4×6マスの長方形を区切って、そのうちの 1つを オレンジに ぬっています。
「1/4 の カードを さがそう」「おなじ 大きさに わけていない カードは どれ？」のように使います。

- カードを作るページ：`https://zku0395-ops.github.io/hori/bunsucard/`
- できあがった PDF：`bunsucard/pdf/` に入っています（ページの上の「できあがった PDF」からも開けます）。
- 用紙は **A4たて**、1まいに **8まい**（1まい 100mm × 70mm）です。うら面と一緒に両面印刷します。

## できること

| 項目 | 内容 |
|---|---|
| カード | セットA・B・C、各50まい（ぜんぶで150まい）。**3つのセットは おなじ カード**です（A-1・B-1・C-1 は おなじ図） |
| おもて | 4×6マスの長方形。左上に カードの番号（A-1 など） |
| オレンジ | どのカードも、オレンジは **1つの形** です。オレンジの形の まわりは太い線、中のマスは細い線です |
| のこりの ところ | オレンジに できるだけ近い形で区切ります（例：オレンジが たて長の 2×4 なら、のこりも 2×4 を2つ → 全体を3つに わける） |
| 1/4 の カード | オレンジが 全体の 1/4 の大きさ（6マス）の カードは、1セットに **5まい** だけです |
| まちがいやすい カード | おなじ大きさに わけていない カード（例：4つに わけたが 大きさが ちがう）が まざっています。どれも オレンジは 1/4 の大きさでは ありません |
| うら面 | 「ぶんすう カード」・ピザの せんせいの絵・「セット A」と ？マーク（ピンクの水玉） |
| こたえの いちらん | どのカードが いくつ分か（1/3 など）。× は おなじ大きさに わけていない カード、★ は 1/4 の大きさの カード |

## ステージ構成

1セット50まいの なかみです（A・B・C おなじ）。

| オレンジの大きさ | まい数 | 区切りかたの れい |
|---|---|---|
| 1/4 | 5 | よこの帯4つ／3×2 の長方形4つ／×の線／かどからの三角形4つ／形のちがう4つ（2×3 が3つ＋よこの帯） |
| 1/2 | 8 | たて・よこ半分／ななめの線（三角形）／台形 |
| 1/3 | 8 | たての帯3つ／形のちがう3つ（2×4 と 4×2） |
| 1/6 | 8 | たての帯6つ／2×2 の正方形6つ／形のちがう6つ |
| 1/8 | 6 | 3×1 の帯8つ／×と十字の線（三角形8つ）／形のちがう8つ |
| 1/12 | 5 | 1×2 や 2×1 の形12こ |
| おなじ大きさに わけていない | 10 | 大きさのちがう形で区切り、1つだけ オレンジ |

- 1/4 の カードは 4・13・22・36・47 ばんです。

## 支援の工夫

- オレンジは いつも1つの形で、まわりだけが太い線です。「全体の どれだけか」に目を向けやすくしています。
- のこりも オレンジに近い形で区切るので、「おなじ形が いくつ ならぶか」で 分数が分かります。
- 中のマスは細い線なので、マスを数えて大きさを くらべることも できます。
- 形はちがっても 大きさが おなじ パーツで区切った カードがあります（例：2×3 と よこの帯）。「形が ちがっても、大きさが おなじなら 1/4」に気づけます。
- 4つに区切っていても 大きさが ちがう カードを まぜて、「おなじ 大きさに わける」ことを たしかめられます。
- 3つのセットが おなじなので、グループごとに 1セットずつ くばって、おなじ問題で 学習できます。
- 白黒で印刷しても、オレンジは 灰色で 分かります。

## 公開の手順

### 1. GitHub Pages

1. このフォルダが `main` ブランチに入ると、`https://zku0395-ops.github.io/hori/bunsucard/` で開けます。
2. ページの上の「できあがった PDF」から、PDF を保存できます。

### 2. Apps Script とスプレッドシート

- このカードは記録をとらないので、Apps Script とスプレッドシートは使いません。

### 3. 印刷のしかた

1. 印刷したい PDF を開きます。
2. 印刷の画面で、次のようにします。
   - 用紙サイズ：**A4**、向き：**たて**
   - 倍率：**100%**（「実際のサイズ」）
   - 両面印刷：**オン**（「長辺とじ」）
3. 点線で 切りはなします。厚めの紙に印刷すると 使いやすいです。
4. うら面が いらないときは、カードを作るページで うら面の「なし」を押して印刷します。

- カードを作るページで印刷するときは、上のボタンで セットを選んで「🖨 いんさつ」を押します。余白は「なし」、「背景のグラフィック」は オン にしてください。

### 4. Googleサイトに置くとき

- 「ボタン」を置き、リンクに PDF か カードを作るページのURLを入れてください。
