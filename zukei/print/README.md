# トンガリはかせの ずけい プリント（三角形・四角形）

図形アプリ「トンガリはかせの ロボット けんきゅうじょ」（[zukei/](../README.md)）と同じ順で練習する、紙のワークシートです。
点をむすんで三角形・四角形をかく、へんとちょう点を数える、形を見分ける、を、スモールステップで練習します。

- プリントを作るページ：`https://zku0395-ops.github.io/hori/zukei/print/`
- できあがった PDF：`zukei/print/pdf/` にあります（ステージごとに1つと、ぜんぶ）
- 用紙は **A4たて**、カラーです。記録はとりません。

## できること

| 項目 | 内容 |
|---|---|
| ステージ | アプリのステージ0〜6の7つ（タングラムは入れていません） |
| れんしゅう | ステージごとに5まい（①かんたん → ⑤むずかしい）。全部で35まい |
| まとめテスト | ステージごとに3まい。全部で21まい。「できた かず」の欄があります |
| こたえ | すべてのプリントに、こたえのページがあります（答えは赤）。自分で点を選ぶ問題は「（れい）」として1つ示します |
| 学年・名前 | PDF は欄が空いています（子どもが手で書きます）。作るページで学年と名前を入れると、入った形で印刷できます |
| 問題 | PDF は決まった問題です。作るページの「べつの もんだいに する」を押すと、新しい問題とこたえを作ります |
| プリントの上 | ステージ名、れんしゅう／まとめテストの番号、トンガリはかせ、「ねん・がつ・にち・なまえ」、はかせの声かけ（やり方） |
| プリントの下 | ロボットと「できたかな？」（よく できた・できた・もう すこし の顔に○を付けます） |

## ステージ構成

| ステージ | れんしゅう①〜⑤ | まとめテスト①〜③ |
|---|---|---|
| 0 てんと せん | ①赤い点をむすぶ（うすい線をなぞる）　②赤い点をむすぶ　③自分で点を選ぶ（よこ・たて）　④ななめ　⑤はしから はしまで（5×5の点） | 赤い点・自分で選ぶ・はしから はしまで をまぜて6問 |
| 1 三角形を つくろう | ①赤い3つの点をむすぶ（はじめの1本はなぞる）　②赤い3つの点をむすぶ　③自分で3つ選ぶ　④赤い点1つと、自分で選んだ点2つ　⑤おおきな・ちいさな・さかさまの三角形（6×6の点） | 6問（①は4×4、③は6×6の点） |
| 2 四角形を つくろう | 三角形と同じ進み方で、点は4つ。⑤は おおきな・ちいさな・へんが ぜんぶ ななめの四角形 | 6問 |
| 3 へんと ちょう点 | ①へんをなぞって数える　②ちょう点に○を付けて数える　③三角形のへんとちょう点を数える　④四角形で数える　⑤いろいろな形で（6問） | 形4つ＋「三角形の へんは □本、ちょう点は □つ」「四角形の…」 |
| 4 みつけよう | ①三角形をぬる　②三角形をぬる（四角形もまざる）　③四角形をぬる　④四角形をぬる（三角形もまざる）　⑤三角形は赤、四角形は青でぬる（どれも9この形から） | 12この形から。①三角形　②四角形　③両方 |
| 5 どっちかな？ | ①②「三角形／どちらでも ない」を○でかこむ　③④「三角形／四角形／どちらでも ない」　⑤わけ（ア・イ・ウ）も選ぶ | ①3つから選ぶ（5問）　②③わけも選ぶ（4問） |
| 6 かきたそう | ①青い線のはしと赤い点をむすぶ（1本はなぞる）　②赤い点へ（三角形・四角形）　③自分で点を選んで三角形（へんを2本）　④ななめの線から三角形　⑤四角形（へんを3本、5×5の点） | 三角形・四角形をまぜて6問 |

- 点をむすぶプリント（ステージ0・1・2・6）は、1まいに6問です。点の間は 9〜13.5mm あります。
- まとめテストは、こたえを見て○の数を「できた かず」に書きます。

## りゆうの プリント（A4よこ・40まい）

先生のワークシート「三角形と四角形①〜」と同じ形のプリントです。作るページは `https://zku0395-ops.github.io/hori/zukei/print/riyu.html` です。

- 1まいに形が4つ（あ・い・う・え）あります。「三角形・四角形・どちらでも ない」を○でかこみ、理由を答えます。
- **りゆうを えらぶ ①〜⑳**：理由を ア・イ・ウ から選んで○を付けます。
- **りゆうを かく ①〜⑳**：理由を自分で書きます。下に「ことばの ヒント」（直線・3本・4本・かこまれて いる など）があります。ヒントは、作るページでなくせます。
- こたえ（40まい）は赤です。「かく」の理由は「（れい）」として示します。
- 上に「ねん・がつ・にち・なまえ」の欄があります。作るページで学年と名前を入れて印刷できます。

| まい | 出てくる形 |
|---|---|
| ①〜④ | きほんの形（三角形・正方形・長方形）と、円・だ円・でこぼこの形 |
| ⑤〜⑧ | 向きや形がちがう三角形・四角形（さかさま・ほそながい・ひし形・台形など）と、かどが丸い形 |
| ⑨〜⑫ | すきまがある形、まがった線がある形 |
| ⑬〜⑯ | へこんだ四角形・たこ形、五角形・六角形・半円・おうぎ形。形の向きもいろいろです |
| ⑰〜⑳ | まとめ（L字の形・家の形など、直線が5本・6本の形も入ります） |

- どのまいにも、三角形・四角形・どちらでもない形が、1つ以上入っています。
- PDF を作り直すときは、`node zukei/print/tools/make-pdf-riyu.js` を動かします。

## 支援の工夫

- **スモールステップ**：「赤い点＋なぞり」→「赤い点だけ」→「自分で選ぶ」→「ことばに合う形」の順に、手がかりを少しずつ減らします。アプリの「光る点」を、紙では赤い大きな点にしました。
- **白黒でも分かる**：むすぶ点は「大きな点＋まわりの輪」、もとの直線は「太い線」、なぞる線は「点線」にしています。色だけで区別していません。
- **文字**：ひらがなの分かち書きです。漢字（三角形・四角形・本・点）には、ふりがなを付けています。
- **へんと ちょう点**：れんしゅう①〜④の上に、「へん」「ちょう点」の説明の図を入れています。
- **まちがいやすい形**：「みつけよう」「どっちかな？」には、かどが丸い形・すきまがある形・まがった線がある形・円を入れています。アプリと同じ形です。
- **四角形**：赤い点をむすぶ問題は、へこんでいない形にしています。自分でかく問題は、へこんだ四角形も正解です。
- **ゆったり書ける**：1まいの問題を4〜6問（みつけようは9〜12この形）にしています。時間は決めていません。
- **ふりかえり**：下の「できたかな？」で、自分で顔を選んで○を付けます。

## 公開の手順

### 1. GitHub Pages で公開する

- 変更を `main` に取り込む（Pull Request をマージする）と、数分後に `https://zku0395-ops.github.io/hori/zukei/print/` で開けるようになります。
- Apps Script やスプレッドシートは使いません。

### 2. 印刷する

**PDF をそのまま使うとき**

1. 作るページの上にある「📄 0 てんと せん」などのボタンを押します。PDF が新しいタブで開きます。
2. 右上の印刷のアイコン（または Ctrl＋P）を押します。
3. 一部だけ印刷するときは、「ページ」で「カスタム」を選び、ページ番号を入れます。
   - れんしゅう①〜⑤＝1〜5ページ、まとめテスト①〜③＝6〜8ページ、こたえ＝9〜16ページです。

**作るページから印刷するとき（学年・名前入り、べつの問題）**

1. 「1. プリントを えらぶ」で、印刷したいステージの「れんしゅう」「まとめテスト」にチェックを入れます。
2. 学年と名前を入れると、入った形で印刷されます。空けておくと、子どもが手で書けます。
3. こたえも印刷するときは「こたえの ページも つける」にチェックを入れます。
4. 「🖨 いんさつ する」を押します。
5. 印刷の画面で、用紙は「A4」、倍率は「100%（実際のサイズ）」、「背景のグラフィック」をオンにします。

- 「べつの もんだいに する」を押すと、PDF とはちがう問題になります。「もとの もんだいに もどす」で、PDF と同じ問題にもどります。

## 注意事項

- **絵**：トンガリはかせとロボットの絵は、図形アプリと同じ画像です（先生の Canva で、このアプリのために作りました）。点・形・顔のしるしは、プログラムで描いています（オリジナル）。
- **問題**：アプリと同じきまりで作った、オリジナルの問題です。
- **白黒で印刷するとき**：「みつけよう」⑤とテスト③は、子どもが赤と青でぬり分けます。色えんぴつがいります。
- **じょうぎ**：線をひくプリントは、じょうぎを使うときれいにひけます。フリーハンドでもかまいません。
- **使っているもの**：BIZ UDPゴシック（Google Fonts）をインターネット経由で読み込んでいます。
- **PDF を作り直すとき**：`node zukei/print/tools/make-pdf.js` を動かします（Playwright と Chromium がいります）。

## これから相談して決めること

- タングラムのプリント（切って使うピース）を足すか
- 発展（五角形の「どっちかな」など）のプリントを足すか
- 点の数や間の広さ（いまは 4×4・5×5・6×6）を変えるか
- まとめテストの数（いまは各3まい）を増やすか
