# トンガリはかせの ロボット けんきゅうじょ

小学校の特別支援学級（1〜4年生）向けの、三角形・四角形の学習アプリです。
研究所の「トンガリはかせ」が、声で問題を出します。
子どもは、点をむすんで形を作ったり、形を見分けたりして、三角形と四角形を学びます。
正解すると「せいかい！」の声とファンファーレが流れ、自分のロボット（例：たろうロボ）がパワーアップします。

## できること

| 項目 | 内容 |
|---|---|
| 学習 | 8つのステージ・25のステップ（うち発展2つ）。1回は4〜6問（タングラムは1〜5問）で、5〜10分で終わります |
| 文字 | ひらがなと分かち書きが中心です。「三角形」「四角形」「直線」「点」「本」だけ漢字を使い、すべてにふりがなを付けています |
| 声 | はかせのセリフはすべて読み上げます（少しゆっくりめ）。はかせや吹き出しを押すか「🔊 もういちど」で聞き直せます |
| ヒント | 3段階です。2回まちがえるとヒントボタンが光り、3回まちがえると いちばんくわしいヒントが自動で出ます |
| ごほうび | 正解するたびに「⚡パワー」がたまります。1回分が終わると、ロボットのアイテムや衣装（全29種類）が1つもらえます。ステージをクリアするとロボットがレベルアップします |
| 先生用画面 | 暗証番号4けたで開きます。どの形でつまずいているかが分かる記録、設定、CSV書き出し、記録の消去ができます |
| 記録 | 問題が終わるたびに、先生のスプレッドシートに自動で届きます |

## ステージ構成

| ステージ | 内容 | ステップ |
|---|---|---|
| 0 てんと せん | 2つの点をむすんで、まっすぐな線をひく | ①光る点をむすぶ　②自分で点を選ぶ（よこ・たて・ななめ・はしからはしまで） |
| 1 三角形を つくろう | ドットから3つの点を選んで三角形を作る | ①光る点で（4×4）　②自分で（4×4、毎回ちがう形）　③自分で（6×6。大きな・小さな・さかさまの三角形） |
| 2 四角形を つくろう | ドットから4つの点を選んで四角形を作る（へこんだ形も正解） | ①光る点で　②自分で（4×4）　③自分で（6×6。大きな・小さな・へんが全部ななめの四角形） |
| 3 へんと ちょう点 | へん・ちょう点を知り、タップして数える | ①三角形で数える　②四角形で数える　③「へんは なん本？」「ちょう点は いくつ？」 |
| 4 みつけよう | 6つの形から、三角形（四角形）を全部見つける | ①三角形　②四角形　③まざった中から |
| 5 どっちかな？ | 「三角形／四角形／どちらでもない」を決め、次に理由を選ぶ | ①三角形か どちらでもないか　②四角形も入れて　③いろいろな形で　（発展）五角形 |
| 6 かきたそう | 1本の直線に、へんを書き足して形を作る | ①光る点で　②三角形（へんを2本）　③四角形（へんを3本）　（発展）同じ直線から ちがう三角形を2つ |
| 7 タングラム | 黒い影の上にピースを置いて形を作る。できたら形やピースの数を答える | ①2まいで　②3〜4まいで（いえ・ふね・さかな）　③7まいで（正方形・ロボット・ロケット） |

- ステップは、前のステップが終わると順に開きます。次のステージは、前のステージをクリアすると開きます。
- 発展のステップは、最初は閉じています。先生用画面の「設定」で開けます。
- 途中でやめても、ホームの「▶ つづきから」で続きのステップから始められます。

### 理由の選択肢（ステージ5）

- 3本の直線で かこまれて いるので 三角形
- 4本の直線で かこまれて いるので 四角形
- まがった せんが あるので どちらでもない
- せんが つながって いないので どちらでもない
- かどが まるく なって いるので どちらでもない
- 5本の直線で かこまれて いるので どちらでもない（発展）

## 支援の工夫

- **まちがいにしない気づき**：3つの点が一直線にならんだときは「ぺちゃんこだね」、四角形の線が交わったときは「せんが ぶつかって いるよ」と はかせが話し、点を選びなおせます。まちがいの回数には入れません。
- **まちがいやすい形を入れる**：さかさまの三角形、ほそ長い三角形、かたむいた四角形、へこんだ四角形、かどが丸い形、すき間がある形、曲線がある形を出します。
- **まちがえ方に合わせた声かけ**：例「かどが まるく なって いるね。三角形は かどが とがって いるよ」「おなじ ところを 2かい かぞえて いないかな？」
- **まちがえた選択肢は消えます**。何度でも選びなおせます。まちがえたときの音は、小さくやさしい音です。
- **ヒントは3段階**です。
  - 点をむすぶ問題：①ことば　②点線の見本　③番号つきで点が光る
  - 数える問題：①ことば　②へんやちょう点の色分け　③いっしょに数えるアニメーションと、答えが光る
  - 見つける・どっちかな：①ことば　②へんの色分けと、丸いかど・すき間・曲線を光らせる　③答えが光る
  - タングラム：①ことば　②区切りの線が出る　③ピースを1まい、置く場所といっしょに光らせる
- **ドラッグがむずかしい子のために**、点はタップだけでむすべます。タングラムのピースは、タップして選ぶと「◀ ▲ ▼ ▶」「まわす」「うらがえす」のボタンでも動かせます。正しい場所の近くに置くと、ぴたっとはまります。
- 問題の画面は、白い方眼のすっきりした背景です。研究所の絵は、ホームとごほうびの画面だけで使います。
- 時間制限はありません。

## ファイル構成

```
zukei/index.html   アプリ本体（Apps Script の HTML ファイル「index」として貼り付けます）
zukei/コード.gs     Apps Script：画面を出す・記録をスプレッドシートに書く
```

カタカナアプリと同じ「Apps Script だけ」の形です。マイクを使わないので、GitHub Pages は使いません。

## 公開の手順

### 1. GitHub Pages

このアプリは GitHub Pages を使いません。2 の手順だけで使えます。

### 2. Apps Script とスプレッドシートの準備（学校のアカウントで）

1. Google ドライブで、新しいスプレッドシートを作ります（名前の例：「ロボット けんきゅうじょ 記録」）。
   - 音読・角・分数・カタカナとは別のスプレッドシートにします。
2. メニュー「拡張機能」→「Apps Script」を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの `コード.gs` の中身を貼り付けます。
4. 左の「ファイル」の「＋」→「HTML」を押し、名前を `index` にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの `index.html` の中身を貼り付けます。貼り付け方は、下の「長いファイルの貼り付け方」を見てください。
6. 💾（保存）を押します。
7. 上の関数の選択欄で `setup` を選び、「▶ 実行」を押します。
   - 初回は「承認が必要です」と出ます。自分のアカウントを選んで「許可」を押します。
   - 「このアプリは Google で確認されていません」と出たときは、「詳細」→「（プロジェクト名）に移動」を押します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。
8. 「名簿」シートの **A列（2行目から）** に、子どもの名前を **ひらがな** で入れます。
   - B列は、アプリが進み具合を自動で書く欄です。手で書きかえないでください。
   - 名前は呼び名かイニシャルにしてください。
9. 「せってい」シートの暗証番号（最初は 1234）を、ほかの人に分からない4けたに変えます。
10. 右上の「デプロイ」→「新しいデプロイ」を押します。
    - 左の歯車から種類「ウェブアプリ」を選びます。
    - 「次のユーザーとして実行」：**自分**
    - 「アクセスできるユーザー」：**（学校のドメイン）内の全員**
11. 「デプロイ」を押し、表示された「ウェブアプリ」のURLをコピーします。Classroom などで子どもに配ります。

> 「次のユーザーとして実行：自分」にすると、子どもにスプレッドシートを共有しなくても記録が届きます。

**プログラムを書き換えたとき**
「デプロイ」→「デプロイを管理」→ 鉛筆のアイコン →「バージョン：新バージョン」→「デプロイ」を押します。URLは変わりません。

**長いファイルの貼り付け方**（`index.html` は長いので、途中で切れることがあります）

1. GitHub で `zukei/index.html` を開き、右上の「Raw」を押します。
2. ブラウザが「翻訳しますか？」と聞いてきたら、「翻訳しない」を押します。
3. Ctrl＋A（全部選ぶ）→ Ctrl＋C（コピー）を押します。
4. Apps Script の `index.html` の中身を全部消して、Ctrl＋V で貼り付けます。
5. いちばん下までスクロールして、最後の行が `</html>` になっているか確かめます。
6. 💾（保存）を押し、「新バージョン」でデプロイします。

「止まった」「開かない」「じゅんび ちゅう… のまま」のときは、まず貼り付けが最後まで入っているかを確かめてください。

### 3. Chromebook の準備

1. 配ったURLを開き、ブックマークかショートカットにしておきます。
2. 音が出るか確かめます。はかせの声は、最初に名前のボタンを押したあとから出ます。
3. 声が出ないときは、Chromebook の音量とミュートを確かめてください。
   - 声は、Chromebook に入っている日本語の読み上げ機能を使います。インターネットにつながっている必要があります。

### 4. Googleサイトに置くとき（必要なときだけ）

「埋め込む」ではなく、**「ボタン」**で置いてください。埋め込むと、枠の中に小さく出て使いにくくなります。

1. Googleサイトの編集画面で、右側の「挿入」→「ボタン」を押します。
2. 「名前」に「ロボット けんきゅうじょ」、「リンク」にウェブアプリのURLを入れて、「挿入」を押します。
3. 右上の「公開」を押します。

## 先生用画面

画面の右下（または右上）の **🔒 せんせい** を押し、暗証番号を入れると開きます。

| タブ | できること |
|---|---|
| 📊 記録 | クラス全体：子どもごとの「いま学習中」「クリアしたステージ」「1回目正答率」「多いまちがい」、クラスで多いまちがい、形ごとの1回目正答率 |
| | 子どもごと：ステップごとの進み具合と正答率、つまずいている形・問題、まちがい方（例「えらんだ：かどが丸い形（三角）」「見のがし：さかさまの三角形」）。「全部のステージを開く」ボタンもここにあります |
| ⚙️ 設定 | 読み上げの速さ（最初は0.85）、声の高さ、文字の大きさ、効果音の大きさ、発展の問題を開く。「保存する」を押すと、スプレッドシートの「せってい」シートに書かれ、子どもの画面にも反映されます |
| 💾 データ | 記録のCSV書き出し、子ども1人分の記録の消去 |

- 「1回目正答率」は、1回目で正解した割合です。まちがえたあとにやり直して正解したものは含みません。
- 「（気づき）」が付いた記録は、ぺちゃんこ・線が交わったなど、まちがいにしていない場面です。

## 全員の記録を見る

スプレッドシートで見られます。

| シート | 内容 |
|---|---|
| きろく | 1問ごとの記録（日時・なまえ・ステージ・ステップ・もんだい・かたち・けっか・かいすう・ヒント・まちがい）。けっかは、1回目で正解が「○」、やり直して正解が「△」です |
| まとめ | 子どもごと・形（問題）ごとの1回目正答率を、低い順に並べます。おもなまちがいも書きます。先生用画面を開いたとき、またはメニュー「ロボット けんきゅうじょ → まとめを更新する」で作り直されます |
| せってい | 暗証番号・読み上げの速さなど |
| 名簿 | 子どもの名前と、進み具合（自動） |

## 注意事項

- 記録は、先生のスプレッドシートにだけ書かれます。外のサービスには送りません。
- 通信が切れたときの記録は、その端末にためておき、次に記録するとき（またはネットにつながったとき）にまとめて送り直します。
- 「名簿」のB列（進み具合）や「きろく」シートの見出しは、変えないでください。
- 絵（トンガリはかせ、ロボット、アイテム、研究所の背景）は、すべてこのアプリのために作ったオリジナルです。絵文字も使っています。
- タングラムは、昔からある7まいの切り分け方を、このアプリで1から描き直したものです。
- 効果音とファンファーレは、アプリの中で音を作って鳴らしています（ほかの音源は使っていません）。

## これから相談して決めること

- タングラムのお題を増やすか（ねこ、うさぎ、ひと など）
- ステージ6（かきたす）で、点の数を多くした問題を入れるか
- ステージ3で、ちょう点やへんを「なぞる」練習を入れるか
- ごほうびのアイテムを増やすか（全部集めたあとは「ぴかぴか スター」がもらえます）
- 長方形・正方形・直角三角形（2年生の内容）へつなげるステージを作るか
