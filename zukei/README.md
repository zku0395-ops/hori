# トンガリはかせの ロボット けんきゅうじょ

小学校の特別支援学級（1〜4年生）向けの、三角形・四角形の学習アプリです。
研究所の「トンガリはかせ」が、声で問題を出します。
子どもは、点をむすんで形を作ったり、形を見分けたりして、三角形と四角形を学びます。
正解すると「せいかい！」の声とファンファーレが流れ、自分のロボット（例：たろうロボ）がパワーアップします。

## できること

| 項目 | 内容 |
|---|---|
| 学習 | 8つのステージ。1回は5問（タングラムは1〜5問）で、5〜10分で終わります。**10回（50問）で1セット**です。1セット終わると、そのステージのクリアです |
| 文字 | ひらがなと分かち書きが中心です。「三角形」「四角形」「直線」「点」「本」だけ漢字を使い、すべてにふりがなを付けています |
| 声 | はかせのセリフはすべて読み上げます（少しゆっくりめ）。はかせや吹き出しを押すか「🔊 もういちど」で聞き直せます |
| ヒント | 3段階です。2回まちがえるとヒントボタンが光り、3回まちがえると いちばんくわしいヒントが自動で出ます |
| ごほうび | 正解するたびに「⚡パワー」がたまります。1回分が終わると、ロボットのアイテムや衣装（全29種類）が1つもらえます。全部集めたら、同じアイテムの「キラキラ版」がもらえます。ステージをクリアするとロボットがレベルアップします |
| 先生用画面 | 暗証番号4けたで開きます。どの形でつまずいているかが分かる記録、設定、スプレッドシートへの送信、CSV書き出し、バックアップ、記録の消去ができます |
| 記録 | その Chromebook の中に保存し、1回終わるごとに先生のスプレッドシートにも自動で届きます |
| 使い方 | GitHub Pages で公開します。1台の Chromebook を1人で使います |

## ステージ構成

1セット（10回）の中で、次のようにステップが進みます。

| ステージ | 内容 | 10回の進み方 |
|---|---|---|
| 0 てんと せん | 2つの点を選んで、まっすぐな線でむすぶ | 1〜4回目：光る点で　5〜10回目：自分で点を選ぶ（よこ・たて・ななめ・はしからはしまで） |
| 1 三角形を つくろう | ドットから3つの点を選び、むすんで三角形を作る | 1〜3回目：光る点で（4×4）　4〜7回目：自分で（4×4、毎回ちがう形）　8〜10回目：自分で（6×6。大きな・小さな・さかさまの三角形） |
| 2 四角形を つくろう | ドットから4つの点を選び、むすんで四角形を作る（へこんだ形も正解） | 1〜3回目：光る点で　4〜7回目：自分で（4×4）　8〜10回目：自分で（6×6。大きな・小さな・へんが全部ななめの四角形） |
| 3 へんと ちょう点 | へん・ちょう点を知り、タップして数える | 1〜3回目：三角形で数える　4〜6回目：四角形で数える　7〜10回目：「へんは なん本？」「ちょう点は いくつ？」 |
| 4 みつけよう | 6つの形から、三角形（四角形）を全部見つける | 1〜3回目：三角形　4〜6回目：四角形　7〜10回目：まざった中から |
| 5 どっちかな？ | 「三角形／四角形／どちらでもない」を決め、次に理由を選ぶ | 1〜3回目：三角形か どちらでもないか　4〜6回目：四角形も入れて　7〜10回目：いろいろな形で |
| 6 かきたそう | 1本の直線に、点を選んで へんを書き足し、形を作る | 1〜3回目：光る点で　4〜7回目：三角形（へんを2本）　8〜10回目：四角形（へんを3本） |
| 7 タングラム | 黒い影の上にピースを置いて形を作る。できたら形やピースの数を答える | 1〜3回目：2まい（1回5問）　4〜7回目：3〜4まい（1回3問）　8〜10回目：7まい（1回1問） |

- 次のステージは、前のステージの1セット（10回）が終わると開きます。
- ホームとステージの画面に、何回終わったか（例：4／10かい）が出ます。
- 途中でやめても、ホームの「▶ つづきから」で続きの回から始められます。
- ステージの画面の「れんしゅう」から、すでに開いたステップを何回でも練習できます。練習は10回の数には入りません（その回でするステップを選んだときだけ数えます）。
- 発展（五角形の「どっちかな」、同じ直線から ちがう三角形を2つ）は、最初は閉じています。先生用画面の「設定」で開けます。10回の数には入りません。

### 点のむすび方（ステージ0・1・2・6）

1. **点を選ぶ**：点を押すと色が変わり、番号が付きます。もう一度押すと、選ぶのをやめられます。
2. 必要な数（線は2つ、三角形は3つ、四角形は4つ）を選ぶと、はかせが「えらんだ てんと てんを むすぼう」と話します。
3. **むすぶ**：選んだ点を2つ順に押すと、線が1本ひけます。指でなぞってもひけます。へんが全部ひけたら完成です。
4. ステージ6では、もとの直線の両はしの点は最初から選ばれています。新しい点を1つ（三角形）か2つ（四角形）選んでから、線をひきます。
5. 「↩ 1つ もどす」で1つ前にもどれます。「えらびなおす」で、点の選びなおしからやり直せます。

### タングラムのお題

| ステップ | お題 |
|---|---|
| 2まい（8種類） | 三角形、四角形、かたむいた四角形、大きな四角形、大きな三角形、さかさまの三角形、四角形（2種類） |
| 3〜4まい（8種類） | いえ、ふね、さかな、き、大きないえ、ねこ、やじるし、ヨット |
| 7まい（6種類） | 正方形、ロボット、ロケット、きかんしゃ、ひと、きのこ |

### 理由の選択肢（ステージ5）

- 3本の直線で かこまれて いるので 三角形
- 4本の直線で かこまれて いるので 四角形
- まがった せんが あるので どちらでもない
- せんが つながって いないので どちらでもない
- かどが まるく なって いるので どちらでもない
- 5本の直線で かこまれて いるので どちらでもない（発展）

## 支援の工夫

- **まちがいにしない気づき**：3つの点が一直線にならんだときは「ぺちゃんこだね」、線が交わったときは「せんが ぶつかって いるよ」と はかせが話し、点や線を選びなおせます。まちがいの回数には入れません。
- **まちがいやすい形を入れる**：さかさまの三角形、ほそ長い三角形、かたむいた四角形、へこんだ四角形、かどが丸い形、すき間がある形、曲線がある形を出します。
- **まちがえ方に合わせた声かけ**：例「かどが まるく なって いるね。三角形は かどが とがって いるよ」「おなじ ところを 2かい かぞえて いないかな？」
- **まちがえた選択肢は消えます**。何度でも選びなおせます。まちがえたときの音は、小さくやさしい音です。
- **ヒントは3段階**です。
  - 点をむすぶ問題：①ことば　②点線の見本　③番号つきで点が光る
  - 数える問題：①ことば　②へんやちょう点の色分け　③いっしょに数えるアニメーションと、答えが光る
  - 見つける・どっちかな：①ことば　②へんの色分けと、丸いかど・すき間・曲線を光らせる　③答えが光る
  - タングラム：①ことば　②区切りの線が出る　③ピースを1まい、置く場所といっしょに光らせる
- **ドラッグがむずかしい子のために**、点は2つを順に押すだけでむすべます（なぞってもむすべます）。タングラムのピースは、タップして選ぶと「◀ ▲ ▼ ▶」「まわす」「うらがえす」のボタンでも動かせます。正しい場所の近くに置くと、ぴたっとはまります。
- 問題の画面は、白い方眼のすっきりした背景です。研究所の絵は、ホームとごほうびの画面だけで使います。
- 時間制限はありません。

## ファイル構成

```
zukei/index.html     アプリ本体（GitHub Pages で公開します）
zukei/img/           Canva で作った絵（ロボット・トンガリはかせ・研究所の背景）
zukei/gas/Code.gs    Apps Script：入口ページと記録の受け取り口
zukei/gas/start.html Apps Script：入口ページの画面
```

音読・角・分数のアプリと同じ形です。
アプリ本体は GitHub Pages で公開します。Apps Script は、先生のスプレッドシートに付けて「入口ページ」と「記録の受け取り口」に使います。

## 公開の手順

### 1. GitHub Pages

アプリ本体は、次のURLで開けます（`main` に入ると、数分で新しくなります）。

`https://zku0395-ops.github.io/hori/zukei/`

- GitHub Pages の設定は、音読アプリと同じです（Settings → Pages で `main` の `/ (root)`）。新しく設定することはありません。

### 2. Apps Script とスプレッドシートの準備（学校のアカウントで）

1. Google ドライブで、新しいスプレッドシートを作ります（名前の例：「ロボット けんきゅうじょ 記録」）。
   - ほかのアプリとは別のスプレッドシートにします。前の版で作ったスプレッドシートを、そのまま使ってもかまいません。
2. メニュー「拡張機能」→「Apps Script」を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、`zukei/gas/Code.gs` の中身を貼り付けます。
   - 前の版の `index.html` が残っているときは、左の一覧で `index.html` の右の「︙」→「削除」を押して消します。
4. 左の「ファイル」の「＋」→「HTML」を押し、名前を `start` にします。中身をすべて消し、`zukei/gas/start.html` の中身を貼り付けます。
5. 💾（保存）を押します。
6. 右上の「デプロイ」→「新しいデプロイ」を押します。
   - 左の歯車から種類「ウェブアプリ」を選びます。
   - 「次のユーザーとして実行」：**自分**
   - 「アクセスできるユーザー」：**全員**
7. 「デプロイ」を押します。承認を求められたら、自分のアカウントを選んで「許可」を押します。
   - 「このアプリは Google で確認されていません」と出たときは、「詳細」→「（プロジェクト名）に移動」を押します。
8. 表示された「ウェブアプリ」のURL（`https://script.google.com/macros/s/…/exec`）が、子どもに配る**入口ページ**です。
9. スプレッドシートを開き直すと、メニューに「ロボット けんきゅうじょ」が出ます。「子どもに配るURLと合言葉を表示」で、URLと合言葉をいつでも確かめられます。

**大切なこと**
- 子どもは、入口ページの「▶ はじめる」から開いてください。記録の送り先と合言葉が、アプリに自動で設定されます。
- アプリは新しいタブで開きます。開かないときは、ボタンの下に出る「このページで ひらく」を押してください。
- 一度設定されれば、次からは GitHub Pages のURLを直接開いても、記録は届きます。
- 「アクセスできるユーザー」を「全員」にできないとき（学校の管理設定で禁止されているとき）は、記録を受け取れません。ICT担当の方に相談してください。
- `Code.gs` や `start.html` を書き換えたときは、「デプロイ」→「デプロイを管理」→ 鉛筆のアイコン →「バージョン：新バージョン」→「デプロイ」で更新します（URLは変わりません）。

### 3. Chromebook の準備（1台ずつ、最初に1回）

1. 入口ページの「▶ はじめる」でアプリを開きます。
2. 「はじめての設定」画面で、先生が次のことを行います。
   - その Chromebook を使う子どもの名前（ひらがな）を入れる
   - 先生用画面の暗証番号（4けた）を決める
3. 先生用画面の「データ」タブで、「送り先」が「✅ 設定ずみ」になっているか確かめます。「今すぐ送る」を押すと、スプレッドシートの「いちらん」にその子の行ができます。
4. 音が出るか確かめます。はかせの声は、「▶ はじめる」を押したあとから出ます。

- 名前・進み具合・もらったアイテム・記録は、その Chromebook のブラウザの中に保存されます。
- Chromebook を取りかえるときは、先生用画面の「データ」→「バックアップを保存」でファイルを作り、新しい端末で「読み込む」を押します。

### 4. Googleサイトに置くとき（必要なときだけ）

Googleサイトでは、入口ページを「埋め込む」で貼らずに、**「ボタン」**を使ってください。
埋め込むと、入口ページがGoogleサイトの枠の中に入り、「▶ はじめる」を押しても開かないことがあります。

1. Googleサイトの編集画面で、右側の「挿入」→「ボタン」を押します。
2. 「名前」に「ロボット けんきゅうじょ」、「リンク」に入口ページのURL（`…/exec`）を入れて、「挿入」を押します。
3. 右上の「公開」を押します。

## 先生用画面

画面の右下（または右上）の **🔒 せんせい** を押し、暗証番号を入れると開きます。

| タブ | できること |
|---|---|
| 📊 記録 | ステージごとの回数（例「4/10回」）、ステップごとの正答率、つまずいている形・問題、まちがい方（例「えらんだ：かどが丸い形（三角）」「見のがし：さかさまの三角形」）。名前を押すと「全部のステージを開く」ボタンが出ます |
| ⚙️ 設定 | 読み上げの速さ（最初は0.85）、声の高さ、文字の大きさ、効果音の大きさ、発展の問題を開く。子どもの名前と暗証番号の変更 |
| 💾 データ | スプレッドシートへの送信（送り先の確認・今すぐ送る・全部の記録を送りなおす・送り先を手で入れる）、CSV書き出し、バックアップ（保存・読み込み）、記録の消去 |

- 「1回目正答率」は、1回目で正解した割合です。まちがえたあとにやり直して正解したものは含みません。
- 「（気づき）」が付いた記録は、ぺちゃんこ・線が交わったなど、まちがいにしていない場面です。

## 全員の記録を見る

先生のスプレッドシートで見られます。

| シート | 内容 |
|---|---|
| いちらん | 1人1行。レベル、クリアしたステージ、いま学習中、回答数、1回目正答率、最終学習日、アイテムの数、ステージごとの回数（◎＝1セットクリア、「4/10」＝4回まで） |
| きろく | 1問ごとの記録（日時・なまえ・ステージ・ステップ・もんだい・かたち・けっか・かいすう・ヒント・まちがい・記録ID）。けっかは、1回目で正解が「○」、やり直して正解が「△」です |
| まとめ | 子どもごと・形（問題）ごとの1回目正答率を、低い順に並べます。おもなまちがいも書きます |

- 「いちらん」と「まとめ」は、記録が届くたびに作り直されます。メニュー「ロボット けんきゅうじょ → 一覧とまとめを更新」でも作り直せます。
- 同じ記録が2回届いても、2回は書きません（記録IDで見分けます）。

## 注意事項

- 記録は、その Chromebook の中と、先生のスプレッドシートにだけ保存されます。ほかのサービスには送りません。
- 送れなかった記録は端末にためておき、次に記録するとき・アプリを開いたとき・ネットにつながったときに送り直します。
- 「きろく」シートの見出しは、変えないでください。
- ロボット、トンガリはかせ、研究所の背景は、Canva の AI で、このアプリのために作ったオリジナルの絵です（ほかの人の絵を読みこませてはいません）。アイテムの絵はプログラムで描いたオリジナルです。絵文字も使っています。
- タングラムは、昔からある7まいの切り分け方を、このアプリで1から描き直したものです。
- 効果音とファンファーレは、アプリの中で音を作って鳴らしています（ほかの音源は使っていません）。

- 長方形・正方形・直角三角形（2年生の内容）へつなげるステージを作るか
