# ロボタンと カタカナ（導入手順）

特別支援学級（1・2年）向けの、カタカナの読み書き学習アプリです。
ロボット先生「ロボタン」が音声で問題を出し、スモールステップでカタカナの読みと書きを練習します。

- `index.html` … アプリ本体
- `コード.gs` … スプレッドシートとつなぐプログラム

---

## 1. スプレッドシートを用意する

1. Google ドライブで **新しいスプレッドシート** を作ります（名前の例：「ロボタンと カタカナ 記録」）。
2. メニュー **拡張機能 → Apps Script** を開きます。
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`コード.gs` の中身を貼り付け** ます。
4. 左の「ファイル」の **＋ → HTML** を押し、名前を **`index`** にします（`.html` は自動で付きます）。
5. できた `index.html` の中身をすべて消し、このフォルダの **`index.html` の中身を貼り付け** ます。
6. 💾（保存）を押します。
7. 上の関数の選択欄で **`setup`** を選び、**▶ 実行** を押します。
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可します。
   - スプレッドシートに「名簿」「きろく」「まとめ」「せってい」の4つのシートができます。

## 2. 名簿を入れる

「名簿」シートの **A列（2行目から）** に、児童の名前を **ひらがな** で入れます。

| なまえ（ひらがな） | しんちょく（自動で記録します。さわらないでください） |
|---|---|
| たろう | |
| はなこ | |

※ B列は、アプリが進み具合を自動で書き込む欄です。手で書きかえないでください。

## 3. 暗証番号・音声を設定する（「せってい」シート）

| こうもく | あたい | せつめい |
|---|---|---|
| 暗証番号 | 1234 | 先生用画面に入るための4けたの数字 |
| よみあげの はやさ | 0.8 | 1がふつう。小さいほどゆっくり |
| こえの たかさ | 1.3 | 1がふつう。大きいほど高い声 |

**暗証番号は必ず変更してください。** 1234のままだと、先生用画面に注意が表示されます。

## 4. ウェブアプリとして公開する

1. Apps Script の右上 **デプロイ → 新しいデプロイ** を押します。
2. 種類の選択（⚙）で **ウェブアプリ** を選びます。
3. 次のように設定します。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（学校のドメイン）内の全員**
4. **デプロイ** を押し、表示された **ウェブアプリのURL** をコピーします。
5. 児童の Chromebook で、このURLをブックマークやショートカットにしておきます。

> 「次のユーザーとして実行：自分」にすると、児童のアカウントからでも先生のスプレッドシートに記録が書き込まれます。児童にスプレッドシートを共有する必要はありません。

### プログラムを更新したとき

**デプロイ → デプロイを管理 → ✏（編集）→ バージョン：新バージョン → デプロイ** を押すと、同じURLのまま新しい内容になります。

## 5. 使い方

### 児童
1. 自分の名前のボタンを押します。
2. 「ロボタンの へや」でコースを選びます。コース1から順番に開きます。
3. 行（アぎょう など）を選び、光っているボタンの学習をします。
4. 最後の「たしかめ」で5問中4問を1回目で正解すると合格です。スタンプがもらえ、次の行が開きます。

### 学習の流れ

| コース | 内容 | 1つの行の学習の順番 |
|---|---|---|
| 1 | 清音46文字（行ごと）＋にている文字 | みる・きく → きいて えらぶ → ひらがなと なかよし → なぞる → かく → たしかめ |
| 2 | 濁音・半濁音 | みる・きく → きいて えらぶ → てんてん・まる → なぞる → かく → たしかめ |
| 3 | 長音「ー」 | みる・きく（手拍子）→ きいて えらぶ → ことばを つくる → なぞる → たしかめ |
| 4 | 促音「ッ」 | 〃 |
| 5 | 拗音「ャュョ」 | 〃 |
| 6 | ことば | みる・きく → よんで えらぶ → きいて えらぶ → ことばを つくる → なぞる → たしかめ |

### 児童への手立て
- 問題文はすべて音声で読み上げます（少しゆっくりめ）。🔊ボタンで何度でも聞けます。
- 選択肢は最初は **2択** です。1回目で続けて正解すると **3択** に増え、まちがえると2択に戻ります。
- まちがえても×は出しません。選んだ答えが消えて、正解が見つかるまで続けられます（誤りなし学習）。
- なぞり書きでは、書き始めの位置に **緑の丸と番号・向きの矢印** が出ます。まちがえるとオレンジの線で正しい書き方を見せます。
- 「かく」では手本が出ません。1回まちがえると緑の丸が、2回まちがえると薄い線が出ます。
- 促音「ッ」は手を ✊（グー）、長音「ー」は 〰️ で、拍の数を目で見て確かめられます。

### 先生
- 画面右下（または右上）の **🔒 せんせい** を押し、暗証番号を入れると先生用画面が開きます。
- **クラス全体**：児童ごとの進み具合・1回目正答率・最終学習日・つまずいている文字、クラスでつまずきの多い文字。
- **児童ごと**：
  - 50音表・濁音表・特殊音の表が、1回目正答率で色分けされます（赤60%未満／黄60〜79%／緑80%以上）。文字を押すと「よむ・ことば・なぞる・かく」ごとの結果が見られます。
  - **つまずいている文字** を正答率の低い順に並べ、どの学習が苦手か（にがて）を表示します。
  - **つまずいている ことば** も表示します。
  - **全コースを開放する** ボタンで、その児童だけすべてのコースを選べるようにできます（途中のコースから始めたいとき）。
- スプレッドシートの「きろく」シートにすべての解答が、「まとめ」シートに児童ごと・文字ごとの正答率が入ります。「まとめ」は先生用画面を開いたとき、またはメニュー **ロボタン → まとめを更新する** で更新されます。

## 6. こまったとき

| こまったこと | 確かめること |
|---|---|
| 声が出ない | Chromebook の音量、ミュートになっていないか。はじめに名前のボタンを押すと音声が使えるようになります。 |
| 名前が出てこない | 「名簿」シートのA列（2行目から）に名前が入っているか。入れた後、アプリを開き直してください。 |
| 「おためしモード」と出る | スプレッドシートにつながっていません。手順4で公開したURLから開いてください。 |
| 記録が入らない | 通信が切れたときは、次に記録するときにまとめて送り直します。 |
